# X-7 퀘스트 아이템 디자인 레퍼런스

2026-09-29 요청에 따라 내장 `image_gen` 도구로 생성한 신규 디자인 제안 5종. 각 PNG는 1536×1024이며 원본을 수정 없이 복사하고 SHA-256 일치를 확인했다. Unreal 에셋으로 임포트하지 않았다.

| 아이템 | 실루엣 / 색상 | 이미지 |
|---|---|---|
| A급 샘플 | 낮고 넓은 육각 밀폐 코어, 양옆 손잡이, 금색 잠금장치와 호박색 창 | [A급](sample-a.png) |
| B급 샘플 | 길쭉한 사각 보호 프레임, 이중 표본 튜브, 윗손잡이, 청록색 | [B급](sample-b.png) |
| C급 샘플 | 단순한 둥근 채집병, 녹색 뚜껑, 해수·퇴적물 표본 | [C급](sample-c.png) |
| 변성 블룸 | 비대칭 꽃·산호 형태의 변성 조직, 보라색 발광 중심, 낮은 운반 받침 | [변성 블룸](mutated-bloom.png) |
| 캐비닛 카드 | 얇은 방수 카드, 청록 패널, 주황 띠, 격리실 B 표시 | [캐비닛 카드](cabinet-card.png) |

육각형 / 세로 사각형 / 원통형으로 A·B·C를 분리하여 색상 없이도 구분하도록 설계했다. 공통 소재는 밝은 아이보리 외장과 어두운 고무·금속, 사용감 있는 해저 연구장비다.

시각 확인: 5종과 각 보조 뷰가 모두 표시되고 주요 형태가 잘리지 않았으며 등급·카드 글자가 읽힌다. 디자인 방향용 컨셉 아트이며, 뷰 사이 세부 배치와 치수는 정확한 제작 도면으로 간주하지 않는다. 생성 후 보정이나 재생성은 하지 않았다.

정확한 생성 프롬프트는 [prompts.json](prompts.json), 원본 경로·크기·해시는 [manifest.json](manifest.json)에 기록했다. 생성 모델의 별도 식별자는 도구 응답에 제공되지 않았으므로 에이전트 모델명을 이미지 모델명으로 표기하지 않았다.
