시스템 개요

지문패드 · 동시 행동

서로 다른 두 플레이어가 떨어진 지점에서 타이밍을 맞춘다. 솔로는 두 지점을 제한 시간 안에 순서대로 인식한다.

차단기 · 정보와 조작 분담

설명자는 지침실에서 노브 위치를 전달하고, 스캐너 담당은 어둠 속 차단기로 이동해 배치를 맞춘다.

목적은 고장 복구를 역할 분담과 대화가 필요한 작업으로 만드는 것이다. 두 수리 방식은 독립적인 종류이며 한 고장마다 반드시 두 방식을 연속 수행하는 규칙은 정하지 않았다.

적용 대상은 미정. 어떤 문·분리수거기·설비가 지문패드 또는 차단기 수리로 연결되는지 별도 지정해야 한다. 차단기 수리의 정전은 현재 사용자 지정에 따라 기지 일반 조명 전체에 적용한다.

배치 구역과 층 구분

사용자 지정 배치 방향 지침실·차단기는 1F 09 전력실에, 지문패드는 통제실 입구와 다른 층의 유지 보수실 입구에 배치한다. 정확한 좌표·회전·치수는 실제 맵에서 조정한다.

기획상 B1 = 실제 맵의 위층인 2층. 문서의 B1·B1-07 등 방 식별자는 유지하고, 배치 설명에 실제 2층임을 함께 표시한다. 새 층을 추가하거나 B1 구역을 지하로 다시 옮기는 지시가 아니다.

패드 이동과 접근

대표 솔로 경로는 A 인식 → 1층 중앙 해치 → 층간 이동 → 실제 2층 해치 출구 → B1-07 입구 바깥 B 인식이다. 반대 패드에서 시작하는 경로도 함께 측정해 이동·상호작용과 여유 시간을 포함한 제한 시간을 정한다.

  • 다인은 층별로 한 명씩 맡아 두 패드에서 동시에 유효 인식.
  • 두 패드는 지침실 내부에 넣지 않고, 패드 간 경로를 고장 문·일방 통행으로 막지 않음.
  • 지문패드와 차단기는 독립적인 수리 종류. 어느 시설에 연결할지는 별도 결정.
  • 지침실은 다인 지침 상호작용으로 잠금. 재시작하면 시간 제한 없이 열리고 다음 새 지침 사용에 잠금. 솔로 잠금 생략 유지.

부스 약 3×4m, 창문과 차단기 사이 약 3–5m는 검토 후보이며 확정 치수가 아니다. 시야·유리 그림 가독성·통행 폭·문턱 충돌·스캐너 조작을 실제 맵에서 확인한다.

지문패드 수리

공간 구성

같은 수리 이벤트에 패드 A와 B를 연결한다. 다인은 각각의 지점에서 상호작용하고, 솔로는 두 지점을 이동할 수 있어야 한다. 솔로 경로를 잠긴 문·일방 통행·접근 불가 구간으로 막지 않는 배치가 필요하다.

첫 인식상호작용을 누르고 있는 동안 인식 상태를 유지. 상대 인식 대기.첫 인식 성공 시 제한 시간 시작.

복구연결된 고장을 복구하고 패드를 완료 상태로 변경.

판정의 경계

  • 다인에서는 같은 플레이어가 두 패드에 연속 입력한 것으로 동시 인식을 대체하지 않는다.
  • 솔로는 첫 패드 반복 인식만으로 성공하지 않는다. 반대 패드의 인식이 필요하다.
  • 다인에서는 상호작용을 계속 누르고 있는 동안 인식을 유지한다. 먼저 누른 사람이 기다렸다가 다른 사람이 누르면 두 인식이 겹치는 시점에 성공한다. 손을 떼면 해당 인식을 해제한다.
  • 솔로 시간 초과 시 첫 인식을 해제하고 다시 시작하는 안을 후보로 둔다. 이동 중 제한 시간을 반복 갱신하는 동작은 별도 결정한다.

제한 시간은 A가 있는 실제 1층과 B가 있는 실제 2층(기획 B1) 사이의 수직 이동·상호작용 시간과 여유 시간을 측정해 정한다. 임의의 초 단위 값을 확정하지 않는다.

솔로지침실과 차단기를 직접 오감.지침과 상호작용해도 잠기지 않음. 지침 확인 후 스캐너 라이트로 이동·조작.
나머지 팀원3–4인 플레이의 다른 작업 지점.다른 수리·청소를 계속하거나 전달·도구 운반을 도움. 추가 필수 역할은 정하지 않음.
  1. 이벤트 시작

    차단기 수리용 지침 배치를 만들고 기지 일반 조명을 끈다. 정전이 고장 발생 즉시 시작되는지, 수리 시작 시점인지 미정.

  2. 입실 후 지침 상호작용

    입실만으로는 문을 잠그지 않는다. 다인에서 설명자가 수리 지침에 한 번 상호작용하면 문이 닫혀 잠긴다. 스캐너 담당자나 전원이 안에 남아 잠겼다면 지침의 재시작으로 문을 열어 역할을 다시 배치한다. 솔로는 지침을 사용해도 잠기지 않는다.

  3. 지침 전달

    설명자는 “왼쪽부터 위에서 3칸, 2칸, 4칸, 5칸”처럼 열 순서와 칸 번호를 전달한다. 마이크가 없으면 창문에 그림으로 남긴다.

  4. 스캐너로 이동·노브 조작

    수리자는 라이트로 길과 차단기를 비춘다. 각 열의 노브를 지침에 해당하는 칸으로 이동한다.

  5. 일치 판정

    조작 순서와 무관하게 모든 열의 노브가 해당 이벤트의 목표 위치와 일치하면 성공한다. 자동 판정 또는 별도 확인 입력, 오답 피드백은 미정.

  6. 완료

    차단기와 기지 조명, 다인 지침실 문을 복구한다. 다른 고장 상태는 별도로 유지한다.

노브와 기준 방향

첨부 스케치의 세로 레일 구조를 따른다. 설명과 조작의 기준을 통일하기 위해 열 번호를 고정하고 칸은 위에서부터 세는 안을 제안한다. 아래 미리보기의 4열·5칸은 설명용 예시이며 실제 개수는 미정이다.

지침 배치는 재시작 전까지 유지한다. 재시작하면 각 열의 목표 위치를 새로 추첨하되 이전과 같은 정답 배열은 사용하지 않는다. 새 지침과 차단기의 정답을 함께 갱신한다.

지침실 재시작과 문 개방

사용자 지정 예외 스캐너 담당자나 4명 전원이 안에 있는 상태에서 누군가 지침을 사용해 문이 잠겼다면, 수리 지침의 재시작 버튼으로 문을 열어 역할을 다시 배치한다. 개방 시간 제한이나 재잠금 대기 시간은 없다.

  1. 재시작 선택

    수리 지침의 재시작을 누르면 이전과 다른 정답을 생성하고 문 잠금을 해제해 문을 연다. 재시작 버튼 입력 자체는 지침 잠금 입력으로 처리하지 않는다.

  2. 열린 상태 유지

    스캐너 담당자와 외부 수리자가 퇴실하고 설명자는 남거나 재입실할 수 있다. 입실·퇴실·잔류 인원·시간 경과만으로 문을 닫지 않는다.

  3. 새 지침 상호작용으로 잠금

    다인에서 수리 지침에 다시 한 번 상호작용하면 문이 닫혀 잠긴다. 재시작 직후에도 새 상호작용이 가능하며 시간을 기다리는 조건은 없다. 솔로는 지침 사용으로 잠기지 않는다.

상황문과 진행 기준
스캐너 담당자가 안에 있음재시작으로 문을 열어 퇴실. 설명자가 다음 지침 상호작용을 하면 다시 잠김.
4명 전원 입실입실만으로 잠기지 않음. 지침 사용으로 전원이 갇혔다면 재시작 후 외부 수리자가 퇴실하고, 설명자가 지침을 다시 사용해 잠금을 시작.
전원 퇴실·재입실문 열림 유지. 입실·점유로 자동 잠기지 않으며 지침 사용 대기.
여러 명 잔류잔류 인원과 무관하게 문 열림 유지. 지침을 새로 사용하면 잠기며 필요하면 재시작을 다시 사용.
솔로입실·지침 사용·재시작 모두에서 잠금 생략 유지.
개방 중 수리 완료완료가 우선. 이후 지침 사용이나 오래된 입력으로 복구된 문을 다시 잠그지 않음.

재시작은 고장 복구가 아니므로 정전·지침실 보조조명과 적용 중인 고장 차감을 유지한다. 대출 유예·고장 발생 시각·차감 누적·다른 고장 진행을 초기화하지 않는다.

확정: 재시작 시 정답을 변경하고 문을 연다. 새 정답은 지침과 차단기 판정에 동일하게 적용한다. 다음 지침 상호작용 전까지 문은 열린 상태다.

기지 일반 조명꺼짐.차단기 복구 시 해당 정전 해제. 여러 정전이 겹치면 복구 범위를 별도 관리.
지침실 보조조명지침 위에서 아래로 약한 조명. 읽기와 그림 전달 가능.이벤트 종료 후 상태는 미정.
스캐너 라이트소지자가 켜서 이동·차단기 작업.켜짐 유지 또는 자동 종료 여부 미정.
  • 지침실 보조조명은 지침 전체의 노브·칸을 읽을 수 있어야 한다. 분위기 때문에 일부 칸을 판독 불가능하게 만들지 않는다.
  • 스캐너를 손에 든 채 조명과 노브 조작이 함께 가능해야 한다. 조작 진입 시 장비를 숨기는 기존 동작이 있다면 라이트가 유지되는지 확인한다.
  • 이동 거리·문·차단기의 칸 번호·창문 그림이 실제 카메라에서 읽히는지 검증한다.
  • 스캐너 고장 위치 탐지·지도 표시는 이전 회의의 추가 제안이다. 이번 사용자 지정에서 확정된 기능은 라이트를 이용한 차단기 수리다.

밝기·색·범위·조작키·충전 소모는 미정. 배터리 부족이나 스캐너 분실로 수리가 불가능해질 때의 복구 방법도 필요하다.

음성·유리 그림 전달

설명자는 창문을 통해 지침을 전달한다. 음성을 사용할 수 없으면 유리창에 노브 위치를 그린다. 수리자는 그림을 확인하고 차단기로 이동할 수 있다.

항목설계 기준·후보
표현세로 열과 노브 위치를 그릴 수 있어야 함. 열 번호와 위에서 세는 칸 기준을 함께 표시하는 후보.
반대편 가독성유리 양쪽의 좌우 반전으로 번호가 바뀌지 않게 설계. 어느 쪽 시점을 기준으로 그리는지 안내.
유지·삭제수리자가 이동한 뒤 다시 확인 가능하도록 이벤트 중 유지하는 후보. 지우기·이벤트 종료 시 초기화 규칙 미정.
다인 공유설명자의 선과 지우기 결과가 창문 밖 플레이어에게 보이도록 동기화 필요.
정보 분리지침을 차단기 UI에 직접 띄우지 않는 후보. 창문 밖에서 지침 원본을 그대로 읽을 수 있는 배치인지도 확인.

그림은 전달 수단이며 노브를 자동으로 맞추거나 정답 입력으로 판정하지 않는다. 솔로의 별도 메모 기능은 아직 정하지 않았다.

조작·UI

UI·조작 후보 실제 키는 기존 상호작용 입력과 연결하고, 컨트롤러 입력도 함께 정한다. 새로운 고정 키나 충전 소모를 임의로 추가하지 않는다.

기존 상시 시간 HUD 제거 방향과 별개로, 솔로 패드의 제한 시간은 해당 수리 중에만 표시하는 후보다. 전화 독촉 UI와 협동 수리 안내가 서로 가리지 않게 배치한다.

상태와 성공 판정

구현용 상태 설계 후보 이름은 설명을 위한 것이며 실제 코드·에셋의 이름이 아니다.

종류상태주요 전이
공통정상 → 고장·수리 대기 → 수리 중 → 복구 완료원인 이벤트와 연결된 수리 성공을 함께 관리. 중복 완료 금지.
다인 패드대기 → 한쪽 인식 → 동시 인식 성공서로 다른 플레이어·같은 수리 사건·서로 다른 패드 조건 확인.
솔로 패드대기 → 첫 인식·시간 진행 → 두 번째 인식 성공 / 시간 초과반대 패드인지, 동일 플레이어인지, 제한 시간을 넘었는지 판정.
차단기정전·지침 생성 → 전달·노브 조작 → 배치 일치 → 복구현재 수리 사건의 지침과 노브 배열을 비교. 지침실 잠금은 별도 상태로 연결.

같은 시설의 오래된 인식·노브 입력이 새 고장을 즉시 해결하지 않도록 수리 사건 식별자를 둔다. 성공 후 늦게 도착한 입력이 재정전·재잠금·중복 비용 처리를 일으키지 않도록 한다.

고장·경제 연결

기존 기획에서는 시설이 고장 난 동안 돈이 차감되고, 대출 완납 후에도 이 차감이 적용된다. 협동 수리의 이동·대기·설명 시간이 금전 부담과 겹치므로 실제 수리 시간을 기준으로 조정한다.

  • 연결된 시설을 수리하면 그 고장의 차감을 종료한다. 다른 시설의 고장이나 별도 대출 의무는 함께 지우지 않는다.
  • 정전만으로 정상 분리수거기의 정산을 전부 막는 규칙은 정하지 않았다. 정상 기계의 쓰레기 투입 즉시 정산은 유지한다.
  • 분리수거기에 협동 수리를 연결할 경우 고장 중 투입·정산 중단, 수리 전까지의 비용 차감, 복구 후 즉시 정산 재개를 함께 확인한다.
  • 지침실 문 잠금을 별도 돈 차감으로 계산할지, 수리 실패 시 추가 비용을 부과할지 미정이다. 하나의 차단기 사건에 문·정전 비용을 중복 부과하지 않는 안을 검토한다.
  • 정전과 처리장 펌프 피해가 겹칠 때 위험한 이동·피해·돈 차감이 과도하게 누적되는지 측정한다. 동시 발생 수와 완충 조건은 미정이다.

구현·데이터 요구

개발 연결 후보 기존 프로젝트의 클래스·네트워크 구조를 확인한 뒤 적용한다. 이 문서에서는 에셋 생성이나 코드 구현을 수행하지 않았다.

  • 상호작용 거리·접근 권한·현재 사건·조작자를 확인한다. 지침의 유효 상호작용·재시작 문 개방은 권위 측에서 판정·공유한다. 재시작 버튼은 지침 잠금 입력과 구분해 개방 즉시 다시 잠기는 오류를 막는다. 재시작과 별개의 새 지침 입력으로 다시 잠그며, 완료된 사건의 늦은 입력은 무시한다. 다인 패드의 같은 사람 중복 판정과 완료 이벤트 중복을 방지한다.
  • 지침과 현재 노브 상태를 분리한다. 수리자에게 정답 UI가 자동 노출되지 않도록 정보 접근과 표시를 설계한다.
  • 그림은 화면 좌표 대신 공통 유리 면 좌표로 공유하는 안을 검토한다. 선 샘플 수·전송량을 제한하면서 글씨와 칸 표시가 읽히는지 확인한다.
