플레이 흐름과 역할

  1. 착수금으로 도구 구매·역할 배분

    기본 4종의 담당을 정한다. 실제로 구매한 장비를 지급하며 시작 전에 자동 구매가 끝난 것으로 처리하지 않는다.

  2. 탐색·절단·오염 제거·운반

    스캐너로 대상을 찾고 절단기·원샷헤라로 작업한다. 모든 담당이 쓰레기 집기·분리수거·Q 전달에 참여할 수 있다.

  3. 폐기물처리장에서 즉시 정산

    정상 분리수거기에 쓰레기를 넣어 돈을 받는다. 기계 고장이나 처리장 피해가 생기면 수리·위험 감수·물량 집적을 판단한다.

  4. 수익을 구매·보급·상환에 배분

    새 장비를 살지, 테이프·폼건 보급을 확보할지, 상환할지 선택한다. 시설 고장 중에는 수리 전까지 돈이 차감되므로 복구 우선순위도 판단한다. 최종 청소 평가는 돈과 별도로 판단하는 방향이다.

Q키 충전 던지기

지정 방향 손이나 인벤토리의 쓰레기·장비를 Q키로 던지고 다시 획득한다. 오래 누를수록 비거리가 증가한다.

  1. 대상 선택

    10월 2일 회의 방향은 손에 든 쓰레기 우선, 쓰레기가 없으면 손에 든 도구, 둘 다 없으면 동작 없음. 인벤토리 선택 슬롯을 직접 던질지는 별도 미정.

  2. 누르는 동안 충전

    조준점 근처 충전 표시를 제안한다. 최대 충전 뒤 강도는 더 증가하지 않는 안이다.

  3. 놓으면 던지기

    성공 시점에 물체 1개를 꺼낸다. 실패·취소 시 소유 상태를 유지하는 후보.

  4. 착지 후 재획득·인계

    물체 종류·수량·장비 상태를 보존하고 동료가 주울 수 있게 한다. 재획득 자체에 돈을 지급하지 않는다.

문·설비 수리

지정 방향 일반 고장 문과 분리수거기는 절연테이프로 고친다. 일반 고장 문은 테이프·도구가 없어도 시간이 오래 걸리는 수동 수리가 가능해 영구 갇힘을 방지한다. 아래 차단기 지침실의 협동 수리 잠금은 별도 규칙이다.

고장 난 문은 실제 통로를 막고, 고장 난 분리수거기는 실제 정산을 막는다. 수익이 끊길 수 있다는 압박은 유지한다. 수리 중 이자 시간을 계속 진행하는 것은 경제 테스트 후보다.

  • 접근 가능한 내부 배선반에서 일반 문을 수리하면 현재 문 고장 사건을 해제한다. 내부 플레이어 사망으로 배선반에 접근할 수 없는 경우의 외부 재진입은 고가·영구 사용 빠루의 강제 개방으로 해결한다. 차단기 지침실은 다인 지침 상호작용으로 잠기며 재시작으로 문을 연다. 입실·시간 만료에 따른 자동 잠금은 없고, 솔로는 지침 상호작용 잠금을 생략한다.
  • 일반 문 현재 E 수리는 중단 시 진행도를 보존하고 다른 플레이어가 이어서 수리할 수 있다. 한 문 사건은 한 명만 수리한다. 절연테이프 1개로 남은 진행도와 관계없이 즉시 복구한다. 지침실의 수동·테이프 우회 허용과 동료 이탈 시 탈출 처리는 별도로 결정한다.

대출과 시간 차감

왜 다시 논의했나

기존 대출이 Day 시스템과 연계돼 있어, Day 흐름을 바꿀 경우 대출도 막거나 삭제할지, 실제 시간 단위로 전환할지 검토가 필요했다. ‘1시간을 하루로 간주’하는 아이디어도 나왔지만, 시간을 다시 도입해야 한다는 부담이 바로 제기됐다.

후반부 중심 후보안

여러 발언을 연결해 정리한 흐름이다. 확정 명세가 아니며, 시간의 기준과 상환의 효과는 추가 결정이 필요하다.

  1. 대출 실행

    돈을 받아 장비 구매 등에 사용한다. 선택 대출인지 초기금까지 포함하는 강제 대출인지 미정.

  2. 30분 유예

    대출을 받은 순간부터 30분의 유예를 두자는 제안. 이 기간 내 상환을 유도하는 발언도 있었으나 상환 규칙은 구체화되지 않았다.

  3. 유예 이후 주기 차감

    초기 1분 제안은 압박이 크다는 의견을 받았고, 김동연이 제안한 3분에 이길호도 동의했다. 차감액은 증가시키지 않고 일정하게 유지하자는 의견이 나왔다.

  4. 잔액이 음수가 되면 게임오버

    차지훈·박준민이 제안한 실패 조건. 0원은 음수와 다르며, 팀 전체 종료인지 개인 실패인지는 정하지 않았다.

이자·징수액은 결정되지 않음

  • 이길호: 이자가 늘어나지 않고 동일하게 차감되는 방식을 선호했다. 반대로 너무 적게 차감하면 초반 대출로 좋은 장비를 모두 확보할 수 있다는 우려도 제기했다.
  • 박준민: ‘3분마다 빌린 돈의 1/10’을 고리대금이라는 표현과 함께 제안했다. 10%를 채택했다는 합의는 없다.
  • 차지훈: 대출 시 갚아야 할 금액을 고정하고, 그 금액의 일정 비율을 지속 징수하는 방식을 제안했다.

‘이자’와 ‘원금 상환’은 구분이 필요하다. 원문만으로는 주기 차감액이 이자만인지, 원금까지 갚는 금액인지 알 수 없다. ‘빌린 돈의 10%’와 ‘고정된 상환 총액의 일정 비율’도 같은 계산식으로 확정하면 안 된다.

초기금과 장비 구매

초기금의 성격은 열린 상태

차지훈이 초기 착수금도 대출로 볼 것인지 질문했다. 박준민은 처음에는 과하다고 보고 교통비 같은 느낌이라고 설명했지만, 이후에는 초기금도 대출로 처리해도 괜찮을 것 같다고 입장을 재검토했다. 뒤이어 강제로 돈을 주고 30분 안에 갚게 한다는 흐름이 언급됐다.

차지훈은 스토리를 제외하면 창업 비용으로 볼 수 있다고 제안했고, 박준민은 스토리를 완전히 무시하는 컨셉은 아니라고 답했다. 초기 지원금 유지·초기 강제 대출·선택 대출 중 어떤 방식을 사용할지는 확정되지 않았다.

초기 장비를 유료화해 역할 분담 유도

  • 박준민이 기존 0원 초기 장비의 가격을 올리자고 제안했다. 목적은 알맞은 역할 분담이다.
  • 이길호가 긍정적으로 반응하고, 처음 살 수 있는 도구를 4개로 정해 하나씩만 살 수 있게 하자고 구체화했다.
  • 도구 4개의 종류·가격·구매 주체·중복 제한 범위는 정하지 않았다.

‘하나씩’의 의미를 확인해야 한다. 팀에 각 도구 1개씩만 허용하는 것인지, 플레이어마다 도구 1개를 선택하는 것인지 원문으로 확정할 수 없다. 4명 플레이가 언급됐지만 인원별 지급·구매 규칙은 미정이다.

게임의 방향성: 힐링과 수익 압박

대출의 기능적 목표는 돈을 벌어야 한다는 동기를 주고 자연스럽게 청소를 시작하게 만드는 것이었다. 다만 주기 징수와 게임오버를 붙이면 힐링 중심에서 긴박한 협동 플레이로 무게가 이동한다는 점을 함께 논의했다.

관점발언에서 확인된 의견

구현 정책: 서버가 차감 시점의 실제 참여 인원을 계산하며 관전자·비활성 인원은 제외한다. 인원이 변해 솔로/다인 인증 방식이 바뀌면 이전 인증을 초기화한다. 동일 안전모드 사건은 한 번만 차감하며 중복 발생 요청으로 타이머를 늘리지 않는다. 잔액 하한은 기존 경제 시스템의 0원 규칙을 유지한다.

테스트 명령: 호스트/서버 콘솔에서 MD.BreakFingerprint를 실행하면 배치된 지문 안전모드 사건을 즉시 발생시킨다. 이벤트 BP의 기본 자동 주기는 300~420초이며 문 고장의 180~300초 설정과 별개다. 패드 A·B와 연결된 분리수거기 목록은 맵 인스턴스에서 지정한다.

검증 범위: 오션맵 1인 플레이에서 실제 상호작용 경로로 A·B 인증과 분리수거기 5대 정지·복구를 확인했다. 격리 2인 PIE에서는 서로 다른 플레이어의 E 유지, 해제·조준 이탈·사망 처리, 금액 차감, 복구 후 쓰레기 정산을 검증했다. 3·4인 차감 수치는 자동화로 확인했으며 실제 3·4인 오션 플레이와 솔로 층간 이동 시간 실측은 후속 검증이다. 오션 1인 테스트는 패드 사이를 이동시켜 인증했으므로 45초를 실측 완료값으로 취급하지 않는다.
