# 빠루 구현 및 검증

2026-10-14 · dev-v2 · 병합 후 솔로/2인 및 Ocean 검증 완료

- 가격: 우선 500원. 아이템 `Item:IT-CB0`, `/Game/Equipment/Tools/DA_Tool_Crowbar`.
- 사용: 빠루 장착 → 고장 문 조준 → **E키**. 즉시 문을 열고 해당 문 고장을 완전히 수리한다. 화면 안내도 `[E] 강제 개방·수리`로 표시한다.
- 좌클릭 도구 사용 경로에서는 빠루를 실행하지 않는다. 기존 E 상호작용 액션을 사용하며 다른 시설·아이템의 입력은 유지한다.
- 영구 사용: 수량·충전·내구도를 차감하지 않는다. 문 안팎 양쪽에서 반복 사용할 수 있다.
- 서버 검증: 현재 도구·조준·실제 거리·사망/운반/상호작용 가능 상태·고장 사건 번호. 정상 문·퍼즐 잠금·다른 시설은 대상이 아니다.
- 복구 시 기존 복구 경로로 배선반 스파크·문 경고음·수동 수리 점유를 정리한다. 별도 차단기 정전이나 다른 시설 고장은 복구하지 않는다.

## 모델과 장착 자세

- 모델: [BbarruEdit_FlatTips.fbx](https://drive.google.com/file/d/1fk-phBNg7DIKatA_odzjTvoasCV9TXqS/view).
- 텍스처: [Bbarru_FlatTips.png](https://drive.google.com/file/d/1pxPH1qKIqyoWJhA9JdX5UyDJwtbCPpn7/view).
- 메시·재질·텍스처·아이콘은 `/Game/Equipment/Crowbar`에 있다. 메시 길이는 약 100cm이며 손잡이 로컬 Z=40cm를 ToolSocket에 맞췄다.
- **1인칭 팔은 3인칭 애니메이션을 Leader Pose로 복제하고 3인칭 메시의 좌표계도 복제한다. 1인칭 빠루는 3인칭 빠루의 위치·회전·크기를 그대로 복제한다.**
- 이전 180/135도 회전, 카메라 기준 팔 이동, 빠루만 위로 세우던 보정 및 해당 조정 변수는 제거했다. 화면 중앙이나 위쪽으로 팔을 끌어올리는 별도 배치는 하지 않는다.
- 도구 전환 시 기존 팔 좌표계를 복원한다. 외부 카메라와 씬 캡처에서는 1인칭 팔·도구 중복 표시를 막는다.

## 최종 검증

- 원본 Development Editor 빌드 성공.
- `MarineDemolition.Crowbar.SoloPIE` / `TwoPlayerPIE` 성공. 실제 Enhanced Input 상호작용 액션을 주입해 일반 문 양쪽과 검은 문의 개방·복구 및 클라이언트 RPC를 검사했다. 좌클릭 경로 차단, 잔액 부족·중복 구매 거부, 영구 재사용, 잘못된 도구·입력 차단·거리 이탈·퍼즐 잠금 거부도 확인했다.
- 실제 Ocean PIE에서 500원 구매, `[E]` 안내, 일반 문 양쪽 E 상호작용·재사용을 확인했다.
- 실제 팔의 92개 공통 뼈 월드 위치와 회전을 비교했다. 위치 오차 0cm, 회전 일치. 솔로/2인에서는 팔 좌표계와 빠루 전체 변환도 3인칭과 일치함을 검사했다.
- 최종 증거: `Saved/Diagnostics/CrowbarPoseCopy_20261014/ETestReport/index.json`, `EFinal/result.json`, `EFinal/firstperson_state.json`, `EFinal/prompt.txt`.
- 이전 각도 보정 관련 검증은 현재 구현의 근거로 사용하지 않는다. 맵은 변경하지 않았다. 원격 최신 상점의 13개 품목을 보존하고 빠루 500원 항목을 추가했으며 한글 이름과 E키 설명을 확인했다. 3·4인 사망·이탈 통합 플레이는 후속 검증이다.

- 병합 후 검증: `Saved/Diagnostics/CrowbarPublish_20261014`. 원본 빌드, 솔로·2인 테스트 및 실제 Ocean 구매·E 상호작용·92개 팔 뼈 복제·원격 품목 보존 검사 성공.
