문서 기준과 상태

사용자 지정 규칙, 회의 제안·반응, 테스트 수치, 이전 기록을 분리합니다. 본 문서가 현행 전체 요약이며, 분야별 상세 규칙은 아래 지정된 문서를 읽습니다.

표시뜻
사용자 지정이 대화에서 사용자가 정한 기능·조건. 팀 회의의 채택과는 별개
회의 방향·제안회의 발언으로 확인. 구체 구현·수치 확정 여부는 별도
테스트 후보가격·시간·금리·조작·예외의 검증 전 가정
미결정·충돌서로 다른 문서·설명 또는 미정 범위를 결정해야 함
이전 분석·기록과거 소스 감사·회고·원본. 최신 완료 상태로 재사용하지 않음

새 규칙은 상세 문서 한곳을 기준으로 관리하고 다른 문서는 요약·링크를 둡니다. 원본 회의·로어 본문은 임의로 다시 쓰지 않습니다.

전체 작업 흐름

  1. 구매·역할 분담

    착수금으로 절단기·원샷헤라·스캐너·폼건을 구매. 가격·지갑·재고·착수금 성격 미정.

  2. 청소·철거·운반

    수영·탐색·절단·오염 제거. 생성 볼륨 쓰레기와 잔해를 집고 Q 충전 던지기·동료 전달.

  3. 즉시 분리수거

    정상 기계는 투입 즉시 정산. 돈과 최종 청소 평가는 분리하는 방향.

  4. 고장 대응

    정산 중단·고장 차감·처리장 피해에 수리 우선순위 판단. 지문패드·정전 차단기 협동 수리 수행.

  5. 재개·결과

    해결한 고장만 해제하고 작업 재개. 종료·실패·결과 산식·귀환 세부는 미정.

협동 수리

종류다인솔로
지문패드서로 다른 두 명이 두 곳에서 동시에 인식한 곳 인식 후 제한 시간 안에 다른 곳 인식
정전 차단기지침실 지침 사용 시 잠금·설명, 스캐너 담당 라이트·노브 조작지침실 지침 상호작용 잠금 생략. 지침 확인 후 직접 이동·조작

기지 일반 조명은 꺼지고 지침실만 지침 위에서 아래로 약한 보조조명이 깔립니다. 마이크 없이 유리 그림으로 전달할 수 있습니다. 성공하면 해당 차단기·조명·지침실 문을 복구합니다.

패드 시간·동시 허용 오차·노브 수·오답·라이트 소모·잠금 우회·인원 이탈은 미정입니다. 협동 수리 시스템 기획서가 상세 상태·UI·데이터·검증 기준입니다.

지침실 문은 입실·점유로 자동 잠그지 않습니다. 다인에서 수리 지침에 한 번 상호작용하면 닫혀 잠깁니다. 재시작을 누르면 문이 열리고, 다음 새 지침 상호작용까지 열린 상태를 유지합니다. 개방 시간 제한·재잠금 대기 시간·카운트다운은 없습니다. 솔로는 지침 사용으로도 잠기지 않습니다. 재시작은 수리 완료가 아니며 지침·노브·그림 초기화 여부는 미정입니다.

협동 수리 배치: 지침실은 1F 09 전력실 내부 유리 부스, 차단기는 창밖 작업 구역의 설비벽. 패드 A는 1F 02 통제실 입구 바깥 중앙 해치 쪽 벽, 패드 B는 B1-07 유지 보수실 입구 바깥·해치 출구 부근 공용 벽입니다. 기획상 B1은 실제 맵의 위층인 2층이며 방 식별자는 유지합니다. 솔로 제한 시간은 양방향 층간 이동을 실측해 결정합니다. 협동 수리 배치 상세·층 구분

X-7과 로어

L01~L07의 기록과 본문을 보존합니다. L02·L06은 1회 유효 원샷헤라 후 조사. L07은 지상 1F 격리 실험실 A 타일 아래, 절단기 철거와 스캐너 하이라이트로 발견하며 L01~L06과 함께 해독하는 이전 방향을 유지합니다.

지침실·차단기는 1F09, 패드 A는 1F02, 패드 B는 실제 2층 B1-07 입구 바깥으로 구역을 정했습니다. 정확한 좌표·치수와 폐기물처리장·기존 “폐기물 대기장”의 대응은 미정입니다.

저장 범위 결정 필요. 10월 2일 회의에서는 “캐릭터 커스터마이징만 저장”한다고 설명했습니다. 이전 로어 기획의 개인 기록·재접속 보존 요구와 충돌합니다. 로어의 세션 내 수집·본문·배치는 유지하고, 개인 영구 저장·재방문 판정은 예외 보존 여부를 결정한 뒤 구현·검증합니다.
