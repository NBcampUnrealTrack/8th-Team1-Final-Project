  • 현장 통로의 작은 쓰레기 생성 볼륨으로 캔·폐전선·플라스틱 포장재 각 1개를 만듭니다. 현재 일반 쓰레기 종류에는 사용 가능한 메시 변형이 없어 실습 생성에서 제외합니다. 절단 잔해 1개도 추가해 총 4개를 정분류하는 구성입니다. 절단 잔해는 실제 분류 데이터에 맞게 연결하며 임의로 금속 처리하지 않습니다. 생성 영역은 수거함 가까운 바닥으로 제한해 쓰레기가 물리 충돌로 갇히거나 범위 밖으로 흩어지지 않게 합니다.

안내와 힌트

지금 할 행동 한 줄 + 실제 조작 키만 표시합니다. 장비 교체는 해당 도구 실습 직전에 가르칩니다. 브릭스 자막에는 키를 박지 않고 InputConfig·재매핑 결과를 별도 힌트에 표시합니다.

상황처리
단계 시작짧은 자막 1회. 강제로 읽고 닫기를 기다리지 않음.
미리 성공즉시 인정. 성공한 동작을 다시 요구하지 않음.
조준·거리 문제“대상 가까이에서 조준하세요.”처럼 원인을 안내.
오래 머묾약 15초 뒤 키 힌트, 약 30초 뒤 대상 방향 힌트 제안. 테스트 후 조정하는 UI 값.
메뉴 열림대기 힌트 타이머 중단. 메뉴 읽기를 지연으로 판단하지 않음.
분리수거 실습집기 키 → 물건 종류 → 같은 이름의 분류 칸 순서로 안내. 색만으로 구분하지 않음.
완료확인 효과 1회. 퀘스트 보상·평가·DAY 정산 UI 없음.

스캐너를 사용하지 않고 먼저 패널을 철거했으면 개방 결과는 인정합니다. 스캔 조작을 아직 경험하지 않았다면 남아 있는 재스캔용 연습 대상을 안내합니다. 순서가 달랐다는 이유로 없어진 대상을 요구하지 않습니다.

혼자·협동·중도 합류

혼자서 모든 단계가 가능합니다. 개인 학습 상태와 공유 공간 상태를 구분하고, 협동에서 이미 열린 대상 때문에 진행이 막히지 않게 합니다.

상황처리 제안
개인 학습이동/수영/장비 사용 경험을 개인 상태로 기록. 팀 완료가 개인 도구 경험을 자동 대체하지 않음.
팀원이 먼저 절단열린 길을 통과하면 공간 진행 인정. 개인 절단 경험이 없으면 별도 재설정 가능한 실습 대상 제공. 종료를 막지는 않음.
팀원이 먼저 원샷 사용제거된 결과 인정. 본인 사용 경험은 별도 대상에서 연습 가능.
중도 합류현재 타깃 상태 동기화. 없어졌거나 제거된 대상을 기다리지 않고 재연습 대상 제공.
동시 입력제거/철거 상태 변경은 1회. 안내·완료 이벤트도 중복 처리 방지.
분리수거공유 물건의 정분류는 팀 진행에 반영. 개인 집기·투입 경험은 별도로 확인하고 연습용 물건 제공. 물건 ID별 투입 승인은 1회만 처리.

개인 재연습 대상의 구현 방식은 제안입니다. 대상별 담당 플레이어를 구분해 재설정이 다른 참가자의 진행을 되돌리지 않도록 해야 합니다. 튜토리얼 종료는 개인별로 선택할 수 있어야 하며 파티 전체 맵 이동 정책은 기존 진입 방식과 대조해 정합니다.

보호와 복구

  • 시간제한·DAY·점검·의뢰 실패·지지대·지주 붕괴를 사용하지 않습니다.
  • 실습 중 산소 고갈 피해·오염수 피해·장비 비용으로 막히는 상황을 만들지 않습니다. 산소를 유지한다면 게이지 위치만 안내하는 안입니다.
  • 위치 복구·대상 재설정·잔해 정리로 수영/파괴 후 막힘을 해소합니다.
  • 실습용 피해/산소 보호는 진입 때 원래 상태를 보관하고 끝내기·건너뛰기·중단 시 복구합니다.
  • 기존 재화·장비·부채·본편 로어 저장은 덮어쓰지 않습니다. 실습 장비를 영구 소유권 지급과 분리합니다.
  • 재접속은 실제 타깃 상태를 먼저 읽습니다. 안내 단계가 뒤처져도 이미 완료된 결과를 인정합니다.

생성 쓰레기와 분류 판정 연결

실습은 볼륨 생성 쓰레기 3개 + 절단 잔해 1개를 대상으로 합니다. 수량·종류 구성은 제안이며, 실제 생성 성공 목록을 확인한 뒤 안내를 시작합니다. 볼륨 생성물과 절단 잔해를 같은 물건으로 중복 집계하지 않습니다.

  • 실제 새 레벨의 세 볼륨은 DrinkCan·CableScrap·PlasticPackaging을 각각 100%로 지정하고 각 1개를 생성하도록 설정했습니다. 캔과 폐전선은 금속, 포장재는 플라스틱으로 분류합니다. 종류·Variant 확률은 기존 검증 규칙에 맞춰 설정합니다.
  • 연습 중 쓰레기가 사라져도 정분류로 인정하지 않습니다. 승인된 정분류만 완료 목록에 반영하고, 분실은 실습 생성기의 원장을 확인해 보충합니다.
  • 중도 합류는 기존 생성 목록·소비 상태를 받습니다. 재연습 시 해당 실습 대상만 재설정하며 다른 참가자의 쓰레기를 전체 삭제하지 않습니다.
현재 코드와의 차이: MD_TrashSorter::ConsumeSortable은 오분류도 물건을 소비하고 점수 이벤트를 발생시킵니다. 따라서 이 문서의 오투입 반환·본편 재화 보호는 구현이 필요한 실습 전용 동작입니다. 소비 전에 오분류를 거절하고 물건을 유지하도록 분기하며, 정상 투입에서는 기존 생성기 소비 원장 갱신을 유지해야 합니다. 기존 OnTrashSorted 방송은 클래스·정분류 여부·카테고리만 전달하므로, 정확한 실습 물건 ID와 출처를 판정하려면 삭제 전에 별도 완료 데이터를 확보해야 합니다. 기존 함수가 이미 ID를 전달한다고 가정하지 않습니다.

정적 코드 확인: Source/MarineDemolition/Public/World/Trash/MD_TrashSpawnVolume.h, Private/World/Trash/MD_TrashSorter.cpp. BP 배치·생성 결과·네트워크 동작은 아직 검증하지 않았습니다.

플레이테스트 기준

처음 하는 사람이 T01~T05를 짧은 안내만으로 수행하고 T06에서 물건을 집고 종류를 구분해 투입하는지 봅니다. 아직 테스트하지 않은 설계 기준입니다.

  • 이동·수영 높이 조절과 장비 교체에서 어디에 막히는가?
  • 스캔 효과를 실제 대상과 연결하는가? 매번 스캔해야 절단 가능하다고 오해하지 않는가?
  • 절단 뒤 열린 길을 스스로 통과하는가? 잔해가 시야/통행을 가리지 않는가?
  • 헤라를 계속 누르지 않고 유효 1회에 전체 가림이 제거되는 것을 이해하는가?
  • 볼륨 생성 쓰레기와 절단 잔해가 각각 목록에 등록되고 정분류되는가? 집기·내려놓기·종류별 투입을 이해하는가? 오투입 뒤 회수와 재시도가 가능한가?
  • 건너뛰기·중단·재진입·파트너 선행 파괴·중도 합류 때 없는 대상을 기다리지 않는가?
  • 볼륨 생성 실패·중복 생성·범위 밖 이동·중도 합류 시 진행이 막히지 않는가?
  • 튜토리얼 전후 본편 로어·재화·소유 장비가 같고 보호 상태가 본편에 남지 않는가?

단계별 체류 시간, 잘못 겨냥한 사용, 장비 교체 실패, 힌트 요청 횟수, 분류 혼동·오투입·분실 및 재시도을 기록합니다. 플레이어에게 평가 점수를 주지 않습니다.
