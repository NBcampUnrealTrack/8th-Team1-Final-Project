# Day3 보안 샘플 캐비닛 배치

에셋: `/Game/Blueprint/Quest/Day3/BP_Quest_Day3SampleCabinet`

1. 기존 Day3 샘플 스포너 대신 이 BP 한 개를 원하는 받침대 위에 배치합니다. 정면은 로컬 +Y입니다. 액터 원점은 본체 바닥 중앙입니다.
2. 시작 상태는 문 닫힘이며, 선반 안에 현재 Day3 샘플 외형이 보입니다.
3. 기존 `BP_QuestCard_M03`를 획득하면 `Quest:X7-M03`가 Phase 1로 진행됩니다. 이 프로젝트의 카드는 핫바 아이템이 아닌 퀘스트 상태로 기록됩니다.
4. Day3의 해당 회수 단계에서 캐비닛을 조준하고 E를 누르면 0.8초 동안 문이 110도 열립니다.
5. 문이 열린 뒤 내부 샘플을 조준하고 E를 다시 눌러 기존 물리 운반 방식으로 가져갑니다. 납품은 기존 메인퀘스트 판정을 따릅니다.

캐비닛이 배치되면 같은 퀘스트 Phase의 일반 무작위 스포너 생성을 막습니다. 이미 월드에 해당 퀘스트 샘플이 있으면 새 샘플을 중복 지급하지 않습니다. 여러 캐비닛을 두어도 여분 보상을 만들지 않습니다.

닫힌 상태의 내부는 충돌 없는 미리보기 메시입니다. 문이 완전히 열린 시점에 동일 외형의 실제 퀘스트 샘플로 전환합니다. 따라서 잠긴 문을 우회해 미리 집을 수 없습니다. 현재 게임에 적용된 Day3 샘플은 `BP_SampleBase`의 Cone 외형이며 새로운 블룸 모델을 임의로 대체하지 않았습니다.

본체·문·유리 메시 3개와 재질 7개는 `Day3/Cabinet` 폴더에 있습니다. 기본 카드 조건, 문 속도, 열리는 각도 및 샘플 위치는 BP 기본값에서 확인할 수 있습니다. 냉각 기믹과 카드 획득 자체의 로직은 변경하지 않았습니다.

검증: 전체 Editor 빌드 성공. PIE에서 카드 전 잠금, 회수 단계 허용, 다른 Day 거부, 원거리 상호작용 거부, 문 열림, 선반 위 샘플 한 개, E키 운반, 반복 입력 중복 방지 통과. 테스트에서는 별도 PIE 퀘스트 상태를 주입했고 정상 카드 획득부터 납품까지의 전체 플레이 및 다중 클라이언트는 재실행하지 않았습니다.

실제 맵 배치는 수행하지 않았습니다. 커밋·푸시 없음.
