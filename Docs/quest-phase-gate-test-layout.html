게이트 메커니즘 3종

유형 1 HP 데미지 존 (배관 파손 / 냉각펌프 고장)

M03a는 배관 파손, M03b는 냉각펌프 고장이다. M03b 펌프는 고장/수리 상태와 오염수 분출 VFX를 제공하고, 격리실 B 데미지존이 그 상태를 읽어 진입·내부 피해를 적용한다. 펌프를 수리하면 피해가 해제된다.
배관 파손 (bStartBroken) → HP −8/s 데미지 존 → 폼건 밀봉 → 존 해제 → 안전 접근
사용처: Day1 (수도관), Day3 M03a (배관), Day3 M03b (냉각펌프 + 연결된 격리실 B 데미지존)

유형 2 잠긴 문 (인프라 수리 → 문 해제)

인프라(전선 등)를 수리하면 C++에서 연결된 문의 잠금을 해제한다. 문의 BeginOverlap에서 bLocked를 검사해 잠겨 있으면 열리지 않는다.
전선 파손 (bStartBroken) → 절연테이프 수리 → SetRepaired() → UnlockLinkedGate() → 문 bLocked = false
사용처: Day1 (전력 ON → 통제실 전자문). 테스트 레벨에서는 Day2 구역에 PowerConduit→BP_Door로 검증.

유형 3 퀘스트 페이즈 게이트 (M03a → M03b)

한 퀘스트(X7-M03) 안에서 Phase[0] 완료가 Phase[1] 시작 조건이다. 카드를 브릭스에게 제시해야 다음 단계(샘플 회수)가 열린다.
B 캐비닛 카드 획득 → 브릭스 제시 (Phase 0 완료) → Phase 1 시작 → 블룸 샘플 회수 가능
FMD_QuestPhaseData 배열로 구현. Phase[0] = INTERACTION (카드), Phase[1] = RecoverIntact (샘플). RequiredCount = 2 (카드 1 + 샘플 1 = Completed).
