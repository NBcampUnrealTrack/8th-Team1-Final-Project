# 07. 경제 시스템 기획서 (Develop)

**문서 버전:** Develop v7 (문서명 분리 · 아이템 카탈로그는 `08` · 9차 회의: 퀘스트 발주처 다중 현장화는 `09` 참조 · 부상 치료는 상인 유료 서비스로 확정, §2.5 신설 · 퀘스트 실패 위약금(M-02) 삭제 — 실패는 호감도만 하락)  
**연구기지:** X-7  
**관련:** `05 수치 기획`(평가 점수), `08 아이템 기획`(상점 품목·효과), `02 시스템 기획`, `01 콘셉트`, `09 퀘스트 기획`(퀘스트 종류·발주처·언락)

이 문서는 **크레딧(₡) 경제** — 착수금, 환급, 퀘스트 보수, 대출, 물가·밸런스 — 을 정의한다.  
**상점에서 파는 아이템의 이름·효과·사용법**은 `08 아이템 기획`을 따른다.  
평가 점수와 크레딧은 **별트랙**이되, 환급·연동 보너스로 느슨히 연동한다.  
가격표 숫자는 이 문서 §4 요약과 `08`이 동일해야 하며, 충돌 시 **이 문서의 가격·수입·지출**을 우선한다.

**확정:**
- **철거 수당 없음** — 철거는 평가 점수(+15/+30)만.
- **샘플 납품 자체에는 크레딧 없음** — 샘플 돈은 **상인 퀘스트 보수**로만 지급.

## 0. 경제 한눈에

| 트랙 | 단위 | 용도 |
|---|---|---|
| 평가 점수 | 점 | Day2/3/4 **현장 점검** |
| 크레딧 | ₡ | 상점 구매, 대출, 메타 성장 |

원칙:
1. **점검 통과는 점수로만** — 돈으로 기준을 살 수 없다.
2. **상점 파워는 크레딧 + 호감도/퀘스트** — 최고티어는 돈만으로 안 열림.
3. 하루 기대 순수입(표준) ≈ **800~1400₡** → 소모품은 부담 없이, 장비 업그레이드는 **1~2일 저축**.
4. 착수금은 “오늘 들어갈 밑천”, 환급은 “분리한 만큼”, **샘플 돈은 퀘스트만**.
5. 철거·샘플(비퀘스트)은 **평가 점수**로만 보상한다.

## 2.5. 치료 서비스 (신규)

부상 → 건강 회복은 **아이템이 아니라 모선 상인에게 받는 유료 서비스**다 (`02` §6 전환 5, §7).  
핫바 슬롯을 쓰지 않는 대신, **모선에 있어야만** 받을 수 있다.

| 항목 | 내용 |
|---|---|
| 이용처 | 모선 상인 (그 외 장소에서는 불가) |
| 비용 | **70₡** /회 (M−09) |
| 효과 | 부상 → 건강 즉시 회복 (HP도 함께 완전 회복) |
| 해금 조건 | 없음 (상시 이용 가능) |
| 호감도 연동 | 없음 (프로토 단순화 — 착수금·대출과 달리 치료비는 고정가) |

의도:
> 회복킷처럼 핫바 슬롯을 잡아먹지 않으면서도, "부상당하면 일단 모선에 들러야 한다"는 동선 압박은 그대로 남긴다.  
> 남용 방지는 위치 제한(모선에서만) + 고정 비용(70₡)으로 건다.

## 3. 환급 · 퀘스트 보수

### 3.1 분리 정분류 환급 (₡)

평가 점수와 **같은 칸**이지만 금액은 약 **40~50% 스케일**.

| 칸 | 평가 점수 | 환급 ₡ | 비고 |
|---|---:|---:|---|
| 금속 | +20 | **10** | 폐공구 +3 → 13 |
| 일반쓰레기 | +12 | **6** | 작업복 +2 → 8 |
| 플라스틱 | +16 | **8** | |
| 오염된 쓰레기 | +32 | **16** | 폐전지 +4 → 20 |
| 안타는 쓰레기 | +16 | **8** | 유리 +2 → 10 |

오분류·미수거는 **크레딧 환급 0** (평가 차감만). 수정 후 정분류하면 환급 지급.

**벽 1세그(70% 제거·만점 정분류) 환급:**  
7×8 + 3×16 = 56+48 = **104₡**  
(철거 성공 평가 점수 +15/+30은 있으나 **크레딧 수당 없음**)

### 3.2 퀘스트 보수 (₡) — 샘플·기타 돈의

샘플을 모선에 납품해도 **기본 현상금은 없다.**  
크레딧은 상인이 건 퀘스트를 성공했을 때만 지급한다.  
(샘플 Intact/손상 **평가 점수**는 `05` 그대로.)

퀘스트 발주처는 현장마다 달라지지만(연구소 본사/화물 보험사/유산관리청 등, `09` §2), 아래 보수 공식은 **현장에 관계없이 동일**하게 재사용한다.  
로어 퀘스트(코덱스 수집)는 **크레딧이 소액**이며 이 표에 넣지 않는다 (`09` §5). 별도의 상인 개인 퀘스트는 없다 (`09` §0.1).

**퀘스트 실패는 크레딧 위약금이 없다.** 실패해도 이미 지급된 착수금·환급은 그대로 유지되며, **호감도만 하락**한다 (`02` §7).

| 퀘스트 유형 | 성공 조건 (예) | 보수 ₡ |
|---|---|---:|
| 회수 C Intact | 지정 C 샘플 Intact 납품 | **80** |
| 회수 B Intact | 지정 B Intact | **160** |
| 회수 A Intact | 지정 A Intact | **280** |
| 회수 S Intact | 지정 S Intact | **450** |
| 손상 허용 회수 | 지정 샘플 손상 이상 납품 | 위 보수의 **50%** |
| 청소 계약 | 지정 구역 정분류 N개 | **120** |
| 마감 계약 | 지정 섹터 마감 | **100** |
| 복합 (A+청소) | A Intact + 청소 조건 | **350** |

규칙:
1. 퀘스트 **미수락** 샘플은 점수만, 크레딧 0.
2. 한 계약(3일) 표준 기대: **퀘스트 2~3건** (예: Day1 B, Day2 A, Day3 S 또는 청소).
3. 평가 쪽 퀘스트 성공 점수(+80/+160)와 **별개**로 위 ₡ 보수를 준다.
4. **실패(미회수·파괴·명시적 포기) 시 크레딧 차감 없음.** 호감도만 하락하며, 미회수보다 파괴가 더 크게 하락한다 (`02` §7). 정확한 호감도 델타값은 미확정 — 확정되는 대로 이 문서와 `09`에 반영.

### 3.3 일일 기대 수입 (표준 · 밸런스 기준)

철거 수당·샘플 현상금 제거분을 **퀘스트 보수**로 메운다.

| 일차 | 착수 | 분리환급 | 연동보너스 | 퀘스트 | **총 수입** | 기대 지출 | **순** |
|---|---:|---:|---:|---:|---:|---:|---:|
| Day1 | 500 | ~180 | ~700 | B회수 **160** | **~1540** | 소모 ~350 | **~1190** |
| Day2 | 500 | ~220 | ~900 | A회수 **280** | **~1900** | 소모+업글 ~700 | **~1200** |
| Day3 | 500 | ~200 | ~700 | S또는청소 **120~450** | **~1520~1850** | 소모 ~400 | **~1120~1450** |
| **3일 합 순** | — | — | — | — | — | — | **~3500~3850** |

→ 풀업+소모 ~4000과 비슷하게 **타이트한 선택 빌드** 유지.

| 벽 1회 정분류 환급으로 지지대 1개? | 104≥90 → **예** |
| 붕괴 과태료(250) vs 지지대(90)? | 지지 안 사면 손해 → **예** |
| A Intact 퀘스트(280) vs 완충 패드(120)? | 패드 가성비 있음 |
| 열선(900) vs Day1~2 순수입? | 저축 1일+α → **예** |
| 풀장비(~2800) vs 3일 순(~3600)? | 풀업+소모 타이트, 올살 불가 → **예** |
| 비퀘스트 샘플 납품으로 돈? | **아니오** (점수만) |
| 철거만으로 돈? | **아니오** (점수만, 분리 환급은 조각 정분류 시) |
| 돈으로 점검 600점 대체? | **불가** |

### 7.2 대실수 시

Day2 무지지 붕괴 + **퀘스트 A** 파괴:
- 점수: −200−130 = −330 (점검 위험)
- 크레딧: 과태료 −250, 퀘스트 보수 0 (위약금 없음, 호감도만 하락)  
→ 경고 착수 삭감과 겹치면 소모품 빌드만 가능.
