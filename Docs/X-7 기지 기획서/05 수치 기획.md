#### Day 4 비상 — 점수 회복 (1600)

- 미회수 샘플 재회수 **+140~220**
- 마감 **+40**
→ **+200~400**으로 1600 도달 설계.

### 3.3 실수 민감도 체크

| 실수 | 점수 | 만회에 필요한 대략적 작업 |
|---|---:|---|
| 오분류 5회 | −60 | 금속 3개 정분류 |
| 무지지 붕괴 1 | −200 | 벽 1세그 풀세트 ≈223 |
| A 파괴 | −130 | B Intact 1개 또는 오염 정분류 ~4개 |

| 경고 | −40 + 다음날 기준 ×1.1 | Day3가 1540으로 상승 |

### 3.4 밸런스 가드레일 (튜닝 규칙)

1. **붕괴(−200) ≤ 벽 풀세트(+223)** — 실수해도 한 벽으로 만회 가능  
2. **A Intact(+220) ≈ 붕괴 1회** — 샘플이 구조 리스크와 동급 무게  
3. **분리 비중 ~45%** — 벽·산재를 스킵하면 Day3가 빠듯해짐  
4. **이론 만점의 35~45%면 클리어** — 완벽주의 강제 금지  
5. **산재만으로 잠재 1800 금지** — 벽 세그먼트 ≥7 필수  
6. **돈과 평가 점수 분리** — 상점 파워로 점검 통과 불가

## 5. 정산 합산 순서

```text
일일 평가 점수 =
  + Σ 분리 정분류 (S+01~09)
  + Σ 철거 성공 (S+10~11)
  + Σ 샘플 Intact/손상 (S+12~13)
  + 마감·퀘스트·정시복귀 (S+14~16)
  − Σ 오분류·미분류·미수거 (S−01~04)
  − Σ 샘플 미회수·파괴 (S−05~06)
  − Σ 붕괴 (S−07~08)
  − Σ 미복귀·사망·경고 (S−09~11)

누적 계약 점수 += 일일 평가 점수
```

점검: 해당 일 종료 시 **누적 ≥ 기준** (경고 시 기준 ×1.1).
