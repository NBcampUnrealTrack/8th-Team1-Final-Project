# 06. 내러티브 문서 (Develop)

**문서 버전:** Develop v4 (01 콘셉트 정합)  
**연구기지:** X-7  
**톤 목표:** 캐주얼 비즈니스 협동. 공포보다 계약 압박. (`01 콘셉트`와 동일)

---

## 1. 로그라인

압력 사고로 **이미 전체 침수**된 해저 연구기지 X-7.  
공식 전투팀이 아닌 민간 철거·회수 계약팀이 사흘 일정으로 투입된다.  
그들은 벽을 긁고 부수며 길을 열고, 오염·따개비·쓰레기를 가르고,  
붕괴되기 전에 연구 샘플을 건져 올린다.

---

## 2. 세계관 핵심

### X-7이란
심해에 설치된 민간/연구 복합 기지.  
사고 이후 **전체가 침수**되었고, 완전히 포기하기 전에 두 가지가 남았다.

1. 위험 구조의 안전 해체와 구역 마감
2. 고가 연구 샘플과 데이터 회수

### 플레이어는 누구인가
영웅도 군인도 아니다.  
**기한이 있는 현장 계약직**이다.

그들이 잘하는 일:
- 오염막·따개비 제거
- 각종 쓰레기 수거·분리
- 격벽 판단
- 임시 지지
- 샘플 회수
- 손해 적은 철수

## 3. 명칭 통일

| 용어 | 사용 |
|---|---|
| 연구기지 | X-7 |
| 플레이어 팀 | 민간 해체·회수 계약팀 |
| 허브 | 해상 모선 |
| 입구 | 모선에서 바로 수중 투입 (에어락 없음) |
| 맵 이동 | **레벨 스트리밍** (기지 ↔ 바다·모선) |
| 현장 상태 | 시작부터 침수 |
| 방 단위 | 섹터 |
| 위험 벽 | 지주격벽 (내력벽) |
| 일반 철거 벽 | 칸막이격벽 (비내력벽) |
| 보통벽 | 내력·칸막이 세그먼트가 아닌 일반 벽면 (따개비 부착) |
| 헤라 | 오염물·따개비 → 물리 → 임시 쓰레기통. 철거 필수 아님 |
| 임시 쓰레기통 | 물리 운반 용기 (구 보관함). 1층 폐기물 대기장에서 무한 보급 |
| 모선 분리 | **금속(실버) / 일반(흰) / 플라스틱(파랑) / 오염(노랑) / 안탐(회색)** 5칸 투입 |
| 분리 절차 | 현장은 혼적 OK → 모선 분류장에서 하나씩 맞는 칸에 넣기 |
| 현장 산출물 | 조각벽→안탐 / 오염된 조각벽·오염물·따개비→오염 / 캔·공구→금속 등 |
| 섹터 진행 | 열리는 문 통과 / 막히면 벽 철거로 다음 섹터 |
| 구역 마감 | 섹터 철거·정리를 끝내 “작업 끝” 제출. (구 용어: 봉인) |
| 이동 | 바닥 접지 시 걷기 / 점프로 수영 전환 |
| 지주 실패 연출 | 절단자가 있는 섹터의 천장 붕괴 |
| 핵심 NPC | 모선 상인 |
| 장기 위기 | **평가 점수** (폐기 게이지 삭제) |
| 고비 | 현장 점검 (2·3일차, **점수** 판정) |

## 4. 상인 캐릭터

### 역할
상인은 상점 점원이자 계약 창구다.
- 착수금 지급
- 상급 샘플 퀘스트 제시
- 호감도에 따른 거래
- 대출 제공
- 2·3일차 점검 통보

### 성격
- 캐주얼하고 장사꾼다
- 성공하면 바로 조건을 열어준다
- 실패하면 감정적으로 겁주기보다 “손해 계산”으로 압박한다
- 공포 연출의 악역이 아님

### 대사 방향
| 상황 | 예시 |
|---|---|
| 계약 시작 | “X-7, 사흘이다. 여섯 시면 배 뜬다.” |
| 퀘스트 제시 | “A급은 Intact로. 깨지면 얘기 다르게 한다.” |
| 성공 | “좋아. 목록 더 열어주지.” |
| 미회수 | “못 가져오면 그게 실패야.” |
| 파괴 | “깨뜨리면 미회수보다 비싸다.” |
| 대출 | “빌려줄게. 이자는 정확히.” |
| Day2 경고 | “경고다. 패널티 붙는다. 점수가 모자라. 다시 실패하면 접는다.” |
| Day3 무경고 실패 | “한 번 더 본다. 내일은 착수금 없다. 점수만 끌어올려.” |
| Day4 비상 | “정규 일정 아니다. 점수 기준만 맞춰라.” |
| 경고 상태 재실패 | “폐기한다. 이번 계약 끝.” |
| 계약 성공 | “계약 완료. 다음 구역 준비해.” |

## 5. 서사 진행 방식

컷신 대작이 아니라 **계약 진행형** 서사다.

| 구간 | 이야기 |
|---|---|
| 초반 | X-7 외곽/저위험 구역 정리, 팀의 작업 방식 학습 |
| 중반 | 생물실험동·데이터 코어 등 가치 있는 회수 |
| 후반 | 심층 구역, S급 샘플, 전속 계약 |

플레이어가 세계를 읽는 통로:
- 어떤 샘플을 살렸는가
- 어떤 벽을 남겼는가
- 상인 호감도가 어떻게 변했는가
- 점검 **점수**를 어떻게 지켰는가

---

## 6. 샘플의 의미

샘플은 점수 아이템 이상이다.

| 관점 | 의미 |
|---|---|
| 상인 | 돈과 신용 |
| 플레이어 | 성장과 해금 |
| 세계관 | X-7의 연구 성과이자 위험 증거 |

그래서 상태가 곧 이야기다.
- Intact: 잘 건져냈다
- 손상: 겨우 가져왔다
- 미회수: 내일의 숙제
- 파괴: 돌이킬 수 없는 손실

운반:
- 손으로 들고 가거나
- **임시 쓰레기통**에 넣어 모선으로 가져간다

---

## 7. 톤 가이드

### 한다
- 코믹한 팀 실수 (쓰레기통 쏟음, 오분류)
- 업무적 압박
- 수중 현장의 급박함
- 손해 명세서처럼 읽히는 실패

### 하지 않는다
- 잔인한 고어
- 과도한 비관 연출
- “돈 없어서 죽은” 리썰 카피 서사
- 헌터/용사 중심 던전 서사

사망 연출도 과장된 비극보다  
“건강 → 부상 → 사망 → 부활 → 점수가 깎임”으로 처리한다.  
중간 Down 단계는 없다.

## 8. 3일 계약 서사 템플릿

### Day 1
“오늘은 현황 파악이다. 점검은 없다.  
길이랑 위험만 표시하고 여섯 시 전에 돌아와.  
대기장에서 쓰레기통 받아 써.”

### Day 2
“어제 연 길로 들어가라.  
오늘 저녁에 중간 점검한다. **점수로 본다.**  
실패하면 경고와 패널티다.”

### Day 3
“마지막 정규일이다.  
이미 경고가 있으면 실패 시 폐기한다.  
경고가 없는 첫 실패는 비상 연장으로 넘긴다.”

### Day 4 비상
“착수금은 없다.  
오늘은 **점수를 기준까지 끌어올리는** 근무다.  
어렵게 만들지도 않는다. 숫자만 맞춰라.”

### 클리어
“계약 유지 데이터 넘겨준다.  
돈, 신용, 진행도. 다음 기지 가자.”

### 게임오버
“현장을 잃었다.  
빚 때문이 아니다. 경고 후에도 기지를 살리지 못했다.”

## 9. 연출 우선순위

1. 모선에서 바로 수중 현장 투입 (레벨 스트리밍)
2. 바닥 접지 걷기 / 점프로 수영 전환 / 모선 복귀
3. 헤라로 오염·따개비가 벗겨지는 손맛 (물리 → 임시 쓰레기통, 쏟기 가능)
4. 각종 쓰레기 손 수거 + 1층 대기장 쓰레기통 보급
5. 막힌 문 → 벽 돌파 → 조각 ~10 낙하 → 손·임시 쓰레기통 운반
6. 모선 분류장: 쓰레기통 비우기 → **5종** 색칸 투입 (실버/흰/파랑/노랑/회색)
7. 지주격벽 오절단 → 본인 섹터 천장 붕괴
8. 샘플 손/임시 쓰레기통 운반, 벽 충돌 시 손상
9. 17:30~18:00 모선 출발 압박
10. 핫바는 장비 전용 (잔해·샘플 가방 없음)
11. Day 전환 시 어제 현장 유지감
12. 2·3일차 **점수** 점검 / 무경고 Day3 실패 시 비상 4일차 / 경고 재실패 시 폐기 통보

이 항목이 보이면 스토리 연출의 최소 완성도이다.
