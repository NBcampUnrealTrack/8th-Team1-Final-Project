현재 원뿔 샘플은 `BP_SampleBase` → `/Engine/BasicShapes/Cone` 참조를 공유한다. 따라서 **퀘스트명이나 C/B/A 등급만으로 외형이 달라지지 않는다.** R07은 부유 동작으로 구분되지만 모델 자체는 같다. Day3 플레이 확인 이미지에서는 노란 조명 아래 원뿔과 체크무늬가 보이며, 이를 고정된 노란 등급 색상으로 해석하면 안 된다.

손상 시 C++는 머티리얼의 `Color` 파라미터를 빨강으로 바꾸려 한다. 실제 머티리얼의 해당 파라미터 지원 여부까지 이번 조사에서 검증하지 않았으므로, 손상 샘플이 반드시 빨갛게 보인다고 단정하지 않는다.

현재 반복 풀에 없는 `X7_R01`, `X7_R03`, `X7_R04`는 목록에서 제외했다. 로어 기록물은 별도 수집·상호작용 대상이므로 이 운반 샘플 목록에 포함하지 않았다.
