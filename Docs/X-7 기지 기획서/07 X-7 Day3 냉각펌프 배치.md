# Day3 격리실 B — 냉각펌프 배치 가이드

## 상태와 진행 순서

냉각펌프는 고장 상태로 시작한다. 펌프의 오염수 분출 VFX와 격리실 B의 진입·내부 피해 트리거가 함께 활성화된다.
플레이어는 B 진입 시 피해를 확인하고 B1-05에서 펌프를 수리한 뒤 돌아와 안전하게 진입한다.

| 상태 | 펌프 오염수 VFX | 격리실 B 피해 |
|---|---|---|
| Broken | ON | ON |
| Repaired / Intact | OFF | OFF |
| 격리실 B의 펌프 연결 누락·미로드 | 펌프 상태에 따름 | ON: 연결 누락으로 우회되지 않음 |

수리는 기존 폼건 발사체의 태그 검증·충전 소모 경로를 사용한다. 수리 대상만 냉각 배관에서 냉각펌프로 바뀐다. E 무료 수리는 차단한다.
냉각 상태는 기존 WallUtility 저장 기록에 포함된다. 별도 중복 냉각 플래그를 저장하지 않는다.

배치용 블루프린트는 이미 프로젝트 에셋으로 저장되어 있으므로 별도 생성 스크립트는 유지하지 않는다.

## 2. B1-05 냉각실에 펌프 배치

1. BP_MD_CoolingPump 1대를 상시 접근 가능한 주 구획에 배치한다. 반복 퀘스트 R05의 막힌 구획 뒤에 두지 않는다.
2. Start Broken = true를 유지한다.
3. Mesh에 냉각펌프 모델을 지정하고 충돌을 확인한다. 조준·폼건 착탄 경로를 다른 장식 메시가 가리지 않게 한다.
4. ContaminatedWaterFX의 위치·회전을 펌프 누출부에 맞춘다. 기본 루프 Niagara를 필요에 따라 교체한다.
5. 펌프 자체에는 별도 데미지 볼륨을 두지 않는다. 실제 피해는 BP_MD_IsolationBHazard가 전담한다.
6. 상속된 LinkTrigger는 냉각펌프에서 비활성화되어 있으며 Extent 0 / NoCollision / Overlap Off 상태를 유지한다.
7. 펌프에 접근해 폼건을 쏠 수 있는 안전한 면을 남긴다.
8. Linked Gate Actor는 비워 둔다. 이것은 문 잠금 해제 기능이므로 카드가 필요한 B 캐비닛에 직접 연결하지 않는다.

펌프는 고장/수리 상태와 분출 VFX만 제공한다. 실제 즉시 진입 피해와 주기 피해는 다음 별도 액터가 전담한다.

## 3. B1-04 격리실 B에 데미지존 배치

1. BP_MD_IsolationBHazard를 B 입구와 방 내부를 덮도록 놓는다.
2. Details > MD > Cooling > Cooling Pump에서 스포이트로 위 펌프를 지정한다.
3. DamageZone의 Box Extent를 방 크기에 맞춘다. Extent는 반길이이며 기본 (400, 400, 200)cm는 전체 8m × 8m × 4m다.
4. 박스를 입구에만 얇게 두면 통과 후 방 안에서 피해가 없어지므로, 샘플까지의 내부 동선을 함께 덮는다.
5. 복도·인접 방·위아래 층을 덮지 않는지 확인한다. 서로 겹치는 데미지존을 여러 개 두면 각각 피해를 주므로 중첩하지 않는다.
6. Damage Per Second = 8, Damage Interval = 1을 기본으로 사용한다.
7. 펌프와 방 볼륨은 함께 로드되도록 배치한다. 펌프가 스트리밍 아웃되면 방은 안전 상태로 바뀌지 않는다.

서버가 플레이어별 피해 간격을 관리한다. 처음 진입하면 기본 8 피해, 계속 머물면 1초마다 8 피해다.
여러 신체 컴포넌트가 겹치거나 같은 프레임에 타이머가 실행되어도 같은 액터의 피해 간격 안에서 중복 피해를 주지 않는다.
수리 직후부터 서버는 추가 방 피해를 적용하지 않는다. 방의 복제 상태·선택적 경고 FX는 최대 0.1초 뒤 갱신된다.
방 경고 효과를 추가하려면 BP의 On Hazard State Changed 이벤트에서 켜고 끈다. 펌프 분출은 기본 구현에 포함된다.

## 4. 카드·캐비닛 연결 범위

기존 카드 조건 AND 펌프의 Is Cooling Restored로 캐비닛 조건을 구성한다.
이번 변경은 펌프/위험구역 흐름이며, 카드 소유·캐비닛 개방·강행 시 샘플 파괴·납품 보상을 새로 구현한 것은 아니다.
실제 캐비닛 블루프린트 연결은 별도 확인 대상이다. 피해만으로 빠른 진입을 완전히 막는다고 가정하지 않는다.

## 5. 배치 후 확인

| 테스트 | 기대 결과 |
|---|---|
| 시작 | 펌프 고장, 분출 VFX 활성, 격리실 B 데미지존 활성 |
| 수리 전 B 진입 | 첫 피해 즉시 적용, 머무는 동안 기본 8 HP/s |
| B에서 퇴장 | 추가 피해 없음 |
| 잘못된 수리 도구 / E | 펌프가 수리되지 않음 |
| 정상 폼건 착탄 | 기존 충전 비용 사용, 펌프 수리 상태 |
| 수리 후 | 분출 VFX와 B 내부 피해 모두 중단 |
| 수리 순간 B에 플레이어가 있음 | 다음 방 피해가 들어오지 않음 |
| 고장/수리 상태 저장 후 불러오기 | 저장된 상태에 맞게 VFX·피해 복원 |
| 두 플레이어 및 늦은 접속 | 피해는 서버에서 한 번, 각 클라이언트에서 펌프 VFX 일치 |
| 펌프 참조 누락 | 경고 로그, 방이 임의로 안전해지지 않음 |

자동화 테스트는 도구 검증·상태 전환·저장 기록 복원·참조 누락을 검사한다.
실제 폼건 조준/발사·충전 차감·HP 변화·VFX 외형·멀티플레이는 위 PIE 확인이 필요하다.
