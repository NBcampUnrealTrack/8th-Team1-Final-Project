# 03. X-7 반복 퀘스트 기획서 (Develop)

**문서 버전:** Develop v1 (기믹 회수 3종 확정 — 전력 복구, 통신 아카이브, 격리 A·B 연계. 1차원 청소 계약 3종을 교체)  
**현장:** X-7 해저 연구기지  
**관련 문서:** `공통 기획서/09 퀘스트 기획`(프레임워크) · `07 경제 시스템`(유형·₡) · `08 아이템`(헤라·테이프·폼건·지지대) · `02 시스템`(오염수 HP·내력 붕괴) · `X-7 기지 기획서/01 X-7 퀘스트 기획`(메인·로어) · `02 X-7 레벨 배치`(도면)

이 문서는 X-7 반복 퀘스트의 **풀·기믹·연계 단계** 정본이다.  
메인 Day 라인과 로어(코덱스)는 `01`에 남긴다. 프레임워크(2회차 노출, 계약당 2~3개, 호감도 비개입, 위약금 없음)는 `09` §4를 그대로 따른다.

**브릭스 개인 퀘스트 체인이 아니다.** 연계 단계는 현장 반복퀘 하나의 내부 페이즈다 (`09` §0.1).

---

## 0. 설계 원칙

1. 완료 조건은 **회수 1~2개**다. 샘플 회수가 `RequiredCount`로 돌아가는 것과 같다.
2. 청소·철거·수리는 목표가 아니라 **꺼내기 위한 기믹**이다. “오염물 N개 제거” 같은 1차원 청소 계약은 내부 풀에서 뺀다.
3. 로어 오브젝트와 **물건을 나누다.** 같은 방을 써도 된다. 코덱스 엔트리를 반복퀘 보상으로 주지 않는다.
4. 기믹은 기존 도구만 쓴다. 헤라, 절단기, 스캐너, 지지대, 절연테이프, 폼건. 새 아이템을 만들지 않는다.
5. 내부 기믹 퀘스트와 외부 경량 수집이 한 계약에 섞이도록 뽑는다 (외부 최소 1개 권장).

## 3. X7-R03 — 전력 복구

발주: “전력 올리고 통제실 백업 가져와.”

### 완료 조건
연구 데이터 카트리지 **1개**를 브릭스에게 납품.

### 플레이어 행동

1. **09 전력실** 배선반. 따개비가 단자를 덮고 있다 → **헤라로 먼저** 뗀다. 떼기 전에는 테이프가 먹지 않는다.
2. 침수 때 이미 끊긴 전선 **2노드** → **절연테이프**. 플레이어가 잘못 잘라서 고치는 사고가 아니다. 퀘스트가 테이프를 쓰게 만든다.
3. 전력 ON → 통제실 **전자문** 잠금 해제.
4. 컴퓨터 Hold 덤프 → 카트리지 스폰 → 모선에서 브릭스 납품.

### 규칙
- 배선반 따개비 → 테이프 순서를 강제한다.
- 09는 내력·붕괴 구간이다 (`02` 레벨 배치). 기믹은 따개비·전선에만 걸고, 천장 리스크는 기존 절단 규칙을 그대로 쓴다.
- 테이프는 상점 45₡ (`08` IT-T1). 시작 지급이 아니다. 사 가서 쓴다.
- 통제실 칸막이 철거는 로어용 우회 경로로 남긴다. 컴퓨터만 전원이 필요하다.

### 대사
| | 텍스트 |
|---|---|
| 발주처 | "전력 올리고 통제실 백업 가져와." |
| 브릭스 | "불 켜고 자료만. 서류는 너희가 알아서 읽어." |

## 5. X7-R04 — 격리 대조 샘플 (연계)

풀에서는 **한 장**이다. 수락 후 단계만 둘로 나뉜다.  
`RequiredCount` 2. 카드 습득 = 1/2 (보상 없음). 샘플 납품 = 2/2 (정산).

A는 **활성 배양**, B는 **대조·사멸**이다. 반복퀘는 그 한 줄만 쓴다. 격리 실패의 자세한 이야기는 로어다.

### 5.1 1단계 — 격리 A 바깥

발주 시점에는 A만 가리킨다. B는 말하지 않는다.

| 항목 | 내용 |
|---|---|
| 위치 | 격리 실험실 A **출입구 바깥** |
| 기믹 | 노출 배관이 탈출 블룸에 찢김 → **오염수 분출** (`02` §2.4). 출입구를 가로막음 |
| 도구 | **폼건** 밀봉. Niagara 정지, HP 위험 볼륨 제거 |
| 보상 오브젝트 | 연구자가 놓고 간 **B 캐비닛 카드** |
| 인벤 | **차지 없음.** 퀘스트 플래그. 사망해도 유지 |
| 이 단계에서 안 하는 것 | A 내부 진입 (Day2 메인 B급 자리) |

카드는 오염수 뒤에 있다. 막기 전에는 집을 수 없다.

브릭스에게 카드를 보여 주면 2단계가 열린다. ₡은 아직 없다.

**브릭스:** “그거 B 캐비닛 키야. 문은 나갔고 냉각도 죽었다. 지지 박고 들어가. 샘플은 깨지지 않게.”

### 5.2 2단계 — 격리 B

카드 목표가 “B 대조 샘플”로 바뀐다. Accepted는 Day가 바뀌어도 유지된다. 오늘 A, 내일 B가 된다.

| 항목 | 내용 |
|---|---|
| 문 | 파손. 사용 불가 |
| 진입 | **내력벽**을 **지지대 설치 후** 절단. 정답 경로가 지지+내력이다 |
| 지지 없이 절단 | 천장 붕괴 HP −60 (`02` §2.3). 안의 샘플은 **파괴 실패** |
| 고온 | 내부 해수 70도 이상. 온도계 소품·대사로만 읽는다. 피해는 새 공식이 아니다 — 오염수와 같은 **HP −8/초** 볼륨에 아지랑이 FX |
| “수리 후 진입 가능” | 문 잠금이 아니다. 벽은 이미 열려 있다. **안에서 작업할 수 있는가**다. 들어가서 아프면 나와서 고친다 |
| 냉각 기계실 | **격리 B 옆 소방.** B1 배양·냉각(Day3 메인)과 분리 |
| 수리 | 압축기 전선이 이미 끊김 → **절연테이프 1노드.** 섹터 조명이 아니라 **냉각 펌프 회로**. 수리 시 고온 볼륨 OFF |
| 캐비닛 | 카드 **그리고** 냉각 완료. 둘 다 있어야 열린다 |
| 고온인 채 개방 | 샘플 파괴 (Intact 실패). 급습으로 냉각을 스킵할 수 없다 |
| 회수물 | 고열에 변성된 블룸이 든 **퀘스트 전용 샘플 1개.** Day2 B급과 별도 스폰 |
| 납품 | 브릭스 직접. 분류장 아님. 이때 정산 |

### 5.3 실패
| 상황 | 처리 |
|---|---|
| 카드만 가진 채 18:00 / 계약 종료 | 미회수. 크레딧 0, 호감도 하락 |
| 고온 캐비닛 강제 개방 | 샘플 파괴 |
| 포기 | Failed. 위약금 없음 |

### 5.4 대사
| | 텍스트 |
|---|---|
| 발주처 (1단계) | "격리 A 쪽 배관부터. 연구자가 카드를 놓고 나왔다." |
| 브릭스 (카드 확인) | "그거 B 캐비닛 키야. 문은 나갔고 냉각도 죽었다. 지지 박고 들어가. 샘플은 깨지지 않게." |
| 발주처 (2단계 카드) | "B 대조 샘플. Intact." |
| 브릭스 (완료) | "변성된 거다. 본사 목록에 이렇게 적혀 있어. 다음은 분류나 해." |

발주·브릭스 대사에 사멸 온도 정답을 넣지 않는다. “고열에 변성된 샘플”이면 충분하다.

## 6. 연계 퀘스트 구현 메모

현재 `FMD_RepeatQuestState`는 단계가 없다. Offered → Accepted → Completed/Failed와 `CurrentProgress`만 있다.

X7-R04는 새 퀘스트 종류를 만들지 않고 **같은 슬롯의 페이즈**로 간다.

| 항목 | 규칙 |
|---|---|
| 풀 | R04 하나. 2장을 뽑지 않는다 |
| Progress | 카드 플래그 = 1 / 샘플 납품 = 2 = Completed |
| 카드 납품 | Completed로 올리지 않는다. 브릭스 상호작용으로 페이즈만 전환 |
| 카드 전달 대상 | 모선 분류장이 아니라 **브릭스** |
| 카드 표현 | 핫바·손 슬롯 없음. HUD 퀘스트 위젯에만 “격리 B 캐비닛 카드” |
| 고온 볼륨 | `02` §2.4 오염수 DoT 재사용. FX만 고온 |
| 테이프 노드 | 조명 복구와 별도. “냉각 회로” 태그 |
| 캐비닛 조건 | `bHasCard && bCoolingRestored` |

R01·R03은 단계 없이 `RequiredCount`만 쓴다.

## 9. 개발 우선순위

1. 반복퀘 페이즈(R04) + 브릭스 중간 상호작용. 카드 플래그.
2. R03 전력 노드·전자문·카트리지.
3. R04 오염수 배관, 고온 볼륨(오염수 DoT 재사용), 캐비닛 게이트.
4. R01 랙 3종 기믹.
5. `02 X-7 레벨 배치`에 §7 소품·방을 반영.
6. R02·R05·R06~R08은 기존 사양 유지. 구현은 기믹 3종 다음.
