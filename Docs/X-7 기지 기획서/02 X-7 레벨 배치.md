## 1. 도면

### 1.1 구조 — 두 층 모두 해치 중심 방사형

```
        [모선]
          ↓  (레벨 스트리밍)
        외부 · 진입 항로
          ↓
    ┌── 01 진입구 (1F 하단 중앙) ──┐
    │                              │
    │        ◎ 중앙 해치            │   1F — 8실
    │                              │
    └──────────┬───────────────────┘
               ↓ (수직)
    ┌──────────┴───────────────────┐
    │        ◎ 하부 해치            │   B1 — 7실
    │                              │
    └──────────────────────────────┘
               ↓ (땅굴 · 비공식)
        외부 · 침몰 잔해 지대
```

**두 층 다 해치를 중심에 둔 방사형이다.** 모든 방이 해치에서 한 단계 안에 있고, 방끼리도 인접변으로 이어진다. 긴 복도로 이어진 선형 구조가 아니다.
→ **동선 설계 의미:** 어느 방을 목적지로 잡아도 왕복 거리가 비슷하다. 난이도 차이는 **거리가 아니라 방 안의 기믹**에서 나와야 한다.

## 2. 권장 동선

### 2.1 물리 동선 (고정)

```
모선 → (스트리밍) → 진입 항로 → 01 진입구 → 중앙 해치 → [1F 8실 방사]
                                              ↓
                                          하부 해치 → [B1 7실 방사]
                                              ↓ (B1-05 안쪽)
                                            땅굴 → 침몰 잔해 지대
```

연결은 **문·해치**뿐이다. 외벽은 불가침(01 진입구, 땅굴만 예외).

### 2.2 Day별 목적지

| Day | 층 | 메인 목적지 | 메인 내용 | 같은 층의 반복 슬롯 | 그 김에 걸리는 로어 |
|---|---|---|---|---|---|
| **Day1** | **B1** | **B1-06 통신/서버실** | M01 — 서버랙 3기 중 2기에서 카트리지 | 01 진입구 = R09 · B1-02 = R10 | **L01** (라운지, 통과 동선) |
| **Day2** | **1F** | **09 전력실 → 02 통제실** | M02 — 배선반 복구 → 전자문 → 카트리지 | 07 표본 보관실 = R02 | 없음 |
| **Day3** | **1F → B1** | **05 격리 A 바깥 → B1-04 격리 B ↔ B1-05 냉각** | M03a 폼건 밀봉 → M03b 지지+절단, 냉각 복구, 캐비닛 | B1-05 = R05 · B1-01 = R11 | **L03** (B1 진입 시) |

**Day 언락은 경과 기준이다** — 선행 완료를 조건으로 걸지 않는다 (`09` §1).

### 2.3 Day 배치의 근거

| 판단 | 이유 |
|---|---|
| **Day1을 B1-06으로** | 도면에서 서버랙이 있는 방은 B1-06 하나뿐이다. 다른 선택지가 없다. 하부 해치 **바로 옆방**이라 "01 → 중앙 해치 → 하부 해치 → 옆방"이 거의 직선이고, Day1 동선이 가장 짧다 |
| **Day2를 1F 단층으로** | 09 전력실과 02 통제실이 같은 층 방사 구조라 왕복이 짧다. **구매 게이트(절연테이프)가 처음 걸리는 날**이라 이동 부담을 낮춘다 |
| **Day3를 1F↔B1 왕복으로** | 05 격리 A(1F) → B1-04 격리 B(B1) → B1-05 냉각(B1 반대편). **가장 긴 동선을 마지막 날에 둔다.** 하루 밀도가 Day3의 압박이다 (`03` §6.2) |
| **냉각 회로를 B1-05로** | 구 문서는 "격리 B 옆 소방, B1 아님"이었지만 도면상 냉각 시스템실은 B1-05다. **B1-04(동) ↔ B1-05(남서)** 왕복이 생기는데, 이게 Day3 클라이맥스로 오히려 낫다 — 고온 볼륨 안에서 나와 반대편까지 뛰어갔다 오는 구조 |

### 2.4 층 이동 리듬

| Day | 층 이동 | 의미 |
|---|---|---|
| Day1 | 1F 통과 → **B1** | 해치 하강을 첫날에 가르친다 |
| Day2 | **1F**만 | 층 이동 없이 도구 구매·수리에 집중 |
| Day3 | **1F → B1 → B1 반대편** | 익힌 것을 전부 쓴다 |

### 4.2 트랙 간 충돌 규칙

방이 15개인데 트랙이 3개라 완전 분리는 불가능하다. **우선순위를 정해 둔다.**

| 규칙 | 내용 |
|---|---|
| **1. 메인은 로어와 방을 공유하지 않는다** | 메인은 필수 동선이다. 로어가 공짜로 걸리면 탐험이 아니게 된다 (`09` §5). **현재 배치는 겹침 0** |
| **2. 반복은 로어와 방을 공유해도 된다** | 단 **대상물·스폰 지점을 분리**한다 (`04` §0-4 원문). 로어를 반복 납품물로 쓰지 않는다 |
| **3. 메인과 반복은 방을 공유해도 된다** | 시점이 다르다(메인=Day 고정, 반복=계약 중 자유). 스폰 지점만 겹치지 않게 |

**현재 공유 방 3개**

| 방 | 공유 | 분리 방식 |
|---|---|---|
| **B1-01** | R11(A급 데이터 코어) + L04(해석 데이터 코어) | 반복은 **작업대 위 스폰 지점**, 로어는 **시퀀서 본체 안**. 시간이 부족하면 둘 중 하나를 고르는 선택압 — 구 문서의 "R11 vs L05" 선택압을 여기서 계승한다 |
| **B1-02** | R10(B급 샘플 2) + L03(배양 로그 카트리지) | 반복은 **챔버 열 스폰 지점 2**, 로어는 **넘어진 랙 아래**. 로어를 덮은 쓰레기는 R10·R02와 무관한 일반 산재 쓰레기 |
| **B1-05** | M03b(냉각 회로 테이프) + R05(막힌 구획 철거·마감) + 땅굴 입구 | **방을 세 구획으로 나눈다** — 아래 |

#### B1-05 냉각 시스템실 — 3구획 분할 (필수)

**⚠ 반복 퀘스트가 메인의 선행조건이 되면 안 된다.** R05의 철거 대상을 B1-05 **주 출입구**로 잡으면, R05가 안 뽑힌 계약에서 M03b(Day3 냉각 회로 복구)가 방에 들어가지 못한다. 구획을 갈라야 한다.

| 구획 | 내용 | 접근 | 쓰는 슬롯 |
|---|---|---|---|
| **주 구획** (압축기 열) | 냉각 압축기 · 끊긴 전선 1노드 | **처음부터 열려 있다.** 하부 해치에서 문으로 바로 | **M03b** (Day3 필수) |
| **부속 구획** (냉각탑 하부 정비 구획) | 마감 가능 섹터 · 산재 쓰레기 | **막힌 격벽 1세그먼트 철거** | **R05** (선택) |
| **배관 뱅크 뒤** | 정비 패널 → 땅굴 입구 | 패널 1세그먼트 철거 | **L07** (보류 — §1.4) |

- **주 구획은 어떤 퀘스트도 잠그지 않는다.** M03b는 R05 수행 여부와 무관하게 압축기에 도달한다.
- **세 구획의 벽면이 서로 다르다.** 압축기는 북벽, 부속 구획은 서벽, 배관 뱅크는 남벽 쪽으로 잡는다.
- **부수 효과 (의도적):** R05가 뽑히거나 Day3에 M03b를 하러 오면 이 방에 들어오게 되고, **땅굴 입구를 발견할 확률이 올라간다.** 4등급 은닉(`06` §3)이 완전한 우연에만 의존하지 않게 하는 안전장치다.
