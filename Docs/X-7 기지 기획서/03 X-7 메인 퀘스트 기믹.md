**문서 버전:** Develop v4 (`09` v10.2 반영 — **이월 금지는 메인 한정**임을 명시. 반복 슬롯은 계약 3일 내내 상태·스폰물 유지)
**이전 버전:** Develop v3 (**연계(M03) 두 페이즈를 모두 Day3로 이동**. 3-1의 M02 완료 게이트를 제거 — Day3 시작 시 3-1이 열리고 같은 날 3-2로 이어진다. 연계가 Day를 걸치지 않으므로 v2의 **Day3 압축 모드 분기를 폐기**)
**이전 버전:** Develop v2 (**메인↔반복 교체**. 구 반복퀘 기믹 3종(통신 아카이브·전력 복구·격리 A·B 연계)이 **메인 Day 라인으로 승격**. 구 메인 3종(진입구 안전화·생물실험동 회수·데이터 코어 회수)은 반복 풀로 강등 — 정본 `01` §3. 문서명도 `03 X-7 반복 퀘스트 기획` → `03 X-7 메인 퀘스트 기믹`으로 변경)
**이전 버전:** Develop v1 (기믹 회수 3종 확정 — 전력 복구, 통신 아카이브, 격리 A·B 연계. 1차원 청소 계약 3종을 교체)
**현장:** X-7 해저 연구기지
**관련 문서:** `공통 기획서/09 퀘스트 기획`(프레임워크) · `05 수치`(점수) · `07 경제 시스템`(유형·₡) · `08 아이템`(헤라·테이프·폼건·지지대) · `02 시스템`(오염수 HP·내력 붕괴·§7 호감도) · `X-7 기지 기획서/01 X-7 퀘스트 기획`(Day 요약·반복 풀·로어 요약) · `02 X-7 레벨 배치`(도면) · `04 X-7 로어 퀘스트 기획`(로어 정본)

이 문서는 X-7 **메인 퀘스트 3종의 기믹·연계 단계·이월 규칙** 정본이다.
Day 요약표·반복 풀 8종·로어 요약은 `01`에 남긴다. 프레임워크(Day 언락, 호감도 슬롯 규칙, 이월 금지)는 `09` §1·§1.5·§4를 그대로 따른다.

**브릭스 개인 퀘스트 체인이 아니다.** M-03의 연계 단계는 메인 라인 하나의 내부 페이즈다 (`09` §0.1).

## 0. 설계 원칙

1. 완료 조건은 **회수 1~2개**다. 개수는 `RequiredCount`로 돌아간다.
2. 청소·철거·수리는 목표가 아니라 **꺼내기 위한 기믹**이다. "오염물 N개 제거" 같은 1차원 청소 계약은 메인 라인에 넣지 않는다.
3. 난이도 곡선을 **샘플 등급이 아니라 기믹 단계 수**로 표현한다. Day1 도구 1종 → Day2 도구 2종 + 구매 → Day3 도구 3종 + 순서 강제. (구 라인은 C→B→A 등급으로 표현했다. 등급 트랙은 반복 풀로 넘겼다 — `01` §3)
4. 로어 오브젝트와 **물건을 나눈다.** 같은 방을 써도 된다. 코덱스 엔트리를 메인 보상으로 주지 않는다.
5. 기믹은 기존 도구만 쓴다. 헤라, 절단기, 스캐너, 지지대, 절연테이프, 폼건. 새 아이템을 만들지 않는다.
6. 메인은 **등급 샘플을 스폰하지 않는다.** 메인 스폰물은 카트리지·퀘스트 전용 샘플이다. C/B/A 등급 샘플은 반복 슬롯이 담당한다 (`01` §2.0).

**Day 언락은 경과 기준이다** (`09` §1). Day1을 실패해도 Day2에 M02가, Day2를 실패해도 Day3에 M03이 열린다.

### 1.1 수치

**성공**

| 슬롯 | 점수 구성 | 점수 | ₡ 구성 | ₡ | 호감도 |
|---|---|---:|---|---:|---:|
| M01 (Day1) | C 상당 회수 ×2 (`05` S+12) | **+140** | 회수 C Intact ×2 (`07`) | **160₡** | **+0.4** |
| M02 (Day2) | B 상당 회수 +140 · 청소 계약 +80 (S+12·S+15) | **+220** | 회수 B 160 · 청소 계약 120 | **280₡** | **+0.5** |
| M03a (Day3) | 페이즈 — 점수·₡ 없음 | 0 | 0 | **0₡** | **+0.2** |
| M03b (Day3) | A 상당 Intact (S+12) | **+220** | 회수 A 280 · 냉각 회로 수리 60 | **340₡** | **+0.3** |
| **3일 완주 합** | | **+580** | | **780₡** | **+1.4** |

Day별 호감도는 **+0.4 / +0.5 / +0.5**다. Day3가 두 페이즈로 쪼개져 있을 뿐, 하루 몫은 Day2와 같다.

**실패**

| 슬롯 | 미회수 점수 | 미회수 호감도 | 파괴 점수 | 파괴 호감도 |
|---|---:|---:|---:|---:|
| M01 | **−45** | **−0.4** | — (카트리지는 파괴 상태 없음) | — |
| M02 | **−55** | **−0.5** | — (카트리지는 파괴 상태 없음) | — |
| M03a | 0 | **−0.2** | — | — |
| M03b | **−55** | **−0.3** | **−130** | **−0.6** |
| **최악** | **−155** | **−1.4** | 파괴 포함 **−230** | 파괴 포함 **−1.7** |

- 크레딧 위약금은 없다 (`07` §1.2 M−02 삭제). 실패는 점수·호감도만 깎는다.
- **파괴 실패는 메인 라인에서 M03b 하나뿐이다.** 카트리지는 깨지지 않는다. Day3의 긴장이 "등급이 높아서"가 아니라 "유일하게 깨질 수 있는 목표"에서 나온다.
- 호감도는 등급이 아니라 **슬롯**에 붙는다 (`09` §1.5). 미회수 = −(성공값), 파괴 = −2×(성공값)이라는 기존 비율은 그대로 유지한다.
- 3일 총합 +1.4 / 780₡은 **구 메인 라인과 동일하게 고정**했다. `07`의 일일 기대 순수입(800~1400₡)과 `02` §7 호감도 티어(+2.0 / −2.0) 도달 속도를 건드리지 않기 위한 제약이다.
- 점수 총합은 +580으로 구 라인(+610) 대비 **−30(−5%)**. `05` X-7 목표치를 재계산할 정도는 아니지만 검토 항목으로 남긴다.

## 4. X7-M02 — 전력 복구 (Day 2)

발주: "전력 올리고 통제실 백업 가져와."

### 완료 조건
연구 데이터 카트리지 **1개**를 브릭스에게 납품.

### 플레이어 행동

1. **09 전력실** 배선반. 따개비가 단자를 덮고 있다 → **헤라로 먼저** 뗀다. 떼기 전에는 테이프가 먹지 않는다.
2. 침수 때 이미 끊긴 전선 **2노드** → **절연테이프**. 플레이어가 잘못 잘라서 고치는 사고가 아니다. 퀘스트가 테이프를 쓰게 만든다.
3. 전력 ON → 통제실 **전자문** 잠금 해제.
4. 컴퓨터 Hold 덤프 → 카트리지 스폰 → 모선에서 브릭스 납품.

### 규칙
- 배선반 따개비 → 테이프 순서를 강제한다.
- 09는 내력·붕괴 구간이다 (`02 X-7 레벨 배치`). 기믹은 따개비·전선에만 걸고, 천장 리스크는 기존 절단 규칙을 그대로 쓴다.
- 테이프는 상점 45₡ (`08` IT-T1). 시작 지급이 아니다. **Day1 수입으로 사 가야 한다** — Day2가 첫 "구매 게이트"인 이유다.
- 통제실 칸막이 철거는 로어용 우회 경로로 남긴다. 컴퓨터만 전원이 필요하다.
- 테이프 없이 Day2에 들어가면 M02를 깰 수 없다. 대출(`07` §5, 기본 한도 800₡)로도 살 수 있으니 하드 락은 아니다.

### 대사
| | 텍스트 |
|---|---|
| 발주처 | "전력 올리고 통제실 백업 가져와." |
| 브릭스 | "불 켜고 자료만. 서류는 너희가 알아서 읽어." |

## 5. X7-M03 — 격리 대조 샘플 (연계)

메인 라인 3번은 **한 퀘스트, 두 페이즈**이며 **둘 다 Day3에서만 진행한다.**
`RequiredCount` 2. 카드 확보 = 1/2. 샘플 납품 = 2/2 = Completed.

하루에 폼건 밀봉 → 지지+내력 절단 → 냉각 수리 → 캐비닛 개방 → 납품을 다 해야 한다. **Day3는 시간이 제일 빡빡한 날이다** — 플레이테스트에서 가장 먼저 확인할 지점이다.

A는 **활성 배양**, B는 **대조·사멸**이다. 메인은 그 한 줄만 쓴다. 격리 실패의 자세한 이야기는 로어다.

### 5.1 3-1 — 격리 A 바깥 (Day 3)

**Day3 시작 시** 열린다. M02 완료를 조건으로 걸지 않는다. 발주 시점에는 A만 가리킨다. B는 말하지 않는다.

| 항목 | 내용 |
|---|---|
| 위치 | 격리 실험실 A **출입구 바깥** |
| 기믹 | 노출 배관이 탈출 블룸에 찢김 → **오염수 분출** (`02` §2.4). 출입구를 가로막음 |
| 도구 | **폼건** 밀봉. Niagara 정지, HP 위험 볼륨 제거 |
| 보상 오브젝트 | 연구자가 놓고 간 **B 캐비닛 카드** |
| 인벤 | **차지 없음.** 퀘스트 플래그. 사망해도 유지 |
| 소멸 | **당일 18:00 정산 시 플래그 소멸** (§6). Day3가 계약 마지막 날이므로 실질적으로 그 계약이 끝난다 |
| 이 단계에서 안 하는 것 | A 내부 진입 (반복 슬롯 X7-R10 자리) |

카드는 오염수 뒤에 있다. 막기 전에는 집을 수 없다.

브릭스에게 카드를 보여 주면 3-1이 완료되고 **같은 날 바로 3-2가 열린다.** ₡·점수는 없고 **호감도 +0.2만** 들어간다.

**브릭스:** "그거 B 캐비닛 키야. 문은 나갔고 냉각도 죽었다. 지지 박고 들어가. 샘플은 깨지지 않게."

| 납품 | 브릭스 직접. 분류장 아님. 이때 정산 |

### 5.3 실패
| 상황 | 처리 |
|---|---|
| 3-1을 못 깬 채 18:00 | 미회수. 점수 0, 호감도 −0.2. 3-2는 열리지 않았으므로 **−0.3도 함께 물린다** (Accepted 되지 못한 페이즈가 아니라 미완 라인 전체를 실패로 본다) |

| 고온 캐비닛 강제 개방 | 샘플 파괴. 점수 −130, 호감도 −0.6. **당일 재시도 불가** |

## 6. 메인 이월 금지 · 연계의 Day 배치

프레임워크 규칙은 `09` §1.5. 여기서는 X-7 적용만 쓴다.

### 6.1 이월 금지 (메인 한정)

**이 절은 메인에만 적용된다.** 반복 퀘스트는 계약 3일 내내 상태가 유지되고 계약 종료에 한 번 마감한다 (`09` §1.5, `01` §3).

| 항목 | 규칙 |
|---|---|
| 18:00 정산 | Accepted 상태로 미완인 메인은 **그날 Failed로 확정**한다. 호감도 델타 즉시 반영 |
| 다음날 이어받기 | **없다.** Accepted가 Day를 넘어 유지되지 않는다 |
| 스폰물 | 미회수 카트리지·퀘스트 샘플은 18:00에 **디스폰**한다. 맵에 남겨 다음날 줍는 경로를 없앤다. (반복 슬롯의 등급 샘플은 해당 없음 — 계약 종료까지 남는다) |
| 진행 플래그 | M03a 카드 플래그도 18:00에 소멸한다 |
| Day 라인 | 실패와 **무관하게** 진행한다. M01 실패해도 Day2엔 M02가, M02 실패해도 Day3엔 M03이 열린다 |
| 재수락 | 같은 Day 안에서 Failed 후 재수락은 불가. 다음 계약에서 라인이 처음부터 다시 돈다 |

구 규칙 "M03 Accepted는 Day가 바뀌어도 유지된다(오늘 A, 내일 B)"는 **삭제한다.** M03이 메인으로 올라왔으므로 하루 안에서 끝나야 한다. "미회수 샘플은 맵에 남아 다음 Day에 재회수 가능"은 **반복 슬롯에서는 그대로 유효하다** — 메인 스폰물에만 디스폰이 걸린다.

**연계가 Day를 걸치지 않으므로 이월 금지와 부딪히는 지점이 없다.** 3-1·3-2가 같은 Day3 안에서 끝나기 때문에, 중간 플래그(카드)를 다음날로 넘길 필요 자체가 생기지 않는다.

### 6.2 연계는 Day를 걸치지 않는다

3-1과 3-2는 **둘 다 Day3 전용**이다. 이 배치가 이월 금지와 맞물리는 방식은 다음과 같다.

| 상황 | 처리 |
|---|---|
| Day1·Day2 실패 | Day3에 M03이 정상적으로 열린다. 선행 완료를 보지 않는다 |
| Day3 시작 | 3-1이 Offered. **M02 완료 여부와 무관** |
| 3-1 완료 | 같은 날 3-2가 Offered. 카드 플래그는 하루 안에서만 살아 있으면 된다 |
| 3-1 미완으로 18:00 | 라인 전체 실패 (§5.3). 다음날로 넘길 카드가 애초에 없다 |
| 다음 계약 | 라인이 Day1부터 다시 돈다 |

v2에는 "M02를 깨야 3-1이 열린다 → 못 깼으면 Day3에 3-1·3-2를 압축해서 준다"는 분기가 있었다. **폐기했다.** 연계를 Day3에 몰아두면 그 분기가 필요 없어지고, Day 언락 규칙에 예외가 하나도 남지 않는다 (`09` §1).

대가는 **Day3의 밀도**다. 폼건 밀봉 → 지지+절단 → 냉각 수리 → 개방 → 납품이 하루에 들어간다. 시간이 모자라면 3-1 보상(+0.2)만 챙기고 3-2를 놓치는 결과가 정상적인 실패 경로다.

## 7. 구현 메모

현재 `FMD_RepeatQuestState`는 단계가 없다. Offered → Accepted → Completed/Failed와 `CurrentProgress`만 있다. 메인 라인도 같은 구조를 쓴다.

| 항목 | 규칙 |
|---|---|
| M03 슬롯 | 퀘스트 종류를 새로 만들지 않는다. **같은 슬롯의 페이즈**로 간다 |
| Progress | 카드 플래그 = 1 / 샘플 납품 = 2 = Completed |
| 카드 확인 | Completed로 올리지 않는다. 브릭스 상호작용으로 페이즈만 전환하고 호감도 +0.2를 지급 |
| 카드 전달 대상 | 모선 분류장이 아니라 **브릭스** |
| 카드 표현 | 핫바·손 슬롯 없음. HUD 퀘스트 위젯에만 "격리 B 캐비닛 카드" |
| 고온 볼륨 | `02` §2.4 오염수 DoT 재사용. FX만 고온 |
| 테이프 노드 | 조명 복구와 별도. "냉각 회로" 태그 |
| 캐비닛 조건 | `bHasCard && bCoolingRestored` |
| Day 언락 | `CurrentDay`만 본다. 선행 완료를 보지 않는다. **예외 없음** |
| 3-2 언락 | `M03a == Completed`. 같은 Day 안에서만 성립하므로 Day 경계 처리가 필요 없다 |
| 18:00 정산 | Accepted 메인을 순회해 Failed 확정 + 호감도 델타 적용 + 스폰물·플래그 디스폰 |

M01·M02는 페이즈 없이 `RequiredCount`만 쓴다.

## 10. 개발 우선순위

1. Day 언락을 **경과 기준**으로 변경 + 18:00 이월 금지 정산 (`09` §1.5). 이게 선행이다.
2. M03 페이즈 + 브릭스 중간 상호작용. 카드 플래그. **둘 다 Day3 전용이므로 Day 경계 로직은 없다.**
3. M02 전력 노드·전자문·카트리지.
4. M03 오염수 배관, 고온 볼륨(오염수 DoT 재사용), 캐비닛 게이트.
5. M01 랙 3종 기믹.
6. `02 X-7 레벨 배치`에 §8 소품·방을 반영.
7. 반복 풀(`01` §3) 강등 3종은 기존 사양 그대로 재사용. 구현은 메인 3종 다음.
