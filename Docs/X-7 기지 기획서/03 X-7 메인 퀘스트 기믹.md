## 0. 설계 원칙

1. 완료 조건은 **회수 1~2개**다. 개수는 `RequiredCount`로 돌아간다.
2. 청소·철거·수리는 목표가 아니라 **꺼내기 위한 기믹**이다. "오염물 N개 제거" 같은 1차원 청소 계약은 메인 라인에 넣지 않는다.
3. 난이도 곡선을 **샘플 등급이 아니라 필요한 작업 단계 수**로 표현한다. Day1 도구 2종(헤라 + 테이프) → Day2 도구 2종(**전부 시작 지급**) → Day3 도구 3종 + 순서 강제. (구 라인은 C→B→A 등급으로 표현했다. 등급별 샘플 회수은 반복 풀로 넘겼다 — `01` §3)

   > **⚠ v6 순서 교체의 대가 — Day1↔Day2 곡선 역전.**
   > 필요한 작업 단계 수는 **Day1 4단계**(따개비 헤라 → 테이프 2노드 → 전자문 → 컴퓨터 덤프)로 **Day2 2단계**(랙 3 중 2)보다 많고, 구매도 Day1에만 걸린다. 순서를 뒤집으면 이 역전은 피할 수 없다.
   > **완화책 두 가지를 배치로 잡는다.** ① Day1은 **09 전력실 → 02 통제실, 1F 단층**이라 동선이 가장 짧다 — 단계는 많아도 이동이 없다. ② Day2는 **하부 해치 하강 학습 + 랙 3 중 2 병렬 선택**이라 단계 수는 적어도 새 공간·새 선택이 들어온다.
   > 최종 곡선은 **단계 수가 아니라 동선·공간**으로 오른다: 1F 단층 → B1 하강 → 1F↔B1 왕복(최장). Day3가 정점인 것은 그대로다.
4. 로어 오브젝트와 **물건을 나눈다.** 코덱스 엔트리를 메인 보상으로 주지 않는다.
   *(프레임워크상 같은 방을 써도 되지만, **X-7 실제 배치에서는 메인과 로어의 방 겹침이 0이다** — §2. 방을 나눌 수 있으면 나누는 쪽이 낫다.)*
5. 기믹은 기존 도구만 쓴다. 헤라, 절단기, 스캐너, 지지대, 절연테이프, 폼건. 새 아이템을 만들지 않는다.
6. 메인은 **등급 샘플을 스폰하지 않는다.** 메인 스폰물은 카트리지·퀘스트 전용 샘플이다. C/B/A 등급 샘플은 반복 슬롯이 담당한다 (`01` §2.2).

**연계는 Day3 안에서만 돈다.** 3-1 → 3-2를 하루에 이어서 진행한다. Day를 걸치지 않으므로 이월 금지(§6)와 충돌하는 지점이 없고, 압축·복구 분기도 필요하지 않다.

### 1.1 수치

**성공**

**수치는 퀘스트가 아니라 Day 슬롯에 붙는다.** v6에서 순서를 뒤집을 때 수치는 따라 움직이지 않았다 — Day1 몫은 Day1에 남고, 그 자리에 들어온 전력 복구가 Day1 몫을 받는다. 3일 합(+580 / 780₡ / +1.4)이 구 라인과 **완전히 동일**하게 유지되고, 보상 곡선도 Day1 → Day2로 오르는 형태를 지킨다.

| 슬롯 | 점수 구성 | 점수 | ₡ 구성 | ₡ | 호감도 |
|---|---|---:|---|---:|---:|
| Day1 = 전력 복구 (X7-M02) | B 상당 회수 ×1 (`05` S+12) | **+140** | 회수 B Intact 160 (`07`) | **160₡** | **+0.4** |
| Day2 = 통신 기록 (X7-M01) | C 상당 회수 ×2 +140 · 청소 계약 +80 (S+12·S+15) | **+220** | 회수 C Intact ×2 = 160 · 청소 계약 120 | **280₡** | **+0.5** |
| M03a (Day3) | 페이즈 — 점수·₡ 없음 | 0 | 0 | **0₡** | **+0.2** |
| M03b (Day3) | A 상당 Intact (S+12) | **+220** | 회수 A 280 · **냉각펌프 수리** 60 | **340₡** | **+0.3** |
| **3일 완주 합** | | **+580** | | **780₡** | **+1.4** |

**구성 재계산 근거 (v6).** 단가는 `05` S+12(회수 C 70 / B 140 / A 220)·S+15(청소 계약 +80)와 `07`(회수 C 80₡ / B 160₡ / A 280₡ · 청소 계약 120₡)에서 그대로 가져왔다. **새 단가를 만들지 않았다.**

- **Day1 전력 복구 = 회수 B 상당 ×1 단독.** 카트리지가 1개뿐이므로 B 등급 단가 하나로 140점 / 160₡가 정확히 맞는다. 구 M02에 붙어 있던 청소 계약분 80점 / 120₡는 **떼어냈다** — 배선 복구는 보상 항목이 아니라 "꺼내기 위한 기믹"이고(§0.2), 이쪽이 원칙에 더 맞다.
- **Day2 통신 기록 = 회수 C 상당 ×2 + 청소 계약분.** 카트리지 2개로는 140점 / 160₡까지밖에 안 나오므로, 떼어낸 청소 계약분을 **여기로 옮겼다.** 계상 대상은 **랙 전면 오염·따개비 제거 기믹**(§4 랙 1)이다.
  **별도 완료 조건이 아니다.** 완료 조건은 여전히 카트리지 2개뿐이고, "오염물 N개 제거" 같은 서브목표를 추가하지 않는다(§0.2). 구 M02가 전력 복구를 청소 계약분으로 계상했던 것과 같은 처리다.

Day별 호감도는 **+0.4 / +0.5 / +0.5**다. Day3가 두 페이즈로 쪼개져 있을 뿐, 하루 몫은 Day2와 같다.

**실패**

**실패도 Day 슬롯에 붙는다.** 값은 구 라인과 동일하다 — 어느 퀘스트가 그 자리에 있든 Day1은 −45/−0.4, Day2는 −55/−0.5다.

| 슬롯 | 미회수 점수 | 미회수 호감도 | 파괴 점수 | 파괴 호감도 |
|---|---:|---:|---:|---:|
| Day1 = 전력 복구 | **−45** | **−0.4** | — (카트리지는 파괴 상태 없음) | — |
| Day2 = 통신 기록 | **−55** | **−0.5** | — (카트리지는 파괴 상태 없음) | — |
| M03a | 0 | **−0.2** | — | — |
| M03b | **−55** | **−0.3** | **−130** | **−0.6** |
| **최악** | **−155** | **−1.4** | 파괴 포함 **−230** | 파괴 포함 **−1.7** |

- 크레딧 위약금은 없다 (`07` §1.2 M−02 삭제). 실패는 점수·호감도만 깎는다.
- **파괴 실패는 메인 라인에서 M03b 하나뿐이다.** 카트리지는 깨지지 않는다. Day3의 긴장이 "등급이 높아서"가 아니라 "유일하게 깨질 수 있는 목표"에서 나온다.
- 호감도는 등급이 아니라 **슬롯**에 붙는다 (`09` §1.5). 미회수 = −(성공값), 파괴 = −2×(성공값)이라는 기존 비율은 그대로 유지한다.
- 3일 총합 +1.4 / 780₡은 **구 메인 라인과 동일하게 고정**했다. `07`의 일일 기대 순수입(800~1400₡)과 `02` §7 호감도 티어(+2.0 / −2.0) 도달 속도를 건드리지 않기 위한 제약이다.
- 점수 총합은 +580으로 구 라인(+610) 대비 **−30(−5%)**. `05` X-7 목표치를 재계산할 정도는 아니지만 검토 항목으로 남긴다.

## 2. 로어와의 자리 나누기

**v5 갱신 — 공식 도면 기준.** 방 이름은 `02 X-7 레벨 배치` v6이 기준 문서이고, 구 방 번호 대응표는 `02` §6이다. 로어 기준 문서은 `04`에서 **`06 X-7 로어 폴리싱`**으로 이관됐다.

**메인은 로어와 방을 공유하지 않는다.** 메인은 필수 동선이라 로어가 공짜로 걸리면 탐험이 아니게 된다. 신 배치에서 **겹침은 0**이다.

| 메인 슬롯 | 방 | 같은 방의 로어 | 같은 방의 반복 |
|---|---|---|---|
| Day1 = 전력 복구 (M02) | **09 전력실 → 02 통제실** | 없음 | 없음 |
| Day2 = 통신 기록 (M01) | **B1-06 통신/서버실** | 없음 | 없음 |
| M03a | **05 격리 실험실 A 바깥** | 없음 | 없음 |
| M03b | **B1-04 격리 B ↔ B1-05 냉각 시스템실** | 없음 | **R05**(B1-05 **부속 구획**) — M03b가 쓰는 **주 구획(압축기)은 상시 개방**이라 R05 수행 여부와 무관하다 (`02` §4.2) |

**구 §2에서 무효가 된 문구**

| 구 문구 | 처리 |
|---|---|
| "09 통제실에 로어 L02(서류함 태블릿)" | 무효. 통제실은 **02**이고 로어가 없다. L02는 **04 표본 분석실**로 이동 |
| "07 통신실에 로어 L03(무전기)" | 무효. 통신/서버실은 **B1-06**이고 로어가 없다. 무전기 로어는 **땅굴 L07**로 이동 |

## 3. 메인 1 — 전력 복구 (Day 1) · ID `X7-M02`

### 완료 조건

### 플레이어 행동

4. 컴퓨터 Hold 덤프 → 카트리지 스폰 → 모선에서 브릭스 납품.

### 규칙

- **통제실 칸막이 철거 우회로는 유지한다.** 전원은 **카트리지 단말에만** 걸린다. 전력 복구 실패가 방 진입 자체를 막으면 안 된다.

테이프는 상점 **45₡** (`08` IT-T1)이고 시작 지급이 아니다. **Day1 착수금 500₡으로 출발 전에 사 간다** (`07` §2.3).

## 6. 메인 이월 금지 · 연계의 Day 배치

프레임워크 규칙은 `09` §1.5. 여기서는 X-7 적용만 쓴다.

### 6.1 이월 금지 (메인 한정)

**이 절은 메인에만 적용된다.** 반복 퀘스트는 비상일을 포함해 계약 종료까지 유지하고 실제 종료 때 한 번 마감한다 (`09` §1.5, `01` §3).

| 항목 | 규칙 |
|---|---|
| 18:00 정산 | Accepted 상태로 미완인 메인은 **그날 Failed로 확정**한다. 호감도 변동값 즉시 반영 |
| 다음날 이어받기 | **없다.** Accepted가 Day를 넘어 유지되지 않는다 |
| 스폰물 | 미회수 카트리지·퀘스트 샘플은 18:00에 **디스폰**한다. 맵에 남겨 다음날 줍는 경로를 없앤다. (반복 슬롯의 등급 샘플은 해당 없음 — 계약 종료까지 남는다) |
| 진행 플래그 | M03a 카드 플래그도 18:00에 소멸한다 |
| Day 라인 | 실패와 **무관하게** 진행한다. Day1(전력) 실패해도 Day2엔 통신 기록이, Day2 실패해도 Day3엔 M03이 열린다 |
| 재수락 | 같은 Day 안에서 Failed 후 재수락은 불가. 다음 계약에서 라인이 처음부터 다시 돈다 |

구 규칙 "M03 Accepted는 Day가 바뀌어도 유지된다(오늘 A, 내일 B)"는 **삭제한다.** M03이 메인으로 올라왔으므로 하루 안에서 끝나야 한다. "미회수 샘플은 맵에 남아 다음 Day에 재회수 가능"은 **반복 슬롯에서는 그대로 유효하다** — 메인 스폰물에만 디스폰이 걸린다.

**연계가 Day를 걸치지 않으므로 이월 금지와 부딪히는 지점이 없다.** 3-1·3-2가 같은 Day3 안에서 끝나기 때문에, 중간 플래그(카드)를 다음날로 넘길 필요 자체가 생기지 않는다.

### 6.2 연계는 Day를 걸치지 않는다

3-1과 3-2는 **둘 다 Day3 전용**이다. 이 배치가 이월 금지와 맞물리는 방식은 다음과 같다.

| 상황 | 처리 |
|---|---|
| Day1·Day2 실패 | Day3에 M03이 정상적으로 열린다. 선행 완료를 보지 않는다 |
| Day3 시작 | 3-1이 Offered. **Day2 완료 여부와 무관** |
| 3-1 완료 | 같은 날 3-2가 Offered. 카드 플래그는 하루 안에서만 살아 있으면 된다 |
| 3-1 미완으로 18:00 | 라인 전체 실패 (§5.3). 다음날로 넘길 카드가 애초에 없다 |
| 다음 계약 | 라인이 Day1부터 다시 돈다 |

v2에는 "구 Day2 슬롯을 깨야 3-1이 열린다 → 못 깼으면 Day3에 3-1·3-2를 압축해서 준다"는 분기가 있었다. **폐기했다.** 연계를 Day3에 몰아두면 그 분기가 필요 없어지고, 날짜별 퀘스트 시작 규칙에 예외가 하나도 남지 않는다 (`09` §1).

대가는 **Day3의 밀도**다. 폼건 밀봉 → 지지+절단 → 냉각 수리 → 개방 → 납품이 하루에 들어간다. 시간이 모자라면 3-1 보상(+0.2)만 챙기고 3-2를 놓치는 결과가 정상적인 실패 경로다.

## 7. 구현 메모

현재 `FMD_RepeatQuestState`는 단계가 없다. Offered → Accepted → Completed/Failed와 `CurrentProgress`만 있다. 메인 라인도 같은 구조를 쓴다.

| 항목 | 규칙 |
|---|---|
| M03 슬롯 | 퀘스트 종류를 새로 만들지 않는다. **같은 슬롯의 페이즈**로 간다 |
| Progress | 카드 플래그 = 1 / 샘플 납품 = 2 = Completed |
| 카드 확인 | Completed로 올리지 않는다. 브릭스 상호작용으로 페이즈만 전환하고 호감도 +0.2를 지급 |
| 카드 전달 대상 | 분리 5칸이 아니라 **브릭스** |
| 카드 표현 | 핫바·손 슬롯 없음. HUD 퀘스트 위젯에만 "격리 B 캐비닛 카드" |
| 격리실 B 데미지존 | `AMD_CoolingHazardZone` 박스 트리거. `CoolingPump`에 배치한 펌프 지정. 진입 즉시 피해 + 초당 8 피해, 수리 후 피해 중단 |
| **냉각펌프** | `AMD_CoolingPump`. 시작 고장, 폼건 수리, `ContaminatedWaterFX` 상태 연동. 파괴 가능한 벽 탐지는 사용하지 않으며 `IsCoolingRestored()`로 격리실 B 데미지존·캐비닛 냉각 조건을 조회 |
| 캐비닛 조건 | `bHasCard && bCoolingRestored` |
| 날짜별 퀘스트 시작 | `CurrentDay`만 본다. 선행 완료를 보지 않는다. **예외 없음** |
| 3-2 언락 | `M03a == Completed`. 같은 Day 안에서만 성립하므로 Day 경계 처리가 필요 없다 |
| 18:00 정산 | Accepted 메인을 순회해 Failed 확정 + 호감도 변동값 적용 + 스폰물·플래그 디스폰 |

X7-M01·X7-M02는 페이즈 없이 `RequiredCount`만 쓴다.

### 7.1 v6 순서 교체 — 데이터 쪽에서 고칠 것

에셋은 이미 있다: `Content/Data/Quest/X7/Main/X7-M01.uasset`(통신) · `X7-M02.uasset`(전력) · `X7-M03.uasset`.

| 항목 | 처리 |
|---|---|
| **에셋 이름·QuestId** | **바꾸지 않는다.** 리네임하면 `DA_Site_X7`을 비롯한 참조를 전부 갱신해야 하고, 얻는 것은 "슬롯 번호와 숫자가 맞는다"뿐이다 |

| M03b 도구 | 요구 아이템에서 **절연테이프 제거, 폼건 추가** |

## 10. 개발 우선순위

1. 날짜별 퀘스트 시작을 **경과 기준**으로 변경 + 18:00 이월 금지 정산 (`09` §1.5). 이게 선행이다.
2. **데이터 에셋 Day·보상 필드 교체 + 목록 정렬 키를 Day로** (§7.1). 순서 교체의 실체는 이것뿐이라 제일 싸고, 먼저 넣어야 아래 순서가 맞는다.
3. **Day1 = 전력 노드·전자문·카트리지** (구 3순위에서 승격).
4. M03 페이즈 + 브릭스 중간 상호작용. 카드 플래그. **둘 다 Day3 전용이므로 Day 경계 로직은 없다.**
5. M03a 오염수 배관, M03b **냉각펌프·분출 VFX·격리실 B 데미지존**, 캐비닛 개방 조건.
6. **Day2 = 랙 3종 기믹.**
7. `02 X-7 레벨 배치`에 §8 소품·방을 반영.
8. 반복 풀(`01` §3) 강등 3종은 기존 사양 그대로 재사용. 구현은 메인 3종 다음.
