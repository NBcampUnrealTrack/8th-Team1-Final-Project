## 0. 원칙

1. **완료 = 기록물 조사 1회.** 
2. **운반 없음.** 조사 즉시 코덱스 등록, 오브젝트 소멸.
3. **접근만 기믹.** 헤라·철거·수영 등은 “꺼내기 위한 막힘”이지 목표가 아니다.
4. **반복퀘와 물건을 나눈다.** 같은 방을 써도 되지만, 코덱스 대상(서류함·무전기 등)을 반복퀘 납품물로 쓰지 않는다.
5. **발견 순서는 자유.** 배열 순서 = 코덱스 읽는 순서. **X7-L07만** 암호화(L01~L06 선행).
6. **답을 다 주지 않는다.** X-7은 최초 발견·격리 실패·일정 압박·외부 확산 단서까지. 상부 지시·블룸 기원은 이후 현장.

## 2. 개별 본문

### X7-L01 — 초기 연구 로그
- **위치:** 04·05·06 생물실험동, 실험대 위 데이터 코어  
- **접근:** 코어 표면 오염물 덮개 → 헤라로 긁어 노출 후 조사  
- **대상:** 데이터 코어  
- **역할:** 블룸 최초 발견·명명  
- **본문:** 샘플 명칭을 ‘그레이 블룸’으로 등록. 저온·고압에서만 표면 성장. 현장 별칭(때·따개비)과 동일 물질로 추정. 구조 부식 가속은 별도 보고 예정. — 연구일지 #001

### X7-L02 — 격리 프로토콜 초안
- **위치:** 09 전력·정비 구역, 통제실 서류함(서류함 안에 있을 필요는 없음)  
- **접근:** 지정 문 개방로만 진입  
- **대상:** 서류함(태블릿). 전원 불필요 — 반복퀘 전력 루트와 독립.  
- **역할:** 격리 절차 + 일정·승인 삐걱  
- **본문:** 격리 B→C 전환 초안. 배양 라인 추가 반입 시 재검증 필수. 손메모: ‘일정 조정 건 — 승인 회신 전까지 보류?’ — 통제실 초안 rev.0.4

### X7-L03 — 대피 당시 무전 기록
- **위치:** 07 인근 통신실 무전기  
- **접근:** 없음 — 통신실 진입 후 바로 조사  
- **대상:** 무전기 (반복퀘 서버 카트리지와 별개)  
- **역할:** 사고 당일 대피 — 업무 혼란 톤  
- **본문:** …압력 이상. 배양 쪽 경보. 대피선으로. 물자 담당은? — 이미 나갔대. 기록은 나중에. — 통신 로그 손상

### X7-L04 — 물자 담당자의 메모
- **위치:** 07 저장고, 보급 상자 더미  
- **접근:** 가림 쓰레기 치워 상자 노출 후 조사  
- **대상:** 상자 속 손메모  
- **역할:** N.B. = 브릭스 첫 흔적. 확정 증거는 아님 (`소설화/00` §6)  
- **본문:** 물자 재고 확인 완료. B동 보급 일정 조정 필요. — N.B.

### X7-L05 — 승인되지 않은 실험 기록
- **위치:** B1 심층(배양~냉각), 벽 안 은폐   
- **접근:** 벽을 철거하면 로어가 벽조각과 함께 로어가 나옴 (스캐너는 선택 힌트, 필수 아님)  
- **대상:** 은폐 데이터 코어  
- **역할:** 공식에 없는 후속 실험. 기원 단정 금지  
- **본문:** 공식 배양 로그 외 부가 런. 서명란 공란. ‘선행 반입분과 병합 시험’ 한 줄. 첨부 손상. — 비공식 코어 덤프

### X7-L06 — 블룸 채집 기록 (외부)
- **위치:** 침몰 잔해 지대, 부유하는 채집통  
- **접근:** 수영으로만 닿는 부유 오브젝트 (접지 불가)  
- **대상:** 채집통 태그  
- **역할:** 기지 밖 해양에도 동일 물질  
- **본문:** 외벽 채집 포인트 3. 표류 유기막 동일 스펙트럼. ‘시설 내부 한정’ 가설과 불일치. — 채집 태그

### X7-L07 — 심해 신호 기록 (내부 · 종합)
- **위치:** 화학 합성실 — 눈에 잘 띄는 곳 (숨기지 않음)  
- **접근:** 없음. 방만 들어가면 바로 조사. 내용이 암호화라서 위치 기믹은 필요 없다.  
- **대상:** 신호 기록 단말기(또는 비콘 수신기 단말)  
- **역할:** X-7 단서 묶음. 확산이 이상하다 → 다음 현장  
- **암호화 중:** UI “암호화됨”, 본문 숨김

## 4. 브릭스 대면 선택 (계약 마지막 날 종료 시)

### 개발 범위 (중요)
이 분기의 **플레이 가능한 결과물은 X-7 계약 끝~다음 근거리 현장(예: TR-9) 초입**까지로 잡는다.  
케른 스파·상부 폭로는 개발 템포상 **지금 구현하지 않는다.** 플래그만 남기고, 나중에 붙일 수 있게만 한다.

### 트리거
선택지는 **7/7만으로 즉시 뜨지 않는다.** 아래를 **동시에** 만족할 때만 등장한다.

| 필수 | 내용 |
|---|---|
| 코덱스 | 세션(합집합) 기준 **X-7 7/7** |
| 시점 | 이 계약의 **Day3 종료** 정산/복귀 흐름, 또는 Day3 점검 실패 후 들어간 **비상 Day4 종료** 정산/복귀 흐름 |

- Day1·Day2 종료, 모선 일상 대화, 7/7 직후 임의 대화 → **선택지 없음** (코덱스 열람만).
- 7/7이 안 된 채 Day3(또는 비상 Day4)가 끝나면 → 선택지 없음. 다음 X-7 재계약의 같은 종료 시점까지 미룸.
- **플래그 한 번.** `ToldBriggsAboutX7` = `Told` / `Withheld` / `None` / `ToldLate` (§6.6 로컬 반영).
- 꺼내는 내용: **N.B. 메모·일정 압박·비공식 실험**까지. 상부·블룸 기원·케른은 말하지 않는다.

### 선택지 (이분법만)

| ID | 선택 | 플레이어 톤 (예) |
|---|---|---|
| A | **알린다** | “이 메모… N.B. 맞지?” |
| B | **알리지 않는다** | 코덱스는 덮어 두고 평소처럼 계약만 |

제3 선택 없음.

### 공통 규칙
1. 브릭스는 **무너지거나 자백하지 않는다** (`06` §4).
2. **₡·점수 보상/처벌 없음.**
3. 메인 루프(점검·상점 공식)는 동일.
4. 케른 언락·힌트는 **이 문서 범위 밖** (플래그만 보존).

---

### A — 알린다 (`Told`)

**즉시 (X-7 모선)**  
“…알아서 뭐 하게.” / “그건 네 일 아냐. 다음 목록이나 봐.”

| 항목 | 근거리 결과 (지금 만들 것) |
|---|---|
| 관계 | **거리감** 플래그. 이후 X-7/모선 잡담이 짧아짐 |
| 상점 | 변화 없음 (할인으로 보상하지 않음) |
| 다음 계약 | 다음 현장(TR-9 등) 브리핑에 **한 줄만** 달라짐. 예: “보급 쪽 서류가 꼬인 현장이라더라. …너는 이미 알 만하지.” — 내용 스포 없이 톤만 |
| 근거리 로어 | TR-9 등에서 N.B./보급 흔적을 주우면, `Told`일 때 팀 반응·브릭스 짧은 대사가 **이미 들킨 사이**로 읽힘 |

읽는 느낌: 선을 넘김 → 관계가 얇아지고, 다음 현장이 **조금 더 개인적**으로 들린다.

---

### B — 알리지 않는다 (`Withheld`)

**즉시**  
평소 계약 창. 코덱스 이야기 없음.

| 항목 | 근거리 결과 (지금 만들 것) |
|---|---|
| 관계 | 유지. (선택) “X-7 자료 잘 챙겼더라” 한 줄 |
| 상점 | 변화 없음 |
| 다음 계약 | 브리핑은 **평소 톤** 그대로 |
| 재선택 창 | **다음 현장 출발 전** 또는 **X-7 계약 완전 종료 시** 한 번 더: “그때 말을 안 했는데… 지금 보여 줄까?” → `Told`로 전환 가능 (**늦춘 정직**). 대사 예: “…지금까지 말 안 했구나.” |

읽는 느낌: 보류·보호. 벌주지 않음. 페이오프는 “언제 말했는가”의 온도 차.

---

### 분기 요약 (프로토 범위)

| | A 알린다 | B 알리지 않는다 |
|---|---|---|
| 모선 톤 | 거리감 | 유지 |
| 다음 현장 브리핑 | 한 줄 개인 톤 | 평소 |
| 재선택 | 없음 | 계약 종료/다음 출발 전 1회 |
| 케른 | 미구현 · 플래그만 남김 | 동일 |

### 나중에(케른) 붙일 자리
`Told` / `Withheld` / `ToldLate`(늦춘 정직)만 구분되면, 케른 대면 대사는 그때 가서 쓰면 된다. **지금 할 일 아님.**

## 6. 멀티플레이 규칙 (확정)

로어는 **세션 안에서는 합집합으로 공유**, **디스크에는 직접 집은 사람만** 남긴다.  
남의 로어가 합쳐졌다고 내 세이브에 복사되지 않는다.

### 6.1 수집 (세션 중)
| 항목 | 규칙 |
|---|---|
| 누가 집나 | **아무 플레이어나** 조사 1회 |
| 세션 | 원장에 등록 · 오브젝트는 **전원에게** 소멸 |
| 로컬 | **조사한 그 플레이어**의 세이브에만 해당 LoreId 추가 |
| 중복 | 세션 원장에 이미 있으면 다시 조사 불가 |
| 알림 | 전원을 향해 짧은 토스트 |

### 6.2 코덱스 UI (세션 중)
| 항목 | 규칙 |
|---|---|
| 내용 | 전원 **같은 목록** (= 세션 합집합). 열람만 공유, 소유권 이전 아님 |
| 완성률 | 세션 N/7 (로컬 N/7과 다를 수 있음) |

### 6.3 브릭스 선택 (알린다 / 알리지 않는다)
투표 UI는 **프로토에 두지 않는다.**

| 항목 | 규칙 |
|---|---|
| 언제 | §4 — **Day3 종료** 또는 **비상 Day4 종료** + **세션** 7/7 |
| 개시 | 해당 종료 흐름에서 선택 UI |
| 결정권 | 그 화면 조작 플레이어가 A/B · 세션 페이오프는 전원 |
| 로컬 | **선택을 확정한 플레이어**만 `ToldBriggsAboutX7` 기록. 동석자 로컬에는 안 씀 |

### 6.4 하지 않는 것
- 세션 합집합을 전원 로컬에 통째로 복사  
- 세션 안에서 플레이어마다 다른 코덱스 표시  
- 로어를 손·쓰레기통에 넣어 독점

### 6.5 애매했던 지점 → 답
| 질문 | 답 |
|---|---|
| 로어퀘가 누구에게 뜨나? | 맵 고정물. 누구든 조사 → 세션 코덱스 |
| 누가 저장되나? | **조사한 사람만** 로컬. 합집합 ≠ 저장 |
| 브릭스 선택은 언제? | **Day3 또는 비상 Day4 종료** + 세션 7/7 |
| 브릭스 플래그는? | 확정한 사람 로컬만 |
| 의견이 갈리면? | 보이스. 시스템 투표 없음 |

#### 모델
```
각자 로컬 ──합집합(읽기만)──▶ 세션 원장 ──세션 중 UI·맵──▶ 전원
                │
                │  새로 조사한 LoreId
                ▼
         조사자 로컬에만 append
```

| 단계 | 규칙 |
|---|---|
| **참가 시** | 참가자 로컬들의 **합집합**으로 세션 원장 시작 (판정·맵·UI만) |
| **세션 중 조사** | 세션 원장 += ID, **조사자 로컬만** += ID |
| **남이 이미 가진 ID** | 세션에 보이지만 **내 로컬에 복사되지 않음** |
| **맵 오브젝트** | 세션 원장에 있으면 전원에게 없음 (재조사 불가) |

#### 재시도 + 파티가 바뀐 경우
예: A가 L01·L02, B가 L03·L04를 집음 → 세션 4/7. 종료 후 로컬은 각자 것만.

| | |
|---|---|
| A 로컬 | L01, L02 |
| B 로컬 | L03, L04 |
| 다음 A+C | 세션 시작 = A∪C. B가 집었던 L03·L04는 **맵에 다시 있음** (A·C 로컬에 없으므로). C가 집으면 C 로컬에만 저장 |
| B 혼자/다른 방 | B는 여전히 L03·L04만. A의 것은 자동으로 안 생김 |

**의도:** 같이 두면 세션에서는 이어 보이지만, **영구 소유는 직접 획득분뿐.** 파티가 갈라지면 남의 진행은 가져가지 못한다.

#### `ToldBriggsAboutX7` 세션 판정
세션 7/7·선택 UI 조건은 **합집합**으로 본다.  
플래그 병합(이미 고른 사람이 방에 있을 때):

| 우선 | 값 |
|---|---|
| 1 | 참가자 로컬 중 `Told` / `Withheld` / `ToldLate` |
| 2 | `None` |

- 커밋이 하나면 세션에서 선택 UI 스킵.  
- Told vs Withheld 충돌 → **방장 로컬**.  
- **새로 고른 값**은 확정자 로컬에만 기록 (동석자 복사 없음).

#### 감수할 점
- 세션에서는 친구 코덱스를 같이 볼 수 있어도, 나가면 **내 로컬 개수**로 돌아간다.  
- 친구가 집은 칸은 그 세션에선 못 집으므로, 나중에 혼자/다른 파티로 가서 직접 집어야 내 세이브에 남는다.

#### 한 줄
**합집합 = 세션 판정만 / 로컬 = 직접 획득(·선택 확정)한 사람만.**
