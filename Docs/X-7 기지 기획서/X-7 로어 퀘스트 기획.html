3주 전에 07 벽에서 긁어온 회색 덩어리 말인데, 위에서 정식 명칭을 정하라고 내려왔다. 서류에 뭐라고 적을지 정하라는 뜻이다. 그래서 여기서 정했다. 회의실이 아니라 라운지에서, 커피 마시면서.

후보가 넷이었고 9대 3으로 '그레이 블룸'이 됐다. '회색 곰팡이'를 밀던 사람들은 아직도 억울해한다. 물자 담당이 커피 타러 들어왔다가 한 표 보태고 나갔는데, 본인은 뭘 뽑았는지도 모를 거다.

어차피 현장에서는 다들 그냥 '때'라고 부른다. 서류에만 그레이 블룸이다.

야간 교대는 배양 라인 점검 포함. 라인 D는 손대지 말 것. 이유는 배양 쪽에 물어봐라.

새로운 건 부식 계수입니다. 강재 시편 부식 속도가 대조군의 11.4배로 나왔습니다. 콘크리트는 6.8배입니다. 재측정을 두 번 했고 값은 흔들리지 않았습니다.

이 숫자를 어떻게 읽어야 하는지 적겠습니다. 우리가 지금 서 있는 격벽은 30년을 버티도록 설계됐습니다. 이 계수를 그대로 적용하면 3년이 안 됩니다. 그리고 이게 여기 몇 년째 붙어 있었는지는 아무도 모릅니다.

격리 등급을 B에서 C로 올려야 합니다. 배양 라인을 늘릴 계획이라면 전 라인을 다시 검증해야 합니다. 이건 권고가 아니라 요청입니다.

계통 해석 결과 · 대조 2군

결론부터 적는다. 계통도에 넣을 자리가 없다.

기존 심해 생물막 계통과 전부 대조했고 일치하는 게 없다. 근연군도 못 잡는다. 무기질 침착부와 생물막부의 대사 경로가 아예 따로 논다. 단일 종이라고 기술서에 쓸 수가 없다. 둘이 붙어 있는 건지 원래 그런 건지도 모르겠다.

그리고 이건 본문에 넣을지 고민하다 여기 적어 둔다.

X-7 7/7 후 그 세션 실패 → 다음에 X-7 재계약 클리어선택지. 코덱스는 로컬에 남으므로 다시 모을 필요 없다
왜 클리어에 묶는가. 계약을 무사히 끝낸 자리의 대화이기 때문이다. 정산이 끝나고 브릭스가 돌아서려는 순간이라는 장면이 있어야 "…뭐 더 있나?"가 성립한다.
왜 X-7에만 묶는가. X-7 자료를 X-7에서 막 들고 나온 자리여야 대화가 성립한다.

보류 상태 UI 힌트. 7/7인데 아직 선택하지 않았다면 코덱스 탭 헤더에 X-7 계약을 마치고 브릭스에게 보여줄 수 있습니다., 현장 선택 X-7 카드에 작은 표식 기록 보관함 완성. 느낌표·강조색은 쓰지 않는다 — 할 일 목록이 아니다.

06멀티플레이

한 명이 조사하면 팀원 전원의 로컬에 저장된다. 같이 플레이하면 같이 얻는다.

각자 로컬 ──교집합──▶ 맵 판정 (전원이 가진 것만 제거)
                          │
                          │  누군가 조사 1회
                          ▼
                  참가자 전원 로컬에 append
항목규칙
누가 집나아무 플레이어나 조사 1회
로컬참가자 전원의 세이브에 해당 LoreId 추가
맵 스폰참가자 교집합 판정 — 한 명이라도 미보유면 맵에 있다
코덱스 UI내 로컬 기준. 세션 중이든 아니든 같은 화면
완성률N/7 하나뿐. 세션 수치와 로컬 수치를 병기하지 않는다
참가 시아무것도 복사하지 않는다. 세션 중 새로 조사한 것만 전원에게 저장된다
알림전원을 향해 짧은 토스트
왜 맵 판정이 교집합인가. 구판(합집합 기준 제거)을 그대로 두면 신 규칙에 구멍이 생긴다 — 7/7인 A와 0개인 C가 같이 들어가면 맵에 로어가 하나도 없고 C는 아무것도 못 얻는다. 교집합으로 바꾸면 C가 없는 7개가 맵에 나오고, 누가 줍든 둘 다 저장된다.

부수 효과 — 친구 도와주기가 성립한다. 다 모은 사람이 안 모은 친구와 들어가면 로어가 다시 보이고, 한 번씩 조사해 주면 친구 코덱스가 채워진다.

파티가 바뀌면

예: A + B가 L01~L04를 집음. 누가 집었든 둘 다 4개를 갖고 나온다.

A 로컬L01~L04
B 로컬L01~L04 (같이 했으므로 동일)
다음 A + C (C는 0개)교집합 = ∅ → 7개 전부 맵에 있다. 조사하면 A·C 둘 다 저장 → 세션이 끝나면 A 7개 / C 7개
B 혼자여전히 4개. 나머지 3개는 직접 가거나 다른 파티와 가서 얻는다
경계선 — 방에 들어간 것만으로 받지는 않는다.
7/7인 A와 0개인 C가 만나도 C의 코덱스가 곧바로 7이 되지 않는다. 맵에 나온 7개를 실제로 조사해야 채워진다. "같이 플레이하면 같이 얻는다"이지 "같은 방에 있으면 받는다"가 아니다.

UI에서 사라진 것

"보이는 개수"와 "가진 개수"가 항상 같으므로 구분 표시가 전부 불필요해졌다.

삭제이유
기록물 5 / 7 · 내 기록 3 병기두 수치가 갈리지 않는다
카드 우상단 공유 표식소유가 갈리지 않는다
공유 툴팁 ("내 보관함에는 남지 않습니다")남는다
세션 종료 정산 내 보관함에 N건 추가세션 중 이미 들어갔다

UI가 줄어든 게 이 개정의 실익이다. 구판은 "왜 내 개수가 다른가"를 표식·툴팁·정산 문구 세 곳에서 계속 설명해야 했다.

대신 추가되는 것

이미 확보한 로어 조준프롬프트 F 조사 + 작게 이미 확보한 기록
그걸 조사했을 때확보 토스트는 미보유 팀원에게만. 조사자 본인에게는 안 띄운다
