## 1. 레벨이 전달해야 하는 경험

한 계약(3일) 동안 플레이어는 다음을 경험해야 한다.

1. 같은 기지를 사흘간 **이어서** 철거한다
2. 매일 08:00 투입, 18:00 전 모선 복귀한다
3. 섹터를 돌며 **청소와 철거**를 반복한다  
   (조각벽·오염물·따개비·각종 쓰레기 → 손 / **임시 쓰레기통** → 모선 분류)
4. 2·3일차 점검은 **점수**로 판정 (성공/경고+패널티, 필요 시 비상 4일차)
5. 어제 연 길이 오늘도 남아 있다는 누적감을 느낀다
6. 기지 ↔ 바다(모선)는 **레벨 스트리밍**으로 이동한다

레벨 디자인의 성공 기준:
- “긁을 더러움(오염·따개비)”과 “자를 벽”, “주울 쓰레기”가 풍부하다
- 내력벽을 보면 **천장 베이**가 떠오른다
- 폐기물 점수는 **모선 5종 분류**(금속/일반/플라스틱/오염/안탐)로 읽힌다
- Day1/2/3 작업 구역이 나뉜다
- “지금 복귀해야 하나?”를 시계가 가르친다
- 1층 **폐기물 대기장**에서 임시 쓰레기통을 무한 보급받을 수 있다
- 기지 **폐기물 잠재 점수 ≥ 1800** (`05` 배치 예산). 주력은 철거 조각, 산재는 보조

## 2. 공통 공간 모듈

| 모듈 | 기능 | 비고 |
|---|---|---|
| 해상 모선 | 상점, 대출, 난이도, 정산, 점검, **분류장(5종·색 코딩)** | 안전 허브 |
| 수중 투입 / 바다 | 모선↔기지 연계 | **레벨 스트리밍**으로 전환 |
| 수중 투입구 | 모선에서 바로 잠수 투입 | 에어락/배수 없음, 기지 전체 침수 |
| 섹터(방) | 작업/붕괴 판정 단위 | 플레이어는 항상 한 섹터에 속함 |
| **1층 폐기물 대기장** | **임시 쓰레기통 무한 보급기** | 빈 통 재보급 허브 |
| 열리는 문 | 다음 섹터로 통과 | 철거 없이 진행 |
| 열리지 않는 문 | 동선 차단 | 이 방에서는 벽을 부숴 다음 섹터로 |
| 일반 작업 섹터 | 돌파면에 칸막이/지주 **혼재** | 스캔 후 세그먼트 선택 |
| 보통벽 청소 면 | 따개비·오염 배치 | 내력·칸막이 세그먼트와 구분 |
| 위험 구조 섹터 | 지주격벽, 지지대 | 잘못 자르면 그 섹터 천장 붕괴 |
| 샘플 섹터 | 회수 목표 | 돈/퀘스트 핵심 |
| 유해/심화 섹터 | 고난이도·후반 | 리스크 구간 |

### 레벨 스트리밍 (간단 명시)
- **기지(수중 현장)** 와 **바다·모선 연계 공간**은 레벨 스트리밍으로 로드/언로드한다.
- 청크 경계·스트리밍 볼륨·연출 디테일은 구현 단계에서 정한다.
- 플레이어 체감: 모선↔현장 이동이 끊기지 않는 한 맵처럼 읽히면 충분하다.

### 섹터 진행 규칙
- 각 섹터에는 열리는 문 / 열리지 않는 문이 섞여 있다.
- 우선 열리는 문으로 이동한다.
- 고장 문과 열리는 문을 적절히 섞는다.
- 고장 문일 때만 옆 **내부** 돌파면에서 칸막이/지주 세그먼트를 고른다.
- 칸마다 벽으로 무지성 봉쇄하지 않는다.
- **외벽은 철거하지 않는다.**
- 선택한 벽을 철거한다. **오염막·따개비 제거는 철거 조건이 아니다.**
- 헤라는 오염·따개비가 있는 보통벽·바닥·설비에서 사용 가능하다.
- 바닥에 **각종 쓰레기**(음료캔, 찢어진 작업복 등)를 배치한다.
- 오염·오분류·미수거가 남으면 **평가 점수**가 깎인다.

### 수중 이동 연출
- 기본 현장은 물로 가득 차 있다.
- 발이 바닥에 닿으면 걷기
- **점프로 바닥을 밀면 수영 전환**
- 바닥에서 떨어진 상태는 수영
- 모선 복귀는 수영으로 상단 복귀 포인트에 접근
- 정밀 작업은 걷기(접지)에서 더 잘 되게 튜닝한다.
- “무게추”는 장비가 아니라, 접지=걷기 규칙을 설명하던 회의용 비유다.

## 3. 3일 진행 원칙

### 유지되는 것
- 철거된 벽/개방된 통로
- 설치한 지지대(일부 손상 가능)
- 미회수(미파괴) 샘플 위치
- **평가 점수·경고 상태**
- 구역 마감 상태
- 미수거 잔해·쓰레기 (다음날에도 남음)

### 리셋되지 않는 것
- 맵 전체를 처음부터 다시 만들기
- 어제 연 길을 막아버리는 강제 초기화
- ~~폐기 게이지~~ (시스템에서 삭제됨)

### 허용되는 소량 변화
완전 리셋이 아니라 “밤새 상황이 조금 나빠진” 연출만 허용한다.
- 잔해 위치 소폭 이동
- 약해진 지지대 1개
- 새로운 소형 오염 분출/균열·따개비 소량 재부착
- 동선이 조금 더 지저분해짐

## 4. 일차별 레벨 포커스

| 일차 | 목표 | 점검 | 레벨 설계 포인트 |
|---|---|---|---|
| Day 1 | 탐색, 문/벽 돌파, 청소·분리 품질 학습 | 없음 | 학습, 낮은 처벌, 길 열기 |
| Day 2 | 본격 철거 + 샘플 회수 | **점수** 성공/경고(+패널티) — 기준 **600** | 선택의 밀도 증가 |

| Day 4 비상 | **점수 회복** (청소·분리·마감) | 기준 **1600** / 실패 시 GO | 착수금 없음 |

### Day 1
- 칸막이격벽 위주
- 지주격벽은 “위험하다는 것”만 보여주기
- **보통벽 따개비 + 각종 쓰레기 + 오염**으로 청소 루프 학습
- **1층 폐기물 대기장**에서 임시 쓰레기통 보급 학습
- 샘플 1~2개로 손/쓰레기통 회수 루프 학습
- 18:00 압박 학습

### Day 2
- 실험실/샘플룸 본격 개방
- 지주격벽 작업 1회 이상 요구
- 점검용 **점수 기준** 유도 (분류·샘플·마감)

### Day 3
- 남은 고가 샘플 / 구역 마감 목표 집중
- 막힌 동선이나 붕괴 잔해로 긴장 상승
- 최종 점검 점수 조건을 명확히 배치

### Day 4 비상 (해당 시에만)
- 신규 고난도 구역을 억지로 열지 않는다
- 이미 열린 공간에서 오염·따개비·쓰레기 정리, 잔여 분리로 **점수 회복**
- 착수금 없음 / “안정화 근무”로 읽히게
- 목표가 UI에 분명해야 함: `평가 점수 OO 이상`

## 5. 1차 미션: X-7 B2 생물실험동

### 미션 개요
어제 사고로 **완전 침수**된 B2 생물실험동을 3일간 해체·회수한다.  
(기지는 이미 물에 잠겨 있다. 벽을 잘못 잘라도 추가 침수는 없다. 위험은 **천장 붕괴**다.)

### 권장 동선 (공식 도면)
1. **Day1** 모선 → (레벨 스트리밍) → **01 진입구(하단 중앙)** → 중앙 해치 → 07·02·03 · 청소+철거 · 모선 분류
2. **Day1 필수 학습:** 1층 **폐기물 대기장** 쓰레기통 보급기
3. **Day2** 04·05(철거 진입)·06·09 + Day1 잔여
4. **Day3** 해치 ↓ B1 (배양~냉각) · 수직 확장
5. 연결은 **문/해치**. 외벽은 불가침(진입구 모선 연계만 예외).

상세 평면: `08_프로토타입_도면` Official v1 · `Art/Plans/X7_Proto_Symmetric_Plans.png`

### 배치해야 하는 학습 포인트
| 포인트 | 배치 |
|---|---|
| 열리는 문 / 막힌 문 | Day1 진입구~해치 주변 |
| 부수면 길이 열림 | Day1 칸막이 + Day2 격리실 A |
| 보통벽 따개비 | Day1 복도·라운지 보통벽 |
| 각종 쓰레기 | Day1 라운지(캔·작업복), 창고(비닐·공구) |
| 오염 조각·오분류 감점 | Day1 임시 쓰레기통→모선 **5종** 분류 시 학습 |
| 손/임시 쓰레기통 운반 | Day1 진입구~해치 (가방 인벤 없음) |
| 쓰레기통 무한 보급 | Day1 **1층 폐기물 대기장** |
| 샘플 충돌 손상 | Day1~2 손 운반 구간 |
| 잘못 자르면 천장 붕괴 | Day2 전력실·격리 쪽 내력 + 절단 캐릭터 섹터 |
| 접지 걷기 / 점프→수영 | Day1 **01 진입구** |
| 레벨 스트리밍 복귀 | Day1 모선↔기지 |
| 샘플은 작업 후 회수 | 07 표본 보관 + 분석실 |
| 욕심내면 미복귀 | 심부 샘플을 17:40 이후에 보이게 |
| 점검 조건 | Day2/Day3 **점수** + 지정 샘플/마감 가산 |

## 7. 아트/레벨 키워드

- 캐주얼 SF, 밝은 조명, 과한 고어 지양
- 물에 젖은 실험실, 노란 지지대, 주황 안전 장비
