## 1. 퀘스트 흐름

### 1.1 세 가닥

7종이 각각 독립된 조각이 아니라, **세 가닥이 7개를 관통**한다. 한 로어가 여러 가닥을 동시에 건드리기도 한다.

| 가닥 | 1 라운지 | 2 분석실 | 3 생물실험실 | 4 유전자분석실 | 5 유지보수실 | 6 화학합성실 | 7 땅굴 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **A. 왜 침수됐나** | — | ● 부식 가속 | ● 격리 누출 | ○ | ◉ **보수 연기** | ● 억제 실패 | ○ |
| **B. 연구자들이 뭘 했나** | ● 사람·명명 | ◉ 측정 | ◉ 배양 | ◉ 해석 | ○ | ◉ 합성 | ○ |
| **C. 노라는 누구인가** | ○ 직함만 | — | — | ● "반입분" | ◉ **N.B. 서명** | — | ○ 여운 |

◉ 결정적 · ● 기여 · ○ 스치듯

**가닥 A — 왜 침수됐나 (완결됨)**
블룸이 구조를 먹는다(2) → 격리 밖에서도 자란다(3) → **보수 자재 반입이 계속 밀리고 대신 실험 장비가 먼저 들어왔다(5)** → 억제 시도는 지연 효과뿐이었다(6).
**7/7이면 답이 나온다.** 사고는 갑자기 터진 게 아니라, **고칠 수 있었는데 안 고친 결과**다.

**가닥 B — 연구자들이 뭘 했나 (완결됨)**
방 이름 그대로다. 재고(2) → 키우고(3) → 뜯어보고(4) → 막아보고(6). 라운지(1)가 그 일을 한 **사람들**을 준다.
**이 가닥이 있어야 X-7이 "괴담이 있는 폐허"가 아니라 "사람이 일하던 직장"으로 읽힌다** (`공통 기획서/06 내러티브` §2.5 톤 주의).

**가닥 C — 노라는 누구인가 (완결되지 않음 — 의도)**
명단에 물자·보급 담당 한 명(1) → 반입분이라는 단어가 무게를 갖고(4) → **인수증에 이니셜 N.B.와 "6일 조기 반입"(5)**.
**코덱스는 여기서 멈춘다.** "N.B.가 브릭스"라는 연결은 플레이어가 하고, 확인은 §7 대면에서만 이루어진다.

### 1.2 답을 주지 않는 것 (`04` §0-6 유지)

| 질문 | 이 현장에서 |
|---|---|
| 블룸은 어디서 생겼나 | **답 없음.** 계통 불일치까지만 (4) |
| 누가 일정을 앞당기라 했나 | **답 없음.** "승인 회신 추후 첨부"까지만 (5) |
| 상부·케른은 무엇인가 | **등장하지 않음** |
| 땅굴은 누가 팠나 | **답 없음.** 신원 흔적을 하나도 남기지 않는다 (7) |
| N.B.는 브릭스인가 | **코덱스는 말하지 않음.** 대면에서만 (§7) |

### 1.3 읽는 순서 (강제 아님)

`04` §0-5대로 발견 순서는 자유다. 다만 **코덱스 배열 순서 = 도면 번호 순 = 사건이 진행된 순서**로 맞춰 뒀다.

> 사람들이 있었고(1) → 이상한 걸 발견해 이름 붙이고 재봤고(2) → 키워봤고(3) → 정체를 물었고(4) → 그동안 기지는 삭고 있었고 보수는 밀렸고(5) → 뒤늦게 막아보려 했지만 늦었고(6) → 누군가는 밖으로 나가는 굴을 팠다(7).

## 5. 배치 검증

### 5.0 로어는 세션에 영향이 없다 (v5 전환)

**로어는 스토리를 푸는 수집 트랙이다.** 점수·₡·호감도 어디에도 붙지 않고 (`04` §0), 점검 통과와 무관하며 (`09` §0), 실패 상태가 없다. 놓쳐도 잃는 게 없고 재방문하면 그대로 있다.

그래서 v3·v4에서 잡았던 **왕복 초 예산·Day별 조우 강제·"7종을 5분에 돈다"는 시간 설계는 전부 걷어낸다.** 그건 계약 시간을 잡아먹는 트랙에나 필요한 계산이고, 로어에는 과한 제약이었다.

**남는 요구는 셋뿐이다.**

| # | 요구 | 판정 |
|---:|---|---|
| **1** | **찾을 수 있어야 한다** | 그 방에 들어간 플레이어가 유도 요소를 보고 대상물에 닿을 수 있는가 |
| **2** | **조사되어야 한다** | 조준 → 프롬프트 → 1회 입력 → 코덱스 등록 → 소멸이 정상 동작하는가 |
| **3** | **다른 트랙을 방해하지 않아야 한다** | 반복 스폰물과 오조준이 안 나는가, 로어 때문에 죽지 않는가 |

**이 셋을 만족하면 합격이다.** 왕복이 30초든 2분이든 상관없다.

> **v11부터는 예외도 없다.** 코덱스를 다 채운 뒤에 열리는 화면(브릭스 대면)도 **개발 범위에서 뺐다** (§7.7). 로어는 처음부터 끝까지 세션과 무관하다.

> **아래 §5.1~§5.3은 참고값이다.** 배치 감각을 잡는 데는 쓰되, **검증 기준으로 쓰지 않는다.** 강제 기준은 §5.4 여덟 줄뿐이다.

### 5.1 배치 감각 (참고 · 비강제)

| 항목 | 권장 | 비고 |
|---|---|---|
| 필수 동선에서의 이탈 | 한 방 이상 | 필수 동선 위에 놓으면 탐험이 아니게 된다 (`09` §5) |
| 시선 유도 거리 | **6 m** | 방에 들어간 뒤 이 거리에서 유도 요소가 읽히면 충분 |
| 접근 기믹 | 0~18초 | 기믹은 "막힘"이지 작업이 아니다 |
| 되돌아오기 비용 | 0 | 로어는 문을 잠그지 않는다 |
| 왕복 시간 | **제약 없음** | v5에서 삭제. L07 땅굴이 2분 넘게 걸려도 문제가 아니다 |

### 5.2 층별 루프 (참고 · 비강제)

**1F (L01 → L02) · 약 70초**
중앙 해치 → 03 연구 라운지(L01) → 04 표본 분석실(L02) → 복귀.
도면상 03(북동)과 04(동북)는 **인접**이라 한 번에 처리된다. 04는 1F 막다른 끝이라 여기까지 오는 이유는 L02뿐이다.

**B1 (L03 → L04 → L05 → L06 → L07) · 약 4분 30초**
하부 해치 → B1-02 생물 실험실(L03, 북동) → B1-01 유전자 분석실(L04, 북서) → B1-07 유지 보수실(L05, 남) → B1-03 화학 합성실(L06, 서) → **B1-05 냉각 시스템실(남서, 땅굴 입구) → 땅굴 → L07** → 복귀.
**해치를 중심으로 반시계 방향 한 바퀴**를 돈 뒤 땅굴로 빠진다. 땅굴이 전체의 절반을 먹는다.

> **L06 → L07이 옆방으로 이어지는 게 이 순서의 핵심이다.** B1-03(서)과 B1-05(남서)는 인접이다. "기지 밖 표류물에서도 같은 게 나온다"를 읽은 직후, 옆방에 밖으로 나가는 굴이 있다.

### 5.3 로어의 존재를 알리는 장치 하나

Day1 동선(01 진입구 → 중앙 해치 → 하강)은 **1F 방을 하나도 지나지 않는다.** 그대로 두면 1회차 플레이어가 **로어라는 트랙이 있다는 것 자체를** 모른 채 계약을 끝낼 수 있다.

**로어를 억지로 동선 위에 놓는 대신, 존재만 알린다.**

| 항목 | 값 |
|---|---|
| 대상 | **L01 라운지 게시판** |
| 배치 | 03 연구 라운지 출입문을 **중앙 해치 쪽으로** 내고, 게시판을 문 정면 벽에 붙인다. 문은 처음부터 열려 있다 |
| 효과 | 해치를 오르내리며 문 너머로 **흰 사각형**이 보인다. 들어가는 건 플레이어 선택 |

**이 장치는 L01 하나에만 건다.** 나머지 6개는 그 방에 들어간 사람만 만난다.
"첫 로어를 공짜로 준다"가 아니라 **"트랙이 있다는 걸 공짜로 알린다"**가 목적이다.

### 5.4 검증 체크 (이게 전부다)

§5.0의 세 요구를 그대로 항목화한 것이다. **왕복 시간·Day별 조우·동선 효율은 검증하지 않는다.**

**찾을 수 있는가**
- [ ] 그 방에 들어간 상태에서 **6 m 거리에서 유도 요소가 읽히는가** (수중 안개·B1 조도 적용)
- [ ] L01 게시판이 **중앙 해치에서 문 너머로 보이는가** (§5.3)

**조사되는가**
- [ ] 7개 전부 조준 → 프롬프트 → 1회 입력 → 코덱스 등록 → 소멸이 되는가
- [ ] 접근 기믹(헤라 2 / 철거 2 / 쓰레기 1)이 **끝나기 전에는 프롬프트가 안 뜨는가**
- [ ] L07이 **암호화 상태로 목록에 남고**, 나머지 6개 확보 시 자동 해독되는가

**다른 트랙을 방해하지 않는가**
- [ ] L01 게시판에서 **로어 종이만 조준되는가** (다른 종이는 비상호작용)
- [ ] **B1-01** — 로어 해석 코어(시퀀서 안)와 R11 A급 코어(작업대 위)가 오조준되지 않는가

- [ ] 땅굴 왕복이 **산소 캔 없이** 가능한가
- [ ] 땅굴 출구로 **쓰레기통·샘플 운반이 불가능한가** (지름길 방지)

### 7.5 현장 토스트 · 프롬프트

| 상황 | 문구 | 지속 |
|---|---|---|
| 조준 프롬프트 | `F  조사` + (작게) 기록물 이름 | 상시 |
| 접근 기믹이 남았을 때 | **프롬프트 없음.** 덮개·쓰레기·패널이 먼저다 | — |
| 조사 성공 | `기록물 확보 — 배양 라인 일지  (3/7)` | 3초 |
| 팀원이 조사 (세션) | `스플래시가 기록물을 확보했습니다 — 배양 라인 일지  (3/7)` | 3초 |
| **7/7 달성** | `X-7 기록 보관함 완성 — 암호가 해독되었습니다` | 4초 |
| 이미 확보한 로어 조준 | 프롬프트에 작게 `이미 확보한 기록` (§7.6) | 상시 |
| **땅굴 최초 진입** | `미등록 구역` | 2초, 화면 하단 작게 |

- `(3/7)`은 **내 로컬 기준**이고, 조사하면 전원 로컬에 들어가므로 **팀 전원이 같은 수치를 본다** (`04` §6.1).
- 토스트에 **점수·₡·호감도를 넣지 않는다.**
- 땅굴 진입 토스트는 **딱 네 글자짜리 정보**만 준다. 설명하지 않는 게 이 공간의 연출이다.

### 7.6 멀티플레이 표시 — **표시할 게 없다** (v12)

조사하면 **참가자 전원 로컬에 저장**되므로 (`04` §6.1), **"보이는 개수"와 "가진 개수"가 항상 같다.**

| 화면 | 표시 |
|---|---|
| 현장 HUD 토스트 | `(3/7)` — 내 로컬 기준 (전원 동일) |
| 모선 코덱스 | `기록물 3 / 7` — **싱글·멀티 동일** |
| 남이 주운 항목 | **일반 항목과 구분하지 않는다** |

**v11까지 있던 아래 표시를 전부 삭제한다.**

| 삭제 | 이유 |
|---|---|
| `기록물 5 / 7 · 내 기록 3` 병기 | 두 수치가 갈리지 않는다 |
| 카드 우상단 `공유` 표식 | 소유가 갈리지 않는다 |
| `공유` 툴팁 (*"내 보관함에는 남지 않습니다"*) | 남는다 |
| 세션 종료 정산 `내 보관함에 N건 추가` | 세션 중 이미 들어갔다 |

> **UI가 줄어든 게 이 개정의 실익이다.** 구판은 "왜 내 개수가 다른가"를 표식·툴팁·정산 문구 세 곳에서 계속 설명해야 했다. 이제 설명할 게 없다.

**단, 이건 남는다** — 다 모은 사람이 미보유 친구와 들어가면 **이미 확보한 로어가 맵에 다시 보인다** (`04` §6.1.1 교집합 판정).

| 상황 | 표시 |
|---|---|
| 이미 확보한 로어를 조준 | 프롬프트 `F  조사` + 작게 **`이미 확보한 기록`** |
| 그걸 조사했을 때 | `기록물 확보 — 배양 라인 일지` 토스트는 **미보유 팀원에게만**. 조사자 본인에게는 안 띄운다 |

### 7.7 브릭스 대면 — ⏸ **개발 범위 밖** (v11)

> **⛔ 구현하지 않는다.** 개발 범위가 넓어 **선택지 트랙 전체를 뺐다.**
>
> | 빼는 것 | A/B 선택 UI · 재선택 창 · `ToldBriggsAboutX7` 플래그 · 대면 대사 · 보류 상태 UI 힌트 · 멀티 플래그 병합 |
> |---|---|
> | **남는 것** | **7종 수집 · 코덱스 열람 · L07 해독.** 로어 트랙은 이것으로 완결된다 |
>
> **7/7을 달성하면** 코덱스가 100%가 되고 L07이 해독된다. **그게 끝이다.** 그 뒤에 열리는 화면은 없다.
> 이야기의 종결은 **L07 본문이 진다** — "여기서 더는 못 간다. 다른 지점이 필요하다"가 다음 현장으로 넘기는 훅이다. 브릭스 없이도 성립한다.
>
> **아래 §7.7~§7.7.2는 나중에 붙일 자리로 보존한다.** 설계·대사는 완성돼 있으니 범위가 열리면 그대로 쓰면 된다.

| **필수 3 — 결과** | **클리어.** Day3 최종 점검 통과, 또는 Day3 무경고 실패 후 들어간 **비상 Day4 통과** |

|---|---|
| **X-7** 7/7 + Day3 통과 | **선택지** |

| **X-7 7/7 달성 후 그 세션 실패 → 다음에 X-7 재계약 클리어** | **선택지.** 코덱스는 로컬에 남으므로 다시 모을 필요 없다 |

- **게임오버로 런이 끝나도 코덱스는 로컬에 남는다.** 다음 런을 시작하면 이미 7/7 상태이므로, **그 런을 클리어하는 순간 바로 선택지가 뜬다.**
- 현장(잠수 중)에서는 뜨지 않는다. 브릭스는 모선에 있고, 이건 계약이 끝난 자리의 대화다.
- **플래그는 한 번뿐이다.** `ToldBriggsAboutX7` ∈ `None` / `Told` / `Withheld` / `ToldLate`
- 꺼내는 내용은 **정비 일지·인수증·비공식 실험**까지. 상부·블룸 기원·케른은 말하지 않는다 (§1.2).

> **왜 클리어에 묶는가.** **계약을 무사히 끝낸 자리의 대화**이기 때문이다. 정산이 끝나고 브릭스가 돌아서려는 순간이라는 장면이 있어야 "…뭐 더 있나?"가 성립한다. 게임오버 흐름에 붙이면 그 장면이 성립하지 않는다.
> *(v6~v8에서는 "다음 세션 페이오프가 있으니 다음 세션이 있어야 한다"가 근거였다. v9에서 페이오프를 없앴으므로 근거를 장면 쪽으로 바꿨다 — 규칙 자체는 그대로다.)*
>
> **왜 X-7에만 묶는가.** X-7 자료를 X-7에서 막 들고 나온 자리여야 대화가 성립한다. 다른 현장을 끝내고 X-7 서류를 꺼내는 건 어색하다 (§7.7.2).
>
> 이건 §5.0("로어는 세션에 영향이 없다")과 충돌하지 않는다. **로어가 세션을 바꾸는 게 아니라, 세션 결과가 로어의 결말을 열어 줄 뿐이다.** 방향이 반대다.

| **혼자 다시 가면** | 내 로컬 개수로 돌아간다. 내 세이브만으로 7/7이 아니면 선택창은 안 뜬다 |

**확인 팝업 없음.** 경고를 달면 이 선택이 성공/실패처럼 읽힌다. 어느 쪽도 손해가 아니다.

**A 선택 후** — 코덱스가 실제로 준 정보(정비 일지 + 인수증)로만 말한다.

"인수증에 N.B."

브릭스
(짧은 정적)

"그건 네 일 아냐. 다음 목록이나 봐."
```

**B 선택 후**
```

"그래. 수고했다."
"다음 구역 준비해."
```

**B 이후 재선택 창** — **다음 세션 출발 전** 모선 허브에서 **1회만**
```

`지금 보여준다` → `"…지금까지 말 안 했구나."` (플래그 `ToldLate`)

v6~v8에서 붙였던 "다음 세션 브릭스 태도 세트 3종"은 **전면 폐기**한다.

#### 선택이 바꾸는 것 / 바꾸지 않는 것

| | 항목 |
|---|---|
| **바꾸는 것** | **그 장면의 대사뿐.** A를 고르면 A의 대사가, B를 고르면 B의 대사가 나온다 |
| | `ToldBriggsAboutX7` 플래그가 저장된다 — **읽는 곳이 지금은 없다.** 미래(케른)를 위한 기록일 뿐 |
| **바꾸지 않는 것** | 상점 가격 · 해금 조건 · 재고 |
| | 호감도 · 착수금 · 대출 한도 · 이자 |
| | 점검 기준 · 퀘스트 구성 · 스폰 |
| | **다음 세션의 브릭스 대사** — 계약 시작, 퀘스트 제시, 개인 화제, 성공/실패, 치료, 정산, 브리핑 **전부 평소 그대로** |
| | 다음 현장 브리핑에 붙이려던 "한 줄 추가"도 **삭제** |

#### 구현 결과

브릭스 대사 테이블에 **분기 세트를 만들지 않는다.** 플래그를 읽어 대사를 고르는 코드도 넣지 않는다.
`ToldBriggsAboutX7`은 **세이브에 값만 남는 죽은 플래그**로 둔다 (`04` §6.6 병합 규칙은 유지 — 나중에 되살릴 때 규칙이 없으면 곤란하다).

#### 이 선택은 그럼 뭔가

**A와 B는 게임적으로 완전히 동일하다.** 남는 차이는 **플레이어가 그 장면에서 무엇을 봤는가**뿐이다.

- `Told` → 브릭스가 침묵하고, 선을 그어 버리는 걸 본다
- `Withheld` → 아무 일도 없이 계약이 끝나는 걸 본다
- `ToldLate` → 늦게 말했을 때의 어색함을 본다

이게 약한 선택처럼 보인다면, **해결책은 게임 효과를 붙이는 게 아니라 그 장면을 잘 쓰는 것이다.** 효과를 붙이는 순간 로어가 최적화 대상이 되고, "어느 쪽이 이득이지?"가 "무슨 이야기지?"를 덮는다.

> **케른은 여전히 열려 있다.** 플래그만 남아 있으면 후반 콘텐츠에서 되살릴 수 있다. **지금 할 일이 아닐 뿐이다** (`04` §4).

### 7.7.2 현장 선택과의 충돌 해소

#### 문제

세션은 **시작할 때 현장을 고른다** (`09` §7 미션 선택형). 그래서 이런 상태가 생긴다.

| 상태 | 왜 문제인가 | v9 상태 |
|---|---|---|
| 선택 미확정 상태로 **TR-9를 클리어** | 클리어 자리에서 브릭스가 X-7 이야기를 꺼내는 게 맞나? | **해결** — 트리거를 X-7에 묶었다 |
| 페이오프가 "다음 세션"인데 그 세션이 **X-7일 수도 TR-9일 수도** | 태도 세트를 어디에 붙이나? | **소멸** — 페이오프를 없앴다 (§7.7.1) |
| X-7 7/7인데 **그 세션을 실패** → 다음에 **TR-9**를 고름 | X-7을 다시 안 고르면 선택지를 못 본다 | **남음** → 아래 |

#### 해소 — **트리거를 X-7에 묶는다. 그리고 페이오프가 없으므로 충돌 자체가 사라진다**

| | 규칙 |
|---|---|
| **트리거** | **X-7 계약 클리어에만.** X-7 자료를 X-7에서 막 들고 나온 자리여야 대화가 성립한다 |
| **페이오프** | **없다** (§7.7.1). 다음 세션에 어느 맵을 골라도 **아무것도 달라지지 않는다** |

**§7.7.1에서 태도 변화를 없앤 뒤로 이 절의 문제 대부분이 저절로 해소됐다.**
"다음 세션이 X-7일지 TR-9일지 몰라서 태도 세트를 어디 붙이나"라는 질문 자체가 사라진다 — 붙일 게 없다.

**남은 문제는 하나뿐이다:** X-7 7/7 상태로 다른 맵을 계속 플레이하면 선택지를 못 본다. 아래가 그 답이다.

#### "X-7을 다시 안 가면 못 본다"는 문제인가

문제가 아니다. **보류일 뿐 소멸이 아니다.**

| 항목 | 판단 |
|---|---|
| 코덱스 7/7 | **로컬에 영구 보존.** 게임오버해도 남는다. 다시 모을 필요 없다 |
| 재도전 비용 | X-7을 한 번 더 골라 클리어하면 끝. 로어를 다시 줍지 않아도 된다 |
| 강제성 | 없다. 로어는 점검·진행과 무관한 보너스 트랙이다 (`09` §0) |
| 오히려 | **X-7을 다시 고를 이유가 하나 생긴다.** 미션 선택형 구조에서 재방문 동기는 많을수록 좋다 |

**대신 플레이어가 그 사실을 알아야 한다** — 아래 UI 힌트를 단다.

#### 보류 상태 UI 힌트 (신규)

7/7인데 아직 선택하지 않은 상태에서, **X-7에 가야 한다는 걸 알린다.** 강요하지 않고 알리기만 한다.

| 위치 | 표시 | 조건 |
|---|---|---|
| **코덱스 탭 헤더** | `기록물 7 / 7 · 완성` + 아래 한 줄 **`X-7 계약을 마치고 브릭스에게 보여줄 수 있습니다.`** | 7/7 && 플래그 `None` |
| **현장 선택 화면 X-7 카드** | 우상단 작은 표식 `기록 보관함 완성` | 〃 |
| 선택 확정 후 | 두 표시 모두 **사라진다** | 플래그 ≠ `None` |

- 힌트 문구에 **느낌표·강조색을 쓰지 않는다.** 미완료 퀘스트처럼 보이면 안 된다 — 이건 할 일 목록이 아니다.
- 다른 현장 카드에는 아무것도 안 뜬다.

#### 대사 작성 제약

**대면 대사는 X-7 클리어 직후에만 나오므로 X-7을 전제해도 된다.** "정비 일지" 같은 표현을 현장 설명 없이 그대로 쓴다.
**태도 세트 대사는 존재하지 않는다** (§7.7.1). 다음 세션용 분기 대사를 쓰지 않는다.

#### 다른 현장 코덱스는?

TR-9(5종)·SS 벨몬트도 코덱스를 갖지만, **대면 분기는 X-7에만 설계돼 있다** (`09` §5).
TR-9 코덱스를 다 모아도 이 선택지는 뜨지 않는다. `ToldBriggsAboutX7`은 **X-7 전용 플래그**이며, 다른 현장의 대면은 그 현장 문서가 **같은 형식으로** 따로 정의한다 — **그 현장 클리어에서만 뜨고, 게임 효과는 없고, 플래그만 남긴다.**

#### 구현 조건

```
[계약 클리어 요약 화면 종료 시]
    if (CurrentSiteId == "X7"                       // ← 현장을 본다
        && 내로컬(X7 로어) == 7                        // v12: 합집합 판정 불필요
        && ToldBriggsAboutX7 == None)
        → A/B 선택 UI  →  플래그 확정(확정자 로컬에만 기록)
                        →  그 자리의 대사 재생. 끝.

[모선 허브 진입 시]
    if (ToldBriggsAboutX7 == Withheld && 재선택_미소모)
        → 재선택 UI  →  ToldLate 또는 Withheld 확정, 재선택_소모

    if (X7 로어 == 7 && ToldBriggsAboutX7 == None)
        → 코덱스 헤더·X-7 카드에 보류 힌트 표시     // §7.7.2

[브릭스 대사 조회 시]
    대사세트 = 기본                                  // 분기 없음. 플래그를 읽지 않는다
```

- 선택 UI는 **X-7 클리어 흐름에만** 붙는다. 다른 현장·Day 종료 정산·일상 대화에는 붙지 않는다.
- **게임오버 흐름에는 붙지 않는다** — 그 장면이 성립하지 않는다.
- **`ToldBriggsAboutX7`을 읽는 곳은 재선택 창 하나뿐이다.** 브릭스 대사·상점·호감도 어디에서도 읽지 않는다 (§7.7.1).

</details>

### 7.7.3 대면 없이 로어 트랙이 끝나는 방식 (현행 확정)

선택지를 뺐으므로 **코덱스 자체가 종결점**이다.

| 시점 | 일어나는 일 |
|---|---|
| 6/7 (L01~L06 확보) | L07이 자동 해독된다. **L07을 아직 못 주웠으면** 목록에 `???` 미발견으로 남는다 |
| **7/7** | 코덱스 100%. 토스트 `X-7 기록 보관함 완성 — 암호가 해독되었습니다` 1회 (§7.5) |
| 그 뒤 | **아무것도 없다.** 열리는 화면·대화·해금이 없다 |

**이야기의 종결은 L07 본문이 진다.**

> *"여기서 더는 못 간다. 다른 지점이 필요하다.*
> *누가 일정을 밀었는지는, 여기에는 없다."*

이 두 줄이 **다음 현장으로 넘기는 훅**이다. 브릭스가 없어도 성립한다 — 오히려 답을 줄 사람이 아무도 없다는 게 더 정확한 상태다.

**코덱스 헤더에도 대면 안내를 넣지 않는다.** 7/7 상태는 그냥 `기록물 7 / 7`이고, 그 아래 보조 문구는 평소와 같이 `점검엔 영향 없습니다.`다.
