## 0.5. 회의 반영: 완전 침수 / 접지 이동 / 섹터

### 기지 상태
- X-7 작업 구역은 **시작부터 완전히 침수**되어 있다.
- 에어락/배수 진입 연출은 쓰지 않는다.
- 모선에서 바로 수중 현장으로 투입된다.
- “물이 새로 들어온다”가 메인 실패 연출이 아니다.
- 실패의 핵심 연출은 **섹터 천장 붕괴 / 구조 손실 / 샘플 위험**이다.

### 수중 이동 (접지 = 걷기)
회의에서 말한 “무게추”는 **별도 장비가 아니다.**  
캐릭터가 바닥에 닿으면 걷는다는 규칙을 쉽게 설명하려고 쓴 비유다.

실제 규칙은 단순하다:

| 상태 | 조건 | 조작감 |
|---|---|---|
| 걷기 | 발이 바닥에 닿아 있음 (접지) | 안정적 철거/헤라 작업에 유리 |
| 수영 | 수중에서 바닥 접지가 끊김 | 빠른 이동·수직 이동·모선 복귀에 유리 |

규칙:
1. 바닥에 닿으면 걷는다.
2. 바닥에서 떨어지면 수영한다.
3. **접지 상태에서 `점프`를 누르면 바닥을 밀어 수영 모드로 전환**한다.
4. 모선으로 올라가려면 점프로 수영 전환 후, 상단 복귀 포인트로 이동한다.
5. 수영 중 다시 바닥에 닿으면 걷기로 돌아온다.
6. 정밀 작업(헤라, 지주격벽 절단, 지지대 설치)은 걷기(접지) 상태에서 더 안정적이다.
7. 수영 중에는 작업 정확도가 떨어지거나 일부 행동이 제한될 수 있다.

의도:
> 수중 맵에서도 “바닥을 딛고 일하는 느낌”과 “물속을 헤엄치는 느낌”을 자연스럽게 오가게 한다.  
> 무게추 UI/아이템/토글은 넣지 않는다. 수영 전환은 **점프**로 한다.

### 섹터 (방 단위)
- 기지의 각 방은 **섹터**다.
- 플레이어는 항상 하나의 현재 섹터에 속한다.
- 지주격벽을 잘못 절단하면, 벽이 이어진 모든 방이 아니라  
  **절단 버튼을 누른 캐릭터가 서 있는 섹터의 천장이 무너진다.**

플레이 의미:
- 어디서 자르느냐가 리스크다.
- 같은 벽을 자르더라도, 안전한 인접 섹터에서 작업할지 / 위험 섹터 한가운데서 자를지 선택이 생긴다.
- 협동 시 한 명은 지지, 한 명은 다른 섹터에서 절단 같은 역할이 가능하다.

## 1. 헤라 · 청소 요소

### 목적
현장의 **더러움과 잔여물**을 벗겨 손맛·정리를 만들고,  
철거·수거물을 **깨끗하게 분리·폐기**할 수 있게 한다.

### 청소 요소 구분 (중요)

| 요소 | 대상 | 도구 | 산출물 | 비고 |
|---|---|---|---|---|
| **오염물** | 벽·바닥·설비 표면의 바이오필름·도장·점액층 | 헤라 | 물리 **오염물** | 기존 루프. 철거 필수 아님 |
| **따개비** | **보통벽**에 붙은 부착물 | 헤라 | 물리 **따개비** | 내력벽·칸막이벽·오염물과 **별도** 품목 |
| **각종 쓰레기** | 기지 바닥에 흩어진 생활·작업 쓰레기 | 손 집기 | 물리 **쓰레기** | 헤라 불필요. 종류는 아래 |

> **보통벽:** 철거 판정용 **내력벽 / 칸막이벽**이 아닌 일반 벽면·구조 표면.  
> 따개비는 여기에만 붙는다. (내력·칸막이 세그먼트에는 두지 않는다.)

### 헤라 핵심 규칙
1. 헤라는 **오염물**과 **따개비**에 쓴다. (표면이 있는 곳)
2. **벽을 철거하기 위해 오염막·따개비를 꼭 제거할 필요는 없다.** 남아 있어도 절단·돌파는 가능하다.
3. 긁어낸 오염물·따개비는 **월드 물리 오브젝트**로 떨어진다. 인벤에 들어가지 않는다.
4. 산출물은 **손으로 집어 임시 쓰레기통에 담아** 모선으로 가져간다. 쓰레기통은 **물리**라서 기울이면 **쏟을 수 있다**.
5. 철거 전 벽의 **오염 제거율**이 떨어질 벽 조각의 오염/비오염 비율을 결정한다. (아래 §2.5)
6. 헤라는 철거 잠금이 아니라 **청소 손맛 + 조각 품질 + 모선 분류** 도구다.
7. 샘플 근처는 거칠게 긁으면 손상 위험이 올라간다.

### 각종 쓰레기 (기지 내 산재)
헤라와 별도로, 기지 곳곳에 **손으로 집는 쓰레기**를 배치한다.  
모두 **임시 쓰레기통 → 모선**으로 운반하고, 모선 **5종 컨테이너**에 분리한다. (§11)

예시 품목 → **모선 투입 칸** (프로토 배치용):

| 품목 | 연출 / 의도 | 정분류 칸 |
|---|---|---|
| 음료캔 | 휴게·라운지·복도. 가볍고 굴러감 | **금속** |
| 녹슨 폐공구 | 전력·정비 구역 | **금속** |
| 케이블·전선 잔해 | 설비 주변. 동선에 걸리적임 | **금속** |
| 찢어진 작업복 | 격리·탈의·비상 구역. 부피 큼 | **일반쓰레기** |
| 젖은 서류·라벨 뭉치 | 사무·기록실. 떠다니기 쉬움 | **일반쓰레기** |
| 폐장갑·마스크 | 방호 소모품. 곳곳에 소량 | **일반쓰레기** |
| 플라스틱 비닐·포장재 | 창고·폐기 대기 동선 | **플라스틱** |
| 식품 포장 / 도시락 용기 | 라운지·휴게 (플라스틱 재질) | **플라스틱** |
| 깨진 실험 유리 / 비커 파편 | 분석·배양 근처 | **안타는 쓰레기** |
| 폐전지·소형 배터리 | 소수. 오분류 감점 강조 | **오염된 쓰레기** |

세부 환급·감점 수치는 `05 수치 기획` · 크레딧은 `07 아이템 기획`.

### 섹터 진행과의 관계
- OPEN/BROKEN 문을 섞어 둔다.
- 내부 **비내력·내력 격벽을 충분히** 배치해 철거 일감을 만든다.
- 내력벽은 **천장 베이**와 연결된다 (오절단 시 해당 베이 붕괴).
- 외벽은 절단 불가.
- **보통벽**에는 따개비·오염을, 바닥에 **각종 쓰레기**를 섞어 청소 일감을 만든다.

플레이어 교육 문장:
> 긁고(오염·따개비), 줍고(쓰레기), 자르고, 임시 쓰레기통에 담아 모선으로 간다.  
> 모선에서 **금속 / 일반 / 플라스틱 / 오염 / 안타는 것**으로 가른다.  
> 핫바는 공구함이다.  
> 빨간 벽은 천장을 잡고 있다.  
> 바깥 선체는 건드리지 않는다.

### 장비 차이
- 기본 헤라: 안전한 기본기
- 광폭 헤라: 빠르지만 실수 위험
- 열선 헤라: 두꺼운 오염층·단단한 따개비에 강함

## 1.5. 임시 쓰레기통 · 폐기물 대기장

### 임시 쓰레기통 (물리)
- 월드 오브젝트. (구 용어: 보관함)
- 기울임·충돌·뒤집기에 **내용물이 쏟아질 수 있다.**
- **벽 조각 / 오염된 벽 조각 / 오염물 / 따개비 / 각종 쓰레기 / 샘플**을 담을 수 있다.
- 용량·혼적 규칙은 `05 수치 기획` (프로토: 용량·혼적 제한 느슨, 샘플과 폐기물 혼적 허용).
- 쏟아지면 다시 주워 담아야 한다. (코믹·협동 소스)

### 1층 폐기물 대기장 — 쓰레기통 보급기
- 기지 **1층 폐기물 대기장**에 **임시 쓰레기통이 무한정 나오는 기계**가 있다.
- 플레이어는 여기서 빈 쓰레기통을 꺼내 현장으로 가져간다.
- 현장 스폰 수량에 의존하지 않아도 된다. (분실·유실해도 대기장에서 재보급)
- 모선으로 내용물을 비운 뒤, 빈 통을 다시 쓰거나 대기장에서 새로 받아도 된다.

### 운반 요약
| 대상 | 손 운반 | 임시 쓰레기통 |
|---|---|---|
| 샘플 | ✅ 가능 | ✅ 가능 |
| 벽 조각·오염 조각 | ✅ (소량) | ✅ 권장 |
| 오염물·따개비·각종 쓰레기 | ✅ (소량) | ✅ 권장 |

→ **분리할 폐기물과 샘플은 손으로 들거나, 임시 쓰레기통에 넣어 모선으로 가져간다.**

## 1.6. 맵 이동 (레벨 스트리밍)

- 기지(수중 현장)와 바다·모선 연계 공간은 **레벨 스트리밍**으로 전환한다.
- 세부 청크 분할·로딩 연출은 레벨/엔진 문서에 맡기고, 시스템상으로는  
  **「기지 ↔ 바다(모선) 이동 = 레벨 스트리밍」** 만 명시한다.

## 2. 격벽 철거

### 벽의 두 종류
| 이름 | 다른 표현 | 역할 | 플레이 의미 |
|---|---|---|---|
| 칸막이격벽 | 비내력벽 | 공간만 나눔 | 잘라도 천장 무관. 길·공간 개방 |
| 지주격벽 | 내력벽 | **천장 베이**를 붙잡음 | 오절단 시 **지지 베이 천장 붕괴** |

### 천장 베이
- 섹터 천장을 베이 격자로 나눈다.
- 내력벽 세그먼트마다 지지 베이 ID를 가진다.
- 절단(지지 부족) → 그 베이(들)만 낙하. 범위는 절단자 현재 섹터 안.

플레이어 교육 문장:
> 초록 벽은 칸막이, 빨간 벽은 천장을 잡는다.

### 언제 벽을 부수는가
- OPEN 문으로 이동 + **내부 비내력/내력을 적극 철거**해 공간·일감 확보
- BROKEN 문 옆 우회도 사용
- 외벽 NO CUT
- 오염 제거는 철거 필수 아님 (모선 분류 시 유리)

### 철거 절차
1. 스캔 (비내력 / 내력+지지 베이 / 배관)
2. 내력이면 지지대 검토
3. (선택) 헤라로 오염 제거율 올리기
4. 절단 → **벽 조각 ~10개 낙하** → 조각 수거 → 임시 쓰레기통 → 모선
5. 내력 실패 시 해당 **천장 베이 붕괴** + 대청소

### 실패 결과 (내력 오절단)
- 지지 베이 천장 붕괴 (절단자 섹터)
- 부상/사망 위험, 샘플 손상, 동선 봉쇄
- **점수:** 지지대 없음 **−200** / 지지 있어도 붕괴 **−120** (`05`)
- 추가 침수 없음 (이미 전체 침수)

## 2.5. 벽 조각 · 운반 · 인벤 (회의 확정)

### 벽이 파괴되면
1. 벽은 **약 10개의 벽 조각**으로 떨어져 월드에 남는다.
2. 조각은 파괴 직전 그 벽에 붙어 있던 **오염물 제거율**에 따라 나뉜다.

| 조각 종류 | 조건 (개념) | 모선 정분류 칸 |
|---|---|---|
| **조각벽** (깨끗) | 제거율이 높은 면/영역에서 떨어진 조각 | **안타는 쓰레기** |
| **오염된 조각벽** | 오염이 남은 면/영역에서 떨어진 조각 | **오염된 쓰레기** |

프로토 단순화 예: 제거율 70%면 조각 10개 중 약 7개 깨끗 / 3개 오염.  
(정확한 배분은 `05 수치 기획`.)

### 운반 규칙 (일반 인벤토리 없음)
- 벽 조각·오염물·따개비·각종 쓰레기·샘플은 **인벤 슬롯에 들어가지 않는다.**
- 플레이어는 **한 번에 손(또는 양손)으로 집어서** 이동한다.
- 또는 **임시 쓰레기통**에 담은 뒤, 쓰레기통을 들고 모선으로 간다.
- 모선 도착 후 쓰레기통 내용물을 **분류장**에 부어 분리한다.
- 임시 쓰레기통 상세·1층 보급기는 §1.5.

### 인벤토리 = 핫바(장비 전용)
- UI 핫바만 존재한다.
- 슬롯에는 **장비만** 넣는다. (헤라, 절단 도구, 스캐너, 지지대 등)
- 자원/잔해/샘플용 가방 인벤은 **없다.**

플레이어 교육 문장:
> 부수면 조각이 떨어진다.  
> 손으로 들거나 임시 쓰레기통에 담고, 모선까지 가져간다.  
> 핫바는 공구함이다. 쓰레기는 가방에 안 들어간다.

## 3. 임시 지지대 / 안전 도구

### 임시 지지대
- 지주격벽 작업 전 안정도를 올린다.
- 수량 제한이 있어 “어디에 쓸지” 선택이 생긴다.
- 설치되어 있으면 해당 섹터/벽의 천장 붕괴 위험과 피해가 줄어든다.

### 보조 안전 도구
- 오염 정리 / 균열 패치: 국소 오염 분출·균열 지연 (메인 실패는 붕괴)
- 비상 격문 키트: 위험 섹터 통로 차단
- 산소 확장/캔: 수중 활동 시간 확보

### 구역 마감
“봉인” 같은 추상 표현 대신, **구역 마감**을 쓴다.

의미:
> 이 섹터의 철거·잔해 정리·위험 요소 처리를 끝내고, 점검용으로 “여기 작업 끝” 처리하는 것.

플레이어가 하는 일 (예시):
1. 지정 칸막이/지주 작업 완료
2. 큰 잔해·오염 정리
3. 마감 마커/제출 상호작용

결과:
- 점검 통과 OR 조건으로 사용
- **평가 점수**에 가산
- 해당 섹터는 마감 상태로 유지 (일자 리셋 없음)

## 4. 샘플 회수

### 샘플 상태
| 상태 | 정의 | 결과 (점수 요약, 상세 `05`) |
|---|---|---|
| Intact 회수 | 모선까지 파손 없이 납품 | C+70 / B+140 / A+220 / S+360 |
| 손상 회수 | 가져왔지만 파손 | Intact × 40% |
| 미회수 | 맵에 남김 (파괴되지 않음) | C−20 ~ S−90, 다음날 재시도 |
| 파괴 | 깨짐/유실 | C−45 ~ S−220, 재시도 불가 |

### 핵심 규칙
- **미회수 ≠ 파괴**
- 못 가져오면 손해, 깨뜨리면 더 큰 손해
- 상급 샘플은 상인 퀘스트와 상점 해금에 직접 연결
- 파괴되지 않은 미회수 샘플은 다음 날 다시 집을 수 있다

### 운반 방식 (회의 확정)
샘플도 인벤에 넣지 않는다.  
**손으로 들고 가거나, 임시 쓰레기통에 넣어 모선으로 가져간다.**

| 방식 | 설명 | 리스크 |
|---|---|---|
| **손 운반** | 샘플을 들고 모선까지 이동 | 벽·설비 **충돌 시 손상** 가능 |
| **임시 쓰레기통** | 샘플을 쓰레기통에 담아 운반 | 전도·충돌 시 쏟아짐/손상 가능 |

- 막힌 동선을 벽 철거로 연 뒤에야 닿는 위치
- 주변이 지저분하면 헤라로 정리할 수 있다 (필수는 아님)
- 배관/과열 차단 후 추출
- 붕괴·잔해에 묻히면 손상/미회수 위험

## 6. 건강 / 부상 / 사망

### 설계 원칙
캐릭터 상태는 **세 단계만** 쓴다.  
경미/중상/Down 같은 중간 단계는 두지 않는다.  
긴장은 목숨 게이지보다 **샘플 손실 / 시간 손해 / 점검 실패**에 둔다.

### 상태
| 상태 | 의미 | 플레이 영향 |
|---|---|---|
| 건강 | 정상 | 제한 없음 |
| 부상 | 다친 상태 | 이동·작업 속도 감소, 운반/정밀 작업이 불리해짐 |
| 사망 | 쓰러짐 | 부활 가능. 부활 후 평가/정산 감점 |

### 전환
1. 건강 → 부상: 붕괴·파편·사고 피해
2. 부상 → 사망: 추가 피해 또는 치명적 사고
3. 건강 → 사망: 한 번에 치명타급 사고 (드묾)
4. 사망 → 건강(또는 부상): 부활. 부활 직후 짧은 디버프 + 평가/정산 감점
5. 부상 → 건강: 모선 복귀/치료로 회복 (현장 중간 회복은 최소화)

### 금지에 가까운 방향
- Down 등 중간 상태 추가
- 초반부터 잦은 영구사망
- 사망 즉시 파티 게임오버
- 전투 중심의 하드코어 생존화

## 7. 상인 / 호감도 / 퀘스트

### 상인의 역할
모선 상인은 상점 점원이자 계약 중개자다.
- 장비 판매
- 착수금 지급
- 상급 샘플 퀘스트 부여
- 대출 제공
- 호감도에 따른 거래 조건 변경

### 호감도
- 범위: `-4.0 ~ +5.0`
- 소수점 단위로 변동
- 상점 해금, 착수금 배율, 대출 조건에 영향

### 퀘스트
기본 미션과 별도인 추가 계약이다.
- 예: A급 샘플 Intact 회수, S급 데이터 코어 무파손 회수
- 성공: 호감도 상승 + 보상 + 해금 진행
- 실패: 호감도 하락
  - 미회수 실패 < 파괴 실패 (파괴가 더 큼)

### 해금 원칙
돈만으로 최상위 장비를 열지 않는다.  
`호감도 + 퀘스트 진행`이 필요하다.

## 8. 대출

### 규칙
- 모선 상인에게서만 대출 가능
- **패널티는 이자만**
- 한도/이자율은 호감도에 따라 달라짐
- 일 정산 또는 계약 단위로 이자 적용
- 빚이 있어도 입장 금지/호감도 강제 하락/즉시 실패는 없음

### 의도
대출은 처벌이 아니라, 초반 성장과 실패 후 재기를 위한 리스크 도구다.

## 10. 3일 연속 철거 + 현장 점검

### 진행 유지
- 한 기지는 기본적으로 3일 동안 계속 철거한다.
- 1일차에 부순 벽, 연 통로, 남은 잔해는 이후 일차에도 유지된다.
- 파괴되지 않은 미회수 샘플은 다음 날 재회수 가능하다.
- 게임오버 시에만 전체 리셋된다.
- 클리어 시 돈/퀘스트 진행도/호감도/해금 상태를 유지하고 다음 미션으로 간다.

### 폐기 게이지 — 삭제
- **폐기 게이지는 쓰지 않는다.** (구 설계 폐기)
- 2·3일차 현장 점검은 **점수(평가/정산 누적)** 만으로 판정한다.
- 장기 압박·통과·경고는 모두 점수 기준으로 읽힌다.

### 점수 점검 (Day2 / Day3)
점검에 들어가는 점수 요소 예 (가중치는 `05 수치 기획`):
- 모선 **정분류** 환급·보너스
- 샘플 Intact / 손상 / 미회수 / 파괴
- 구역 마감 완료
- 오분류·오염 잔여·미수거 쓰레기·붕괴 사고 감점
- 미복귀·사망 감점

### 현장 점검 일정
| 일차 | 결과 |
|---|---|
| 1일차 | 점검 없음 |
| 2일차 | **점수 기준** 성공 또는 **경고(+패널티)** |
| 3일차 | **점수 기준** 성공 / 경고 상태 실패 시 게임오버 / 무경고 실패 시 비상 4일차 |
| 4일차(비상) | 성공 시 클리어 / 실패 시 게임오버 |

점검 통과 조건 (하루 종료 시):
1. **누적 평가 점수가 기준 이상** — Day2 **600** / Day3 **1400** / Day4 **1600** (`05`)
2. (선택 가산) 지정 샘플 N개 Intact
3. (선택 가산) 지정 구역 마감 완료

→ 게이지 OR 조건은 제거. **점수가 본심판**, 샘플·마감은 점수에 기여하거나 보조 조건.

### 경고 패널티
경고는 단순 표식이 아니라 실제 손해가 있어야 한다.
- 다음 정규일 착수금 **×0.7** (`07 아이템 기획`)
- 소모품 할인 제거
- 다음 점검 **점수 기준** ×1.1
- 평가 점수 **−40**

### 판정 상세
1. Day2 실패 → 경고 + 패널티, Day3 진행
2. Day3 성공 → 계약 클리어
3. Day3 실패 + 이미 경고 → 게임오버
4. Day3 실패 + 경고 없음 → 즉시 게임오버가 아니라 **경고 부여 + 패널티 + 비상 4일차 개방**
5. Day4 성공 → 클리어
6. Day4 실패 → 게임오버

### 비상 4일차 정의
비상 4일차는 정규 일정이 아니라 **무경고 첫 점검 실패에 대한 구제 연장 근무**다.

규칙:
- 착수금 없음
- 목표 중심: **점수를 기준치 이상으로 회복** (청소·분리·마감·잔여 샘플)
- 난이도를 크게 올리지 않는다  
  (추가 몬스터/신규 고난도 함정 대량 추가 금지)
- 같은 기지 진행도 유지
- 작업 시간은 동일하게 08:00~18:00
- 실패하면 게임오버

의도:
> 팀을 처형하는 날이 아니라, 깎인 점수를 되돌리는 마지막 정리 근무.

## 11. 폐기물 분류 (모선)

현장에서는 **점수 분류를 하지 않는다.**  
현장에서는 섞어 주워 담고, **모선 분류장에서만** 가른다.

### 분리하는 방법 (플레이 절차)

1. **현장 수거**  
   오염물·따개비·쓰레기·조각벽을 **손**으로 집거나 **임시 쓰레기통**에 담는다.  
   (이 단계에서는 종류를 맞출 필요 없음. 섞여도 됨.)
2. **모선 이동**  
   손 운반 또는 임시 쓰레기통을 들고 모선으로 간다. (레벨 스트리밍)
3. **분류장 도착**  
   쓰레기통을 비우거나, 손에 든 물건을 분류대 위에 올린다.  
   내용물이 **개별 물리 오브젝트**로 다시 나온다.
4. **하나씩 투입**  
   플레이어가 물건을 집어 **맞는 컨테이너**에 넣는다.  
   (협동: 한 명은 비우고, 한 명은 분류 가능)
5. **정분류 / 오분류**  
   - 정분류 → 환급·평가 점수 가산  
   - 오분류 → 감점 (잘못 넣은 칸에서 다시 꺼내 수정 가능 여부는 프로토에서 결정)  
   - 미분류·미수거 잔여 → 일 종료 시 감점

플레이어 교육 문장:
> 현장은 담기만 한다.  
> 모선에 가서 **다섯 칸**에 맞게 넣는다.  
> **실버=금속, 흰=일반, 파랑=플라스틱, 노랑=오염, 회색=안탐.**

### 모선 분리 5종 (확정)

| 컨테이너 | 색 | 색 의도 | 넣는 것 | 대표 예시 |
|---|---|---|---|---|
| **금속** | **메탈릭 실버** (`#C0C0C0` 계열) | 금속 질감 | 금속류 | 음료캔, 폐공구, 전선·케이블 |
| **일반쓰레기** | **흰색** (`#FFFFFF`) | 생활·기본 | 생활·섬유·종이 등 | 찢어진 작업복, 젖은 서류, 폐장갑·마스크 |
| **플라스틱** | **파란색** (`#2F6BFF`) | 재활용 플라스틱 관례 | 플라스틱·비닐류 | 비닐·포장재, 도시락 용기 |
| **오염된 쓰레기** | **노랑** (`#F5C400`) | 위험·주의 | 오염·위험·생물 부착물 | 헤라 **오염물**, **따개비**, **오염된 조각벽**, 폐전지 |
| **안타는 쓰레기** | **콘크리트 그레이** (`#6E6E6E`) | 불연·잔해·유리 | 불연·건설 잔해·유리 등 | **조각벽**(깨끗), 깨진 실험 유리·비커 |

정분류 점수: 금속 **+20** / 일반 **+12** / 플라스틱 **+16** / 오염 **+32** / 안탐 **+16** (`05`)

색 규칙:
- 컨테이너 본체·뚜껑·바닥 투입구·UI 아이콘에 **같은 색**을 쓴다.
- 현장 쓰레기 오브젝트에도 **작은 색 띠/태그**를 붙여, 모선 가기 전에 어느 칸인지 힌트를 줄 수 있다. (필수는 아님, Day1 학습용 권장)
- 오분류 연출 시에도 칸 색이 보이면 “어디에 잘못 넣었는지”가 바로 읽힌다.

### 현장 산출물 → 정분류 칸 매핑

| 현장 산출물 | 정분류 칸 |
|---|---|
| 조각벽 (깨끗) | 안타는 쓰레기 |
| 오염된 조각벽 | 오염된 쓰레기 |
| 오염물 (헤라) | 오염된 쓰레기 |
| 따개비 (헤라) | 오염된 쓰레기 |
| 음료캔 / 폐공구 / 전선 | 금속 |
| 작업복 / 서류 / 방호 소모품 | 일반쓰레기 |
| 비닐·포장 / 플라스틱 용기 | 플라스틱 |
| 유리 파편 | 안타는 쓰레기 |
| 폐전지 | 오염된 쓰레기 |

### 루프 요약

| 단계 | 장소 | 내용 |
|---|---|---|
| 생성 | 현장 | 오염물 / 따개비 / 각종 쓰레기 / 철거 조각벽(~10) |
| 수거 | 현장 | 손 또는 임시 쓰레기통 (혼적 OK) |

## 13. 개발 구현 시 우선순위

1. 핫바(장비) + 손 집기 + **임시 쓰레기통** 물리(담기/쏟기) + 1층 보급기
2. 벽 파괴 → 조각 ~10 + 오염 제거율 분배 (조각벽 → 안타는 것 / 오염된 조각벽 → 오염)
3. 헤라: 오염물 + 따개비 물리 + 각종 쓰레기 배치(금속·일반·플라스틱·안탐·오염 태그)
4. 모선 분류장: **5종 컨테이너** 투입 + 정/오분류 점수 (`05` 수치)
5. 샘플 손/임시 쓰레기통 운반 + 충돌 손상·파괴 점수
6. 칸막이/지주격벽 + 천장 붕괴 (**무지지 −200**)
7. 3일 진행 + 08~18 복귀 + **점수 기반** Day2/3 점검
8. 레벨 스트리밍(기지 ↔ 바다) + 상인/대출 (폴리시)
