# 04. UI 기획서 (Develop)

**문서 버전:** Develop v2 (점수 점검 · ₡ · 5색 분류 · 폐기 게이지 삭제)  
**연구기지:** X-7  
**관련:** `01 콘셉트` · `02 시스템` · `05 수치` · `07 아이템`  
**원칙:** 캐주얼 톤, 적은 정보량으로도 손해가 읽히게. **평가 점수**와 **크레딧 ₡**는 항상 분리 표시.

---

## 1. 전체 화면 흐름

```text
모선 허브
 ├─ 상인 / 상점
 ├─ 대출
 ├─ 미션/일차 준비
 │   ├─ 구역 확인
 │   ├─ 난이도 선택(계약 시작 시)
 │   └─ 퀘스트 수락
 ├─ 로드아웃 (핫바 장비만)
 └─ Day 출발
      ↓
모선에서 바로 수중 투입 (레벨 스트리밍)
      ↓
인게임 HUD (08:00~18:00)
  · 현장: 청소 / 철거 / 손·임시 쓰레기통
  · 모선 복귀: 5색 분류장 + 샘플 납품
      ↓
18:00 모선 출발 / 미복귀 확정
      ↓
일일 정산 리포트 (점수 트랙 + ₡ 트랙)
      ↓
호감도 / 해금 갱신
      ↓
Day2·Day3 현장 점검 (누적 점수 기준)
     ↓
(무경고 Day3 실패 시) 비상 Day4 — 점수 회복
     ↓
다음 날 계속 / 클리어 / 게임오버
```

---

## 2. 모선 허브

플레이어가 매일 가장 많이 보는 화면이다.

### 고정 표시
| 정보 | 예시 | 이유 |
|---|---|---|
| 현재 일차 | Day 2 / 3 · (비상 Day4) | 계약 진행 위치 |
| **누적 평가 점수** | 820 / 1400 | 장기 위기 = 점검 점수 (`05`) |
| 다음 점검 | Day3 · 기준 1400 (경고 시 ×1.1) | 목표 가시화 |
| 경고 상태 | 없음 / 경고(+패널티 적용중) | 게임오버 임박도 |
| 비상일 여부 | 정규 Day / 비상 Day4 | 착수금 0 · 점수 회복 안내 |
| 호감도 | +2.4 | 상점/착수금 |
| **보유 크레딧** | 17,500₡ | 구매/대출 판단 (`07`) |
| 현재 빚/이자 | 5,000₡ / 10% | 상환 압박 |
| 오늘 근무 | 08:00~18:00 | 규칙 상기 |
| 오늘 착수금 | 500₡ (경고 시 350₡) | 출발 전 확정 |
| 출발 버튼 | DAY START | 핵심 CTA |

**표시하지 않음:** 폐기 게이지 (시스템 삭제).

### 허브에서 가능한 행동
- 상인 대화
- 상점 구매
- 대출/상환
- 퀘스트 확인
- 로드아웃 편성 (핫바 장비만)
- 출발

## 3. 상점 UI

### 카테고리
1. 도구 (헤라·절단 등)
2. 스캐너
3. 안전 (지지대 등)
4. 회수
5. 소모품
6. 모선 업그레이드

### 아이템 카드에 반드시 넣을 것
- 이름
- 가격 (**₡**)
- 한 줄 기능 설명
- 해금 상태
- 잠김 조건  
  예: `호감도 +2.0 필요 · 퀘스트 성공 2회`

### UX 포인트
- 잠긴 아이템도 “다음에 뭐가 열리는지” 보이게
- 호감도 옆에 `다음 해금까지 0.6` 표시
- 임시 쓰레기통은 **상점 비매품** — 1층 대기장 보급만 (`07` IT-B0)

## 5. 미션 / 난이도 / 퀘스트 UI

### 미션 카드
- 구역명: `X-7 B2 생물실험동`
- 계약 일수: `3 Day Contract`
- 현재 진행도: 개방 구역, 남은 샘플
- 점검 요약: `Day2 ≥600 · Day3 ≥1400` (Day4 `≥1600`)

### 난이도 카드 (계약 시작 시)
각 카드에 요약:
- 착수금 (₡)
- 시간 압박
- 상급 샘플 수
- 붕괴 리스크
- 실패 리스크 (점수·과태료)

### 퀘스트 카드
- 목표 (샘플 Intact 등)
- 성공 시: 호감도 `+0.4` · **퀘스트 보수 N₡** · (평가 점수는 `05` 별도)
- 실패/파괴 시: 호감도 · 위약(보수 예정액의 40%)
- 수락/거절
- 안내: “샘플 납품 자체에는 돈이 없다. 퀘스트만 ₡.”

## 6. 인게임 HUD

### 항상 보이는 정보
| 위치 권장 | 정보 |
|---|---|
| 상단 | 현재 시각, 18:00까지 남은 시간, Day |
| 좌상단 | 팀 상태(정상/Down/사망/미복귀 위험) |
| 우상단 | 샘플 `회수/목표`, **오늘 평가 점수**(실시간) |
| 하단 | **핫바(장비만)**, 상호작용 프롬프트 |
| 하단 중앙 | 상태바(산소/부상) |
| 손/통 휴대 시 | 들고 있는 대상 아이콘 · 임시 쓰레기통 적재량 `n/12` |

### 상황형 팝업
- 지주격벽 감지
- 배관/과열 경고
- 17:00 철수 권고
- 17:30 강력 경고
- 샘플 Intact/손상 확정
- 천장 붕괴 (점수 −200 / −120 · 과태료 ₡)
- 쓰레기통 전도·쏟음

### 스캔 오버레이
아이콘만으로 읽히게:
- 칸막이격벽
- 지주격벽
- 배관
- 과열
- 균열
- 샘플 반응

텍스트 장문 설명은 허브/도움말로 분리한다.

### 표시하지 않음
- 폐기 게이지 미니
- 무게추 토글/아이콘
- 자원 가방 인벤 그리드

## 7. 모선 분류장 UI (5색)

현장은 섞어 담기만, **모선에서만** 분리한다.

| 칸 | 라벨 | 색 |
|---|---|---|
| 금속 | Metal | 실버 |
| 일반쓰레기 | General | 흰 |
| 플라스틱 | Plastic | 파랑 |
| 오염된 쓰레기 | Contaminated | 노랑 |
| 안타는 쓰레기 | Non-combustible | 회색 |

### UX
- 투입 시 즉각 피드백: `+20점 · +8₡` / `오분류 −12점`
- 오염계를 비오염 칸에 넣으면 **강조 경고** (−24점)
- 샘플 납품 패널은 분류장과 분리:  
  - 항상 `평가 점수 +N`  
  - 퀘스트 중이면 추가로 `퀘스트 보수 +N₡`
- 18:00 전 미분류 잔여가 있으면 경고 배지

## 9. 일일 정산 리포트

정산은 “성적표”가 아니라 **손해 명세서 + 성장 보고서**다.  
**상단 탭 또는 2단 레이아웃으로 점수 / ₡를 분리**한다.

### A. 평가 점수 (점검용)
1. 분리 정분류 합 (+20/12/16/32/16 계열)
2. 철거 성공 보너스 (+15 / +30)
3. 샘플 Intact / 손상 / 미회수 / 파괴
4. 구역 마감 · 퀘스트 성공 점수 · 정시 복귀
5. 오분류 · 미수거 · 붕괴 · 미복귀 · 사망 차감
6. **오늘 점수 / 누적 점수 / 다음 점검 기준**

### B. 크레딧 ₡ (상점용)
1. 착수금
2. 분리 환급
3. 퀘스트 보수 / 위약
4. 평가 연동 보너스 (당일 점수 × 1₡)
5. 붕괴·미복귀·사망 과태료
6. 대출 이자 · 상점 지출
7. **오늘 순이익 · 보유 ₡**

### 읽기 순서
상단: 오늘 성공한 것  
중단: 깎인 것  
하단: 누적 점수 vs 점검 · 최종 ₡과 다음 날 상태

**표시하지 않음:** 폐기 게이지 증감, 철거 수당, 샘플 납품 현상금.

## 10. 현장 점검 UI

판정은 **누적 평가 점수**만. (`05`: Day2 **600** / Day3 **1400** / Day4 **1600**)

### 2일차
- 제목: `Day 2 Site Inspection`
- 표시: `누적 점수 XXX / 600`
- 결과:
  - 성공 → 다음 날 진행
  - 실패 → `WARNING` + 패널티 요약 후 Day3 진행

### 3일차
- 제목: `Day 3 Final Inspection`
- 표시: `누적 점수 XXX / 1400` (경고 상태면 기준 ×1.1)
- 결과:
  - 성공 → 계약 클리어
  - 실패 + 경고 상태 → 게임오버
  - 실패 + 경고 없음 → 경고+패널티 후 `Emergency Day 4` 안내

### 비상 4일차
- 제목: `Emergency Day 4 — Score Recovery`
- 명시 문구:
  - 착수금 없음 (0₡)
  - 목표: **누적 점수 ≥ 1600**
  - 난이도 과도 상승 없음
- 성공 → 클리어
- 실패 → 게임오버

### 경고 패널티 표시 예시
- 다음 착수금 **×0.7**
- 소모품 할증/할인 제거
- 다음 점검 기준 **×1.1**
- 평가 점수 **−40** (`05` S−11)

제외 표시:
- 게이지 직접 상승 없음
- 호감도 하락 없음 (경고 자체로는)

### 클리어 요약에 보여줄 유지 데이터
- 크레딧 ₡
- 호감도
- 퀘스트 진행도
- 상점 해금
- 대출 잔액
- (참고) 누적 평가 점수 — 다음 기지로 넘어가면 리셋 여부는 메타 규칙에 따름

## 11. UI 카피 톤

- 짧게, 업무적으로, 약간 장사꾼 말투
- 공포 연출 카피 지양
- 예:
  - “모선 출발까지 00:40”
  - “미복귀 1명 · 평가 −35 · 과태료 40₡”
  - “지주격벽 · 지지대 권장”
  - “누적 820 / 1400 · 경고 없음”
  - “경고 적용 · 재실패 시 계약 종료”
  - “비상 4일차 · 착수금 없음 · 점수 1600”
  - “실버·흰·파랑·노랑·회색으로 가른다”
  - “핫바는 공구함이다”

## 12. 구현 우선순위

1. 허브 상태 패널 (Day / **누적 점수·점검 기준** / 호감도 / ₡ / 시계 규칙)
2. 인게임 시계 + 18:00 경고 + 핫바
3. 모선 5색 분류 피드백 (점수·₡ 분리 토스트)
4. 정산 리포트 (점수 단 / ₡ 단)
5. 점검 결과 화면 (600 / 1400 / 1600)
6. 상점 해금 · 대출 · 퀘스트 상세
7. 임시 쓰레기통 적재 HUD · 대기장 보급 프롬프트
