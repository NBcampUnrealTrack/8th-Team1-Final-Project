# 04. UI 기획서 (Develop)

**문서 버전:** Develop v5 (9차 회의: 사망 처리 HUD · 세이브 버튼 반영 · 퀘스트 실패 위약금 삭제, 호감도만 하락으로 정정 · §5.5 퀘스트 목록 3탭 화면 신설)  
**연구기지:** X-7  
**관련:** `01 콘셉트` · `02 시스템` · `05 수치` · `07 경제` · `08 아이템`  
**원칙:** 캐주얼 톤, 적은 정보량으로도 손해가 읽히게. **평가 점수**와 **크레딧 ₡**는 항상 분리 표시.

## 1. 전체 화면 흐름

```text
모선 허브
 ├─ 상인 / 상점
 ├─ 대출
 ├─ 미션/일차 준비
 │   ├─ 구역 확인
 │   ├─ 난이도 선택(계약 시작 시)
 │   └─ 퀘스트 수락
 ├─ 로드아웃 (핫바 장비만)
 └─ Day 출발
      ↓
모선에서 바로 수중 투입 (레벨 스트리밍)
      ↓
인게임 HUD (08:00~18:00)
  · 현장: 청소 / 철거 / 손·임시 쓰레기통
  · 모선 복귀: 5색 분류장 + 샘플 납품
      ↓
18:00 모선 출발 / 미복귀 확정
      ↓
일일 정산 리포트 (점수 트랙 + ₡ 트랙)
      ↓
호감도 / 해금 갱신
      ↓
Day2·Day3 현장 점검 (누적 점수 기준)
     ↓
(무경고 Day3 실패 시) 비상 Day4 — 점수 회복
     ↓
다음 날 계속 / 클리어 / 게임오버
```

## 2. 모선 허브

플레이어가 매일 가장 많이 보는 화면이다.

### 고정 표시
| 정보 | 예시 | 이유 |
|---|---|---|
| 현재 일차 | Day 2 / 3 · (비상 Day4) | 계약 진행 위치 |
| **누적 평가 점수** | 820 / 1400 | 장기 위기 = 점검 점수 (`05`) |
| 다음 점검 | Day3 · 기준 1400 (경고 시 ×1.1) | 목표 가시화 |
| 경고 상태 | 없음 / 경고(+패널티 적용중) | 게임오버 임박도 |
| 비상일 여부 | 정규 Day / 비상 Day4 | 착수금 0 · 점수 회복 안내 |
| 호감도 | +2.4 | 상점/착수금 |
| **보유 크레딧** | 17,500₡ | 구매/대출 판단 (`07`) |
| 현재 빚/이자 | 5,000₡ / 10% | 상환 압박 |
| 오늘 근무 | 08:00~18:00 | 규칙 상기 |
| 오늘 착수금 | 500₡ (경고 시 350₡) | 출발 전 확정 |
| 출발 버튼 | DAY START | 핵심 CTA |

**표시하지 않음:** 폐기 게이지 (시스템 삭제).

### 허브에서 가능한 행동
- 상인 대화
- 상점 구매
- 대출/상환
- 퀘스트 확인
- 로드아웃 편성 (핫바 장비만)
- **세이브** (세션 생성자만 버튼 노출, `02` §10.5)
- 출발

- 가격 (**₡**)
- 한 줄 기능 설명
- 해금 상태
- 잠김 조건

### UX 포인트
- 잠긴 아이템도 “다음에 뭐가 열리는지” 보이게
- 호감도 옆에 `다음 해금까지 0.6` 표시
- **쓰레기통은 상점 비매품** — 기지 **폐기물 대기장**에서만 무한 보급 (`08` IT-B0). 대형통 없음.

## 5. 미션 / 난이도 / 퀘스트 UI

### 미션 카드
- 구역명: `X-7 B2 생물실험동`
- 계약 일수: `3 Day Contract`
- 현재 진행도: 개방 구역, 남은 샘플
- 점검 요약: `Day2 ≥600 · Day3 ≥1400` (Day4 `≥1600`)

### 난이도 카드 (계약 시작 시)
각 카드에 요약:
- 착수금 (₡)
- 시간 압박
- 상급 샘플 수
- 붕괴 리스크
- 실패 리스크 (점수·과태료)

### 퀘스트 카드 (= 반복 퀘스트 카드, §5.5 참고)
- 목표 (샘플 Intact 등)
- 성공 시: 호감도 `+0.4` · **퀘스트 보수 N₡** · (평가 점수는 `05` 별도)
- 실패/파괴 시: **호감도만 하락** (크레딧 위약금 없음 — 미회수보다 파괴가 더 크게 하락, `07` §3.2)
- 수락/거절
- 안내: “샘플 납품 자체에는 돈이 없다. 퀘스트만 ₡.”

> 이 카드는 **반복 퀘스트 전용**이다. 메인 퀘스트·로어 퀘스트는 완전히 다른 화면이 필요하다 — §5.5.

## 5.5. 퀘스트 목록 화면 (3탭, 신규)

### 왜 탭이 3개인가
퀘스트는 **메인 / 반복 / 로어** 3종류뿐이고 (`09` §0), 서로 **상호작용 모델이 완전히 다르다.**  
하나의 “퀘스트 카드” 컴포넌트를 셋 다에 재사용하면 안 된다 — 탭마다 리스트 형태·버튼·상태 표시를 따로 설계해야 한다.

### 탭별 차이 한눈에

| 탭 | 데이터 원천 | 리스트 형태 | 항목 상태 | 수락/거절 | 진행도 |
|---|---|---|---|---|---|
| **메인퀘** | `09` §1, `10` §2 (Day별 고정) | Day1/2/3 세로 3줄 고정 | 완료 / 진행중 / 잠김 | **없음** (자동 활성) | 하위목표 체크 |
| **반복퀘** | `09` §4, `10` §3 (계약당 2~3개 랜덤) | 카드 2~3개 | 제시 / 수락 / 진행중 / 완료 / 실패 | **있음** (개별 수락·거절, 수락 후 포기 가능) | N/M 진행도 |
| **로어퀘** | `09` §5, `10` §4 (현장 고정 배치, 발견형) | 현장 전체 목록 (X-7 기준 7개) | 미발견 / 발견 / (일부) 암호화됨 | **없음** (자동 등록, 아이템처럼) | 전체 완성률 N/7 |

### 탭1: 메인퀘
- Day1/2/3을 항상 세로로 나열한다. **현재 Day만 펼쳐진 카드**로 하위목표(외부/내부 서브목표 등)를 보여주고, 지난 Day는 완료 체크, 다음 Day는 잠김(회색 처리)으로 표시한다.
- **수락/거절 버튼이 없다.** 그 Day가 되면 자동으로 활성화되는 목표다.
- 완료하지 않아도 다음 Day 진행에는 영향이 없다(`09` §1). UI에서도 강제로 막지 말고 “미완료” 배지만 남긴 채 계속 보이게 한다.
- 같은 현장을 재방문해도 항상 **동일한 라인**이 나온다 — 매번 다시 확인할 필요 없이 익숙한 목록이어야 한다.

### 탭2: 반복퀘
- 기존 §5 “퀘스트 카드” 스펙을 그대로 쓴다.
- 계약당 2~3개 카드가 제시되고(현장 2회차 방문부터, `09` §4), **카드별 개별 수락/거절** 버튼이 있다.
- 수락 후: 진행도 `N/M` 표시 + **포기(파기) 버튼** 노출. 포기 시 확인 팝업(“포기하면 호감도가 떨어집니다”).
- 미수락 카드는 계약이 끝나도 실패 처리되지 않는다 — 조용히 사라진다 (`07` §3.2 규칙1).
- 완료/실패 결과는 **호감도만** 반영한다. 크레딧 위약금은 없다.

### 탭3: 로어퀘 (코덱스)
- **수락/거절 개념 자체가 없다.** “지금까지 발견한 기록물 목록”일 뿐이다.
- 미발견 항목은 `???` 잠김 아이콘, 발견하면 이름·내용이 공개된다.
- 상단에 **전체 완성률 바** (`N/7`, 현장별로 총 개수 다름).
- 일부 항목(X-7의 “심해 신호 기록” 등, `10` §4)은 발견해도 곧바로 안 열리고 **“암호화됨”** 으로 표시되다가, 나머지를 다 모으면 자동으로 해독된다 — 잠금 아이콘은 **미발견 / 발견(암호화) / 해독됨** 3단계로 표시해야 한다.
- 실패·포기 개념이 없다. 파괴되지 않는 한 언제든 재방문해서 주울 수 있다.

### 공통 주의
- 패널 타이틀을 탭 공통으로 “퀘스트 목록”이라고 고정하지 않는다. 탭에 따라 바뀌는 게 자연스럽다 — 예: 로어퀘 탭에서는 “기록 보관함(코덱스)”처럼, 퀘스트라기보다는 **수집물 목록**에 가깝게 표기한다.
- 세 탭 다 **점검(Day2/3/4) 통과와 무관한 보너스**다 (`09` §0 원칙1). 이 사실이 UI에서도 드러나야 오해가 없다 — 예: “점검엔 영향 없음” 같은 보조 문구.

## 6. 인게임 HUD

### 항상 보이는 정보
| 위치 권장 | 정보 |
|---|---|
| 상단 | 현재 시각, 18:00까지 남은 시간, Day |
| 좌상단 | 팀 상태(정상/부상/사망/미복귀 위험) · 사망 중에도 **마이크 아이콘 활성** 유지 |
| 우상단 | 샘플 `회수/목표`, **오늘 평가 점수**(실시간) |
| 하단 | **핫바(장비만)**, 상호작용 프롬프트 |
| 하단 중앙 | 상태바(**HP**/산소/부상) |
| 손/통 휴대 시 | 들고 있는 대상 아이콘 · 임시 쓰레기통 적재량 `n/12` |

### 상황형 팝업
- 지주격벽 감지
- **전선 교차 / 수도관 교차** (절단 조준 시)
- **전원 차단** (전선 절단 → 암전)
- **수도 파열 · 오염수 확산** (Niagara)
- **오염수 노출 · HP 감소** (위험 볼륨 진입 시 짧은 경고 + HP 바 깜빡임)
- 배관/과열 경고
- 17:00 철수 권고
- 17:30 강력 경고
- 샘플 Intact/손상 확정
- 천장 붕괴 (점수 −200 / −120 · 과태료 ₡)
- 쓰레기통 전도·쏟음
- 전선 수리 완료 / 수도 밀봉 완료
- **사망 → 부활** (즉시 리스폰, 평가 −30 안내 · 죽은 자리에 오염물 생성됨 안내)

### 스캔 오버레이
아이콘·라인만으로 읽히게:
- 칸막이격벽
- 지주격벽
- **전선** (앰버/노랑 라인)
- **수도관** (시안 라인)
- 배관(기타)·과열·균열
- 샘플 반응

텍스트 장문 설명은 허브/도움말로 분리한다.

### 표시하지 않음
- 폐기 게이지 미니
- 무게추 토글/아이콘
- 자원 가방 인벤 그리드

## 7. 모선 분류장 UI (5색)

현장은 섞어 담기만, **모선에서만** 분리한다.

| 칸 | 라벨 | 색 |
|---|---|---|
| 금속 | Metal | 실버 |
| 일반쓰레기 | General | 흰 |
| 플라스틱 | Plastic | 파랑 |
| 오염된 쓰레기 | Contaminated | 노랑 |
| 안타는 쓰레기 | Non-combustible | 회색 |

### UX
- 투입 시 즉각 피드백: `+20점 · +8₡` / `오분류 −12점`
- 오염계를 비오염 칸에 넣으면 **강조 경고** (−24점)
- 샘플 납품 패널은 분류장과 분리:  
  - 항상 `평가 점수 +N`  
  - 퀘스트 중이면 추가로 `퀘스트 보수 +N₡`
- 18:00 전 미분류 잔여가 있으면 경고 배지

## 9. 일일 정산 리포트

정산은 “성적표”가 아니라 **손해 명세서 + 성장 보고서**다.  
**상단 탭 또는 2단 레이아웃으로 점수 / ₡를 분리**한다.

### A. 평가 점수 (점검용)
1. 분리 정분류 합 (+20/12/16/32/16 계열)
2. 철거 성공 보너스 (+15 / +30)
3. 샘플 Intact / 손상 / 미회수 / 파괴
4. 구역 마감 · 퀘스트 성공 점수 · 정시 복귀
5. 오분류 · 미수거 · 붕괴 · 미복귀 · 사망 차감
6. **오늘 점수 / 누적 점수 / 다음 점검 기준**

### B. 크레딧 ₡ (상점용)
1. 착수금
2. 분리 환급
3. 퀘스트 보수 / 위약
4. 평가 연동 보너스 (당일 점수 × 1₡)
5. 붕괴·미복귀·사망 과태료
6. 대출 이자 · 상점 지출
7. **오늘 순이익 · 보유 ₡**

### 읽기 순서
상단: 오늘 성공한 것  
중단: 깎인 것  
하단: 누적 점수 vs 점검 · 최종 ₡과 다음 날 상태

**표시하지 않음:** 폐기 게이지 증감, 철거 수당, 샘플 납품 현상금.

## 10. 현장 점검 UI

판정은 **누적 평가 점수**만. (`05`: Day2 **600** / Day3 **1400** / Day4 **1600**)

### 2일차
- 제목: `Day 2 Site Inspection`
- 표시: `누적 점수 XXX / 600`
- 결과:
  - 성공 → 다음 날 진행
  - 실패 → `WARNING` + 패널티 요약 후 Day3 진행

### 3일차
- 제목: `Day 3 Final Inspection`
- 표시: `누적 점수 XXX / 1400` (경고 상태면 기준 ×1.1)
- 결과:
  - 성공 → 계약 클리어
  - 실패 + 경고 상태 → 게임오버
  - 실패 + 경고 없음 → 경고+패널티 후 `Emergency Day 4` 안내

### 비상 4일차
- 제목: `Emergency Day 4 — Score Recovery`
- 명시 문구:
  - 착수금 없음 (0₡)
  - 목표: **누적 점수 ≥ 1600**
  - 난이도 과도 상승 없음
- 성공 → 클리어
- 실패 → 게임오버

### 경고 패널티 표시 예시
- 다음 착수금 **×0.7**
- 소모품 할증/할인 제거
- 다음 점검 기준 **×1.1**
- 평가 점수 **−40** (`05` S−11)

제외 표시:
- 게이지 직접 상승 없음
- 호감도 하락 없음 (경고 자체로는)

### 클리어 요약에 보여줄 유지 데이터
- 크레딧 ₡
- 호감도
- 퀘스트 진행도
- 상점 해금
- 대출 잔액
- (참고) 누적 평가 점수 — 다음 기지로 넘어가면 리셋 여부는 메타 규칙에 따름
