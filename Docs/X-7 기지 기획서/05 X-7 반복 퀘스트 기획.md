## 0. 설계 원칙

1. **반복은 계약이 수명 단위다.** 추첨은 계약 시작 시 1회다. 정규 계약은 Day3에 끝나지만, 비상 4일차가 열리면 상태·진행도·스폰물을 그날까지 유지한다 (`공통 12` §3). 실패 판정은 실제 계약 종료 때 한 번 한다. 이월 금지는 메인에만 걸린다.
2. **미회수 스폰물도 계약 종료까지 맵에 남는다.** Day1에 뽑힌 R10의 B급 샘플을 Day3에 회수해도 성공이다.
3. **호감도는 슬롯에 붙는다.** 등급 성공값의 절반, 소수점 1자리, 상한 +0.2 (`09` §1.5). 점수·₡는 등급이 그대로 결정한다.
4. **등급별 샘플 회수는 전부 반복에 있다.** 메인은 카트리지·퀘스트 전용 샘플만 스폰한다 (`01` §2.2).
5. **1회차 예외는 R09 하나다.** 반복 풀은 2회차부터 노출되므로 그대로 두면 1회차에 등급 샘플이 통째로 사라진다. R09를 1회차 Day1 고정 노출로 빼고 랜덤 풀에서 제외한다.
6. **큰 보상 2장은 겹치지 않는다.** R10·R11은 합쳐서 최대 1개 (`01` §6 메모 3).

### 1.1 실제 진행을 연결할 목표

현재 코드에는 회수 납품과 **메인** Interaction 진행이 있다. 반복 의뢰의 청소·마감·복합 목표는 별도 진행 연결이 필요하다. 반복 DA 8개가 전부 회수 타입이라는 제보는 최신 에셋에서 재확인한다. 아래는 에셋 실측값이 아니라 **기획상 필요한 동작**이다.

| ID | 목표 구분 | 진행을 세는 행동 |
|---|---|---|
| R02 | 손상 허용 회수 | 해당 샘플 2개 납품 |
| R05 | 마감 | 부속 격벽 철거·청소 조건 충족 후 지정 구역 마감 |
| R06 | 청소 계약 / 조사 | 서로 다른 해수 스캔 지점 3곳 완료. 샘플 납품 없음 |
| R07 | 청소 | 지정 표류 폐기물 5개를 현장 대기장에서 정분류 |
| R08 | 손상 허용 회수 | 생물 샘플 2개 납품 |
| R09 | 복합 | 부유물 2개 정리 + 진입구 청소·마감 + C급 샘플 1개 납품 |
| R10 | 온전한 회수 | B급 샘플 2개 Intact 납품 |
| R11 | 온전한 회수 | A급 코어 1개 Intact 납품 |

같은 물건이나 스캔 지점을 반복해서 세지 않는다. 마감은 마커를 누르기 전에 구역 조건을 검사한다. R09는 샘플만 납품해도 완료되지 않는다. 진행·완료·보상은 서버에서 한 번만 확정한다.

**보상 표의 총액을 유지한다.** R05 +40은 기본 구역 마감 점수다. R09 +110도 마감 +40과 C급 회수 +70을 합한 값이므로 이미 지급한 마감 점수를 다시 더하지 않는다. 크레딧과 호감도는 아래 기존 표를 따른다. 구현 근거와 확인 절차는 [공통 15](../공통%20기획서/15%20구현%20대조%20및%20플레이%20검증%20기획.md) §9를 본다.

## 14. 개발 우선순위

1. **R09** — 1회차 고정 노출이라 첫 플레이 경험에 직결된다. 별도 노출 경로부터.
2. **R10** — Intact 판정이 이미 있는 회수 로직을 그대로 쓴다.
3. **R11** — A급 1개, R10과 배타 가중치 처리 필요.
4. **R02·R05** — R02는 손상 허용 회수를 재사용한다. R05는 마감 조건 검사와 반복 의뢰 진행 연결을 추가해야 한다.
5. **R06·R07·R08** — 외부 구역. 해수 스캔(R06)만 신규 기믹이고 나머지는 기존 수거·회수다.

**8종의 서브목표·대사·실패 처리 작성은 끝났다.** 구현 완료를 뜻하지 않는다. R05·R06·R07·R09는 §1.1의 행동과 진행 연결을 검증해야 한다.

- R09·R10·R11 — 구 메인 전제(첫날 / 오늘 하루 / 최종 목표)를 걷어냈고, R09는 **1회차용·일반용 2종**으로 갈랐다 (§2~§4)
- R02·R05·R06·R07·R08 — 방의 기능에 맞춰 신규 작성 (§5~§9)
