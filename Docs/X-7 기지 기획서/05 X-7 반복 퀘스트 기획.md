# 05. X-7 반복 퀘스트 기획서 (Develop)

**문서 버전:** Develop v1 (반복 8종 상세 정본 신설. **R09·R10·R11 상세를 복구** — 구 메인 Day1~3 상세가 `01` v7 교체(`361e07a`) 때 표 한 줄로 축약되면서 서브목표·대사·스폰·실패 처리가 문서에서 사라졌다. 호감도는 슬롯 기준(`09` §1.5)으로 재산했고, 점수·₡는 강등 시 불변이므로 구 값을 그대로 승계했다. R02·R05·R06·R07·R08은 **틀만** 세우고 서목표·대사는 TBD로 남긴다)
**현장:** X-7 해저 연구기지
**관련 문서:** `공통 기획서/09 퀘스트 기획`(프레임워크 §1.5·§4) · `05 수치`(점수) · `07 경제 시스템`(유형·₡) · `08 아이템` · `02 시스템`(§7 호감도) · `X-7 기지 기획서/01 X-7 퀘스트 기획`(**풀 총괄·수치표 정본**) · `03 X-7 메인 퀘스트 기믹`(메인 정본) · `02 X-7 레벨 배치`(도면) · `04 X-7 로어 퀘스트 기획`(로어 정본)

이 문서는 X-7 **반복 퀘스트 8종의 목표·기믹·대사·스폰·실패 처리** 정본이다.
풀 구성표와 호감도 규칙표는 `01` §3에 남긴다 — `01` §2↔`03`과 같은 분업이다. 프레임워크(추첨 시점, 이월, 슬롯 호감도)는 `09` §1.5·§4를 그대로 따른다.

**이 문서는 새 설계를 담지 않는다.** 전부 `01`·`03`·`09`에 이미 확정된 내용의 상세화이거나, git에서 복구한 구 상세다. 새로 지어낸 수치는 없다.

## 0. 설계 원칙

1. **반복은 계약이 수명 단위다.** 추첨은 계약 시작 시 1회, 조합은 3일 내내 고정. 실패 판정은 계약 종료(Day3 18:00) 한 번뿐이다 (`09` §1.5·§4). 이월 금지는 메인에만 걸린다.
2. **미회수 스폰물도 계약 종료까지 맵에 남는다.** Day1에 뽑힌 R10의 B급 샘플을 Day3에 회수해도 성공이다.
3. **호감도는 슬롯에 붙는다.** 등급 성공값의 절반, 소수점 1자리, 상한 +0.2 (`09` §1.5). 점수·₡는 등급이 그대로 결정한다.
4. **등급 샘플 트랙은 전부 반복에 있다.** 메인은 카트리지·퀘스트 전용 샘플만 스폰한다 (`01` §2.0).
5. **1회차 예외는 R09 하나다.** 반복 풀은 2회차부터 노출되므로 그대로 두면 1회차에 등급 샘플이 통째로 사라진다. R09를 1회차 Day1 고정 노출로 빼고 랜덤 풀에서 제외한다.
6. **큰 보상 2장은 겹치지 않는다.** R10·R11은 합쳐서 최대 1개 (`01` §6.3).

## 3. X7-R10 — "생물실험동 회수" (내부)

**구 메인 Day2.** Intact 조건이 이 퀘스트의 핵심 압박이다.

| 항목 | 내용 |
|---|---|
| 위치 | 04·05·06 생물실험동 |
| 목표 | 진입 + **B급 샘플 2개 Intact** 회수 |
| 샘플 스폰 | 퀘스트 활성 시 **B급 2개**가 04·05·06에 스폰 (`01` §2.0) |
| 07 유형 매핑 | 회수 B Intact ×2 (160₡×2) |

### 수치

| 결과 | 점수 | ₡ | 호감도 |
|---|---:|---:|---:|
| 성공 | **+280** (140×2) | **320₡** | **+0.4** (0.2×2) |
| 미회수 | −35 /개 | — | −0.2 /개 |
| 파괴 | −85 /개 | — | −0.4 /개 |

### 대사 (재작성 필요)

- 발주처: "생물실험동이 우선이다. B급은 반드시 Intact."
- 브릭스: "여기부터 진짜다. 깨뜨리면 **오늘 하루가** 마이너스야."

> **TBD — 브릭스 대사의 정산 단위가 틀렸다.** 반복은 일일 정산이 아니라 계약 종료에 한 번 정산한다 (`09` §1.5). "오늘 하루"를 "이번 계약"으로 바꿔야 한다.

### 실패 처리

**Intact 조건이므로 손상 회수는 성공이 아니다.** 손상분은 미회수로 처리한다. 미회수 샘플은 계약 종료까지 맵에 남으므로 다음 Day에 재시도 가능하다.

## 4. X7-R11 — "데이터 코어 회수" (내부)

**구 메인 Day3.** 이름에서 "최종"을 뗐다 — 더 이상 계약의 끝이 아니다 (`01` §3.1).

| 항목 | 내용 |
|---|---|
| 위치 | B1 심층 (배양~냉각) |
| 목표 | 해치를 통해 B1 진입, **A급 데이터 코어 1개** 회수 |
| 샘플 스폰 | 퀘스트 활성 시 **A급 1개**가 B1 심층에 스폰 (`01` §2.0) |
| 07 유형 매핑 | 회수 A Intact(280₡) |
| 로어와의 관계 | B1 기록물 **X7-L05**(`04` 정본)와 같은 구간 — 시간이 부족하면 A급 샘플과 기록물 중 하나를 고르는 선택압 |

### 수치

| 결과 | 점수 | ₡ | 호감도 |
|---|---:|---:|---:|
| 성공 | **+220** | **280₡** | **+0.2** (A 상한) |
| 미회수 | −55 | — | −0.2 |
| 파괴 | −130 | — | −0.4 |

> **A 파괴 페널티를 슬롯 기준으로 내렸다.** 구 표의 −0.8을 그대로 두면 랜덤으로 뽑히는 선택 퀘스트 하나가 메인 3일 성공분(+1.4)의 절반 넘게 깎는다 (`01` §3.2).

### 대사 (재작성 필요)

- 발주처: "데이터 코어가 **최종 목표**. 회수하면 **임무 완료**다."
- 브릭스: "이걸로 **이번 계약은 끝**이야. 무사히 나가는 것도 일이다."

> **TBD — 전제가 무효다.** 두 대사 모두 이 퀘스트가 계약의 마지막이라는 구 메인 Day3 전제로 쓰였다. 반복 슬롯은 계약 중 아무 때나 뽑히므로 "최종 목표"·"계약은 끝" 표현을 전부 걷어내야 한다.

### 실패 처리

구 상세에는 "A급 샘플 **또는** 코덱스 기록물 1개"라는 양자택일 문구가 있었으나, 로어는 점수·₡·호감도 트랙 밖이므로(`01` §5) **완료 조건은 A급 코어 1개 회수 하나로 확정한다.** 기록물은 같은 구간에 있다는 선택압으로만 남는다.

## 14. 개발 우선순위

1. **R09** — 1회차 고정 노출이라 첫 플레이 경험에 직결된다. 별도 노출 경로부터.
2. **R10** — Intact 판정이 이미 있는 회수 로직을 그대로 쓴다.
3. **R11** — A급 1개, R10과 배타 가중치 처리 필요.
4. **R02·R05** — 손상 허용 회수 / 마감 계약. 기존 유형 재사용으로 기믹 신규 구현 없음.
5. **R06·R07·R08** — 외부 구역. 해수 스캔(R06)만 신규 기믹이고 나머지는 기존 수거·회수다.

**대사 재작성이 R09·R10·R11 세 건 걸려 있다** (§2·§3·§4의 TBD). 구 메인 전제(첫날 / 오늘 하루 / 최종 목표)가 남아 있어 그대로 쓰면 반복 슬롯과 모순된다.
