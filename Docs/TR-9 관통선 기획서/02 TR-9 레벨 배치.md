## 1. 미션 개요

침수된 터널 안에 갇힌 화물열차를 3일간 조사·해체·회수한다.
(터널 자체가 완전 침수 상태다. 화차 문을 잘못 잘라도 추가 침수는 없다. 위험은 X-7과 동일하게 **천장 붕괴**이며, 다만 TR-9은 붕괴가 발생하는 지점이 화차 문·터널 지지 구조로 한정된다 — `01` §1 철거 판정.)

### 권장 동선 (공식 도면)

1. **Day1** 모선 → (레벨 스트리밍) → **외부: 진입 접근 구간** (문/벽 없음, 학습용 이동) → **화차 1호** 진입(열리는 문) → **화차 2호**(컨테이너 1개 절단 학습) → 화물 선적 목록 회수 → 마감(화차열 진입 구역) → 모선 복귀
2. **Day2** **화차 3호**(잠긴 사무 캐비닛 — 컨테이너 취급, 로어 #1) → **화차 4호**(개인 로커, 로어 #3 — 오염물로 덮여 있어 헤라 필요 / 대피 통로 분기점, TR9-R05 선택 시 진입) → **손상 컨테이너 구역**(화차 5~6호, 컨테이너 3개 절단, 손상 샘플 2개 회수) → 마감(손상 구역) → (선택: **기관실** 분기 진입, TR9-R04) → 모선 복귀
3. **Day3** 화차열 끝 → **터널 진입부**(화차 문 1개 — 부식으로 잠김, **지주격벽 판정**이라 지지대 설치 후 절단) → **터널 붕괴 구간**(잔해 청소, 조사관 가방 로어 #4) → 마감(터널 구간, 대형) → 복귀 전 **외부: 터널 밖 표류 잔해 지대**(로어 #5, 마무리 동선) → 모선 복귀
4. 연결은 화차 간 **문**(대부분 열림) + 터널 진입부의 **화차 문 1개**(절단 필요)뿐. 화차 외벽은 불가침.

**도면 기준 문서은 `03 TR-9 터널 도면.html`이다.** 평면·종단면·횡단면, 기믹 게이트, 에어포켓 용량,
컨테이너 절단 2종, 체인지 배치표가 거기 들어 있다. 이 문서의 텍스트 도면과 어긋나면 `03`을 따른다.

> **`03` 반영 대기.** `03`에서 맵이 0–240 m로 늘고 환기 수직구 공동(Ø16 m)·대피선 공동(폭 14 m)·
> 펌프실이 새로 들어갔다. 아래 §1 동선과 §4 콘텐츠 배치는 아직 구 200 m 선형 기준이다.

## 2. 배치해야 하는 학습 포인트

| 포인트 | 배치 |
|---|---|
| 열리는 문 통과 (철거 없이 진행) | Day1 화차 1~2호 |
| 컨테이너 절단 학습 (칸막이격벽 판정) | Day1 화차 2호 |
| 화차 문도 잘릴 수 있다는 것 학습 (지주격벽 판정, 흔치 않은 예외) | Day3 터널 진입부 — 첫 등장을 여기로 늦춰서 "문은 보통 그냥 연다"는 룰을 먼저 학습시킨 다음 예외를 보여준다 |
| 보통벽 따개비 | 화차열 전역 벽면 |
| 각종 쓰레기(화물 파손·잔해) | 손상 컨테이너 구역 위주 (화차 5~6호) |
| 손/임시 쓰레기통 운반 | Day1 화차 1~2호 |
| 쓰레기통 무한 보급 | 진입 접근 구간 초입 대기장 |
| 컨테이너 안에 숨겨진 목표물 | Day1 화차 2호(TR9-R01), Day2 손상 컨테이너 구역(TR9-R02) — 열기 전까지 안 보임 (`01` §3) |
| 오염물로 가려진 로어 아이템 | Day2 화차 4호 개인 로커 (헤라로 긁어야 노출) |
| 잔해로 덮인 로어 아이템 | Day3 터널 붕괴 구간 조사관 가방 (주변 잔해 먼저 치워야 노출) |
| 지지대 설치 후 절단 | Day3 터널 진입부 (첫 지주격벽 경험) |
| 잘못 자르면 천장 붕괴 | Day3 터널 진입부·터널 붕괴 구간 한정 (화차열 안에서는 발생 안 함 — 컨테이너는 칸막이격벽이라 붕괴 없음) |
| 수영 접근 필요 부유 오브젝트 | 로어 #5 (터널 밖 표류 잔해 지대) |
| 점검 조건 | 표준·4인 기준 Day2 **500** / Day3 **1200** (`05` §3B) — Day3는 표준/실패 경로가 갈리도록 설계됨. 실제 기준은 `05` §0.1 난이도 배율 · §0.2 인원 배율 적용 |

## 3. 난이도별 차이 (단순화 확정)
난이도별로 맵 콘텐츠(화차 문 잼 개수, 손상 샘플 등급, 지지 구조 등)를 따로 만들지 않는다. **TR-9도 난이도 불문 이 도면 하나만 쓴다** — 난이도는 오직 점검 점수 목표만 바꾼다 (`02` §9, `05` §0.1: 안전 ×0.8 / 표준 ×1.0 / 위험 ×1.2 / 극한 ×1.4).
