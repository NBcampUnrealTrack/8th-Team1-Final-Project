# 스캐너 퀘스트 샘플 소리 탐지

스캐너를 들면 반경 30m 안의 퀘스트 귀속 아이템 위치에서 0.5초 길이의 모노 3연속 비프음이 난다. 여러 대상은 1.5초마다 하나씩 순서대로 울린다. 스캔 버튼이나 스캔 모드에 관계없이 동작한다.

플레이어 캐릭터 Blueprint의 ScannerComponent → MD / Scanner / Quest Locator에서 활성화 여부, Quest Locator Radius(cm), Quest Locator Interval(초), Quest Locator Sound를 조절한다. 일반·정밀 스캐너 모두 기존 Ability.WallScan 장착 판정을 따른다.

소리는 샘플 루트에 붙고 3D 공간화·거리 감쇠를 적용한다. 벽 차폐는 사용하지 않는다. 스캐너를 든 로컬 플레이어에게만 재생하며 서버 전체에 방송하지 않는다. QuestDefinitionId를 복제해 접속 클라이언트도 귀속 샘플을 판별한다.

스캐너 해제, 반경 이탈, 숨겨짐, 부착/운반 중인 아이템, 파괴된 아이템은 제외한다. 플레이어가 다른 물건을 들거나 UI가 이동·시점을 잠그는 동안도 소리를 중단한다. 주기적 상태 확인은 0.1초 간격이다.

음원: /Game/Audio/Scanner/SW_QuestSampleBeacon. 원본: ContentSource/Audio/SW_QuestSampleBeacon.wav (모노 24kHz, 16-bit PCM).

검증: 전체 Editor 빌드 통과. MarineDemolition.Scanner.QuestLocator 자동 테스트 통과 — 일반 아이템 제외, 퀘스트 아이템 감지, 샘플 루트 부착, 순차 대상 전환, 숨김/거리 이탈/장착 해제/파괴 중단, 귀속 ID 복제 속성 확인. 테스트는 오디오 출력 없는 격리 게임 월드이며 실제 헤드폰 방향감·음량 및 다중 클라이언트 청취는 별도 확인이 필요하다.
