# 샘플 수면 부유 설정

샘플 또는 퀘스트 스포너의 Details에서 **Float On Water**를 검색해 체크한다. 기본값은 꺼짐이다.

| 설정 | 의미 | 기본값 |
|---|---|---:|
| Float On Water | 수면 근처에서 부력과 상하 흔들림 적용 | 꺼짐 |
| Surface Z | 수면의 월드 Z 좌표(cm). 물 메시/물 볼륨을 자동 인식하지 않는다 | 0 |
| Height Offset | 수면 대비 샘플 무게중심 높이(cm). 메시가 너무 잠기면 올린다 | 0 |
| Bob Amplitude | 상하 흔들림 목표 진폭(cm) | 3 |
| Bob Period | 흔들림 주기(초) | 3 |
| Capture Depth · 고급 | 기준 높이 아래에서 부유 기능이 작동하는 깊이(cm) | 100 |

직접 배치한 `BP_SampleBase`와 샘플 자식 Blueprint에서 설정할 수 있다. 퀘스트가 생성하는 샘플은 `BP_QuestSampleSpawner` 인스턴스에서 체크한다. 스포너에서 켜면 그 스포너가 생성하는 샘플에 설정 전체를 전달한다. 끄면 샘플 Blueprint의 기본 설정을 유지한다.

스포너의 Arrow를 실제 수면 가까이에 배치하고 `Surface Z`를 물 표면 높이에 맞춘다. `Height Offset`을 포함한 기준면보다 30cm 위 또는 `Capture Depth`보다 깊은 곳에서는 부유 힘을 적용하지 않는다. 바닥 아래나 다른 층의 샘플을 수면까지 끌어올리는 기능이 아니다. **해당 높이의 모든 XY 위치에 적용하는 평면 방식**이므로 실내·육지에 부유 옵션을 켠 샘플을 배치할 때도 주의한다.

중력과 충돌을 유지하면서 힘으로 떠오른다. 손에 들거나 부착·보관되어 있는 동안은 부유하지 않으며, 놓은 뒤 수면 근처에 있으면 다시 작동한다. 수평 이동은 감쇠하지만 해류로 특정 방향에 밀어내는 기능은 포함하지 않는다. 물 플러그인의 실제 파도 높이를 추적하는 방식도 아니다.

부유 위치는 서버 물리에서 계산하고 기존 샘플 이동 복제로 전달한다. 부유 옵션은 월드 액터 스냅샷에 저장·복원된다. 샘플의 기존 손상·파괴·납품 규칙은 유지되므로 강한 충돌에서는 여전히 손상될 수 있다.
