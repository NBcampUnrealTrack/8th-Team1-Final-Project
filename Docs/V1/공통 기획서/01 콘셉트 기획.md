# 콘셉트 기획 현재 기준

2026-10-01 시스템 축소 회의 반영. 새 코어는 재확립 중이다.

## 확정 방향

메인·반복 의뢰와 DAY 진행, 벽 헤라질, 지지대, 지주격벽 규칙을 중심에 두지 않는다. **로어퀘스트와 벽을 부수는 개념은 유지한다.**

기존 소개인 ‘사흘간 청소·철거·분리·샘플 회수 후 점검을 통과하는 계약’은 현재 게임의 확정 정의로 쓰지 않는다. 아래 구판 내용은 제작 배경 기록이다.

## 코어 재확립

플레이어가 벽을 부수는 이유, 반복하고 싶은 행동, 협동 선택, 시작과 종료를 박준민이 정리한다. 운반·분류·경제·산소·샘플 등의 포함 여부는 새 코어에서 결정한다. 새로운 타이머·의뢰·보상을 이 문서에서 임의로 도입하지 않는다.

# 01. 콘셉트 기획서 (Develop)

물에 잠긴 현장에서 청소하고, 벽을 잘라 길을 내고, 물건을 건져 오는 협동 게임이다. 사흘 동안 일을 해서 점검을 통과하고 다음 계약으로 넘어간다. 이 문서는 게임의 분위기와 주요 재미를 설명한다.

**문서 버전:** Develop v6 (9차 회의: 사망 처리·100% 클리어/로그라이크·세이브·이동 속도·다중 현장/09 문서 반영 · 공통/전용 기획서 폴더 분리)  
**적용 대상:** 전체 현장 공통  
**관련 문서:** `02 시스템` · `03 레벨` · `04 UI` · `05 수치` · `06 내러티브` · `07 경제` · `08 아이템` · `09 퀘스트` · `X-7 기지 기획서/01 X-7 퀘스트` · `TR-9 관통선 기획서/01 TR-9 퀘스트`

이 문서는 **한 문장으로 게임이 무엇인지**를 고정한다.  
규칙·숫자는 각각 02 / 05 / 07을 따른다. UI 표시는 `04`를 따른다.

---

## 1. 한 줄 정의

> **침수된 해저 연구기지를 사흘간 청소·철거·분리·샘플 회수하는 캐주얼 비즈니스 협동 게임.**

전투/던전 클리어가 아니라 **기한이 있는 현장 계약**이다.

---

## 2. 게임 소개

압력 사고로 **이미 전체가 잠긴** 연구기지 X-7.  
민간 철거·회수 팀이 모선에서 투입되어,  
벽을 잘라 길을 내고 쓰레기를 모아 분리하며,  
붕괴·파손 전에 샘플을 건져 올린다.  
2·3일차 **평가 점수**로 현장 점검을 통과해야 계약을 유지한다.

---

## 3. 플레이어가 하는 일과 재미

| 하고 싶은 일 | 실제로 하는 일 |
|---|---|
| 수중 현장에서 “일한다” | 접지 걷기 / 점프→수영, 08:00~18:00 |
| 지저분한 기지를 치운다 | 헤라(오염·따개비) + 산재 쓰레기 수거 |
| 길을 연다 | 칸막이/지주 철거 → 조각 ~10 → 운반 |
| 돈·장비를 굴린다 | 분리 환급·퀘스트·상점 (크레딧 ₡) |
| 팀을 살린다 | 지지대·동선·샘플 Intact·정시 복귀 |

핵심 손맛:
1. **긁기** (헤라)  
2. **자르기** (격벽)  
3. **나르기** (손 / 임시 쓰레기통, 쏟을 수 있음)  
4. **분리하기** (현장 대기장의 5종 분류 칸)  
5. **건지기** (샘플)

## 4. 톤 & 비주얼 방향

| 한다 | 하지 않는다 |
|---|---|
| 캐주얼 SF, 밝은 수중, 스타일라이즈드 | 공포 던전, 고어, 하드코어 서바이벌 |
| 계약·손해 명세서 같은 압박 | “돈이 없어 죽는” 리썰 카피 |
| 코믹한 쏟음·오분류 | 잔인한 트랩 연출 |
| 이모지 헬멧 계약직 캐릭터 | 용사/헌터 서사 |

아트 키워드 (Tripo/로비와 동일 계열):
- 밝은 stylized painterly (사실적 PBR 지양)
- 크림·씨폼·브라스, 맑은 시안 수중 분위기
- 식생·이끼로 “무서운 침수”를 과장하지 않음 (플레이 오염/따개비는 별도 시스템)
- 기지 모니터·디스플레이는 **꺼진/빈 화면** (월드에 UI 텍스처를 넣지 않음)

## 5. 하루 진행 순서

```text
모선에서 착수금과 장비 준비 → 수중 기지로 이동
  → 청소·철거 → 통에 담아 현장 대기장에서 분류 → 작업 재개
  → 샘플을 챙겨 18:00 전 모선 복귀
  → 샘플 납품과 정산 → 전원 복귀 여부 확인
```

사흘 누적:
- 맵 진행(열린 길·잔해) 유지  
- **평가 점수** 누적 → Day2 **500** / Day3 **1200** / (비상 Day4 **1380**) — 표준·4인 기준, 인원이 적으면 배율로 낮아짐 (`05` §0.2)  
- 폐기 게이지 **없음**

## 6. 주요 시스템

### 6.1 청소
- **오염물** · **보통벽 따개비** (헤라) → 물리 드롭  
- **각종 쓰레기** (손 집기)  
- 철거 **필수 조건 아님** (품질·점수에 유리)

### 6.2 철거
- **칸막이(비내력)** / **지주(내력)**  
- 내력 오절단 → **절단자 섹터 천장 붕괴** (추가 침수 없음)  
- 벽 안 **전선·수도관** — 스캔으로 표시, **피해서** 절단 (`02` §2.4)  
- 전선 절단 → 방 조명 OFF → **절연테이프** 수리  
- 수도관 절단 → 오염수(Niagara) → **폼건** 밀봉  
- 조각 → 깨끗=안탐 / 오염=오염 칸

### 6.3 운반 · 인벤
- **일반 가방 인벤 없음** · 핫바=장비만  
- 폐기물·샘플: **손** 또는 **임시 쓰레기통**  
- 1층 **폐기물 대기장**에서 쓰레기통 무한 보급

### 6.4 현장 대기장 분리
주울 때는 섞어 담고, **현장 대기장의 다섯 칸에 종류별로 넣는다** (`02` §11):

| 칸 | 색 |
|---|---|
| 금속 | 실버 |
| 일반쓰레기 | 흰 |
| 플라스틱 | 파랑 |
| 오염된 쓰레기 | 노랑 |
| 안타는 쓰레기 | 회색 |

### 6.5 샘플
- Intact / 손상 / 미회수 / 파괴  
- **평가 점수**로 반영  
- **크레딧은 퀘스트 보수만** (납품 현상금·철거 수당 없음)

### 6.6 평가 점수와 돈
- **평가 점수** = 점검 (`05`)  
- **크레딧 ₡** = 착수금·분리 환급·퀘스트·상점·대출 (`07`)  
- 상점 품목·수리 도구 = `08`  
- UI에서 점수와 ₡는 **항상 분리 표시** (`04`)

### 6.7 이동 · 맵
- 접지=걷기 / 점프=수영, **이동 속도는 빠르게** (참고작 대비 개선점, `02` §0.5)
- 기지 ↔ 바다·모선 = **레벨 스트리밍**  
- 시작부터 **완전 침수**, 에어락 연출 없음

### 6.8 사망 처리
- 힐링/청소 장르 특성상 죽어서 대기하는 다운타임을 두지 않는다  
- **빠르게 부활**, 사망 중에도 **마이크 사용 가능**  
- 죽은 자리에는 **오염물/따개비 잔해**가 남는다 (“플레이어 자체가 쓰레기가 된다”)  
- 리스폰은 **모선 고정** / 붕괴 사고 오염물은 **입구 쪽 고정** (`02` §6)

### 6.9 100% 클리어 · 로그라이크 재도전
- 완벽 청소(100%)는 **점검 통과 필수 조건이 아닌 도전과제**  
- 후반에 강해진 장비로 **초반 맵을 다시 돌아 더 쉽게 클리어**하는 재도전 재미 설계 (`02` §10.6)

### 6.10 세이브
- **세션 생성자만** 세이브 가능, **게임오버 시 세이브 삭제** (`02` §10.5)
