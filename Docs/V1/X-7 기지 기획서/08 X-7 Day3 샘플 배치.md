1: # Day3 격리실 B — 샘플 배치 가이드
2: 
3: ## 목적
4: 
5: Day3 메인 퀘스트 M03b의 회수물인 **변성 블룸 퀘스트 샘플 1개**를 B1-04 격리실 B의 캐비닛 안에 배치하기 위한 가이드다.
6:

8: 
9: > **Git 규칙:** 이 작업에서 `Content/Maps/L_Ocean.umap`은 커밋하지 않는다. 맵 배치는 에디터에서 직접 확인하고, 커밋 대상은 샘플 BP/데이터/문서 등 명시적으로 필요한 파일만 포함한다.

47: ## 3. 격리실 B에 스포너 배치
48: 
49: ### 위치
50: 
51: 스포너는 **B1-04 격리실 B의 B 캐비닛 내부**에 둔다.
52: 
53: 현재 레벨 구조에서는 샘플 보관 캐비닛 메시/액터를 기준으로 내부 선반 쪽에 맞춘다. 이전 배치 확인 때 사용한 캐비닛 기준 액터 이름은 `SampleStorageEdit2`였다.
54: 
55: 권장 배치 기준은 다음과 같다.
56: 
57: 1. Content Browser에서 `BP_MD_IsolationBSampleSpawner`를 찾는다.
58: 2. B1-04 격리실 B의 B 캐비닛 내부로 드래그한다.
59: 3. Actor Label을 `Day3_IsolationB_SampleSpawner`로 지정한다.
60: 4. 스포너의 원점보다 **DefaultSpawnPoint Arrow 위치**를 실제 샘플이 놓일 위치에 맞춘다.
61: 5. Arrow가 캐비닛 벽이나 선반 메시 안쪽에 박히지 않게 한다.
62: 6. 샘플이 물리 활성화될 경우를 고려해 위쪽으로 약간의 여유 공간을 둔다.
63: 
64: 이전 테스트에서 사용한 참고 위치는 약 다음과 같다.
65: 
66: `X 1128.68 / Y -462482.49 / Z -4240.72`
67: 
68: 이 좌표는 **참고값일 뿐 고정값이 아니다.** 실제 캐비닛 위치가 바뀌었다면 에디터의 현재 메시 위치에 맞춰 다시 정렬한다.

72: ## 4. BP_MD_IsolationBSampleSpawner 설정
73: 
74: Details에서 아래 값을 확인한다.
75: 
76: | 항목 | 권장 값 |
77: |---|---|
78: | Spawn Zone Tag | `Env.Zone.X7.IsolationB` |
79: | Samples To Spawn | `1` |
80: | Sample Class | `BP_SampleBase` 계열 기본값 유지 |
81: | Occupied Check Radius | `80 cm` 기본값 유지 |
82: | Spawn Protection Duration | `3 s` 기본값 유지 |
83: 
84: ### 중요한 점
85: 
86: - `Samples To Spawn`은 반드시 1이다.
87: - 일반 `BP_QuestSampleSpawner`의 다른 Zone 태그를 사용하지 않는다.
88: - 격리실 B 전용 태그와 M03b Phase의 `SpawnZoneTag`가 **완전히 동일해야 한다.**
89: - 스포너를 여러 개 배치하지 않는다.
90: - 같은 위치에 수동 샘플 액터와 스포너를 동시에 두지 않는다.
91: 
92: 퀘스트 스포너는 활성 퀘스트 Phase의 `SpawnZoneTag`와 자신의 `SpawnZoneTag`가 일치할 때 필요한 수량만 생성한다.

96: ## 5. 냉각펌프 / 데미지존과의 관계
97: 
98: 샘플 스포너 자체는 플레이어에게 피해를 주거나 냉각 상태를 관리하지 않는다.
99: 
100: Day3 흐름은 아래처럼 역할을 분리한다.
101: 
102: | 액터 | 역할 |
103: |---|---|
104: | `BP_MD_CoolingPump` | 처음부터 Broken, 폼건 수리, 오염수 분출 VFX 상태 제공 |
105: | `BP_MD_IsolationBHazard` | 펌프가 Broken일 때 격리실 B 데미지 적용, 수리되면 피해 중단 |
106: | `BP_MD_IsolationBSampleSpawner` | M03b 활성 시 캐비닛 위치에 퀘스트 샘플 1개 생성 |
107: 
108: 따라서 샘플 스포너를 `CoolingPump`나 `IsolationBHazard`에 직접 연결할 필요는 없다.

112: ## 6. 캐비닛과의 관계
113: 
114: 기획상 B 캐비닛은 아래 두 조건을 모두 만족해야 정상 개방된다.
115: 
116: `카드 보유 AND 냉각 복구`
117: 
118: 샘플은 캐비닛 내부에 스폰시키되, **스포너가 캐비닛 잠금 조건을 담당하지 않는다.**
119: 
120: 즉 역할은 다음처럼 분리한다.
121: 
122: 1. M03b 활성 → 샘플 스포너가 캐비닛 내부에 샘플 생성
123: 2. 냉각펌프 Broken → 격리실 B 데미지 활성
124: 3. 냉각펌프 수리 → 데미지 중단
125: 4. 카드 + 냉각 완료 → 캐비닛 개방
126: 5. 플레이어가 샘플 회수
127: 6. 브릭스에게 직접 납품
128: 
129: 캐비닛 개방 조건이나 고온 강행 시 샘플 파괴 로직이 아직 별도 구현 상태라면, 샘플 스포너 쪽에서 임시로 그 기능을 대신 구현하지 않는다.

151: ## 8. 배치가 잘못됐을 때 확인할 것
152: 
153: ### 샘플이 안 생김
154: 
155: 1. `X7-M03` Phase 1의 `SpawnZoneTag` 확인
156: 2. 스포너의 `SpawnZoneTag` 확인
157: 3. 두 값이 모두 `Env.Zone.X7.IsolationB`인지 확인
158: 4. `Samples To Spawn = 1`인지 확인
159: 5. M03b가 실제 Active 상태인지 확인
160: 6. 같은 퀘스트에 이미 귀속된 샘플이 월드에 존재하는지 확인
161: 
162: ### 엉뚱한 방에서 샘플이 생김
163: 
164: - 일반 `BP_QuestSampleSpawner` 중 `Env.Zone.X7.IsolationB` 태그를 잘못 가진 액터가 없는지 확인한다.
165: - 격리실 B 전용 태그는 이 스포너 하나만 사용한다.
166: 
167: ### 샘플이 캐비닛 밖으로 떨어짐
168: 
169: - Actor 위치보다 `DefaultSpawnPoint` Arrow 위치를 조정한다.
170: - 캐비닛 선반 충돌 안쪽에 Arrow가 박혀 있지 않은지 확인한다.
171: - 바닥/선반에서 5~15cm 정도 위에 놓고 테스트한다.
172: 
173: ### 샘플이 여러 개 생김
174: 
175: - 격리실 B 전용 스포너가 중복 배치되어 있는지 확인한다.
176: - 수동으로 배치한 `BP_SampleBase`가 남아 있지 않은지 확인한다.
177: - 같은 `Env.Zone.X7.IsolationB` 태그를 가진 다른 스포너가 없는지 확인한다.
