### A — 알린다 (`Told`)

**즉시 (X-7 모선)**  
“…알아서 뭐 하게.” / “그건 네 일 아냐. 다음 목록이나 봐.”

| 항목 | 결과 |
|---|---|
| 관계 | **변화 없음.** 다음 세션 브릭스 대사는 평소 그대로다 |
| 상점 · 호감도 · 착수금 | 변화 없음 |
| 다음 계약 | **변화 없음.** 브리핑도 평소 톤 |
| 남는 것 | `ToldBriggsAboutX7 = Told` 플래그. **읽는 곳이 지금은 없다** — 케른용 예약 |

읽는 느낌: 선을 넘긴 그 장면 하나. **브릭스가 침묵하고 선을 그어 버리는 걸 본 것**이 전부이자 목적이다.

> **v9에서 "거리감 플래그 · 다음 현장 브리핑 한 줄"을 삭제했다.** 로어는 이야기 전달용이고 게임에 영향을 주지 않는다 (`06` §7.7.1).

---

### B — 알리지 않는다 (`Withheld`)

**즉시**  
평소 계약 창. 코덱스 이야기 없음.

| 항목 | 결과 |
|---|---|
| 관계 · 상점 · 호감도 · 다음 계약 | **전부 변화 없음** |
| 재선택 창 | **다음 세션 출발 전 모선 허브에서 1회만**: “…그때 X-7 자료, 잘 챙겼더라.” → `ToldLate`로 전환 가능 (**늦춘 정직**). 대사: “…지금까지 말 안 했구나.” |
| 남는 것 | `ToldBriggsAboutX7 = Withheld` 플래그. 읽는 곳은 **재선택 창 하나뿐** |

읽는 느낌: 보류·보호. 벌주지 않음. 차이는 **“언제 말했는가”를 플레이어가 기억한다는 것**뿐이다.

|---|---|---|

## 6. 멀티플레이 규칙 (확정 · v12 전면 개정)

> **개정 요지 — 한 명이 조사하면 팀원 전원의 로컬에 저장된다.**
> 구판은 "세션에서는 합집합으로 보여주되 디스크에는 직접 집은 사람만" 남겼다. 그래서 세션이 끝나면 개수가 줄어드는 감각이 있었고, `공유` 표식·툴팁·정산 안내로 그걸 계속 설명해야 했다.
> **신판은 세션 중 획득분을 전원 로컬에 넣는다.** 설명할 게 없어지고 UI가 단순해진다.

### 6.1 수집 (세션 중)
| 항목 | 규칙 |
|---|---|
| 누가 집나 | **아무 플레이어나** 조사 1회 |
| **로컬** | **참가자 전원**의 세이브에 해당 LoreId 추가 |
| 세션 | 원장에도 등록 · 오브젝트는 전원에게 소멸 |
| 알림 | 팀원 모두에게 짧은 알림 |
| 이미 가진 사람 | 아무 일 없음 (중복 append 하지 않는다) |

### 6.1.1 맵 오브젝트 판정 — **교집합 기준** (신규)

**"전원이 이미 가진 로어만 맵에서 제거한다."** 한 명이라도 없으면 맵에 있다.

| 상황 | 맵 |
|---|---|
| 참가자 **전원**이 이미 보유 | 없음 |
| **한 명이라도** 미보유 | **있음** — 누가 주워도 전원에게 저장된다 |

> **왜 합집합이 아니라 교집합인가.** 구판(합집합 기준 제거)을 그대로 두면 신 규칙에 구멍이 생긴다 —
> 7/7인 A와 0개인 C가 같이 들어가면 **세션 원장이 7/7이라 맵에 로어가 하나도 없고, C는 아무것도 못 얻는다.**
> 교집합으로 바꾸면 C가 없는 7개가 맵에 나오고, 누가 줍든 둘 다 저장된다.
>
> **부수 효과 — 친구 도와주기가 성립한다.** 다 모은 사람이 안 모은 친구와 들어가면 로어가 다시 보이고, 한 번씩 조사해 주면 친구 코덱스가 채워진다. 이미 가진 사람에게는 중복이지만 조사 1회짜리라 비용이 없다.

### 6.2 코덱스 UI
| 항목 | 규칙 |
|---|---|
| 내용 | **내 저장 기록 기준.** 세션 중이든 아니든 같은 화면 |
| 완성률 | **N/7 하나뿐.** 세션 수치와 로컬 수치를 병기하지 않는다 |
| 폐지된 표시 | `공유` 표식 · 그 툴팁 · `기록물 5 / 7 · 내 기록 3` 병기 · 세션 종료 정산의 `내 보관함에 N건 추가` — **전부 삭제** |

> 세션 중 획득분이 즉시 내 로컬에 들어가므로 **"보이는 개수"와 "가진 개수"가 항상 같다.** 구분해서 보여줄 이유가 사라졌다.

### 6.3 브릭스 선택 (알린다 / 알리지 않는다) — ⏸ **범위 밖**

> 대면 자체가 개발 범위 밖이므로 **이 절도 구현하지 않는다** (§4 · `06` §7.7). 보존용이다.

| 항목 | 규칙 |
|---|---|
| 언제 | **7/7 + X-7 계약 클리어**(Day3 통과 또는 비상 Day4 통과). 클리어 요약 직후 (`06` §7.7) |
| 개시 | 클리어 흐름에서 선택 UI. **게임오버 흐름·Day 종료 정산에는 붙지 않는다** |
| 판정 기준 | **그냥 내 7/7.** v12부터 참가자 코덱스가 세션 중 같아지므로 합집합 판정이 필요 없다 (§6.1) |
| 결정권 | 그 화면 조작 플레이어가 A/B · 세션 선택 이후의 변화는 전원 |
| 로컬 | **선택을 확정한 플레이어**만 `ToldBriggsAboutX7` 기록. 동석자 로컬에는 안 씀 |
| 혼자 다시 갔을 때 | 내 로컬만으로 7/7이 아니면 선택창은 안 뜬다 |

### 6.4 하지 않는 것
- **참가 시점에 남의 코덱스를 통째로 복사** — 저장은 **세션 중 새로 조사한 것만**이다. 방에 들어갔다고 남이 이미 가진 게 넘어오지 않는다
- 로어를 손·쓰레기통에 넣어 독점
- 조사 횟수 제한 · 쿨다운 · 소유권 표시

> **경계선.** 7/7인 A와 0개인 C가 만나도 **C의 코덱스가 곧바로 7이 되지는 않는다.** 맵에 나온 7개를 실제로 조사해야 채워진다.
> "같이 플레이하면 같이 얻는다"이지 "같은 방에 있으면 받는다"가 아니다.

### 6.5 애매했던 지점 → 답
| 질문 | 답 |
|---|---|
| 로어퀘가 누구에게 뜨나? | 맵 고정물. 누구든 조사 1회 |
| 누가 저장되나? | **참가자 전원 로컬** (v12 개정) |
| 남이 이미 가진 건 나도 받나? | **아니다.** 세션 중 **새로 조사한 것만** 전원에게 저장된다 |
| 다 모은 사람이 친구를 도울 수 있나? | **가능하다.** 친구에게 없는 로어는 맵에 나오므로, 한 번씩 조사해 주면 친구 코덱스가 채워진다 (§6.1.1) |
| **브릭스 선택은 언제?** | ⏸ **구현하지 않는다** — 대화 선택 기능이 개발 범위 밖이다 (§4 · `06` §7.7) |
| **7/7을 채우면 뭐가 일어나나?** | **코덱스 100% + L07 해독 + 토스트 1회.** 그게 끝이다. 열리는 화면·대화·해금이 없다 (`06` §7.7.3) |
| 그럼 이야기는 어떻게 끝나나? | **L07 본문이 진다** — "여기서 더는 못 간다. 다른 지점이 필요하다"가 다음 현장으로 넘기는 훅이다 |
| 의견이 갈리면? | 해당 없음 (선택 자체가 없다) |

### 6.6 로컬 세이브 · 재시도 · 파티 교체 (확정)

#### 모델
```
각자 로컬 ──교집합──▶ 맵 판정 (전원이 가진 것만 제거)
                          │
                          │  누군가 조사 1회
                          ▼
                  참가자 전원 로컬에 append
```

| 단계 | 규칙 |
|---|---|
| **참가 시** | 아무것도 복사하지 않는다. 각자 로컬 그대로 |
| **맵 스폰** | **참가자 교집합**으로 판정 — 한 명이라도 없는 로어는 맵에 있다 (§6.1.1) |
| **세션 중 조사** | **참가자 전원 로컬** += ID |
| **남이 이미 가진 ID** | 맵에 나와 있으면 조사해서 받고, 전원이 가졌으면 애초에 안 나온다 |
| **코덱스 표시** | 내 저장 기록 기준. 세션 중에도 동일 |

#### 재시도 + 파티가 바뀐 경우
예: **A + B**가 L01~L04를 집음. 누가 집었든 **둘 다 4개**를 갖고 나온다.

| | |
|---|---|
| A 로컬 | L01~L04 |
| B 로컬 | L01~L04 *(같이 했으므로 동일)* |
| **다음 A + C** (C는 0개) | 교집합 = ∅ → **7개 전부 맵에 있다.** 조사하면 A·C 둘 다 저장 → 세션이 끝나면 **A 7개 / C 7개** |
| B 혼자 | 여전히 4개. 나머지 3개는 직접 가거나 다른 파티와 가서 얻는다 |

**의도:** **같이 플레이하면 같이 얻는다.** 누가 먼저 눌렀는지가 소유를 가르지 않는다.
다만 **방에 들어간 것만으로 받지는 않는다** — 세션 중 실제로 조사해야 한다 (§6.4).

#### `ToldBriggsAboutX7` 세션 판정 — ⏸ **범위 밖**

> **이 플래그를 구현하지 않는다** (§4). 아래는 보존용이다.
> **로어 수집·코덱스 규칙(§6.1·§6.1.1·§6.2·§6.6 앞부분)은 그대로 유효하다.**
> *(v12 참고 — 전원 저장으로 바뀌면서 참가자 코덱스가 세션 중 같아지므로, 되살릴 때 7/7 판정에 합집합·교집합 구분이 필요 없어졌다.)*

세션 7/7·선택 UI 조건은 **합집합**으로 본다.  
플래그 병합(이미 고른 사람이 방에 있을 때):

| 우선 | 값 |
|---|---|
| 1 | 참가자 로컬 중 `Told` / `Withheld` / `ToldLate` |
| 2 | `None` |

- 커밋이 하나면 세션에서 선택 UI 스킵.  
- Told vs Withheld 충돌 → **방장 로컬**.  
- **새로 고른 값**은 확정자 로컬에만 기록 (동석자 복사 없음).

#### 감수할 점 (v12)
- **진행이 빨라진다.** 4인이 흩어져 한 바퀴 돌면 한 세션에 7/7이 나올 수 있다. 로어는 선택 콘텐츠이라 문제로 보지 않는다 — 오히려 "같이 하면 이야기를 같이 읽는다"가 의도다.
- **다 모은 사람에게 로어가 다시 보인다.** 친구가 미보유면 맵에 나온다. 중복처럼 느껴질 수 있으나 조사 1회라 비용이 없고, 코덱스에는 이미 확보로 표시된다.
- **한 명이 다 주워 버릴 수 있다.** 빨리 도는 사람이 전부 눌러도 전원이 받으므로 손해는 없다. 다만 남이 본문을 읽을 기회가 줄 수는 있다 — 코덱스에서 언제든 다시 읽히므로 규칙으로 막지 않는다.
