# 모선 사다리 샘플 파손 방지 존

L_Ocean의 BP_MD_Ladder와 BP_MD_Ladder2에 각각 BP_SampleProtection_ShipLadder_01/02를 배치했다. 아웃라이너 폴더는 Gameplay/SampleProtection이며 해당 사다리에 부착되어 함께 이동한다.

재사용 Blueprint: /Game/Blueprint/Sample/BP_SampleProtectionZone

존 안에 샘플 액터의 중심이 있으면 물리 충격에 의한 손상·파괴 및 기존 OnAnyDamage 손상을 막는다. 일반 물리 충돌은 유지하므로 선체에 걸리는 현상 자체를 없애지는 않는다. 손상된 샘플을 복구하지 않으며 존에서 나오는 즉시 기존 판정을 따른다. 일시적 스폰/그랩 보호 타이머 및 소비형 완충 효과는 덮어쓰거나 소모하지 않는다.

ProtectionBounds의 Box Extent 기본값은 X=300, Y=200, Z=400cm이다. 전체 크기는 앞뒤 6m × 좌우 4m × 높이 8m. 중앙은 사다리 상·하단 중간에서 바깥쪽 1m이며 수면 아래 접근부부터 갑판 이탈 지점까지 포함한다. 컴포넌트의 Box Extent/액터 스케일로 조절하거나 Protection Enabled를 꺼서 비활성화한다.

존 자체는 이동을 막지 않고 게임 중 표시되지 않는다. Overlap 시작/종료 이벤트 대신 피해 시점의 좌표를 회전·스케일을 반영한 박스에 검사하므로 진입 이벤트 순서나 빠른 이동에 따른 보호 등록 지연이 없다.

검증: Editor 전체 빌드 및 MarineDemolition.Sample.ProtectionZone 자동 테스트 통과. 격리 게임 월드에서 실제 샘플 Hit 델리게이트에 파괴 임계값 이상의 충격을 주어 내부 생존/손상 없음, 외부 파괴를 확인했다. 일반 피해 차단, 회전/스케일, 비활성화도 검사했다. 저장된 두 존의 하단·상단·갑판 이탈점·3m 앞 접근점 포함 여부, 비충돌 설정을 독립 조회했다. 실제 플레이어의 운반·사다리 왕복 조작은 이번 검증에서 실행하지 않았다.
