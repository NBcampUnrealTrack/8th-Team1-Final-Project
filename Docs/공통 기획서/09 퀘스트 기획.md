# 09. 퀘스트 기획서 (Develop)

**문서 버전:** Develop v8 (11차 회의: **§1.5 샘플 스폰·보상 규칙 신설** — 샘플은 Day별 자동 갱신 퀘스트가 등급별로 스폰하며, 샘플 납품 자체는 점수·₡ 0. 모든 보상이 퀘스트 완료에 귀속되고 실패 시 점수·호감도만 하락. 등급별 점수·₡·호감도 수치 확정(기존 미확정 호감도 델타 포함))  
**이전 버전:** Develop v7 (9차 회의: 상인 개인 퀘스트 삭제 · 로어 퀘스트 상호작용 방식 명시 · 퀘스트 실패 위약금 삭제, 호감도는 반복 퀘스트 풀 선정에 관여 안 함 · 공통/전용 기획서 폴더 분리)

평가 점수 숫자는 `05`, 크레딧 금액은 `07`, 세계관·캐릭터·현장 설정은 `06`을 따른다.

## 0. 퀘스트 분류 (미션 선택형)

게임은 오픈월드가 아니라 **미션 선택형**이다. 플레이어는 메인 메뉴에서 현장과 계약 난이도를 선택 후 3일 계약에 들어간다.

| 유형 | 구조 | 발주 | 목적 | 보상 | 필수 여부 |
|---|---|---|---|---|---|
| **메인 퀘스트** | 현장별 스토리 진행 (Day별 언락) | 현장 발주처 | 샘플 회수·청소·마감 (스토리 연결) | 평가 점수 + 크레딧 + 호감도 | 점검 무관 (진행 보너스) |
| **반복 퀘스트** | 현장별 사이드 풀 (매 계약마다 랜덤 조합) | 현장 발주처 (같은 이름) | 샘플·청소·마감 (스토리 무관) | 평가 점수 + 크레딧 | 점검 무관 (보너스 선택) |
| **로어 퀘스트** | 수집형 (현장 고정배치) | 없음 | 현장 기록물 수집, 코덱스 완성 → 블룸 미스터리 전개 | 소액 크레딧 + 코덱스 엔트리 | 점검 무관 (선택) |

**퀘스트 유형은 이 3가지뿐이다.** (상인 개인 퀘스트 체인은 폐기 — §0.1)

### 0.1 상인 개인 퀘스트 폐기 (9차 회의 확정)
- 별도의 "브릭스 개인 퀘스트 체인" 시스템은 **만들지 않는다.**
- 브릭스의 배경·개인사(`06` §4)는 캐릭터 설정으로는 유지하되, 플레이어에게 전달하는 수단은 **일반 대사(호감도 티어별 잡담) + 로어 퀘스트/코덱스**로 통합한다.
- 즉 블룸 확산 미스터리의 단서는 이제 **전부 로어 퀘스트(§6 유형) 하나의 트랙**으로 전달된다. 별도 퀘스트 UI·언락 게이트를 추가로 만들지 않는다.

### 원칙
1. 점검(Day2/3/4) 통과에는 **어떤 퀘스트도 필수 아니다** — 기존 `05` 설계 그대로, 모든 퀘스트는 보너스.
2. 메인 퀘스트는 한 현장의 "스토리 진행"이며, 반복 퀘스트와는 독립적이다.
3. 현장을 여러 번 플레이하면:
   - 메인 퀘스트는 매번 **같은 라인** 반복 (Day 1→2→3 진행)
   - 반복 퀘스트는 매번 **다른 조합** (현장별 풀에서 랜덤)
   - 로어 퀘스트는 완료한 엔트리가 **영구 누적** (현장 무관, 코덱스로 계속 쌓임)
4. 보상 공식(`07` §3.2)은 모든 메인/반복 퀘스트에서 동일하게 재사용한다. 새로 만드는 건 **대사·명칭·스토리 연결뿐**이다.
5. 100% 클리어·로그라이크 재도전(`02` §10.6)과 로어 퀘스트 완성도는 같은 "도전과제" 성격으로 묶인다.

## 1. 메인 퀘스트 (현장별 스토리 진행)

**메인 퀘스트**는 한 현장의 **3일 계약 기간 동안 Day별로 언락**되는 스토리 진행 퀘스트다.  
같은 현장을 재방문하면 메인 퀘스트는 매번 **동일한 라인**을 반복한다.

### 구조
| 단계 | 시점 | 특징 |
|---|---|---|
| Day 1 메인 | 계약 1일차 시작 시 노출 | 진입·탐색·학습 중심 |
| Day 2 메인 | Day1 완료 후 Day2 시작 시 노출 | 샘플·정보 수집 강화 |
| Day 3 메인 | Day2 완료 후 Day3 시작 시 노출 | 마지막 수거·마감 |
| (선택) 자유 | 계약 진행 중 언제든 | 반복 퀘스트와 병행 가능 |

### 발주처는 가볍게
발주처는 브릭스처럼 캐릭터화하지 않는다. 이름·목소리 없는 짧은 의뢰 텍스트 수준으로 가볍게 유지한다.  
개인 서사의 무게는 **브릭스에게만** 싣는다 (`06` §0 원칙).

### 보상 공식
`07` §3.2 유형(회수 Intact, 손상 허용 회수, 청소 계약, 마감 계약, 복합) + 숫자를 그대로 재사용.  
메인/반복 구분 시 보상은 **동일**하게 적용한다 (다른 것은 스토리 연결뿐).

## 1.5. 샘플 스폰 · 보상 규칙 (신규 확정)

### 스폰 메커니즘
샘플은 맵에 미리 흩어져 있는 수집물이 **아니다.** 퀘스트가 샘플을 만든다.

| 항목 | 규칙 |
|---|---|
| 갱신 시점 | **Day가 시작될 때마다 퀘스트가 자동 갱신**된다 (메인 퀘스트는 Day별 고정 라인, §1) |
| 스폰 조건 | 그 Day의 퀘스트가 활성화되면, **퀘스트가 지정한 등급의 샘플**이 맵에 스폰된다 |
| 스폰 개수 | 퀘스트 목표 개수와 **1:1**. 목표에 없는 여분 샘플은 스폰하지 않는다 |
| 등급 결정 | 퀘스트 등급이 곧 샘플 등급. 현장별 등급 범위·Day별 배정은 각 현장 전용 문서 (X-7은 `X-7 기지 기획서/01 X-7 퀘스트 기획` §2) |
| 등급 진행 | Day가 지날수록 등급이 **점진적으로 상승**한다 (낮은 등급 → 상위 등급 순) |
| 미회수 샘플 | 파괴되지 않았으면 다음 Day에도 맵에 남는다 (`02` §10 진행 유지) |

의도:
> 맵에 뿌려둔 샘플을 "몇 개나 주웠는지"로 채점하면, 개수가 많을 때 물리적으로 못 가져오는 샘플까지 손해로 잡혀 불합리하다.  
> 퀘스트가 요구한 것만 스폰하고, 퀘스트 단위로만 정산한다.

### 점수·보상 귀속 (중요)
**샘플 자체는 점수로 환산되지 않는다.** 샘플을 모선에 납품하는 행위 자체에는 평가 점수도 크레딧도 붙지 않는다.

| 상황 | 평가 점수 | 크레딧 ₡ | 호감도 |
|---|---|---|---|
| 샘플 납품 (그 자체) | **0** | **0** | **0** |
| 퀘스트 완료 (샘플 회수 조건 충족) | **+ (등급별)** | **+ (등급별)** | **+ (등급별)** |
| 퀘스트 실패 (미회수) | **− (등급별)** | **0** (위약금 없음) | **− (등급별)** |
| 퀘스트 실패 (파괴) | **− (등급별, 미회수보다 큼)** | **0** (위약금 없음) | **− (등급별, 미회수보다 큼)** |

### 등급별 수치 (프로토 확정)

**성공 (퀘스트 완료 시)**

| 샘플 등급 | 평가 점수 | 크레딧 ₡ | 호감도 |
|---|---:|---:|---:|
| C | **+70** | **+80** | **+0.2** |
| B | **+140** | **+160** | **+0.3** |
| A | **+220** | **+280** | **+0.4** |
| S | **+360** | **+450** | **+0.5** |

**실패 — 미회수 (18:00까지 맵에 남김, 다음날 재시도 가능)**

| 샘플 등급 | 평가 점수 | 크레딧 ₡ | 호감도 |
|---|---:|---:|---:|
| C | **−20** | 0 | **−0.2** |
| B | **−35** | 0 | **−0.3** |
| A | **−55** | 0 | **−0.4** |
| S | **−90** | 0 | **−0.5** |

**실패 — 파괴 (재시도 불가)**

| 샘플 등급 | 평가 점수 | 크레딧 ₡ | 호감도 |
|---|---:|---:|---:|
| C | **−45** | 0 | **−0.4** |
| B | **−85** | 0 | **−0.6** |
| A | **−130** | 0 | **−0.8** |
| S | **−220** | 0 | **−1.0** |

규칙:
1. 손상 회수(파손된 채 납품)는 **파괴가 아니다.** 퀘스트 조건이 "Intact"면 실패(파괴 취급 아님 → 미회수 등급 감점 적용), 조건이 "손상 허용"이면 성공 처리하되 **점수는 40%**(`05` S+13) · **크레딧은 50%**(`07` §3.2)를 지급한다 — 두 트랙의 비율이 다르다.
2. 크레딧은 **성공 시에만** 지급된다. 실패해도 이미 받은 착수금·분리 환급은 회수하지 않는다 (`07` §1.2 M−02 삭제).
3. 파괴는 항상 미회수보다 무겁다 — 점수·호감도 모두.
4. 퀘스트를 **수락하지 않은** 경우 그 샘플은 스폰되지 않으므로, 미수락에 대한 감점은 존재하지 않는다.

## 2. 다중 구역 원칙 (허브 · 외부 · 내부)

현장은 공통적으로 **3개 구역**으로 나눌 수 있다 (X-7 기준 정립, `10` 참고):

| 구역 | 설명 | 퀘스트 배분 원칙 |
|---|---|---|
| **모선 허브** | 계약 시작/종료, 정산, 상점 | 퀘스트 수락·완료 창구 (미션 선택형 진입점) |
| **외부** (바다 등) | 허브와 현장 진입구 사이 구간 | 위험도 낮은 탐색·수집 위주. **메인/반복/로어에 나눠 배치**하며 별도 카테고리를 만들지 않는다 |
| **내부** (현장 본체) | 실제 철거·청소 현장 | 메인·반복 퀘스트의 주력 배치 |

### 외부 구역 퀘스트 배치 원칙
- 외부(바다 등)는 자체 퀘스트 유형이 아니다. **위치가 외부인 메인/반복/로어 퀘스트**로 취급한다.
- 메인 퀘스트의 외부 배치: 보통 Day1(진입 학습)·Day3(복귀 전 마무리) 같은 시작/종료 지점에 배치해 학습·마무리 동선으로 쓴다.
- 반복 퀘스트의 외부 배치: 내부보다 위험도 낮은 수집·정찰형 목표로 채운다.
- 로어 퀘스트의 외부 배치: 블룸이 어떻게 퍼져나가는지(전파 경로) 보여주는 소재로 우선 배치한다.
- 상세 예시는 `10` X-7 편 참고 — 다른 현장 문서를 만들 때도 이 배분 원칙을 그대로 따른다.

## 4. 반복 퀘스트 (현장별 사이드 풀)

**반복 퀘스트**는 메인 퀘스트와 무관하게, 같은 현장을 여러 번 플레이할 때마다  
**풀에서 랜덤하게 조합되는 사이드 미션**이다. 점검 통과와 무관하며, 보상은 메인과 동일하다 (`07` §3.2).

### 구조
- 매 계약(3일)마다 현장의 반복 퀘스트 풀에서 **2~3개를 랜덤으로 선택**
- 메인 퀘스트와 **병행 가능** (Day 중간중간에 수락 가능)
- 내용은 "샘플 N개 회수", "구역 청소 마감", "특정 오염물 정리" 등 명확한 목표
- 외부(바다) 구역 반복 퀘스트도 이 풀에 **함께 섞여 있다** (§2 배분 원칙)
- **호감도는 반복 퀘스트 풀 선정에 관여하지 않는다.** 호감도가 영향을 주는 곳은 상점 해금·착수금 배율·대출뿐이다 (`02` §7, `07` §2.2·§4·§5). 풀에서 어떤 퀘스트가 뽑히는지는 호감도와 무관하게 순수 랜덤이다.
- **퀘스트 실패(미회수·파괴·포기)는 크레딧 위약금이 없다.** 호감도만 하락하며(미회수보다 파괴가 더 크게 하락), 이미 지급된 착수금·환급은 그대로 유지된다 (`07` §3.2).

### 현장별 반복 퀘스트 풀

X-7 전체 풀(내부+외부)은 `X-7 기지 기획서/01 X-7 퀘스트 기획` §4 참고.
TR-9 전체 풀(내부+기관실+터널)은 `TR-9 관통선 기획서/01 TR-9 퀘스트 기획` §3 참고.

- 반복 퀘스트 미완료: 다음 방문 시 다른 조합으로 교체

## 5. 로어 퀘스트 (수집형)

### 개념
현장 곳곳에 배치된 **기록물**(데이터 코어, 낡은 태블릿, 항해일지, 화물 전표 등)을 수집하면  
**코덱스(기록 보관함)** 엔트리가 열린다.  
블룸 확산 미스터리(`06` §2.5)의 단서는 **전부 이 트랙으로만** 전달된다 (§0.1).

### 규칙
| 항목 | 규칙 |
|---|---|
| 배치 | 현장당 3~5개 + 외부 구역 1~2개, 필수 동선 밖 소량 탐험 보상 위치 |
| 상호작용 | 기록물 오브젝트에 접근 → 프롬프트("F: 조사") → **상호작용 키 1회** → 즉시 코덱스 등록 후 오브젝트 소멸 |
| 운반 | **없음.** 손/임시 쓰레기통에 담아 모선까지 나를 필요가 없다 (샘플·폐기물 운반 규칙 `02` §2.5와는 별개 취급) |
| 접근 장애물 | 일부는 오염물에 덮여 있거나(헤라로 제거), 막힌 구획 안이거나(벽 철거·문 개방), 정밀 스캐너로만 위치가 드러난다 — 현장별 상세는 각 전용 문서(`10` 등) |
| 보상 | 코덱스 엔트리 1개 + 소액 크레딧 (청소 계약 보수와 동급 수준, `07` 참고) |
| 점검 영향 | **없음** — 순수 보너스 |
| 미회수 시 | 파괴되지 않는 한 다음 날/재방문 시 재시도 가능 |
| 미스터리 전개 | 엔트리를 모을수록 코덱스 안에서 **자동으로 정렬·연결**되어 읽힌다 (별도 퀘스트 언락 없음) |

### 코덱스 소재 예 (현장별)
| 현장 | 소재 예 |
|---|---|
| X-7 | 연구 로그, 격리 프로토콜 초안, 대피 당시 무전 기록 (상세는 `10` §5) |
| TR-9 관통선 | 화물 전표, 터널 점검 보고서, 승무원 개인 물품 |
| SS 벨몬트 | 승객 명부, 항해일지, 선원 구역 낙서·메모 |

### 코덱스 UI 메모 (구현 참고, 상세는 `04` 확장 시 정의)
- 모선 허브에 "기록 보관함" 진입점 추가 후보.
- 완성률(N/M) 표시로 100% 클리어 도전과제(`02` §10.6)와 자연스럽게 묶인다.
- 케른 스파 등 신규 현장 언락 조건은 **특정 현장의 코덱스 완성률**로 건다 (호감도 게이트 대신).

## 6. 보상 구조 통합

| 퀘스트 유형 | 평가 점수 | 크레딧 | 호감도 | 로어 | 해금 |
|---|---:|---:|---:|---:|---|
| **메인 퀘스트 (샘플 회수)** | 등급별 (§1.5) | 등급별 (§1.5) | 등급별 (§1.5) | 없음 | 다음 Day 언락 |
| **메인 퀘스트 (청소·마감)** | 마감 +40 (`05` S+14) | 청소 120₡ / 마감 100₡ (`07` §3.2) | +0.2 | 없음 | 다음 Day 언락 |
| **반복 퀘스트** | 등급별 ×0.5 또는 유형별 | 유형별 (`07` §3.2) | +0.1~0.2 | 없음 | 없음 |
| **로어 퀘스트** | 없음 | 소액 (30~50₡) | 없음 | 있음 | 코덱스 엔트리 → 신규 현장 |

**샘플 회수 퀘스트의 점수·₡·호감도 정본은 §1.5 등급별 표다.** 샘플 납품 자체에는 아무 보상이 없고, 전부 퀘스트 완료에 귀속된다.  
메인과 반복은 **같은 보상 공식** 사용 (스토리 연결만 다름). 반복 퀘스트는 호감도 폭만 절반 수준으로 낮게 잡는다.  
충돌 시: **점수=09 §1.5(샘플 관련) / 05(그 외)**, **크레딧=07**, **호감도=09 §1.5**.

## 7. 미션 선택 흐름 & 진행 (메인 메뉴)

```
미션 선택 (메인 메뉴)
  ↓
현장 선택 (X-7 / TR-9 / SS 벨몬트 / 신규)
  ↓
난이도 선택 (안전 / 표준 / 위험 / 극한)
  ↓
계약 시작 (3일 계약, 모선 투입)
  ├─ 모선 대기 중
  │   ├─ (선택) 바다 외부 퀘스트 선택 (일부 수행 가능)
  │   └─ 기지 진입 준비
  ├─ Day1: 
  │   ├─ 메인 Day1 노출 (완료 후 Day2 언락)
  │   ├─ 반복 퀘스트 풀 (2회차 이상)
  │   └─ 바다 외부 퀘스트 계속 진행 가능 (자유 시간 활용)
  ├─ Day2: 
  │   ├─ 메인 Day2 노출 (완료 후 Day3 언락)
  │   ├─ 반복 퀘스트 병행
  │   └─ 바다 외부 퀘스트 계속 가능
  └─ Day3: 
      ├─ 메인 Day3 노출 (완료로 계약 마감)
      ├─ 반복 퀘스트 병행
      ├─ 바다 외부 퀘스트 계속 가능 (18:00 전)
      └─ 18:00 모선 출발, 계약 종료
```

### 퀘스트 노출 규칙
- **메인 퀘스트**: Day별로 언락, 현장 방문 시마다 동일한 라인
- **반복 퀘스트**: 같은 현장 2회차 방문부터 노출, 매번 랜덤 조합 (2~3개)
- **로어 퀘스트**: 현장에 고정배치, 발견형 (아이콘/표시로 찾기)

### 주요 원칙
- 메인과 반복 퀘스트는 **병행 가능** (Day 중간에 반복 퀘스트 수락 가능)
- 로어 퀘스트는 계약 실패/게임오버와 무관하게 **코덱스에 영구 기록**
- 별도의 상인 개인 퀘스트 알림/게이트는 **없음** (§0.1)

## 8. 신규 현장 추가 체크리스트

1. `06` §2.6 로스터에 현장 한 줄 추가 (개요·원인·톤 포인트)
2. 이 문서 §3에 발주처·메인 퀘스트 요약 한 줄 추가, 상세는 별도 전용 폴더/문서로 분리 (예: `X-7 기지 기획서/`, `TR-9 관통선 기획서/`)
3. 코덱스 소재 3~5개 + 외부 1~2개 기획 (§5)
4. **단가(`05` §1~2)·공식(`07`/`08`)은 공통이라 그대로 재사용**하되, **콘텐츠 배치·일차별 점수 궤적(`05` §3·§4)은 현장마다 새로 기획한다** — 다른 현장 수치를 복사해 붙이지 않는다. 각 현장 전용 문서(§3B/§3C 등)에 그 현장만의 시뮬레이션을 담는다 (예: `05` §3B TR-9)
5. 발주처 대사만 새 현장 지명으로 교체 (브릭스는 캐릭터 자체가 불변, §0.1)
