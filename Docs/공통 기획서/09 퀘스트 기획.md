## 0. 퀘스트 분류 (미션 선택형)

게임은 오픈월드가 아니라 **미션 선택형**이다. 플레이어는 메인 메뉴에서 현장과 계약 난이도를 선택 후 3일 계약에 들어간다.

| 유형 | 구조 | 발주 | 목적 | 보상 | 필수 여부 |
|---|---|---|---|---|---|
| **메인 퀘스트** | 현장별 스토리 진행 (Day별 언락) | 현장 발주처 | 샘플 회수·청소·마감 (스토리 연결) | 평가 점수 + 크레딧 + 호감도 | 점검 무관 (진행 보너스) |
| **반복 퀘스트** | 현장별 사이드 풀 (매 계약마다 랜덤 조합) | 현장 발주처 (같은 이름) | 샘플·청소·마감 (스토리 무관) | 평가 점수 + 크레딧 + **호감도 절반** | 점검 무관 (보너스 선택) |
| **로어 퀘스트** | 수집형 (현장 고정배치) | 없음 | 현장 기록물 수집, 코덱스 완성 → 블룸 미스터리 전개 | 없음 (코덱스만) | 점검 무관 (선택) |

**퀘스트 유형은 이 3가지뿐이다.** (상인 개인 퀘스트 체인은 폐기 — §0.1)

### 0.1 상인 개인 퀘스트 폐기 (9차 회의 확정)
- 별도의 "브릭스 개인 퀘스트 체인" 시스템은 **만들지 않는다.**
- 브릭스의 배경·개인사(`06` §4)는 캐릭터 설정으로는 유지하되, 플레이어에게 전달하는 수단은 **일반 대사(호감도 티어별 잡담) + 로어 퀘스트/코덱스**로 통합한다.
- 즉 블룸 확산 미스터리의 단서는 이제 **전부 로어 퀘스트(§6 유형) 하나의 트랙**으로 전달된다. 별도 퀘스트 UI·언락 게이트를 추가로 만들지 않는다.

### 원칙
1. 점검(Day2/3/4) 통과에는 **어떤 퀘스트도 필수 아니다** — 기존 `05` 설계 그대로, 모든 퀘스트는 보너스.
2. 메인 퀘스트는 한 현장의 "스토리 진행"이며, 반복 퀘스트와는 독립적이다.
3. 현장을 여러 번 플레이하면:
   - 메인 퀘스트는 매번 **같은 라인** 반복 (Day 1→2→3 진행)
   - 반복 퀘스트는 매번 **다른 조합** (현장별 풀에서 랜덤)
   - 로어 퀘스트는 완료한 엔트리가 **영구 누적** (현장 무관, 코덱스로 계속 쌓임)
4. 보상 공식(`07` §3.2)은 모든 메인/반복 퀘스트에서 동일하게 재사용한다. 새로 만드는 건 **대사·명칭·스토리 연결뿐**이다.
5. 100% 클리어·로그라이크 재도전(`02` §10.6)과 로어 퀘스트 완성도는 같은 "도전과제" 성격으로 묶인다.

## 1. 메인 퀘스트 (현장별 스토리 진행)

**메인 퀘스트**는 한 현장의 **3일 계약 기간 동안 Day별로 언락**되는 스토리 진행 퀘스트다.  
같은 현장을 재방문하면 메인 퀘스트는 매번 **동일한 라인**을 반복한다.

### 구조
| 단계 | 시점 | 특징 |
|---|---|---|
| Day 1 메인 | 계약 1일차 시작 시 노출 | 진입·탐색·학습 중심 |
| Day 2 메인 | **Day2 시작 시 노출 (Day1 완료 불필요)** | 목표 심화, 구매 도구 게이트 |
| Day 3 메인 | **Day3 시작 시 노출 (Day2 완료 불필요)** | 마지막 수거·마감 |
| (선택) 자유 | 계약 진행 중 언제든 | 반복 퀘스트와 병행 가능 |

**Day 언락은 경과 기준이다.** 선행 Day 완료를 조건으로 걸지 않는다. Day1을 실패해도 Day2에는 Day2용 메인이 열린다 — 실패가 라인 전체를 잠그면, 한 번 놓친 플레이어에게 남은 계약 기간이 빈 껍데기가 된다.

**연계(체인) 퀘스트는 하루 안에서만 이어진다.** 한 메인을 2단계로 쪼개고 2단계가 1단계 완료를 조건으로 걸 수 있지만, **두 단계를 같은 Day에 배치해야 한다.** Day를 걸치면 이월 금지(§1.5)와 부딪혀 중간 플래그를 넘길지 말지가 매번 예외 처리가 된다. 같은 Day에 두면 Day 언락 규칙에 예외가 남지 않는다. X-7 적용 예: `X-7 기지 기획서/03` §6.2 (3-1·3-2 모두 Day3).

### 발주처는 가볍게
발주처는 브릭스처럼 캐릭터화하지 않는다. 이름·목소리 없는 짧은 의뢰 텍스트 수준으로 가볍게 유지한다.  
개인 서사의 무게는 **브릭스에게만** 싣는다 (`06` §0 원칙).

### 보상 공식
`07` §3.2 유형(회수 Intact, 손상 허용 회수, 청소 계약, 마감 계약, 복합) + 숫자를 그대로 재사용.  
**점수·크레딧은 메인/반복 구분 없이 동일**하게 적용한다. **호감도만 슬롯에 따라 다르다** — 반복은 메인의 절반이다 (§1.5).

### 메인 라인의 구성은 현장이 정한다
메인 3종을 **등급 상승(C→B→A)**으로 짤 수도 있고, **기믹 단계 수 상승**(도구 1종 → 2종 → 3종+순서 강제)으로 짤 수도 있다. 둘 중 하나를 골라 현장 문서에 명시한다.
- 등급 상승형: 샘플 트랙이 메인에 있다. 예 — `TR-9 …/01` (현행)
- 기믹 상승형: 샘플 등급 트랙을 반복 풀로 넘기고, 메인은 회수 오브젝트 + 기믹으로 짠다. 예 — `X-7 기지 기획서/01` (v7에서 교체)

기믹 상승형을 쓰면 **1회차 방문에 등급 샘플이 아예 없어진다** (반복은 2회차부터, §4). 현장 문서에서 반복 1종을 1회차 고정 노출로 빼 주어야 한다.

## 1.5. 샘플 스폰 · 보상 규칙 (신규 확정)

### 스폰 메커니즘
샘플은 맵에 미리 흩어져 있는 수집물이 **아니다.** 퀘스트가 샘플을 만든다.

| 항목 | 규칙 |
|---|---|
| 갱신 시점 | **메인**은 Day가 시작될 때마다 그 Day용 라인이 갱신된다 (§1). **반복**은 계약 시작 시 1회 추첨하고 3일 내내 유지된다 (§4) |
| 스폰 조건 | 그 Day의 퀘스트가 활성화되면, **퀘스트가 지정한 등급의 샘플**이 맵에 스폰된다 |
| 스폰 개수 | 퀘스트 목표 개수와 **1:1**. 목표에 없는 여분 샘플은 스폰하지 않는다 |
| 등급 결정 | 퀘스트 등급이 곧 샘플 등급. 현장별 등급 범위·스폰 주체는 각 현장 전용 문서 (X-7은 `X-7 기지 기획서/01` §2.0) |
| 등급 진행 | **등급 상승형 현장**은 Day가 지날수록 등급이 올라간다. **기믹 상승형 현장**은 등급 트랙이 반복 풀에 있어 Day와 무관하고, 뽑힌 반복 퀘스트가 등급을 결정한다 (§1) |
| 미회수 샘플 | **메인 스폰물은 18:00에 디스폰**한다. **반복 스폰물은 계약 종료까지 맵에 남는다** (아래 이월 표) |

의도:
> 맵에 뿌려둔 샘플을 "몇 개나 주웠는지"로 채점하면, 개수가 많을 때 물리적으로 못 가져오는 샘플까지 손해로 잡혀 불합리하다.  
> 퀘스트가 요구한 것만 스폰하고, 퀘스트 단위로만 정산한다.

### 점수·보상 귀속 (중요)
**샘플 자체는 점수로 환산되지 않는다.** 샘플을 모선에 납품하는 행위 자체에는 평가 점수도 크레딧도 붙지 않는다.

| 상황 | 평가 점수 | 크레딧 ₡ | 호감도 |
|---|---|---|---|
| 샘플 납품 (그 자체) | **0** | **0** | **0** |
| 퀘스트 완료 (샘플 회수 조건 충족) | **+ (등급별)** | **+ (등급별)** | **+ (슬롯별)** |
| 퀘스트 실패 (미회수) | **− (등급별)** | **0** (위약금 없음) | **− (슬롯별)** |
| 퀘스트 실패 (파괴) | **− (등급별, 미회수보다 큼)** | **0** (위약금 없음) | **− (슬롯별, 미회수의 2배)** |

### 등급별 수치 (프로토 확정)

**성공 (퀘스트 완료 시)**

| 샘플 등급 | 평가 점수 | 크레딧 ₡ | 호감도 (메인 슬롯) | 호감도 (반복 슬롯) |
|---|---:|---:|---:|---:|
| C | **+70** | **+80** | **+0.2** | **+0.1** |

|---|---:|---:|---:|---:|

**실패 — 파괴 (당일 재시도 불가)**

| 샘플 등급 | 평가 점수 | 크레딧 ₡ | 호감도 (메인) | 호감도 (반복) |
|---|---:|---:|---:|---:|

| A | **−130** | 0 | **−0.8** | **−0.4** |
| S | **−220** | 0 | **−1.0** | **−0.4** |

### 호감도는 슬롯에 붙는다 (v10 재편)

**점수·크레딧은 샘플 등급이 결정하고, 호감도는 그 퀘스트가 앉은 슬롯이 결정한다.**

| 항목 | 규칙 |
|---|---|
| 메인 슬롯 | 등급 성공 호감도를 그대로 쓴다 (C +0.2 ~ S +0.5) |
| 반복 슬롯 | 등급 성공 호감도의 **절반, 소수점 1자리, 상한 +0.2** |
| 미회수 실패 | **−(성공값)** |
| 파괴 실패 | **−2×(성공값)** |
| 등급 없는 목표 | 카트리지·기록물·기믹 회수처럼 등급이 없으면 현장 문서가 슬롯 호감도를 직접 authored 값으로 정한다. 이때도 미회수·파괴 비율은 위와 같다 |
| 계약 총합 제약 | 한 현장의 **메인 3일 완주 호감도 총합은 +1.4**를 기준으로 맞춘다. `02` §7 티어(+2.0 / −2.0) 도달 속도가 이 값에 묶여 있다 |

바꾼 이유: 메인/반복은 등급이 아니라 **약속의 무게**가 다르다. 같은 A급 샘플이라도 스토리 라인으로 발주된 것과 랜덤 풀에서 뽑힌 선택 계약은 상인이 보는 값이 같을 수 없다. 등급에만 묶어 두면 현장이 메인↔반복 구성을 바꿀 때마다(예: X-7 v7) 호감도 곡선이 통째로 흔들린다.

파괴 페널티도 슬롯을 따라 내려간다. A급이 반복 풀로 내려왔는데 파괴 −0.8을 유지하면, 선택 퀘스트 하나가 메인 하루 성공분의 두 배 넘게 깎아 먹는다.

### 이월 규칙은 슬롯마다 다르다 (v10.2 정정)

**메인은 하루짜리, 반복은 계약짜리다.** 이월 여부가 슬롯을 따라 갈린다.

| 항목 | 메인 슬롯 | 반복 슬롯 |
|---|---|---|
| 수명 단위 | **Day 1일** | **계약 3일 전체** |
| 풀 갱신·발주 | Day 시작마다 그 Day용 라인 | **계약 시작 시 1회** 추첨 (Day 시작마다 다시 뽑지 않는다) |
| Accepted 유지 | **Day를 넘지 않는다** | **Day를 넘어 유지된다.** Day1에 수락한 것을 Day3에 완료해도 성공이다 |
| 미완 판정 시점 | **매일 18:00** — 그날 Failed 확정, 호감도·점수 델타 즉시 반영 | **계약 종료(Day3 18:00)** — 그때까지 미완이면 Failed |
| 스폰물 | 미회수 샘플·회수 오브젝트를 18:00에 **디스폰**. 비상 4일차도 예외 없음 | **맵에 남는다.** 다음 Day에 이어서 회수 가능 (비상 4일차 포함) |
| 진행 플래그 | 18:00에 소멸 | 계약 종료까지 유지 |
| 파괴 | 즉시 실패 확정 (시점 무관) | 즉시 실패 확정 (시점 무관) |
| 재수락 | 같은 Day 안에서 Failed 후 재수락 불가. 다음 계약에서 라인이 처음부터 다시 돈다 | 계약 안에서 Failed 후 재수락 불가. 다음 계약에서 다른 조합으로 교체 |

**메인이 이월되지 않는 이유:** "미회수 샘플은 맵에 남아 다음날 재회수 가능"은 하루 단위 압박(18:00 복귀·점검)을 무력화한다. 오늘 못 챈 것을 내일 주우면 되는 구조에서는 Day가 구분되지 않는다. 대신 **라인을 잠그지는 않는다** — 실패의 대가는 그날 정산에서 끝나고, **Day에 맞는 메인은 실패 이력과 무관하게 열린다** (§1 경과 기준 언락).

**비상 4일차에도 예외는 없다 (확정).** **메인 퀘스트는 Day3까지가 끝이다.** 비상 4일차에는 메인이 발주되지 않고, Day3의 미회수 메인 스폰물도 18:00에 그대로 디스폰된다. 4일차를 메인 라인의 연장으로 쓰면 Day3의 18:00 마감이 무의미해지기 때문이다 — 4일차는 **남은 일을 치우는 날**이지 못 깬 퀘스트를 다시 깨는 날이 아니다.

> 4일차의 점수 회복 재원은 **반복 슬롯 잔여분 + 청소·분리 + 구역 마감**이다. 반복 스폰물은 계약 종료까지 남으므로 4일차에도 회수할 수 있다. 정본은 `12 비상 4일차`.

**반복이 이월되는 이유:** 반복은 애초에 Day에 매달린 퀘스트가 아니다. 계약 시작 시 2~3개를 뽑아 3일 내내 병행하는 사이드 계약이고, "Day1에 받아서 Day3에 낸다"가 정상 플레이다. 여기에 하루 마감을 걸면 계약 후반에 뽑힌 목표를 손댈 시간이 사라지고, 매일 다시 추첨하는 구조로 되돌아간다.

**연계 퀘스트.** 메인 연계는 두 단계를 **같은 Day**에 배치한다 (§1) — Day를 걸치면 위 메인 규칙과 부딪힌다. 1단계만 깨고 18:00을 넘기면 라인 전체를 실패로 처리하고, 이미 지급된 1단계 호감도는 회수하지 않는다. 반복 연계는 상태가 유지되므로 Day를 걸쳐도 된다.

`05` S−05의 "다음날 재시도 가능" 문구는 **반복 슬롯에만** 해당한다. 메인은 재시도가 없다.

규칙:
1. 손상 회수(파손된 채 납품)는 **파괴가 아니다.** 퀘스트 조건이 "Intact"면 실패(파괴 취급 아님 → 미회수 등급 감점 적용), 조건이 "손상 허용"이면 성공 처리하되 **점수는 40%**(`05` S+13) · **크레딧은 50%**(`07` §3.2)를 지급한다 — 두 트랙의 비율이 다르다.
2. 크레딧은 **성공 시에만** 지급된다. 실패해도 이미 받은 착수금·분리 환급은 회수하지 않는다 (`07` §1.2 M−02 삭제).
3. 파괴는 항상 미회수보다 무겁다 — 점수·호감도 모두. 비율은 정확히 2배다.
4. 퀘스트를 **수락하지 않은** 경우 그 샘플은 스폰되지 않으므로, 미수락에 대한 감점은 존재하지 않는다.
5. **호감도는 슬롯, 점수·₡는 등급.** 위 슬롯 표를 따른다.
6. **이월은 슬롯마다 다르다.** 메인은 Day 1일, 반복은 계약 3일. 위 이월 표를 따른다.

|---|---|---|
| **모선 허브** | 계약 시작/종료, 정산, 상점 | 퀘스트 수락·완료 창구 (미션 선택형 진입점) |

### 외부 구역 퀘스트 배치 원칙
- 외부(바다 등)는 자체 퀘스트 유형이 아니다. **위치가 외부인 메인/반복/로어 퀘스트**로 취급한다.
- 메인 퀘스트의 외부 배치: 보통 Day1(진입 학습)·Day3(복귀 전 마무리) 같은 시작/종료 지점에 배치해 학습·마무리 동선으로 쓴다.
- 반복 퀘스트의 외부 배치: 내부보다 위험도 낮은 수집·정찰형 목표로 채운다.
- 로어 퀘스트의 외부 배치: 블룸이 어떻게 퍼져나가는지(전파 경로) 보여주는 소재로 우선 배치한다.
- 상세 예시는 `X-7 기지 기획서/01`·`03` 참고 — 다른 현장 문서를 만들 때도 이 배분 원칙을 그대로 따른다.

## 4. 반복 퀘스트 (현장별 사이드 풀)

**반복 퀘스트**는 메인 퀘스트와 무관하게, 같은 현장을 여러 번 플레이할 때마다  
**풀에서 랜덤하게 조합되는 사이드 미션**이다. 점검 통과와 무관하며, **점수·크레딧은 메인과 동일**하고 **호감도만 절반**이다 (§1.5, `07` §3.2).

### 구조
- **계약 시작 시** 현장의 반복 퀘스트 풀에서 **2~3개를 랜덤으로 선택**하고, 그 조합을 3일 내내 유지한다
- 메인 퀘스트와 **병행 가능** (Day 중간중간에 수락 가능)
- 내용은 "샘플 N개 회수", "구역 청소 마감", "특정 오염물 정리" 등 명확한 목표
- 외부(바다) 구역 반복 퀘스트도 이 풀에 **함께 섞여 있다** (§2 배분 원칙)
- **호감도는 반복 퀘스트 풀 선정에 관여하지 않는다.** 호감도가 영향을 주는 곳은 상점 해금·착수금 배율·대출뿐이다 (`02` §7, `07` §2.2·§4·§5). 풀에서 어떤 퀘스트가 뽑히는지는 호감도와 무관하게 순수 랜덤이다.
- **퀘스트 실패(미회수·파괴·포기)는 크레딧 위약금이 없다.** 호감도만 하락하며(미회수보다 파괴가 더 크게 하락), 이미 지급된 착수금·환급은 그대로 유지된다 (`07` §3.2).

- **호감도는 등급 성공값의 절반, 상한 +0.2**다 (§1.5 슬롯 표). 파괴 실패도 슬롯 기준으로 −2×(성공값)이다.
- **큰 보상 2장이 한 계약에 겹치지 않게** 뽑기 가중치를 둔다. 반복 풀에 A/B급 샘플 퀘스트가 여러 장 있으면 합쳐서 최대 1장만 나오게 한다 — 겹치면 일일 기대 순수입(`07` 800~1400₡)이 무너진다.

- 현장 2회차 방문부터: 메인 + 반복 2~3개 노출
- 반복 퀘스트 미완료: 다음 방문 시 다른 조합으로 교체
- **1회차 고정 노출 예외.** 현장이 기믹 상승형이면(§1) 1회차에 등급 샘플이 아예 없어진다. 이때 현장 문서가 반복 1종을 **1회차 Day1 고정 노출**로 지정하고 랜덤 풀에서 제외한다. X-7 적용 예: `X-7 …/01` §2.0의 X7-R09.
- **반복은 계약 내내 상태가 유지된다.** Day1에 수락한 것을 Day3에 완료해도 성공이고, 미회수 스폰물도 맵에 남는다. 실패 판정은 **계약 종료(Day3 18:00)** 에 한 번만 한다 (§1.5). 계약 안에서 Failed 후 재수락은 불가하고, 다음 계약에서 다른 조합으로 교체된다.
- **추첨은 계약 시작 시 1회**다. Day 시작마다 다시 뽑지 않는다 — 그러면 이월이 무의미해진다.

## 5. 로어 퀘스트 (수집형)

### 개념
현장 곳곳에 배치된 **기록물**(데이터 코어, 낡은 태블릿, 항해일지, 화물 전표 등)을 수집하면  
**코덱스(기록 보관함)** 엔트리가 열린다.  
블룸 확산 미스터리(`06` §2.5)의 단서는 **전부 이 트랙으로만** 전달된다 (§0.1).

### 완료 판정 (중요)
로어는 **메인/반복의 “청소·마감 %”와 다른 모델**이다.  
샘플 회수가 목표 개수만큼이면 끝나듯, 로어는 해당 `AMD_LoreActor` **조사 1회**면 끝난다.  
섹터 내 오염물·조각·쓰레기 비율로 로어 완료를 판정하지 **않는다.**  
헤라·철거·수영·스캔은 **접근 기믹**일 뿐 완료 조건이 아니다.

### 규칙
| 항목 | 규칙 |
|---|---|
| 배치 | 현장당 내부 위주 + 외부 1~2개, 필수 동선 밖 탐험 위치 |
| 상호작용 | 기록물 접근 → 프롬프트("F: 조사") → **상호작용 1회** → 즉시 코덱스 등록 후 오브젝트 소멸 |
| 운반 | **없음.** (`02` §2.5 샘플·폐기물과 별개) |
| 접근 기믹 | 오염 덮개(헤라), 가림 잔해, 칸막이 철거, 수영 부유물, (선택) 스캐너 힌트 — 현장 로어 문서 |
| 점검 영향 | **없음** |
| 미회수 시 | 파괴되지 않는 한 재방문 재시도 |
| 미스터리 전개 | 코덱스 안에서 정렬·연결 (별도 퀘스트 언락 UI 없음) |

### 현장별 정본
| 현장 | 문서 |
|---|---|
| X-7 (7종, LoreId·본문·기믹) | **`X-7 기지 기획서/04 X-7 로어 퀘스트 기획`** |
| TR-9 (5종) | `TR-9 관통선 기획서/01` §4 (추후 `03` 분리 가능) |
| SS 벨몬트 | 미작성 — `03` 형식으로 신규 |

### 코덱스 UI 메모 (상세 `04` §5.5)
- 모선 퀘스트 화면 로어 탭 = 기록 보관함.
- 완성률 N/M · 미발견 / 암호화 / 해독 3상태.
- 케른 스파 등 언락은 **현장 코덱스 완성률**(호감도 게이트 대신).

## 6. 보상 구조 통합

| 퀘스트 유형 | 평가 점수 | 크레딧 | 호감도 | 로어 | 해금 |
|---|---:|---:|---:|---:|---|
| **메인 퀘스트 (샘플 회수)** | 등급별 (§1.5) | 등급별 (§1.5) | **메인 슬롯** 등급별 (§1.5) | 없음 | 없음 — Day는 경과로 열린다 |
| **메인 퀘스트 (청소·마감)** | 마감 +40 (`05` S+14) | 청소 120₡ / 마감 100₡ (`07` §3.2) | +0.2 | 없음 | 없음 — Day는 경과로 열린다 |
| **메인 퀘스트 (기믹 회수, 등급 없음)** | 유형별 (`05`) | 유형별 (`07` §3.2) | 현장 문서 authored (§1.5) | 없음 | 연계 2단계만 1단계 완료 게이트 (같은 Day 내) |
| **반복 퀘스트** | 등급별 또는 유형별 (메인과 동일) | 유형별 (`07` §3.2) | **반복 슬롯** = 등급별 ×0.5, 상한 +0.2 | 없음 | 없음 |

로어는 위 표에 **포함하지 않는다.** 코덱스 수집만 하며 점수·₡·호감도 지급이 없다. 현장 완성 시 신규 현장 언락 후보는 `09` §5 / 현장 로어 문서.

**샘플 회수 퀘스트의 점수·₡·호감도 정본은 §1.5 등급별 표다.** 샘플 납품 자체에는 아무 보상이 없고, 전부 퀘스트 완료에 귀속된다.  
메인과 반복은 **점수·₡가 같은 공식**이고, **호감도만 슬롯에 따라 갈린다** (§1.5).  
충돌 시: **점수=09 §1.5(샘플 관련) / 05(그 외)**, **크레딧=07**, **호감도=09 §1.5 슬롯 표**.

**Day 언락은 보상이 아니다.** 구 표는 메인 완료 보상에 "다음 Day 언락"을 적었지만, v10부터 Day는 경과로 열린다 (§1). 완료로 열리는 것은 연계 퀘스트의 2단계뿐이다.

## 7. 미션 선택 흐름 & 진행 (메인 메뉴)

```
미션 선택 (메인 메뉴)
  ↓
현장 선택 (X-7 / TR-9 / SS 벨몬트 / 신규)
  ↓
난이도 선택 (안전 / 표준 / 위험 / 극한)
  ↓
계약 시작 (3일 계약, 모선 투입)
  ├─ 모선 대기 중
  │   ├─ (선택) 바다 외부 퀘스트 선택 (일부 수행 가능)
  │   └─ 기지 진입 준비
  ├─ Day1: 
  │   ├─ 메인 Day1 노출 (완료 후 Day2 언락)
  │   ├─ 반복 퀘스트 풀 (2회차 이상)
  │   └─ 바다 외부 퀘스트 계속 진행 가능 (자유 시간 활용)
  ├─ Day2: 
  │   ├─ 메인 Day2 노출 (완료 후 Day3 언락)
  │   ├─ 반복 퀘스트 병행
  │   └─ 바다 외부 퀘스트 계속 가능
  └─ Day3: 
      ├─ 메인 Day3 노출 (완료로 계약 마감)
      ├─ 반복 퀘스트 병행
      ├─ 바다 외부 퀘스트 계속 가능 (18:00 전)
      └─ 18:00 모선 출발, 계약 종료
```

### 퀘스트 노출 규칙
- **메인 퀘스트**: **Day 경과로** 언락(선행 완료 불필요), 현장 방문 시마다 동일한 라인. 연계 2단계만 1단계 완료 게이트이며, **같은 Day 안에서만** 이어진다 (§1)
- **반복 퀘스트**: 같은 현장 2회차 방문부터 노출, 매번 랜덤 조합 (2~3개). 기믹 상승형 현장은 1종을 1회차 고정 노출 (§4)
- **로어 퀘스트**: 현장에 고정배치, 발견형 (아이콘/표시로 찾기)

### 주요 원칙
- 메인과 반복 퀘스트는 **병행 가능** (Day 중간에 반복 퀘스트 수락 가능)
- **메인은 18:00에 미완이면 Failed로 확정되고 다음날로 이월되지 않는다.** 그날의 Day 메인은 실패 이력과 무관하게 열린다. **반복은 계약 종료까지 상태가 유지된다** (§1.5)
- 로어 퀘스트는 계약 실패/게임오버와 무관하게 **코덱스에 영구 기록**
- 별도의 상인 개인 퀘스트 알림/게이트는 **없음** (§0.1)

## 8. 신규 현장 추가 체크리스트

1. `06` §2.6 로스터에 현장 한 줄 추가 (개요·원인·톤 포인트)
2. 이 문서 §3에 발주처·메인 퀘스트 요약 한 줄 추가, 상세는 별도 전용 폴더/문서로 분리 (예: `X-7 기지 기획서/`, `TR-9 관통선 기획서/`)
3. 코덱스 소재는 현장 `03` 로어 문서에 기록 (X-7 완료: `X-7 …/03`)
4. **단가(`05` §1~2)·공식(`07`/`08`)은 공통이라 그대로 재사용**하되, **콘텐츠 배치·일차별 점수 궤적(`05` §3·§4)은 현장마다 새로 기획한다** — 다른 현장 수치를 복사해 붙이지 않는다. 각 현장 전용 문서(§3B/§3C 등)에 그 현장만의 시뮬레이션을 담는다 (예: `05` §3B TR-9)
5. 발주처 대사만 새 현장 지명으로 교체 (브릭스는 캐릭터 자체가 불변, §0.1)

## 9. 개발 구현 우선순위

1. **Day 언락을 경과 기준으로 변경** (§1). 지금 구조는 "선행 Day 완료 후 노출"이다. 연계 2단계는 같은 Day 안에서만 이어지므로 Day 경계 로직이 필요 없다
2. **18:00 정산은 메인만** 마감한다 — Accepted 미완 Failed 확정 · 호감도·점수 델타 · 스폰물·진행 플래그 디스폰. **반복은 건드리지 않고 계약 종료에서 한 번 마감**한다 (§1.5). 반복 추첨을 계약 시작으로 옮기는 것은 이미 반영됨
3. **호감도를 슬롯 기준으로 계산** — 등급 테이블에서 호감도를 떼고 슬롯(메인/반복) 배율로 옮긴다 (§1.5)
4. 메인/반복 퀘스트 데이터를 현장별로 분리 (기존 시스템 재사용)
5. X-7 메인 기믹 3종 + 반복 풀 + 로어 배치 (`X-7 …/03` / `01` / `04` / `02` 레벨)
6. 반복 뽑기 가중치 — 외부 최소 1개 보장 · 고보상 2장 동시 금지 · 1회차 고정 노출 예외 (§4)
7. 코덱스 UI 최소 버전 (목록 + 완성률)
8. ~~신규 현장(TR-9 관통선) 메인/반복/로어 콘텐츠 제작~~ — 완료, `TR-9 …/01` 참고. **단 TR-9은 아직 구 프레임(등급 상승형·이월 허용)이므로 §1·§1.5 재적용 검토 필요**
9. 신규 현장(SS 벨몬트) — `01` Day 요약·반복 풀 + 로어 전용 문서 형식으로 문서화
