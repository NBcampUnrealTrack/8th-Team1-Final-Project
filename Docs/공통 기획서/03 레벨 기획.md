# 03. 레벨 기획서 (Develop)

각 현장에 작업 구역, 운반 경로, 위험 요소를 어떻게 배치할지 정한다. 구체적인 방 위치는 X-7과 TR-9의 전용 배치 문서를 따른다. 인원이 줄어도 맵 배치는 같고, 점검에 필요한 점수만 낮아진다.

## 1. 맵에서 플레이어가 할 일

한 계약(3일) 동안 플레이어는 다음을 경험해야 한다.

1. 같은 기지를 사흘간 **이어서** 철거한다
2. 매일 08:00 투입, 18:00 전 모선 복귀한다
3. 섹터를 돌며 **청소와 철거**를 반복한다  
   (조각벽·오염물·따개비·각종 쓰레기 → 손 / **임시 쓰레기통** → 모선 분류)
4. 2·3일차 점검은 **점수**로 판정 (성공/경고+패널티, 필요 시 비상 4일차)
5. 어제 연 길이 오늘도 남아 있다는 누적감을 느낀다
6. 기지 ↔ 바다(모선)는 **레벨 스트리밍**으로 이동한다

레벨 디자인의 성공 기준:
- “긁을 더러움(오염·따개비)”과 “자를 벽”, “주울 쓰레기”가 풍부하다
- 내력벽을 보면 **천장 베이**가 떠오른다
- 폐기물 점수는 **모선 5종 분류**(금속/일반/플라스틱/오염/안탐)로 읽힌다
- Day1/2/3 작업 구역이 나뉜다
- “지금 복귀해야 하나?”를 시계가 가르친다
- 1층 **폐기물 대기장**에서 임시 쓰레기통을 무한 보급받을 수 있다
- 기지 **폐기물 잠재 점수 ≥ 1800** (`05` 배치 예산). 주력은 철거 조각, 산재는 보조
- 콘텐츠 밀도는 **하루 리얼타임 10분** 기준으로 잡는다 (`02` §5, 플레이테스트로 재조정 가능)

## 1.5. 폐기물 배치 예산 (레벨 적용, 원칙만 — 실제 수치는 현장별)

기지 **폐기물 잠재 점수 ≥ 1800**을 만족하도록 세그먼트·산재·따개비·오염 노드 개수를 잡는다. 단가는 `05` §1~2 공통표를 따르되, **정확한 개수·배치는 맵마다 새로 기획**한다 (`09` §8).

- X-7 확정 수치: `05` §3A.1·§4A (세그먼트 8, 산재 30, 따개비 10, 오염 6 등)
- TR-9 확정 수치: `05` §3B.1·§4B (세그먼트 8, 산재 40, 따개비 14, 오염 8 등 — 샘플 트랙이 없는 만큼 분리 비중을 더 크게 잡음)
- 신규 현장 추가 시 이 절의 원칙만 재사용하고, 개수는 각 현장 전용 문서에 `05` §3X/§4X 형태로 새로 추가한다.

## 2. 공통 공간 모듈

| 모듈 | 기능 | 비고 |
|---|---|---|
| 해상 모선 | 상점, 대출, 난이도, 정산, 점검 | 안전 허브. **사망 시 리스폰 고정 지점** (`02` §6). 분류장은 두지 않는다 — 분류는 현장 대기장 (`02` §11) |
| 수중 투입 / 바다 | 모선↔기지 연계 | **레벨 스트리밍**으로 전환 |
| 수중 투입구 | 모선에서 바로 잠수 투입 | 에어락/배수 없음, 기지 전체 침수 |
| 섹터(방) | 작업/붕괴 판정 단위 | 플레이어는 항상 한 섹터에 속함. 붕괴 사망 시 오염물은 **섹터 입구 쪽 고정 위치**에 생성 (`02` §6) |
| **폐기물 대기장** | **통 무한 보급기 + 분리 5칸(색 코딩) + 응고제 디스펜서** | 현장 베이스캠프. 하루 내내 되돌아오는 기준점 (`02` §1.5·§11) |
| 열리는 문 | 다음 섹터로 통과 | 철거 없이 진행 |
| 열리지 않는 문 | 동선 차단 | 이 방에서는 벽을 부숴 다음 섹터로 |
| 일반 작업 섹터 | 돌파면에 칸막이/지주 **혼재** + 일부 **전선·수도관** | 스캔 후 세그먼트·유틸 회피 |
| 보통벽 청소 면 | 따개비·오염 배치 | 내력·칸막이 세그먼트와 구분 |
| 위험 구조 섹터 | 지주격벽, 지지대, 유틸 밀도↑ | 잘못 자르면 천장 붕괴 / 암전·오염수 |
| 샘플 섹터 | 회수 목표 | 돈/퀘스트 핵심 |
| 유해/심화 섹터 | 고난이도·후반 | 리스크 구간 |

### 레벨 스트리밍 (간단 명시)
- **기지(수중 현장)** 와 **바다·모선 연계 공간**은 레벨 스트리밍으로 로드/언로드한다.
- 청크 경계·스트리밍 볼륨·연출 디테일은 구현 단계에서 정한다.
- 플레이어 체감: 모선↔현장 이동이 끊기지 않는 한 맵처럼 읽히면 충분하다.

### 섹터 진행 규칙
- 각 섹터에는 열리는 문 / 열리지 않는 문이 섞여 있다.
- 우선 열리는 문으로 이동한다.
- 고장 문과 열리는 문을 적절히 섞는다.
- 고장 문일 때만 옆 **내부** 돌파면에서 칸막이/지주 세그먼트를 고른다.
- 칸마다 벽으로 무지성 봉쇄하지 않는다.
- **외벽은 철거하지 않는다.**
- 선택한 벽을 철거한다. **오염막·따개비 제거는 철거 조건이 아니다.**
- 헤라는 오염·따개비가 있는 보통벽·바닥·설비에서 사용 가능하다.
- 바닥에 **각종 쓰레기**(음료캔, 찢어진 작업복 등)를 배치한다.
- 오분류·대기장 미분류 잔여가 남으면 **평가 점수**가 깎인다. (현장에 남은 미수거 자체는 감점 없이 다음날로 이월된다)

### 수중 이동 연출
- 기본 현장은 물로 가득 차 있다.
- 발이 바닥에 닿으면 걷기
- **점프로 바닥을 밀면 수영 전환**
- 바닥에서 떨어진 상태는 수영
- 모선 복귀는 수영으로 상단 복귀 포인트에 접근
- 정밀 작업은 걷기(접지)에서 더 잘 되게 튜닝한다.
- “무게추”는 장비가 아니라, 접지=걷기 규칙을 설명하던 회의용 비유다.

## 3. 3일 진행 원칙

### 유지되는 것
- 철거된 벽/개방된 통로
- 설치한 지지대(일부 손상 가능)
- 미회수(미파괴) 샘플 위치
- **평가 점수·경고 상태**
- 구역 마감 상태
- 미수거 잔해·쓰레기 (다음날에도 남음)

### 리셋되지 않는 것
- 맵 전체를 처음부터 다시 만들기
- 어제 연 길을 막아버리는 강제 초기화
- ~~폐기 게이지~~ (시스템에서 삭제됨)

### 허용되는 소량 변화
완전 리셋이 아니라 “밤새 상황이 조금 나빠진” 연출만 허용한다.
- 잔해 위치 소폭 이동
- 약해진 지지대 1개
- 새로운 소형 오염 분출/균열·따개비 소량 재부착
- 동선이 조금 더 지저분해짐

## 4. 날짜별 주요 작업과 배치

| 일차 | 목표 | 점검 | 레벨 설계 포인트 |
|---|---|---|---|
| Day 1 | 탐색, 문/벽 돌파, 청소·분리 품질 학습 | 없음 | 학습, 낮은 처벌, 길 열기 |
| Day 2 | 본격 철거 + 샘플 회수 | **점수** 성공/경고(+패널티) — 기준 **500** | 선택의 밀도 증가 |
| Day 3 | 잔여 목표 마무리 + 구역 마감 | **점수** 기준 **1200** / 경고 재실패 GO / 무경고 실패 시 Day4 | 시간 압박 |
| Day 4 비상 | **점수 회복** (청소·분리·마감) | 기준 **1380** / 실패 시 GO | 착수금 없음 |

> 위 기준은 **표준 난이도 · 4인** 기준선이다. 난이도 배율(`05` §0.1)과 인원 배율(`05` §0.2 — 1인 ×0.40 / 2인 ×0.65 / 3인 ×0.85 / 4인 ×1.00)이 곱해진다.  
> **레벨 콘텐츠 배치는 난이도·인원과 무관하게 항상 동일하다** — 배치량은 4인 기준 하나만 만들고, 소수 인원 대응은 점검 기준을 내리는 쪽으로만 처리한다.

### Day 1
- 칸막이격벽 위주
- 지주격벽은 “위험하다는 것”만 보여주기
- **스캐너로 전선·수도관 보기 → 피해서 자르기** 1회 이상 학습
- (의도적) 전선 또는 수도 사고 1회 → 테이프/폼건 수리 튜토리얼 가능
- **보통벽 따개비 + 각종 쓰레기 + 오염**으로 청소·운반·분리 과정 학습
- **1층 폐기물 대기장**에서 임시 쓰레기통 보급 학습
- 샘플 1~2개로 손/쓰레기통 회수 과정 학습
- 18:00 압박 학습

### Day 2
- 실험실/샘플룸 본격 개방
- 지주격벽 작업 1회 이상 요구
- 점검용 **점수 기준** 유도 (분류·샘플·마감)

### Day 3
- 남은 고가 샘플 / 구역 마감 목표 집중
- 막힌 동선이나 붕괴 잔해로 긴장 상승
- 최종 점검 점수 조건을 명확히 배치

### Day 4 비상 (해당 시에만)
- 신규 고난도 구역을 억지로 열지 않는다
- 이미 열린 공간에서 오염·따개비·쓰레기 정리, 잔여 분리로 **점수 회복**
- 착수금 없음 / “안정화 근무”로 읽히게
- 목표가 UI에 분명해야 함: `평가 점수 OO 이상`

## 5. 공간 연출 체크리스트

- [ ] 모선→수중 투입이 매일 첫 인상으로 작동하는가
- [ ] 기지 ↔ 바다가 **레벨 스트리밍**으로 자연스럽게 이어지는가

- [ ] 지주격벽 실패 시 해당 캐릭터 섹터 천장 붕괴가 읽히는가
- [ ] Day 전환 후 어제 현장이 바로 보이는가

- [ ] 점검 목표(**점수**/샘플/마감)가 공간에 실재하는가

- [ ] 보통벽 따개비·각종 쓰레기가 “청소 일감”으로 읽히는가
- [ ] 4인이 동시에 막히지 않도록 주동선/부동선이 있는가

## 6. 아트/레벨 키워드

- 캐주얼 SF, 밝은 조명, 과한 고어 지양
- 물에 젖은 실험실, 노란 지지대, 주황 안전 장비
- 보통벽의 따개비, 바닥에 흩어진 캔·작업복
- “위험한 직장”이지 “공포 던전”이 아님
- 이모지 헬멧 캐릭터가 이질감 없이 들어가게 소품 스케일 유지
