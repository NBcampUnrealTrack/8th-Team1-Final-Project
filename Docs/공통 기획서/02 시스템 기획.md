## 0.5. 회의 반영: 완전 침수 / 접지 이동 / 섹터

### 기지 상태
- X-7 작업 구역은 **시작부터 완전히 침수**되어 있다.
- 에어락/배수 진입 연출은 쓰지 않는다.
- 모선에서 바로 수중 현장으로 투입된다.
- “물이 새로 들어온다”가 메인 실패 연출이 아니다.
- 실패의 핵심 연출은 **섹터 천장 붕괴 / 구조 손실 / 샘플 위험**이다.

### 수중 이동 (접지 = 걷기)
회의에서 말한 “무게추”는 **별도 장비가 아니다.**  
캐릭터가 바닥에 닿으면 걷는다는 규칙을 쉽게 설명하려고 쓴 비유다.

실제 규칙은 단순하다:

| 상태 | 조건 | 조작감 |
|---|---|---|
| 걷기 | 발이 바닥에 닿아 있음 (접지) | 안정적 철거/헤라 작업에 유리 |
| 수영 | 수중에서 바닥 접지가 끊김 | 빠른 이동·수직 이동·모선 복귀에 유리 |

규칙:
1. 바닥에 닿으면 걷는다.
2. 바닥에서 떨어지면 수영한다.
3. **접지 상태에서 `점프`를 누르면 바닥을 밀어 수영 모드로 전환**한다.
4. 모선으로 올라가려면 점프로 수영 전환 후, 상단 복귀 포인트로 이동한다.
5. 수영 중 다시 바닥에 닿으면 걷기로 돌아온다.
6. 정밀 작업(헤라, 지주격벽 절단, 지지대 설치)은 걷기(접지) 상태에서 더 안정적이다.
7. 수영 중에는 작업 정확도가 떨어지거나 일부 행동이 제한될 수 있다.

의도:
> 수중 맵에서도 “바닥을 딛고 일하는 느낌”과 “물속을 헤엄치는 느낌”을 자연스럽게 오가게 한다.  
> 무게추 UI/아이템/토글은 넣지 않는다. 수영 전환은 **점프**로 한다.

### 이동 속도 (9차 회의: 참고작 분석 반영)
- 참고작(Viscera Cleanup Detail) 대비 **이동 속도는 빠르게** 가는 방향으로 확정.
- 참고작은 이동이 느리고 물리(양동이 등 운반물)가 불안정해 답답하다는 평이 다수였음.
- 우리 게임은 **임시 쓰레기통이 물리 오브젝트**라 너무 빠르게 움직이면 내용물을 쏟을 수 있음 →  
  이동 자체의 기본 속도는 올리되, **쓰레기통을 들고/끌고 있을 때의 안정성(쏟김 판정)** 은 별도 튜닝 대상으로 남긴다.
- 목적: “느려서 답답하다”는 참고작의 단점을 반복하지 않는 것.

### 섹터 (방 단위)
- 기지의 각 방은 **섹터**다.
- 플레이어는 항상 하나의 현재 섹터에 속한다.
- 지주격벽을 잘못 절단하면, 벽이 이어진 모든 방이 아니라  
  **절단 버튼을 누른 캐릭터가 서 있는 섹터의 천장이 무너진다.**

플레이 의미:
- 어디서 자르느냐가 리스크다.
- 같은 벽을 자르더라도, 안전한 인접 섹터에서 작업할지 / 위험 섹터 한가운데서 자를지 선택이 생긴다.
- 협동 시 한 명은 지지, 한 명은 다른 섹터에서 절단 같은 역할이 가능하다.

## 1. 헤라 · 청소 요소

### 목적
현장의 **더러움과 잔여물**을 벗겨 손맛·정리를 만들고,  
철거·수거물을 **깨끗하게 분리·폐기**할 수 있게 한다.

### 청소 요소 구분 (중요)

| 요소 | 대상 | 도구 | 산출물 | 비고 |
|---|---|---|---|---|
| **오염물** | 벽·바닥·설비 표면의 바이오필름·도장·점액층 | 헤라 | 물리 **오염물** | 기존 루프. 철거 필수 아님 |
| **따개비** | **보통벽**에 붙은 부착물 | 헤라 | 물리 **따개비** | 내력벽·칸막이벽·오염물과 **별도** 품목 |
| **각종 쓰레기** | 기지 바닥에 흩어진 생활·작업 쓰레기 | 손 집기 | 물리 **쓰레기** | 헤라 불필요. 종류는 아래 |

> **보통벽:** 철거 판정용 **내력벽 / 칸막이벽**이 아닌 일반 벽면·구조 표면.  
> 따개비는 여기에만 붙는다. (내력·칸막이 세그먼트에는 두지 않는다.)

### 헤라 핵심 규칙
1. 헤라는 **오염물**과 **따개비**에 쓴다. (표면이 있는 곳)
2. **벽을 철거하기 위해 오염막·따개비를 꼭 제거할 필요는 없다.** 남아 있어도 절단·돌파는 가능하다.
3. 긁어낸 오염물·따개비는 **월드 물리 오브젝트**로 떨어진다. 인벤에 들어가지 않는다.
4. 산출물은 **손으로 집어 임시 쓰레기통에 담아** 모선으로 가져간다. 쓰레기통은 **물리**라서 기울이면 **쏟을 수 있다**.
5. 철거 전 벽의 **오염 제거율**이 떨어질 벽 조각의 오염/비오염 비율을 결정한다. (아래 §2.5)
6. 헤라는 철거 잠금이 아니라 **청소 손맛 + 조각 품질 + 모선 분류** 도구다.
7. 샘플 근처는 거칠게 긁으면 손상 위험이 올라간다.

### 각종 쓰레기 (기지 내 산재)
헤라와 별도로, 기지 곳곳에 **손으로 집는 쓰레기**를 배치한다.  
모두 **임시 쓰레기통 → 모선**으로 운반하고, 모선 **5종 컨테이너**에 분리한다. (§11)

예시 품목 → **모선 투입 칸** (프로토 배치용):

| 품목 | 연출 / 의도 | 정분류 칸 |
|---|---|---|
| 음료캔 | 휴게·라운지·복도. 가볍고 굴러감 | **금속** |
| 녹슨 폐공구 | 전력·정비 구역 | **금속** |
| 케이블·전선 잔해 | 설비 주변. 동선에 걸리적임 | **금속** |
| 찢어진 작업복 | 격리·탈의·비상 구역. 부피 큼 | **일반쓰레기** |
| 젖은 서류·라벨 뭉치 | 사무·기록실. 떠다니기 쉬움 | **일반쓰레기** |
| 폐장갑·마스크 | 방호 소모품. 곳곳에 소량 | **일반쓰레기** |
| 플라스틱 비닐·포장재 | 창고·폐기 대기 동선 | **플라스틱** |
| 식품 포장 / 도시락 용기 | 라운지·휴게 (플라스틱 재질) | **플라스틱** |
| 깨진 실험 유리 / 비커 파편 | 분석·배양 근처 | **안타는 쓰레기** |
| 폐전지·소형 배터리 | 소수. 오분류 감점 강조 | **오염된 쓰레기** |

세부 환급·감점 수치는 `05 수치 기획` · 크레딧은 `07 경제 시스템`.

### 섹터 진행과의 관계
- OPEN/BROKEN 문을 섞어 둔다.
- 내부 **비내력·내력 격벽을 충분히** 배치해 철거 일감을 만든다.
- 내력벽은 **천장 베이**와 연결된다 (오절단 시 해당 베이 붕괴).
- 외벽은 절단 불가.
- **보통벽**에는 따개비·오염을, 바닥에 **각종 쓰레기**를 섞어 청소 일감을 만든다.

플레이어 교육 문장:
> 긁고(오염·따개비), 줍고(쓰레기), 자르고, 임시 쓰레기통에 담아 모선으로 간다.  
> 모선에서 **금속 / 일반 / 플라스틱 / 오염 / 안타는 것**으로 가른다.  
> 핫바는 공구함이다.  
> 빨간 벽은 천장을 잡고 있다.  
> 바깥 선체는 건드리지 않는다.

### 장비 차이
- 기본 헤라: 안전한 기본기
- 광폭 헤라: 빠르지만 실수 위험
- 열선 헤라: 두꺼운 오염층·단단한 따개비에 강함

## 1.1. 오염물 렌더링 구현 (데칼 + 런타임 마스크)

이 절은 §1 오염물의 **비주얼 구현 스펙**이다. 규칙(무엇을 언제 지우는가)은 §1을 따르고, 여기서는 "어떻게 지워 보이게 하는가"만 다룬다.  
결정: 데칼 다량 배치 방식이 아니므로(9차 회의) 렌더링 부하 우려가 낮아 **데칼 기반**으로 구현한다.

### 구조 개요
1. 오염물은 **데칼 액터**로 벽·바닥·설비 표면에 배치한다.
2. 각 오염물 데칼은 자신만의 **런타임 렌더 타겟(마스크)**을 하나씩 가진다. 시작값은 전부 검정(오염 100%).
3. 헤라로 긁으면, 히트 지점을 데칼의 로컬 UV 좌표로 변환해 `Draw Material to Render Target`으로 그 자리에 흰색(브러시)을 그려 넣는다.
4. 데칼 머티리얼은 `Opacity = ContaminationTex.a * (1 - RTMask)`로 오염 텍스처를 지운다.

### 데칼 배치 규칙
- 오염물 데칼은 **보통벽·바닥·설비 표면** 단위로 배치한다 (§1 대상 정의).
- 같은 스태틱 메시를 여러 번 재사용하는 모듈러 벽이라도, **데칼은 액터 단위로 개별 배치**되므로 인스턴스 간 마스크가 서로 섞이지 않는다 (데칼 방식을 선택한 주된 이유 중 하나).
- 데칼 크기·투영 깊이는 표면 굴곡(파이프·모서리 등)을 감안해 여유 있게 잡는다.

### 런타임 마스크 (Render Target)
| 항목 | 스펙 |
|---|---|
| 해상도 | 256×256 (프로토 기준, 표면 크기에 따라 조정) |
| 초기값 | 전부 검정 (오염 100%) |
| 그리기 | 헤라 히트 시 `Draw Material to Render Target`, 브러시 머티리얼(원형, 소프트 엣지, 반경/강도 파라미터화) |
| 블렌드 | 누적(가산) — 여러 번 스치면 흰 영역이 넓어짐. 이미 지운 곳은 다시 어두워지지 않음 |
| 메모리 관리 | 섹터 진입 시 생성, 섹터 언로드(레벨 스트리밍 아웃) 시 해제 |

### 헤라 히트 → UV 변환
1. 헤라 트레이스가 데칼 표면에 히트하면 월드 히트 위치를 구한다.
2. 히트 위치를 **데칼의 로컬 트랜스폼 기준**으로 변환(Inverse Transform)하고, 데칼 박스 크기로 나눠 0~1 UV로 정규화한다.
3. 이 UV를 `Draw Material to Render Target`의 브러시 위치 파라미터로 넘긴다.

### 오염 제거율 산출 (§2.5 연동)
- 벽 철거 시 필요한 **오염 제거율**(§2.5, 조각벽/오염된 조각벽 배분 기준)은 이 렌더 타겟의 **평균 밝기값**으로 그대로 계산한다.
- 매 프레임 계산할 필요 없이, 철거 판정 시점에 렌더 타겟을 **밉맵 최하단(1×1)까지 내려 샘플**하면 평균값을 저렴하게 얻는다.
- 즉 시각 효과(오염 지워짐)와 점수 계산(오염 제거율)이 **같은 데이터 하나**로 처리된다 — 별도 트래킹 시스템 불필요.

### 성능 노트
- 데칼 개수가 많지 않은 프로토 규모 기준으로는 데칼 자체의 렌더 비용은 무시할 수준.
- 다만 **렌더 타겟은 액터 하나당 하나씩** 생성되므로, 오염물 데칼 개수가 늘어나면 메모리 사용량이 선형으로 증가한다. 섹터 단위 생성/해제로 억제한다 (위 표).

### 구현 우선순위
1. 데칼 + 정적 오염 텍스처 배치 (마스크 없이, 지워지지 않는 버전)
2. 렌더 타겟 마스크 추가 + 브러시 페인팅 (헤라 히트 → UV 변환 → Draw to RT)
3. 오염 제거율 계산(밉맵 샘플) → §2.5 조각 배분에 연결
4. 섹터 단위 RT 생성/해제 최적화

## 1.5. 임시 쓰레기통 · 폐기물 대기장

### 임시 쓰레기통 (물리)
- 월드 오브젝트. (구 용어: 보관함)
- 기울임·충돌·뒤집기에 **내용물이 쏟아질 수 있다.**
- **벽 조각 / 오염된 벽 조각 / 오염물 / 따개비 / 각종 쓰레기 / 샘플**을 담을 수 있다.
- 용량·혼적 규칙은 `05 수치 기획` (프로토: 용량·혼적 제한 느슨, 샘플과 폐기물 혼적 허용).
- 쏟아지면 다시 주워 담아야 한다. (코믹·협동 소스)

### 1층 폐기물 대기장 — 쓰레기통 보급기
- 기지 **1층 폐기물 대기장**에 **임시 쓰레기통이 무한정 나오는 기계**가 있다.
- 플레이어는 여기서 빈 쓰레기통을 꺼내 현장으로 가져간다.
- 현장 스폰 수량에 의존하지 않아도 된다. (분실·유실해도 대기장에서 재보급)
- 모선으로 내용물을 비운 뒤, 빈 통을 다시 쓰거나 대기장에서 새로 받아도 된다.
- **상점에서 팔지 않는다.** 대형/업그레이드 쓰레기통도 **없다.** 입수처는 대기장뿐이다.

### 운반 요약
| 대상 | 손 운반 | 임시 쓰레기통 |
|---|---|---|
| 샘플 | ✅ 가능 | ✅ 가능 |
| 벽 조각·오염 조각 | ✅ (소량) | ✅ 권장 |
| 오염물·따개비·각종 쓰레기 | ✅ (소량) | ✅ 권장 |

→ **분리할 폐기물과 샘플은 손으로 들거나, 임시 쓰레기통에 넣어 모선으로 가져간다.**

## 2. 격벽 철거

### 벽의 두 종류
| 이름 | 다른 표현 | 역할 | 플레이 의미 |
|---|---|---|---|
| 칸막이격벽 | 비내력벽 | 공간만 나눔 | 잘라도 천장 무관. 길·공간 개방 |
| 지주격벽 | 내력벽 | **천장 베이**를 붙잡음 | 오절단 시 **지지 베이 천장 붕괴** |

### 천장 베이
- 섹터 천장을 베이 격자로 나눈다.
- 내력벽 세그먼트마다 지지 베이 ID를 가진다.
- 절단(지지 부족) → 그 베이(들)만 낙하. 범위는 절단자 현재 섹터 안.

플레이어 교육 문장:
> 초록 벽은 칸막이, 빨간 벽은 천장을 잡는다.

### 언제 벽을 부수는가
- OPEN 문으로 이동 + **내부 비내력/내력을 적극 철거**해 공간·일감 확보
- BROKEN 문 옆 우회도 사용
- 외벽 NO CUT
- 오염 제거는 철거 필수 아님 (모선 분류 시 유리)

### 철거 절차
1. **스캔** (비내력 / 내력+지지 베이 / **전선** / **수도관**)
2. 내력이면 지지대 검토
3. 전선·수도관이 지나는 세그먼트는 **우회 절단**하거나 해당 유틸을 피한 컷 경로 선택
4. (선택) 헤라로 오염 제거율 올리기
5. 절단 → **벽 조각 ~10개 낙하** → 조각 수거 → 임시 쓰레기통 → 모선
6. 내력 실패 시 해당 **천장 베이 붕괴** + 대청소
7. 전선/수도를 잘랐으면 즉시 **수리**(테이프/폼건) 또는 작업 구역 이탈

### 실패 결과 (내력 오절단)

**지지대 미설치 상태:**
- 지주격벽을 잘못 자르면 → 지지 베이 천장 붕괴 (절단자 섹터)
- **캐릭터 피해:** 붕괴 반경 안에 있으면 즉시 **HP −60**(프로토). 오염수·산소 고갈과 동일하게 **HP 피해로만 처리** — 붕괴 자체가 직접 부상 판정을 내리지 않는다. 이후 상태 전환은 `§6` 규칙 그대로: **HP 30 이하 → 부상**, **HP 0 → 사망**
- 샘플 손상, 동선 봉쇄
- **점수:** **−200** (`05`)
- 추가 침수 없음 (이미 전체 침수)

**지지대 설치 상태:**
- 같은 벽을 절단해도 → **붕괴 발생 안 함**
- 플레이어가 안전하게 철거 작업 가능
- 캐릭터 피해 없음, 점수 페널티 없음

## 2.4. 벽 속 전선 · 수도관 (유틸리티)

벽(칸막이·지주 세그먼트) **안**에 숨은 설비. 겉으로는 안 보이고 **스캐너로만** 경로가 보인다.  
의도: “무턱대고 자르지 말고, 스캔 후 피해서 철거한다.”

### 공통
| 항목 | 규칙 |
|---|---|
| 배치 | 일부 세그먼트에 **전선 스플라인** / **수도관 스플라인** (둘 다 있을 수 있음) |
| 탐지 | **기본·정밀 스캐너 모두** 표시. 정밀은 경로·교차 경고 강화 (`08`) |
| 정석 플레이 | 스캔 → 유틸 라인 확인 → **안 지나는 면/세그먼트만** 절단 |
| 실수 시 | 해당 유틸 **절단 판정** → 아래 사고 → 아이템으로 수리 |

플레이어 교육 문장:
> 스캔하면 노란 전선과 파란 관이 보인다.  
> 그걸 피해서 벽을 가른다.

### 전선
| 항목 | 규칙 |
|---|---|
| 절단 시 | 그 전선이 담당하는 **섹터(방) 조명 OFF** (암전) |
| 연출 | 천장/벽 조명 꺼짐, UI에 `전원 차단` 토스트 |
| 점수 | 절단 즉시 **−25** (`05` S−12). 미수리 지속 추가는 없음 |
| 수리 | **절연테이프(IT-T1)** 1개 = 끊긴 전선 노드 **1곳** 복구 → 조명 ON |
| 수리 실패 시 | 암전 유지 → 시야·작업 난이도↑ (수영/철거 정확도 디버프 가능) |

### 수도관
| 항목 | 규칙 |
|---|---|
| 절단 시 | 파열부에서 **오염수 분출** |
| 연출 | **Niagara**로 오염수가 섹터로 퍼지는 것을 표시 (볼륨/데칼 확산) |
| 점수 | 파열 즉시 **−20** (`05` S−13). 미밀봉 **30초마다 −8** (상한 −80/사고) |
| **캐릭터 피해** | 오염수 **근처(위험 볼륨 안)**에 있으면 **HP 지속 감소** (아래) |
| 분류 | 바닥에 고인/묻은 오염은 헤라·청소 대상 **오염물**로 취급 가능 |
| 수리 | **폼건(IT-FG0)** 사격으로 파열구 밀봉 (카트리지·내구 `08`) |
| 밀봉 시 | Niagara 분출 정지, 틱 감점 중단, **HP 깎는 위험 볼륨 제거** |

#### 오염수 근접 HP 피해
| 항목 | 프로토 수치 |
|---|---|
| 판정 | 캐릭터가 오염수 FX/데칼의 **위험 반경** 안에 있으면 (대략 파열부 기준 **~250cm**, 확산에 따라 커질 수 있음) |
| 피해 | **HP −8 /초** (볼륨 안에 있는 동안 지속) |
| 최대 HP | **100** (프로토). 산소와 **별개** |
| HP 30 이하 | **부상** 상태로 전환 (`§6`). 볼륨에 계속 있으면 추가 피해로 HP 0 → **사망**까지 진행 |
| 탈출 | 볼륨 밖으로 나가면 깎임 **즉시 중단** (자동 회복은 없음 · 모선 치료/`§6`) |
| 의도 | 파열을 방치한 채 근처에서 작업하면 아프다 → **폼건으로 막거나 거리를 둔다** |

교육 카피:
> 더러운 물 근처에 있으면 몸이 상한다. 폼으로 막거나 떨어져라.

### 철거와의 관계
- 유틸을 피한 절단은 **철거 성공 점수 그대로** (`05` S+10/11).
- 유틸을 자르면서 벽을 부숴도 조각은 떨어진다. 다만 사고 패널티가 붙는다.
- 구역 마감 조건에 “해당 섹터 **열린 파열 수도 0** / **암전 미수리 0**”을 넣을 수 있다 (`03` 배치).

## 2.5. 벽 조각 · 운반 · 인벤 (회의 확정)

### 벽이 파괴되면
1. 벽은 **약 10개의 벽 조각**으로 떨어져 월드에 남는다.
2. 조각은 파괴 직전 그 벽에 붙어 있던 **오염물 제거율**에 따라 나뉜다.

| 조각 종류 | 조건 (개념) | 모선 정분류 칸 |
|---|---|---|
| **조각벽** (깨끗) | 제거율이 높은 면/영역에서 떨어진 조각 | **안타는 쓰레기** |
| **오염된 조각벽** | 오염이 남은 면/영역에서 떨어진 조각 | **오염된 쓰레기** |

프로토 단순화 예: 제거율 70%면 조각 10개 중 약 7개 깨끗 / 3개 오염.  
(정확한 배분은 `05 수치 기획`.)

### 운반 규칙 (일반 인벤토리 없음)
- 벽 조각·오염물·따개비·각종 쓰레기·샘플은 **인벤 슬롯에 들어가지 않는다.**
- 플레이어는 **한 번에 손(또는 양손)으로 집어서** 이동한다.
- 또는 **임시 쓰레기통**에 담은 뒤, 쓰레기통을 들고 모선으로 간다.
- 모선 도착 후 쓰레기통 내용물을 **분류장**에 부어 분리한다.
- 임시 쓰레기통 상세·1층 보급기는 §1.5.

### 인벤토리 = 핫바(장비 전용)
- UI 핫바만 존재한다.
- 슬롯에는 **장비만** 넣는다. (헤라, 절단 도구, 스캐너, 지지대, **절연테이프**, **폼건** 등)
- 자원/잔해/샘플용 가방 인벤은 **없다.**

플레이어 교육 문장:
> 부수면 조각이 떨어진다.  
> 손으로 들거나 임시 쓰레기통에 담고, 모선까지 가져간다.  
> 핫바는 공구함이다. 쓰레기는 가방에 안 들어간다.

## 3. 임시 지지대 / 안전 도구

### 임시 지지대
- 지주격벽 작업 전 안정도를 올린다.
- 수량 제한이 있어 “어디에 쓸지” 선택이 생긴다.
- **설치되어 있으면 해당 세그먼트 오절단 시 천장 붕괴가 발생하지 않는다** — 안전하게 철거 가능.

**게임플레이 의도:**
> 지지대는 “안전 확보”의 전략적 선택. 제한된 수량을 어디에 배치할지 결정하면서 철거 전략을 세운다.

### 보조 안전 도구
- **임시 지지대:** 지주격벽 작업 전 안정도 (상점 **안전 = 이 품목만**)
- **절연테이프:** 잘린 전선 → 섹터 조명 복구 (`08`)
- **폼건:** 터진 수도관 Niagara 분출 밀봉 (`08`)
- 산소 확장/캔: 수중 활동 시간 확보

> 강화 지지대·균열 패치·비상 격문은 프로토에서 **상점 미판매**.

### 구역 마감
“봉인” 같은 추상 표현 대신, **구역 마감**을 쓴다.

의미:
> 이 섹터의 철거·잔해 정리·위험 요소 처리를 끝내고, 점검용으로 “여기 작업 끝” 처리하는 것.

플레이어가 하는 일 (예시):
1. 지정 칸막이/지주 작업 완료
2. 큰 잔해·오염 정리
3. 마감 마커/제출 상호작용

결과:
- 점검 통과 OR 조건으로 사용
- **평가 점수**에 가산
- 해당 섹터는 마감 상태로 유지 (일자 리셋 없음)

## 4. 샘플 회수

### 샘플 스폰 (퀘스트 연동)
샘플은 맵에 미리 뿌려두지 않는다. **Day 시작 시 자동 갱신되는 퀘스트가 해당 등급의 샘플을 스폰**한다. 상세 규칙·수치 정본은 `09` §1.5.

- 퀘스트 목표 개수와 스폰 개수가 1:1 — 못 가져올 여분 샘플을 만들지 않는다.
- Day가 지날수록 등급이 상승한다 (X-7: Day1 C → Day2 B → Day3 A).
- 퀘스트를 수락하지 않으면 샘플이 스폰되지 않는다.

### 샘플 상태
| 상태 | 정의 | 결과 (점수 요약, 상세 `09` §1.5) |
|---|---|---|
| Intact 회수 | 모선까지 파손 없이 납품 | **퀘스트 성공** → C+70 / B+140 / A+220 / S+360 |
| 손상 회수 | 가져왔지만 파손 | Intact 조건 퀘스트면 **실패(미회수 등급 감점)**, 손상 허용 퀘스트면 성공 ×50% |
| 미회수 | 맵에 남김 (파괴되지 않음) | **퀘스트 실패** → C−20 ~ S−90, 다음날 재시도 |
| 파괴 | 깨짐/유실 | **퀘스트 실패** → C−45 ~ S−220, 재시도 불가 |

### 핵심 규칙
- **샘플 납품 자체는 점수·크레딧이 0이다.** 모든 보상은 **퀘스트 완료**에 귀속된다.
- 퀘스트 성공 시 **점수 + 크레딧 + 호감도**를 함께 받는다.
- 퀘스트 실패 시 **점수와 호감도만 하락**한다. 크레딧 위약금은 없다 (`07` §1.2 M−02 삭제).
- **미회수 ≠ 파괴** — 못 가져오면 손해, 깨뜨리면 더 큰 손해 (점수·호감도 둘 다).
- 상급 샘플은 상인 퀘스트와 상점 해금에 직접 연결
- 파괴되지 않은 미회수 샘플은 다음 날 다시 집을 수 있다

### 운반 방식 (회의 확정)
샘플도 인벤에 넣지 않는다.  
**손으로 들고 가거나, 임시 쓰레기통에 넣어 모선으로 가져간다.**

| 방식 | 설명 | 리스크 |
|---|---|---|
| **손 운반** | 샘플을 들고 모선까지 이동 | 벽·설비 **충돌 시 손상** 가능 |
| **임시 쓰레기통** | 샘플을 쓰레기통에 담아 운반 | 전도·충돌 시 쏟아짐/손상 가능 |

- 막힌 동선을 벽 철거로 연 뒤에야 닿는 위치
- 주변이 지저분하면 헤라로 정리할 수 있다 (필수는 아님)
- 배관/과열 차단 후 추출
- 붕괴·잔해에 묻히면 손상/미회수 위험

## 6. 건강 / 부상 / 사망

### 설계 원칙
캐릭터 상태는 **세 단계만** 쓴다.  
경미/중상/Down 같은 중간 단계는 두지 않는다.  
긴장은 목숨 게이지보다 **샘플 손실 / 시간 손해 / 점검 실패**에 둔다.

### 상태
| 상태 | 의미 | 플레이 영향 |
|---|---|---|
| 건강 | 정상 | 제한 없음 |
| 부상 | 다친 상태 | 이동·작업 속도 감소, 운반/정밀 작업이 불리해짐 |
| 사망 | 쓰러짐 | **빠르게 부활** (대기 없음). 부활 후 평가/정산 감점 |

### 전환
1. 건강 → 부상: **HP가 30 이하로 하락** — 원인 불문(오염수 근접 DoT `§2.4`, 붕괴 피해 `§2.3`, 산소 고갈 DoT `§6.2` 전부 동일 규칙으로 HP만 깎고, HP 임계치가 상태를 결정한다)
2. 부상 → 사망: **HP가 0에 도달** — 부상 상태에서 계속 피해(오염수 노출 지속, 붕괴 반경 재노출 등)를 받아 HP가 바닥나면 전환
3. 건강 → 사망: 한 번에 치명타급 사고로 HP가 30을 거치지 않고 바로 0까지 떨어지는 경우 (드묾)
4. 사망 → 건강(또는 부상): **빠르게 부활**. 부활 직후 짧은 디버프 + 평가/정산 감점 (`05` S−10 −30)
5. 부상 → 건강: **모선에서 상인에게 비용을 지불하고 회복** (`07` §2.5). 자동 회복·시간 경과 회복은 없다. 핫바 아이템을 쓰지 않는다 — 대신 **모선에 있어야만** 가능

### 사망 처리 상세 (9차 회의 확정)
청소·힐링 장르에 “죽고 나서 아무것도 못 하고 대기”하는 구간은 맞지 않는다는 판단으로,  
생존 게임식 다운·대기 연출 대신 아래 방식을 쓴다.

| 항목 | 규칙 |
|---|---|
| **부활 속도** | 즉시에 가깝게 빠르게 부활한다. 별도의 긴 다운 상태를 두지 않는다 |
| **사망 중 마이크** | 사망 상태에서도 **음성 채팅(마이크)은 계속 사용 가능** — 대화에서 소외되지 않게 |
| **사망 위치 오염물** | 죽은 자리에 **오염물/따개비류 잔해가 생성**된다 (콘셉트: “플레이어 자체가 쓰레기가 된다”) |
| **리스폰 위치** | **모선에서 고정 스폰**. 죽은 자리로 그대로 복귀시키지 않는다 (천장 붕괴로 방에 재진입이 막히는 경우가 있어서) |
| **붕괴 사고 시 오염물 위치** | 천장 붕괴로 사망한 경우, 오염물 생성 위치는 **해당 섹터 입구 쪽으로 고정** (무너진 자리 안쪽에 생성되면 회수 불가능해지므로) |

의도:
> 죽는 것 자체를 벌주기보다, “내가 죽은 자리에 치울 거리가 하나 더 생긴다”는 콘셉트로 흡수한다.  
> 대기·정지 다운타임을 만들지 않는다.

### HP (프로토)
- 캐릭터 **HP 100**. HUD 상태바에 표시 (`04`).
- **오염수 위험 볼륨** 안에서만 지속 감소 (`§2.4`). 일반 수중 잠수는 HP를 깎지 않는다 — 단, **산소가 0이 되면 별도로 HP가 깎이기 시작한다** (아래 §6.1).
- **내력벽 오절단으로 인한 천장 붕괴**도 동일하게 HP 피해로 처리한다 (`§2.3` 실패 결과, 1회성 피해).
- **상태 전환 임계치 (신규 확정):** 원인(오염수/붕괴/산소 고갈)과 무관하게 **HP 30 이하 → 부상**, **HP 0 → 사망**. 붕괴·오염수가 직접 부상·사망을 판정하지 않고, 전부 HP 수치 하나로 귀결된다.
- HP 피해는 **평가 점수가 아니다** (`05`에 넣지 않음).

### 6.1 산소 (프로토, 신규)

| 항목 | 수치 |
|---|---|
| 기본 지속시간(활동 가능 시간) | **300초** (5분) |
| 소모 조건 | **수면 아래(잠수) 상태일 때만** 감소 |
| 미소모 조건 | **수면 위**(수면을 뚫고 올라온 상태) 또는 **모선 위**에 있으면 소모되지 않음 |
| 회복 | **모선 복귀 시 즉시 100% 충전**. 수면 위는 소모만 멈출 뿐 자동 충전은 아님 |
| 확장 아이템 | 산소 캔 **+90초**(1회성), 산소 확장 탱크 **기본값 +40%**(상시) — `08` §5.2 |
| 0 도달 시 | 즉시 **HP 지속 감소** 시작 (아래 §6.2) |

**5분(300초)으로 잡은 이유:** 하루 리얼타임이 10분(`§5`)이고 Day1 기본 로드아웃이 산소 캔 2개(총 +180초, `07` §4.1)이므로,  
기본 300초 + 캔 2개 = **총 8분** 활동 가능. 10분짜리 하루 안에서 여유 있게 쓰다가 후반에 한 번 정도 모선/수면 위를 챙기면 되는 수준으로 설계했다.

### 6.2 산소 고갈 HP 피해 (프로토, 신규)

| 항목 | 수치 |
|---|---|
| 피해량 | **HP −15/초** (산소 0인 동안, 수면 아래에서만 지속) |
| 중단 조건 | **수면 위로 올라오거나 모선에 도달하면 즉시 피해 중단** (오염수 DoT, `§2.4`와는 별개 규칙 — 동시에 적용될 수 있음) |
| 사망까지 | HP 100 기준 **약 6.7초** — 즉시 죽지는 않지만 빠르게 위험해짐 |
| 회복 | 산소 재보충(캔 사용, 수면 위, 모선 복귀 중 하나) 즉시 피해 중단. **HP 자동 회복은 없음** — 부상 상태에서 건강으로 돌아오려면 **모선에서 상인에게 비용을 지불**해야 한다 (`§6` 전환 5, `07` §2.5) |

의도:
> 산소가 떨어지면 “빨리 위로 올라가라”는 압박은 주되, 준비만 하면 죽지 않는 여유를 준다.  
> 오염수 DoT(`§2.4`, −8/초)보다 더 급박하게(−15/초) 설계해 “질식”과 “오염 노출”이 다른 종류의 위험으로 느껴지게 한다.

### 금지에 가까운 방향
- Down 등 중간 상태 추가
- 초반부터 잦은 영구사망
- 사망 즉시 파티 게임오버
- 전투 중심의 하드코어 생존화

## 7. 상인 / 호감도 / 퀘스트

### 상인의 역할
모선 상인은 상점 점원이자 계약 중개자다.
- 장비 판매
- 착수금 지급
- 상급 샘플 퀘스트 부여
- 대출 제공
- **부상 치료 서비스 제공** (부상 → 건강, 유료. `07` §2.5)
- 호감도에 따른 거래 조건 변경

### 호감도
- 범위: `-4.0 ~ +5.0`
- 소수점 단위로 변동
- 상점 해금, 착수금 배율, 대출 조건에 영향

### 퀘스트
기본 미션과 별도인 추가 계약이다.
- 예: A급 샘플 Intact 회수, S급 데이터 코어 무파손 회수
- 성공: 호감도 상승 + 보상 + 해금 진행
- 실패: **호감도 하락만** (크레딧 위약금 없음, `07` §3.2)
  - 미회수 실패 < 파괴 실패 (파괴가 더 크다). 등급별 델타는 아래와 같이 확정 — 정본은 `09` §1.5

| 실패 유형 | C급 | B급 | A급 | S급 |
|---|---:|---:|---:|---:|
| 미회수 (기한 내 못 가져옴) | −0.2 | −0.3 | −0.4 | −0.5 |
| 파괴 (샘플을 깨뜨림) | −0.4 | −0.6 | −0.8 | −1.0 |

  - 점수 델타는 `05` S−05(미회수) / S−06(파괴)을 따른다. 크레딧 위약금은 없다.
  - 호감도 범위가 `-4.0 ~ +5.0`이므로, 단일 사고 최악은 **B급 2개 동시 파괴 −1.2**(X-7 Day2 기준)다.
- 호감도는 **상점 해금·착수금 배율·대출**에만 영향을 준다. 반복 퀘스트 풀에 어떤 퀘스트가 뽑히는지에는 관여하지 않는다 (`09` §4).

### 해금 원칙
돈만으로 최상위 장비를 열지 않는다.  
`호감도 + 퀘스트 진행`이 필요하다.

## 9. 난이도 선택 (단순화 확정)

출발 전 선택: **안전 / 표준 / 위험 / 극한**

**난이도가 바꾸는 것은 오직 하나, 현장 점검 점수 목표(Day2/Day3/Day4 기준)뿐이다.** 맵 콘텐츠(세그먼트·산재·샘플 개수·붕괴 리스크), 착수금, 물가, 패널티, 호감도 변동폭은 난이도와 **무관하게 전부 동일**하다 — 현장은 매번 같은 맵을 쓰고, 더 높은 점수를 채워야 하는 것만 달라진다.

| 난이도 | 점검 기준 배율 | 의도 |
|---|---:|---|
| 안전 | ×0.8 | 여유 있게 통과 |
| 표준 | ×1.0 | 기본 (`05` 확정 수치의 기준선) |
| 위험 | ×1.2 | 같은 맵을 더 꼼꼼히/완전히 처리해야 통과 |
| 극한 | ×1.4 | 맵을 거의 다 처리해야 통과 |

정확한 기준값(현장별)은 `05 수치 기획` §0.1을 따른다.

### 9.1 인원 배율 (신규)

점검 기준은 **4인을 기준선(×1.00)** 으로 잡는다. 인원이 줄면 같은 시간에 처리할 수 있는 양이 줄어들므로 **점검 목표도 함께 내린다.** 난이도와 같은 원리로, **맵 콘텐츠는 인원과 무관하게 항상 동일**하고 바뀌는 것은 점수 목표뿐이다.

| 인원 | 점검 기준 배율 |
|---|---:|
| 1인 | ×**0.40** |
| 2인 | ×**0.65** |
| 3인 | ×**0.85** |
| 4인 | ×**1.00** (기준선) |

- 선형(0.25/0.5/0.75)이 아닌 이유: 왕복 동선·분류장 대기·마감 제출처럼 **인원이 늘어도 줄지 않는 고정 비용**이 있고, 반대로 소수 인원은 동선 충돌·역할 대기가 없어 1인당 실효 처리량이 더 높다. 상세 근거는 `05` §0.2.
- **최종 기준 = 표준기준 × 난이도 배율 × 인원 배율 × (경고 시 1.1)**
- **인원은 계약 시작(Day1 출발) 시점으로 고정**된다. 도중 합류해도 기준을 올리지 않고(늦게 온 사람은 순수 이득), 도중 이탈해도 내리지 않는다(악용 방지). 세이브 후 재개도 최초 인원을 유지한다.

인원별 확정 수치는 `05` §0.2.

**바꾸지 않는 것 (명시):** 착수금·물가·환급·과태료(`07`), 단순 적 HP·전투 시스템(없음), 복잡한 스킬 콤보, 필수 하드코어 사망, 맵 진행도 리셋, 콘텐츠 배치(세그먼트·샘플·붕괴 리스크 등, `05` §3A/§3B는 난이도와 무관하게 표준 하나만 존재).

## 10. 3일 연속 철거 + 현장 점검

### 진행 유지
- 한 기지는 기본적으로 3일 동안 계속 철거한다.
- 1일차에 부순 벽, 연 통로, 남은 잔해는 이후 일차에도 유지된다.

- 게임오버 시에만 전체 리셋된다.
- 클리어 시 돈/퀘스트 진행도/호감도/해금 상태를 유지하고 다음 미션으로 간다.

### 폐기 게이지 — 삭제
- **폐기 게이지는 쓰지 않는다.** (구 설계 폐기)
- 2·3일차 현장 점검은 **점수(평가/정산 누적)** 만으로 판정한다.
- 장기 압박·통과·경고는 모두 점수 기준으로 읽힌다.

### 점수 점검 (Day2 / Day3)
점검에 들어가는 점수 요소 예 (가중치는 `05 수치 기획`):
- 모선 **정분류** 환급·보너스
- 샘플 Intact / 손상 / 미회수 / 파괴
- 구역 마감 완료
- 오분류·모선 미분류 잔여·붕괴 사고 감점 (현장 미수거 자체는 감점 없음)
- 미복귀·사망 감점

### 현장 점검 일정
| 일차 | 결과 |
|---|---|
| 1일차 | 점검 없음 |
| 2일차 | **점수 기준** 성공 또는 **경고(+패널티)** |

| 4일차(비상) | 성공 시 클리어 / 실패 시 게임오버 |

점검 통과 조건 (하루 종료 시):
1. **누적 평가 점수가 기준 이상** — Day2 **500** / Day3 **1200** / Day4 **1380** (표준 난이도 · **4인** 기준선, `05` §0)

2. (선택 가산) 지정 샘플 N개 Intact

### 경고 패널티
경고는 단순 표식이 아니라 실제 손해가 있어야 한다.

- 다음 점검 **점수 기준** ×1.1

### 판정 상세
1. Day2 실패 → 경고 + 패널티, Day3 진행
2. Day3 성공 → 계약 클리어

6. Day4 실패 → 게임오버

## 10.6. 100% 클리어 · 로그라이크 재도전 (9차 회의 확정)

### 배경
못 끝내고 하루를 마감했을 때 남는 “찜찜함”을 처벌이 아니라 **재미 요소**로 살린다.

### 100% 클리어 (완벽 청소)
- 100% 완벽 청소(모든 오염·따개비·쓰레기·조각을 정분류까지 완료)는 **필수 목표가 아니라 도전과제 성격**이다.
- 점검 통과(`§10` 점수 기준)에는 필요 없다. 진짜 "청소"를 좋아하는 플레이어가 노리는 별도 목표로 둔다.

### 로그라이크식 재도전
- 맵/도구가 확장되면(상점 해금·상위 장비), **후반에 얻은 좋은 도구로 이미 지나온 초반 맵을 다시 돌아 더 쉽게 100% 클리어**할 수 있게 한다.
- 즉 "한 번 지나가면 끝"이 아니라, 장비가 강해질수록 과거 구역을 정리하는 재미가 생기는 구조.
- 현재 1차 미션(`03` X-7 B2) 범위에서는 설계 방향만 명시하고, 여러 기지/맵을 오가는 재도전 흐름은 이후 콘텐츠 확장 시 구체화한다.

### 금지에 가까운 방향
- 100% 클리어를 점검(Day2/3/4) 통과 조건에 강제로 넣는 것
- 로그라이크 재도전을 위해 이전 기지 진행 상태를 리셋하는 것 (`§10` 진행 유지 원칙과 충돌)

## 11. 폐기물 분류 (모선)

현장에서는 **점수 분류를 하지 않는다.**  
현장에서는 섞어 주워 담고, **모선 분류장에서만** 가른다.

### 분리하는 방법 (플레이 절차)

1. **현장 수거**  
   오염물·따개비·쓰레기·조각벽을 **손**으로 집거나 **임시 쓰레기통**에 담는다.  
   (이 단계에서는 종류를 맞출 필요 없음. 섞여도 됨.)
2. **모선 이동**  
   손 운반 또는 임시 쓰레기통을 들고 모선으로 간다. (레벨 스트리밍)
3. **분류장 도착**  
   쓰레기통을 비우거나, 손에 든 물건을 분류대 위에 올린다.  
   내용물이 **개별 물리 오브젝트**로 다시 나온다.
4. **하나씩 투입**  
   플레이어가 물건을 집어 **맞는 컨테이너**에 넣는다.  
   (협동: 한 명은 비우고, 한 명은 분류 가능)
5. **정분류 / 오분류**  
   - 정분류 → 환급·평가 점수 가산  
   - 오분류 → 감점 (잘못 넣은 칸에서 다시 꺼내 수정 가능 여부는 프로토에서 결정)  
   - 모선 미분류 잔여(분류대·쓰레기통에 남김) → 일 종료 시 감점. **현장에 남은 미수거는 감점 없음** — 다음날 이월

플레이어 교육 문장:
> 현장은 담기만 한다.  
> 모선에 가서 **다섯 칸**에 맞게 넣는다.  
> **실버=금속, 흰=일반, 파랑=플라스틱, 노랑=오염, 회색=안탐.**

### 모선 분리 5종 (확정)

| 컨테이너 | 색 | 색 의도 | 넣는 것 | 대표 예시 |
|---|---|---|---|---|
| **금속** | **메탈릭 실버** (`#C0C0C0` 계열) | 금속 질감 | 금속류 | 음료캔, 폐공구, 전선·케이블 |
| **일반쓰레기** | **흰색** (`#FFFFFF`) | 생활·기본 | 생활·섬유·종이 등 | 찢어진 작업복, 젖은 서류, 폐장갑·마스크 |
| **플라스틱** | **파란색** (`#2F6BFF`) | 재활용 플라스틱 관례 | 플라스틱·비닐류 | 비닐·포장재, 도시락 용기 |
