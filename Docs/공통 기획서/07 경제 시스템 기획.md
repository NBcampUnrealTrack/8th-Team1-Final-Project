이 문서는 **크레딧(₡) 경제** — 착수금, 환급, 퀘스트 보수, 대출, 물가·밸런스 — 을 정의한다.  
**상점에서 파는 아이템의 이름·효과·사용법**은 `08 아이템 기획`을 따른다.  
평가 점수와 크레딧은 따로 계산한다. 분리 작업에서는 점수와 환급금을 함께 받고, 평가 연동 보너스는 정해진 비율로 크레딧에 더한다.  
가격표 숫자는 이 문서 §4 요약과 `08`이 동일해야 하며, 충돌 시 **이 문서의 가격·수입·지출**을 우선한다.

**확정:**
- **철거 수당 없음** — 철거는 평가 점수(+15/+30)만.
- **샘플 납품 자체에는 크레딧 없음** — 샘플 돈은 **상인 퀘스트 보수**로만 지급.

5. 철거·샘플(비퀘스트)은 **평가 점수**로만 보상한다.

## 2. 착수금 (일일)

매일 모선 출발 전 상인이 지급. **Day4 비상은 착수금 0.**

### 2.1 기본 착수금 (난이도 무관, 확정)

`02` §9 난이도 단순화 원칙에 따라 착수금은 **난이도와 무관하게 항상 동일**하다. 난이도가 바꾸는 것은 `05` §0.1의 점검 점수 목표 배율뿐이다.

| 항목 | 값 | 의도 |
|---|---:|---|
| 일 착수금 | **500₡** | 난이도 상관없이 동일. 업글은 환급으로 |
| 계약 3일 합(이론) | 1500 | |

### 2.2 수정 배율

| 조건 | 착수금 배율 |
|---|---|
| 호감도 ≥ +2.0 | ×1.1 |
| 호감도 ≤ −2.0 | ×0.9 |
| **경고 상태** (점검 실패 다음 정규일) | ×**0.7** |
| Day4 비상 | **0₡** |

호감도 중립이면 정상일은 **500₡**, 경고 다음 정규일은 `500×0.7 = 350₡`, 비상 4일차는 **0₡**다. **비상 여부를 먼저 판정**하며, 비상에는 호감도·경고와 무관하게 지급하지 않는다. 정규일에만 기본 착수금에 호감도 배율과 해당 일자의 경고 배율을 적용한다.

**2026-09-18 구현 대조:** 최신 dev는 비상일에 ×0.7을 곱하고 별도로 저장한 경고 배율은 지급 계산에 사용하지 않는다. 중립 호감도에서 비상일에 350₡가 나오는 것은 구현 불일치다. [공통 15](15%20구현%20대조%20및%20플레이%20검증%20기획.md) §3의 확인 절차를 따른다. 같은 날 재접속·저장 불러오기로 착수금이 중복 지급되어서도 안 된다.

## 2.5. 치료 서비스 (신규)

부상 → 건강 회복은 **아이템이 아니라 모선 상인에게 받는 유료 서비스**다 (`02` §6 전환 5, §7).  
핫바 슬롯을 쓰지 않는 대신, **모선에 있어야만** 받을 수 있다.

| 항목 | 내용 |
|---|---|
| 이용처 | 모선 상인 (그 외 장소에서는 불가) |
| 비용 | **70₡** /회 (M−09) |
| 효과 | 부상 → 건강 즉시 회복 (HP도 함께 완전 회복) |
| 해금 조건 | 없음 (상시 이용 가능) |
| 호감도 연동 | 없음 (프로토 단순화 — 착수금·대출과 달리 치료비는 고정가) |

의도:
> 회복킷처럼 핫바 슬롯을 잡아먹지 않으면서도, "부상당하면 일단 모선에 들러야 한다"는 동선 압박은 그대로 남긴다.  
> 남용 방지는 위치 제한(모선에서만) + 고정 비용(70₡)으로 건다.

## 3. 환급 · 퀘스트 보수

### 3.1 분리 정분류 환급 (₡)

평가 점수와 **같은 칸**이지만 금액은 약 **40~50% 스케일**.

| 칸 | 평가 점수 | 환급 ₡ | 비고 |
|---|---:|---:|---|
| 금속 | +20 | **10** | 폐공구 +3 → 13 |
| 일반쓰레기 | +12 | **6** | 작업복 +2 → 8 |
| 플라스틱 | +16 | **8** | |
| 오염된 쓰레기 | +32 | **16** | 폐전지 +4 → 20 |
| 안타는 쓰레기 | +16 | **8** | 유리 +2 → 10 |

오분류·미분류·미수거는 전부 **크레딧 환급 0** (오분류·대기장 미분류만 평가 차감, 현장 미수거는 차감도 없음 — `05` S−04 삭제). 수정 후 정분류하면 환급 지급.

**벽 1세그(70% 제거·만점 정분류) 환급:**  
7×8 + 3×16 = 56+48 = **104₡**  
(철거 성공 평가 점수 +15/+30은 있으나 **크레딧 수당 없음**)

### 3.2 퀘스트 보수 (₡) — 샘플·기타 돈의

샘플을 모선에 납품해도 **기본 현상금은 없다.**  
크레딧은 상인이 건 퀘스트를 성공했을 때만 지급한다.  
(샘플 Intact/손상 **평가 점수**는 `05` 그대로.)

퀘스트 발주처는 현장마다 달라지지만(연구소 본사/화물 보험사/유산관리청 등, `09` §2), 아래 보수 공식은 **현장에 관계없이 동일**하게 재사용한다.  
로어 퀘스트(코덱스)는 이 표·경제 트랙에 **넣지 않는다** (`09` §5). 별도의 상인 개인 퀘스트는 없다 (`09` §0.1).

**퀘스트 실패는 크레딧 위약금이 없다.** 실패해도 이미 지급된 착수금·환급은 그대로 유지되며, **호감도만 하락**한다 (`02` §7).

| 퀘스트 유형 | 성공 조건 (예) | 보수 ₡ |
|---|---|---:|
| 회수 C Intact | 지정 C 샘플 Intact 납품 | **80** |
| 회수 B Intact | 지정 B Intact | **160** |
| 회수 A Intact | 지정 A Intact | **280** |
| 회수 S Intact | 지정 S Intact | **450** |
| 손상 허용 회수 | 지정 샘플 손상 이상 납품 | 위 보수의 **50%** |
| 청소 계약 | 지정 구역 정분류 N개 | **120** |
| 마감 계약 | 지정 섹터 마감 | **100** |
| 복합 (A+청소) | A Intact + 청소 조건 | **350** |

규칙:
1. 퀘스트 **미수락** 샘플은 점수만, 크레딧 0.
2. 한 계약(3일) 표준 기대: **퀘스트 2~3건** (예: Day1 B, Day2 A, Day3 S 또는 청소).
3. 평가 쪽 퀘스트 성공 점수(+80/+160)와 **별개**로 위 ₡ 보수를 준다.
4. **실패(미회수·파괴·명시적 포기) 시 크레딧 차감 없음.** **평가 점수와 호감도만** 하락하며, 미회수보다 파괴가 더 크게 하락한다. 등급별 확정 델타는 `09` §1.5:
   - 미회수: 점수 −20/−35/−55/−90 (C/B/A/S) · 호감도 **메인** −0.2/−0.3/−0.4/−0.5 · **반복** −0.1/−0.2/−0.2/−0.2
   - 파괴: 점수 −45/−85/−130/−220 (C/B/A/S) · 호감도 **메인** −0.4/−0.6/−0.8/−1.0 · **반복** −0.2/−0.4/−0.4/−0.4
   - **점수·₡는 등급이, 호감도는 슬롯(메인/반복)이 결정한다.** 기준 문서 `09` §1.5
   - **이월은 슬롯마다 다르다.** 메인은 매일 18:00에 Failed 확정 + 스폰물 디스폰(재회수 없음). 반복은 비상일을 포함해 계약 종료까지 유지하고 실제 종료 때 한 번 마감한다 (`09` §1.5)
5. **샘플 납품 자체에는 크레딧도 평가 점수도 없다.** 샘플은 **그 샘플을 요구하는 퀘스트가** 스폰하며(현장에 따라 메인이 아니라 반복 슬롯일 수 있다 — `X-7 …/01` §2.0), 모든 보상은 퀘스트 완료에 귀속된다 (`09` §1.5).

## 7. 밸런스 검증

### 7.1 체크리스트

| 질문 | 답 (표준) |
|---|---|
| Day1 착수만으로 지지 3+산소 2 가능한가? | **예** (350≤500) |
| Day1 착수만으로 광폭 헤라+지지 3 가능한가? | **아니오** (720>500) → 의도 |
| 벽 1회 정분류 환급으로 지지대 1개? | 104≥90 → **예** |
| 붕괴 과태료(250) vs 지지대(90)? | 지지 안 사면 손해 → **예** |
| A Intact 퀘스트(280) vs 완충 패드(120)? | 패드 가성비 있음 |
| 열선(900) vs Day1~2 순수입? | 저축 1일+α → **예** |
| 풀장비(~2800) vs 3일 순(~3600)? | 장비를 모두 사고 소모품까지 충분히 사기에는 빠듯함 → **예** |
| 비퀘스트 샘플 납품으로 돈? | **아니오** (점수만) |
| 철거만으로 돈? | **아니오** (점수만, 분리 환급은 조각 정분류 시) |
| 돈으로 점검 600점 대체? | **불가** |

### 7.2 대실수 시

Day2 무지지 붕괴 + **퀘스트 A** 파괴:
- 점수: −200 −130 = **−330** (점검 위험)
- 크레딧: 과태료 **−250**, 퀘스트 보수 0 (위약금 없음)
- 호감도: **−0.8** (메인 슬롯 A 파괴. 같은 A급이 반복 슬롯이면 −0.4, `09` §1.5)  
→ 경고로 착수금까지 줄면 새 장비보다 필요한 소모품을 우선 사야 한다. 지지대 1개(90₡)를 아끼려다 과태료 250₡와 점수 −200을 잃은 경우다.

## 8. 상점 UI에 보여줄 정보

### 8.1 상점 화면 상태 표시 (10차 회의 확정: 2개로 축소)

상점 화면에는 **보유 크레딧과 호감도만** 띄운다.

| 항목 | 표기 |
|---|---|
| 보유 크레딧 | `8888₡` |
| 호감도 | `호감도 +0.0` (부호 항상 표기, 소수점 1자리) |

**상점 화면에서 뺀 것** (이전 판에 있었음):

| 뺀 항목 | 이유 · 이동처 |
|---|---|
| 오늘 착수금 | 상점에서 매번 볼 값이 아니다. 상인 메뉴/정산 화면에서 확인한다 |
| 활성 퀘스트 보수 미리보기 | 퀘스트 화면 소관 (`09`) |
| 다음 해금까지 남은 호감도 | 해금 조건은 **아이템 카드에 이미 적힌다** (`04` §3). 상단에 중복 표시할 필요가 없다 |
| 소모품 권장 일일 구매량 힌트 | 근거 수치가 없다. 필요해지면 `05`에 권장량을 먼저 정의한다 |

이유: 상점은 **고르고 사는 화면**이다. 판단에 필요한 건 "얼마 있나(크레딧)"와 "무엇이 열렸나(호감도)" 둘이고, 나머지는 다른 화면에서 볼 값이라 상단을 채우면 목록에서 눈이 분산된다.

### 8.2 아이템 카드

- 가격 ₡, 한 줄 기능 설명, 해금 상태, 잠김 조건 → 필수 필드는 `04` §3
- 잠긴 품목도 목록에 남기고 조건을 보여준다 (`04` §3 UX 포인트)
- 가격 표시 자리가 **호버 시 구매 버튼으로 바뀐다** (`04` §3)

### 8.3 다른 화면 (상점 아님)

- 평가 점수와 크레딧 게이지는 **분리 표시** — HUD 소관
- 샘플 납품 UI: “평가 점수 +N” / 퀘스트 중이면 “퀘스트 보수 +N₡”
