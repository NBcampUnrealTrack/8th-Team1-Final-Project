# 08. 아이템 기획서 (Develop)

**문서 버전:** Develop v5 (10차 회의: **소모품 충전 모델 도입** — 폼 카트리지를 탄약에서 충전물로 변경(§4.3), 열선 헤라에 충전 게이지 명시(§2.1), 폼건 수리 서비스 삭제. 만충 시 상점 구매 차단 규칙 추가)  
**이전 버전:** Develop v4 (상점 품목 · 전선/수도 수리 도구 · 산소 시스템 본문은 02 §6.1~6.2 참조 · 부상 치료는 아이템 아닌 상인 유료 서비스로 이관, 07 §2.5)  
**적용 대상:** 전체 현장 공통  
**관련:** `07 경제 시스템`(가격·해금·수입), `02 시스템`(스캔·절단·수리 규칙), `04 UI`, `05 수치`

이 문서는 **상점에서 사고 / 시작 시 지급되는 아이템**의 역할·사용법·핫바 취급을 정의한다.  
가격·해금·물가는 `07`을 따른다. 규칙 본문은 `02`.

## 0. 원칙

1. 핫바 = **장비·소모 도구**만. 폐기물·샘플은 손/쓰레기통.
2. 시작 지급(IT-x0)은 Day1부터 바로 쓸 수 있어야 한다.
3. 업그레이드는 **속도·안전·정보** 트레이드오프 (무조건 상위가 아님).
4. **벽 속 전선·수도관**은 스캔으로 보고 피해서 철거하는 게 정석.  
   잘못 자르면 수리 소모품(테이프·폼건)이 필요하다.

### 2.1 열선 헤라 충전 (10차 회의: 잔량 개념 도입)

이전 판은 배터리를 "90초분 소모품"으로만 적어 두어 **잔량이라는 상태가 없었다.** 상점에서 "이미 가득 찼으니 살 필요 없다"를 판정할 수 없어 충전 게이지를 명시한다.

| 항목 | 값 |
|---|---|
| 충전 게이지 상한 | **90초** (= 배터리 1개분) |
| 사용 | 열선 헤라 작동 중 실시간 감소 |
| 보충 | **배터리 1개 = 충전 90초** (= 만충) |
| 0 도달 | 열선 효과 정지 → 기본 헤라 속도로 동작 |
| 상점 | 충전이 **만충이면 배터리를 팔지 않는다.** 상인이 대사로 거절한다 (`04` §3) |

상한을 배터리 1개분으로 둔 이유: `07` §4의 `35₡/개`와 기존 "90초분" 표기를 그대로 쓰면서 잔량 상태만 추가하는 최소 변경이다. 상한을 늘리려면 배터리 여러 개를 쌓는 규칙과 소지 한도가 함께 필요하고, 그건 인벤토리 기획(`02` §2.5)에 아직 없다.

## 4. 유틸 수리 (신규)

### 4.1 절연테이프 — IT-T1

| 항목 | 내용 |
|---|---|
| 가격 | **45₡** /개 (`07`) |
| 유형 | **1회용 소모품** |
| 용도 | 잘린 **전선** 수리 → 해당 **섹터(방) 조명 복구** |
| 사용 | 핫바 장착 → 끊긴 전선 노드(또는 절단 지점)에 상호작용 1회 |
| 소모 | **1개 = 전선 노드 1곳** 수리. 사용 즉시 소모 |
| 제한 | 이미 복구된 전선에는 사용 불가. 미수리 상태면 방 조명 OFF 유지 |

교육 카피:
> 전선을 잘랐으면 불이 꺼진다. 절연테이프로 한 번 감으면 다시 켠다.

### 4.2 폼건 · 폼 카트리지 — IT-FG0 / IT-FG1

| 항목 | 내용 |
|---|---|
| 폼건 IT-FG0 | **380₡**, 장비. 핫바 장착 후 **발사**로 터진 수도관 입구를 막음 |
| 폼 카트리지 IT-FG1 | **55₡**/개. 폼건 **충전물** (§4.3) |
| 충전 게이지 | 폼건 **충전 100**. 관 1곳 밀봉 = **−25** (4회분). **카트리지 1개 = +25** |

**프로토 확정 (10차 회의: 카트리지를 탄약에서 충전물로 변경):**
1. 폼건은 핫바 장비.
2. **사격 1회 = 충전 −25** + 명중 시 해당 파열 수도관 **밀봉**.
3. **카트리지 1개 = 충전 +25.** 충전이 **100(만충)이면 카트리지를 팔지 않는다** — 상인이 대사로 거절한다 (§4.3).
4. 밀봉 성공 시 Niagara 오염수 FX **정지**, 추가 오염 확산 중단, **HP 위험 볼륨 제거**.
5. 미밀봉 동안 오염수가 섹터에 퍼지면 `02`/`05` 패널티.
6. 오염수 **근처**에 있으면 캐릭터 **HP 지속 감소** (`02` §2.4).

교육 카피:
> 수도관을 건드리면 더러운 물이 뿜는다. 가까이 있으면 HP가 깎인다. 폼건으로 구멍을 막는다.

### 4.3 카트리지 = 충전물 (10차 회의 변경 내역)

**바꾼 것**

- 이전 판: 카트리지는 **탄약**이었다 ("사격 1회 = 카트리지 1개 소모"). 폼건 내구는 별도로 닳고 **수리 120₡ 또는 신규 구매**로 회복했다.
- 이번 판: 카트리지가 **충전물**이 됐다. 사격이 충전을 깎고, 카트리지가 충전을 채운다. 게이지가 하나로 합쳐졌다.
- 이유: 상점에서 "이미 가득 찼으니 살 필요 없다"를 판정하려면 **호환 장비에 잔량 상태가 있어야 한다.** 탄약 모델에는 그 상태가 없었다.

**삭제된 것**

- **폼건 수리 120₡** — 충전을 카트리지로 회복하므로 별도 수리 서비스가 필요 없어졌다. `07` §4 가격표에는 원래 없던 항목이라 가격표 수정은 불필요하다.

**⚠️ 미확정 — 밸런스 검토 필요**

만충까지 카트리지 4개 = **220₡**다. 삭제된 수리 서비스가 **120₡**였으므로, 수리를 되살릴 경우 카트리지가 항상 손해가 되어 무의미해진다. 둘 중 하나가 필요하다:

- 수리 서비스를 되살리지 않는다 (현재 판)
- 되살린다면 가격을 220₡ 이상으로 올리거나, 카트리지 단가를 30₡ 이하로 내린다

폼건 본체 **380₡** 대비 만충 비용 220₡가 적정한지도 함께 봐야 한다.

**상점 UI 연동**

충전 만충 시 구매 차단은 UI가 자체 판단하지 않는다. 장비·인벤 시스템이 "가득 찬 품목 ID 목록"을 상점 위젯에 넘기고, 위젯은 그 목록에 있는 품목의 구매를 막고 상인 대사를 띄운다. 규칙이 바뀌어도 UI는 그대로 쓴다.
