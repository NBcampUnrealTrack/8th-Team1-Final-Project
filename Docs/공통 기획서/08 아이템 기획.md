# 08. 아이템 기획서 (Develop)

**문서 버전:** Develop v4 (상점 품목 · 전선/수도 수리 도구 · 산소 시스템 본문은 02 §6.1~6.2 참조 · 부상 치료는 아이템 아닌 상인 유료 서비스로 이관, 07 §2.5)  
**연구기지:** X-7  
**관련:** `07 경제 시스템`(가격·해금·수입), `02 시스템`(스캔·절단·수리 규칙), `04 UI`, `05 수치`

이 문서는 **상점에서 사고 / 시작 시 지급되는 아이템**의 역할·사용법·핫바 취급을 정의한다.  
가격·해금·물가는 `07`을 따른다. 규칙 본문은 `02`.

---

## 0. 원칙

1. 핫바 = **장비·소모 도구**만. 폐기물·샘플은 손/쓰레기통.
2. 시작 지급(IT-x0)은 Day1부터 바로 쓸 수 있어야 한다.
3. 업그레이드는 **속도·안전·정보** 트레이드오프 (무조건 상위가 아님).
4. **벽 속 전선·수도관**은 스캔으로 보고 피해서 철거하는 게 정석.  
   잘못 자르면 수리 소모품(테이프·폼건)이 필요하다.

## 4. 유틸 수리 (신규)

### 4.1 절연테이프 — IT-T1

| 항목 | 내용 |
|---|---|
| 가격 | **45₡** /개 (`07`) |
| 유형 | **1회용 소모품** |
| 용도 | 잘린 **전선** 수리 → 해당 **섹터(방) 조명 복구** |
| 사용 | 핫바 장착 → 끊긴 전선 노드(또는 절단 지점)에 상호작용 1회 |
| 소모 | **1개 = 전선 노드 1곳** 수리. 사용 즉시 소모 |
| 제한 | 이미 복구된 전선에는 사용 불가. 미수리 상태면 방 조명 OFF 유지 |

교육 카피:
> 전선을 잘랐으면 불이 꺼진다. 절연테이프로 한 번 감으면 다시 켠다.

### 4.2 폼건 · 폼 카트리지 — IT-FG0 / IT-FG1

| 항목 | 내용 |
|---|---|
| 폼건 IT-FG0 | **380₡**, 장비. 핫바 장착 후 **발사**로 터진 수도관 입구를 막음 |
| 폼 카트리지 IT-FG1 | **55₡**/개. 폼건 장전용 소모 |
| 내구도 | 폼건 **내구 게이지 100**. 관 1곳 밀봉 = **내구 −25** (카트리지 1개 ≈ 내구 25 보충도 가능 — 프로토: **사격 1회 = 카트리지 1개 소모**, 내구는 “총기 마모”로 밀봉 **4회**마다 수리/교체 권장) |

**프로토 확정 (단순화):**
1. 폼건은 핫바 장비.
2. **사격 1회 = 폼 카트리지 1개 소모** + 명중 시 해당 파열 수도관 **밀봉**.
3. 폼건 본체 **내구도 4회**(사용 횟수). 0이 되면 발사 불가 → 상점에서 **수리 120₡** 또는 새 폼건 구매.
4. 밀봉 성공 시 Niagara 오염수 FX **정지**, 추가 오염 확산 중단, **HP 위험 볼륨 제거**.
5. 미밀봉 동안 오염수가 섹터에 퍼지면 `02`/`05` 패널티.
6. 오염수 **근처**에 있으면 캐릭터 **HP 지속 감소** (`02` §2.4).

교육 카피:
> 수도관을 건드리면 더러운 물이 뿜는다. 가까이 있으면 HP가 깎인다. 폼건으로 구멍을 막는다.

## 5. 지지 · 생존 · 회수

### 5.1 안전 = 지지대만

| ID | 이름 | 가격 | 유형 | 효과 |
|---|---|---:|---|---|
| IT-P1 | 임시 지지대 | 90/개 | 소모(설치) | 내력 절단을 ‘지지 있음’으로. **상점 안전 카테고리의 유일한 품목** |

강화 지지대·균열 패치·비상 격문은 **상점에서 팔지 않는다** (프로토 단순화).  
수도 파열 대응은 **폼건**, 구조 붕괴 대응은 **지지대**로만 한다.

### 5.2 생존 · 회수

| ID | 이름 | 가격 | 유형 | 효과 |
|---|---|---:|---|---|
| IT-O1 | 산소 캔 | 40/개 | 소모 | 활동 +90초 |
| IT-O2 | 산소 확장 탱크 | 320 | 장비 | 기본 산소 +40% |
| IT-G1 | 샘플 완충 패드 | 120 (3회) | 소모 | 손 운반 충돌 손상 1회 무효 |

기본 산소 지속시간(300초/5분)·수면 위/모선 무소모·0 도달 시 HP 피해(−15/초) 등 산소 시스템 본문 규칙은 `02` §6.1~6.2.

부상 → 건강 회복은 아이템이 아니라 **모선 상인의 유료 치료 서비스**로 처리한다 (핫바 슬롯을 쓰지 않음). 가격·상세는 `07` §2.5.

### 5.3 쓰레기통 — 상점 비매품 (대기장 전용)

| ID | 이름 | 입수 | 효과 |
|---|---|---|---|
| IT-B0 | 임시 쓰레기통 | 기지 **폐기물 대기장** 보급기에서 **무한** | 물리 운반 · 슬롯 12 (`05`) |

- **상점에서 팔지 않는다.** (대형 쓰레기통 IT-B1도 **삭제**)
- 분실·유실·모선에 두고 와도 대기장에서 다시 꺼내면 된다.
- 상세 규칙은 `02` §1.5.
