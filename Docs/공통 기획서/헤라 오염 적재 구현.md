# 전달 — 헤라 오염 적재 구현 요약

**대상:** 구현 담당
**원본 기획:** `02 시스템 기획` §1.2 (정본) · 수치 요약 `05 수치 기획` §6
**한 줄 요약:** 헤라로 긁을수록 날에 오염물이 쌓이고(0~100), **포화(67+) 상태로 긁으면 지운 자리에 오염이 되묻는다.** 쓰레기통에 털어서 비운다.
**주의:** 적재량으로 **제거 속도·효율을 깎는 로직은 없다.** 페널티는 역오염 하나뿐이다.

---

## 1. 핵심 상태값

**`ScrapeLoad` (float, 0~100)** — 헤라 인스턴스마다 1개. **자연 감소 없음** (시간·수영으로 안 씻김). 멀티 환경이므로 서버 권威 + 복제 필요.

### 증가

| 트리거 | 증가량 |
|---|---|
| 오염물 긁기 | **오염 마스크 1% 제거당 +0.6** × 장비 배율 |
| 따개비 제거 | **1개당 +8** × 장비 배율 |

> 기존 마스크/진행도 시스템(`MD_ScrapeMaskAtlas`, `MD_ScrapeFaceProgress`)에서 "이번 틱에 실제로 지운 양"을 받아 곱하면 됨. 새 계산 불필요.

### 장비 배율

| 장비 | 배율 |
|---|---|
| 기본 헤라 IT-H0 | ×1.0 |
| 광폭 헤라 IT-H1 | ×1.6 |
| 열선 헤라 IT-H2 | ×0.5 — **단, 충전 0이면 ×1.0** |

> `FScrapeToolSpec`(`MD_ScrapeTypes.h`)에 필드 하나 추가하는 형태가 자연스러움.

### 감소

**쓰레기통에 털어내기 1회 = −20.** 홀드 게이지 아님, **누를 때마다 1회** 처리되는 개별 동작.

| 목표 | 횟수 |
|---|---|
| 만충(100) → 0 | 5회 |
| 3단계 해제(100 → 66) | **2회** |

- 비용·시간 소모 없음. 임시 쓰레기통(`MD_TrashBin`)이 있으면 현장 어디서나 가능.
- 게이지가 **−20씩 뚝 떨어지게** 표시 (보간 없음).

## 2. 3단계 상태

| 단계 | 범위 | 제거 효율 | 영향 |
|---|---|---|---|
| 0 | 0 | ×1.0 | 없음 |
| **1** | **1 ~ 33** | **×1.0** | 없음 |
| **2** | **34 ~ 66** | **×1.0** | 없음 |
| **3** | **67 ~ 100** | **×1.0** | **역오염 발생** |

> ⚠️ **제거 효율은 어느 단계에서도 깎지 않는다.** 적재량으로 스크레이프 속도·제거량을 감소시키는 로직을 넣지 말 것.
> 3단계의 페널티는 **역오염 하나뿐**이다.

### 날 메시 — 끈적이는 액체 슬라임

단계별로 **메시 교체** (보간 없이 경계값 넘는 즉시 스왑).

| 단계 | 형태 |
|---|---|
| 1 | 날 **끝 1/3** 얇게 코팅, 형태 유지 |
| 2 | 날 **2/3**까지 두껍게, 아래로 처지고 **끝에 방울 맺힘** |
| 3 | 날 **전체 + 손잡이 목**까지, 덩어리째 늘어져 흘러내림 |

- 재질: 반투명 + 젖은 하이라이트 강하게. 색은 오염 칸 색(**노랑 `#F5C400`**)에 수렴, 단계 오를수록 탁하게.
- 휘두를 때 **약간 늦게 따라오는 흔들림**(관성), 정지 시 처짐.
- 2단계의 처짐·방울이 **유일한 예고 신호**다. 수치를 안 봐도 손에 든 도구로 "곧 3단계"가 읽혀야 함.

---

## 3. 3단계 역오염 (핵심 메커닉)

| ScrapeLoad | 제거 효율 | 역오염 |
|---|---|---|
| **67 ~ 100** | **×1.0 (너프 없음)** | 제거하려던 양의 **40%** 만큼 마스크를 **되돌림** (지운 자리가 다시 어두워짐) |

**실효 제거량 = 60%.** 효율 배율을 따로 곱하지 않는다 — 역오염만으로 손해가 충분히 발생하고, 둘 다 넣으면 이중 처벌이 된다.

### 대상별 동작
1. **오염물 표면** → 지운 만큼 되돌아와 제거율이 안 오름
2. **깨끗한 보통벽·바닥·설비** → 그 자리에 **새 오염 데칼 생성**
3. **샘플 근처** → 오염 부착 + 기존 손상 위험 판정 그대로

### 점수 처리
**별도 감점 이벤트를 만들지 말 것.** 오염 제거율이 떨어지면 기존 §2.5 규칙대로 벽 조각이 *오염된 조각벽*으로 더 많이 배분되고, 정분류 점수가 자동으로 달라진다. **기존 점수 체계 안에서 손해가 발생**한다.

## 4. UI (`04 UI 기획` §6)

**주 표현은 날 메시다. HUD는 보조.**

| 요소 | 규칙 |
|---|---|
| 위치 | 핫바 **헤라 슬롯 아이콘 위 얇은 링/바** (별도 패널 만들지 말 것) |
| 색 | 1단계 흰 → 2단계 노랑 `#F5C400` → 3단계 **적색 점멸** |
| 3단계 진입 | 토스트 `헤라 포화 · 긁을수록 다시 묻는다` **1회만** (반복 금지) |
| 3단계 유지 중 | 아이콘 적색 점멸 유지. **매 히트마다 경고 띄우지 말 것** — 역오염은 지운 자리가 다시 어두워지는 걸로 이미 보인다 |
| 털어내기 | 게이지 −20씩 **뚝** 떨어짐 |
| 3단계 벗어남 | 66 이하 진입 시 적색 해제 |

## 5. 구현 순서

1. `ScrapeLoad` 카운터 (0~100) + 긁기 시 증가 · 복제
2. **3단계 날 메시 교체** ← 여기까지가 시각적으로 읽히는 최소 단위
3. 쓰레기통 털어내기 1회 −20
4. 3단계 역오염 (마스크 되돌리기 + 깨끗한 표면에 데칼 생성)
5. 장비별 배율
6. *(이번 범위 아님)* 아래 §6

## 6. 이번 범위 아님 — 나중

기획은 확정됐지만 **지금 구현하지 말 것** (`02` §1.2.6).

- 오염물 **액체화** (헤라 적재 100 = 액체 1.0 유닛, 통 상한 5.0 유닛)
- 액체 **물리·출렁임·쏟기** → 쏟은 자리에 오염 데칼 생성
- 모선 분류장 **응고제 디스펜서** → 오염물 덩어리 → 오염 칸 +32
- 쓰레기통 **통째 투입** (통은 사라지고 점수 0, 내용물만 개별 판정)

지금은 **털어내면 −20 줄어드는 것까지만.** 통 안에 뭐가 쌓이는지는 다음 단계.

---

## 7. 설정 (연출·물성 참고)

오염물은 **물보다 무겁고 점도가 매우 높다.** 그래서 수중에서도 흩어지지 않고 덩어리·액체 형태를 유지한다. 물속에서 털어도 통 안으로 그대로 떨어지는 근거가 이것이다.

*(선택) 쓰레기통 입구에 고무 립을 달아 훑어내리는 모션을 주면 "물속에서 턴다"는 그림이 더 확실해진다. 필수는 아님.*

## 8. 확정 수치 한눈에

```text
ScrapeLoad        0~100, 자연감소 없음
증가              오염 1%제거당 +0.6 / 따개비 1개당 +8
장비배율          기본 x1.0 / 광폭 x1.6 / 열선 x0.5 (충전0이면 x1.0)
단계              1: 1~33  2: 34~66  3: 67~100
제거효율          전 단계 x1.0 (절대 깎지 않음)
3단계 67~100      역오염 40% (지운 양의 40%가 되돌아옴 -> 실효 제거 60%)
털어내기          1회 -20 (만충->0 = 5회 / 3단계해제 = 2회)
날 메시           끈적이는 액체 슬라임, 3단계 스왑, 노랑 #F5C400
```
