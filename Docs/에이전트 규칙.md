# ProjectATM 에이전트 규칙 (팀 공용)

AI 코딩 에이전트(Claude Code / Codex 등)가 이 프로젝트에서 지켜야 할 규칙이다.

`.gitignore` 가 `/CLAUDE.md`, `/AGENT.md`, `.claude/` 를 **의도적으로 제외**하고 있다
(에이전트 설정은 각자 것). 그래서 팀 공용 규칙은 이 파일에 두고, 각자 로컬
`CLAUDE.md` 에서 이 파일을 불러 쓴다. 설정 방법은 맨 아래.

---

## 프로젝트 기본

- Unreal Engine 5.8, 프로젝트 루트에 `MarineDemolition.uproject`
- 통합 브랜치는 `dev`, 기능 작업은 `feat/<이름>` (소문자 케밥케이스)
- 엔진은 **런처 설치본(Installed Build)** 이다. `Engine/Build/InstalledBuild.txt` 가 있고
  `.git` 도 `.cpp` 도 없다 — 엔진 내부 구현을 읽을 수 없고 git 커밋으로 대조할 수도 없다.
  엔진 버전 대조는 `Tools/MultiUser/Check-EngineVersion.bat`(맥은 `.command`)로 한다.
- 프로젝트 C++ 빌드는 **에디터가 떠 있는 동안에는 할 수 없다** (Live Coding 충돌).

## 작업 방식

- 작고 표적화된 수정을 선호한다. 거대한 바이너리(`.uasset` / `.umap`) 덤프를 읽지 않는다.
- 블루프린트 내부를 추측하지 말고 MCP 툴(Revvy / UmgMcp)로 확인한다.
- **남의 파일은 컨벤션 위반이 있어도 고치지 않고 보고만 한다.**
- 빌드 성공만으로 PR 을 올리지 않는다. 에디터에서 확인받은 뒤에 올린다.
- 바이너리 에셋(`.uasset`, `.umap`)은 편집 전 `git lfs lock`, 푸시 직후 unlock.

## 멀티유저 편집(Concert) 중 자동화

에디터가 멀티유저 세션에 붙어 있으면 일부 자동화가 팀 전원에게 영향을 준다.
**에디터 상태를 바꾸는 작업 전에 가드레일을 먼저 통과시킨다.**

```python
import os, sys, unreal
sys.path.append(os.path.join(
    unreal.Paths.convert_relative_path_to_full(unreal.Paths.project_dir()),
    "Tools", "MultiUser"))
import mu_guard
mu_guard.assert_safe("compile_blueprint")   # 세션 중이면 예외
```

- 세션 밖이면 즉시 통과하므로, 접속 여부를 미리 확인할 필요 없이 그냥 호출한다.
- 막히는 작업: `compile_blueprint`(**레벨을 디스크에 저장한다**), `import_asset`,
  `save_all`, `delete_asset`, `create_landscape`, `modify_material`
- 중간 산출물은 `/Game/_AgentScratch` 아래에 만든다. 이 경로는 세션 전파에서 제외된다.
- 호스트는 맥미니 1대 고정(상시 가동), 접속 경로는 Tailscale 단독.
- 상세: [멀티유저 편집 운영 규칙](MultiUser/멀티유저%20편집%20운영%20규칙.md)

## 스크립트 작성 시

- `.bat` 은 **ASCII 전용**으로 쓴다. cmd.exe 가 배치 파일을 OEM 코드페이지로 파싱해서
  UTF-8 한글이 들어가면 `goto` / `echo` 가 잘려 제어 흐름이 깨진다.
  로직과 한글 메시지는 `.ps1`(UTF-8 **BOM 필수**)에 둔다.
- 셸 스크립트는 LF 로 커밋되어야 한다(`.gitattributes` 에 고정해 둠). CRLF 면
  맥에서 `bad interpreter: /usr/bin/env bash^M` 으로 죽는다.

## 각자 머신에서 설정하는 법

로컬 `CLAUDE.md`(gitignore 대상)를 프로젝트 루트에 만들고 아래를 넣는다.
머신마다 한 번만 하면 된다.

```markdown
# ProjectATM

팀 공용 에이전트 규칙은 아래 파일에 있다. **작업 시작 전에 반드시 읽을 것.**

@Docs/에이전트 규칙.md

(위 import 가 동작하지 않는 환경이면 `Docs/에이전트 규칙.md` 를 직접 읽는다.)
```

이렇게 해두면 규칙 내용은 git 한 곳에서 관리되고, 머신별 개인 설정은
각자 `CLAUDE.md` 에 자유롭게 덧붙일 수 있다.
